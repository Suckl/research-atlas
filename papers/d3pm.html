0 导读：这篇论文解决什么问题

2020 年的 DDPM 让扩散模型在图像生成上一举追上了 GAN。扩散模型的做法可以一句话说清：先规定一个“慢慢把数据弄脏”的过程，比如每一步往像素值上加一点高斯噪声，加到最后图像变成一片纯噪声；再训练一个神经网络学习反过来“一点点擦干净”，生成时从纯噪声出发，一步步擦回一张图。这套方法有一个默认前提：数据是连续的实数，“加一点噪声”才有意义。

文字不满足这个前提。一句话是一串 token（词或词的片段），每个 token 只是词表里的一个编号。给编号 1532 加上 0.3 得不到任何东西，编号之间也没有“相近”的概念，所以高斯噪声没法直接加到 token 上。在这篇论文之前，Hoogeboom 等人（2021）提出过一种离散版本，叫多项式扩散（multinomial diffusion）：每一步以一定概率把 token 换成词表里随机挑的另一个 token。它能用，但在文本上离自回归模型（逐个往后写的普通语言模型）差得很远，也没有在大词表上验证过。

D3PM（Discrete Denoising Diffusion Probabilistic Models）的核心想法是：把“加噪”写成一个转移矩阵 \(Q_t\)。矩阵第 \(i\) 行第 \(j\) 列的数，就是“这一步里状态 \(i\) 变成状态 \(j\) 的概率”。只要选的矩阵满足几个简单条件，任意一步的加噪结果和反向训练需要的“后验分布”都能用矩阵乘法精确算出来，于是连续扩散的整套训练方法（变分下界）可以原封不动地搬到离散数据上。更重要的是，矩阵怎么选变成了一个设计空间：论文比较了均匀替换、变成 [MASK]（吸收态）、模仿高斯的“只往相邻值跳”、以及按词向量近邻替换四种。

最重要的结果有三条。第一，在文本上，“变成 [MASK]”的吸收态加噪远好于其他几种：字符级数据集 text8 上 1.45 对均匀替换的 1.61 bits/char，LM1B 上困惑度 76.9 对 137.9。第二，在 CIFAR-10 图像上，模仿高斯的离散加噪配合新提出的混合损失，似然（3.435 bits/dim）超过了原始 DDPM，但图像质量（FID 7.34）仍不如它。第三，论文证明 BERT、自回归语言模型、生成式掩码语言模型都可以看成 D3PM 的特例；吸收态 D3PM 的训练目标化简以后，就是一个按 \(1/t\) 加权的掩码语言模型损失。三年后的 MDLM 和四年后的 LLaDA，用的正是这个目标的连续时间版本。同时也要看到它的位置：模型只有 7000 万参数，在 LM1B 上仍明显落后同样大小的自回归模型（76.9 对 43.6）。

1 引言：为什么要把扩散搬到离散数据上

这一节要回答的问题：生成模型已经有 GAN、VAE、自回归模型、标准化流好几种，扩散模型凭什么值得做？它在图像和音频上成功了，为什么在文本、分割图这类离散数据上一直没做起来？这篇论文打算从哪里下手？
先补一点背景：自回归生成为什么慢，扩散为什么可能更快。

今天的大语言模型几乎都是自回归（autoregressive, AR）模型：给定前面所有的 token，预测下一个 token，接上去再预测下一个。生成一段 256 个 token 的文字，就必须串行地做 256 次网络计算，因为第 \(n\) 个 token 要等前 \(n-1\) 个都确定了才能算。

扩散模型的生成方式不同。它从一张“全是噪声”的画布出发，每一步让网络看一遍整张画布，同时修改所有位置，修改若干步以后得到结果。步数是事先选定的，和序列长度没有直接关系。如果 20 步就能修出一段 256 个 token 的文字，网络只需要算 20 次，而且每次都是对整段文字并行计算。这就是论文所说的“并行迭代精修”（parallel iterative refinement），也是人们想把扩散用到文本上的主要动机之一。另一个动机是：扩散模型每一步都能看到左右两边的上下文，天然适合填空、改写这类不是从左到右的任务。

论文先交代扩散模型的位置。它在图像（DDPM 等）和音频（WaveGrad、DiffWave）上，样本质量追上了 GAN，似然（衡量模型给真实数据打多高概率的指标）接近自回归模型，而且训练目标稳定：它和最大似然、得分匹配（score matching）都有直接联系，不像 GAN 那样容易训崩。

扩散模型其实从 2015 年 Sohl-Dickstein 等人提出时起，就同时有连续和离散两种版本：原文用的离散例子是二值变量（0/1）。但后来几乎所有的进展都集中在连续空间的高斯扩散上。离散扩散只在 Hoogeboom 等人 2021 年的工作里被用到文本和图像分割上，也就是前面说的多项式扩散；Song 等人在 DDIM 的附录里推导过同样的扩展，但没有做实验。总之在这篇论文之前，离散扩散还没有在大规模文本或图像生成上表现出竞争力。

论文的出发点是：离散数据不需要先被“放松”或嵌入到连续空间里，可以直接在离散状态之间定义加噪过程；而离散加噪的形式比“加高斯噪声”灵活得多，可以把领域知识写进转移矩阵。比如对图像的 256 个灰度值，可以让噪声更倾向于把一个灰度值换成相邻的灰度值，模仿连续扩散的局部性；对文本，可以让 token 被替换成意思相近的 token，或者直接变成一个专门的 [MASK] 符号。

论文列出的贡献有这几项：

  • 一个统一的离散扩散框架 D3PM，包含已有的均匀替换，以及新提出的离散高斯、嵌入近邻和吸收态（[MASK]）三种结构化加噪方式；
  • 借助吸收态，把扩散模型和自回归模型、掩码语言模型联系起来；
  • 一个能稳定训练的辅助损失，和一族基于互信息的噪声日程；
  • 在字符级文本生成上明显超过各种非自回归基线，并把离散扩散扩展到 8192 个 token 的大词表和更长的序列；
  • 在 CIFAR-10 上，似然超过、样本质量接近原始 DDPM。

论文图 1 用一个二维的玩具例子把这件事画了出来：把“瑞士卷”形状的点云量化到网格上，每个点是一个二维的类别变量。上排是三种前向过程在 \(t=T/2\) 时把数据弄成什么样，每个小图角上附着对应转移矩阵的热力图：均匀加噪让点四散到整个网格；离散高斯让点只向邻近格子扩散，卷的形状还隐约可见；吸收态把一部分点直接“吸”到了网格边上的特殊状态。下排是学到的离散高斯反向过程，从均匀分布的噪声一步步恢复出瑞士卷。本站在 第 4 节 用一个 6 个状态的小例子重新画了这几种矩阵。

容易混淆的一点：“用扩散模型生成文字”有两条完全不同的路线。一条是本文这种离散扩散：状态始终是 token，噪声是“随机替换”。另一条是把 token 先映射成连续的词向量，在向量上加高斯噪声，最后再“取整”回最近的词，代表作是 2022 年的 Diffusion-LM（见本站 Diffusion-LM 精读）。后来的 LLaDA 等大规模扩散语言模型走的是第一条路线，而且具体是本文的吸收态分支。

2 背景：连续扩散模型是怎么工作的，为什么不能直接用在 token 上

这一节要回答的问题：扩散模型的“前向过程”“反向过程”“变分下界”具体是什么？训练一个扩散模型，对前向过程有哪两条硬性要求？高斯扩散为什么恰好满足这两条？而这些东西换到 token 上，卡在了哪里？后面整篇论文做的事情，就是给离散数据找一个同样满足这两条要求的前向过程。

2.1 前向过程：按固定规则一步步加噪

记干净的数据为 \(x_0\)（比如一张图片的全部像素值）。前向过程定义了一串越来越“脏”的版本 \(x_1,x_2,\dots,x_T\)，每一步只依赖上一步：

$$q(x_{1:T}\mid x_0)=\prod_{t=1}^{T} q(x_t\mid x_{t-1})$$

“只依赖上一步”叫马尔可夫性质：要知道 \(x_t\) 的分布，只需要知道 \(x_{t-1}\)，更早的历史不重要。连续扩散最常用的一步是：

$$q(x_t\mid x_{t-1})=\mathcal{N}\big(x_t;\ \sqrt{1-\beta_t}\,x_{t-1},\ \beta_t I\big)$$

意思是：先把上一步的值缩小一点（乘以 \(\sqrt{1-\beta_t}\)），再加上方差为 \(\beta_t\) 的高斯噪声。\(\beta_t\) 是一个事先定好的小数（DDPM 从 \(10^{-4}\) 线性增加到 0.02），叫噪声日程。这个过程没有任何要学的参数。

它有一个很方便的性质：多步加噪可以合成一步。把 \(T\) 个高斯一步步叠起来，结果还是高斯，而且能直接写出来：

$$q(x_t\mid x_0)=\mathcal{N}\big(x_t;\ \sqrt{\bar\alpha_t}\,x_0,\ (1-\bar\alpha_t) I\big),\qquad \bar\alpha_t=\prod_{s=1}^{t}(1-\beta_s)$$

\(\bar\alpha_t\) 从接近 1 慢慢降到接近 0。当它接近 0 时，\(x_T\) 的分布就是标准高斯 \(\mathcal{N}(0,I)\)，不管 \(x_0\) 原来是什么。这个“最后忘掉起点”的分布叫平稳分布。可以把它想成一滴墨水滴进一杯水：一开始墨迹的形状还能看出来，搅得足够久以后，无论原来滴成什么形状，最后都是一杯均匀的淡灰色。

2.2 反向过程与变分下界

生成模型是反过来走的这条链：

$$p_\theta(x_{0:T})=p(x_T)\prod_{t=1}^{T}p_\theta(x_{t-1}\mid x_t)$$

\(p(x_T)\) 是起点分布（先验），通常就取前向过程的平稳分布；\(p_\theta(x_{t-1}\mid x_t)\) 是神经网络，参数为 \(\theta\)，负责“看到第 \(t\) 步的脏数据，给出第 \(t-1\) 步稍干净一些的数据的分布”。连续扩散里它也是一个高斯，均值（有时还有方差）由网络给出。

先补一点背景：KL 散度与变分下界。

KL 散度 \(D_{\mathrm{KL}}[q\,\|\,p]\) 衡量两个分布 \(q\) 和 \(p\) 有多不一样：两者完全相同时它等于 0，否则是正数。对离散分布，它就是 \(\sum_x q(x)\log\frac{q(x)}{p(x)}\)，把所有可能的取值加一遍。

训练生成模型最理想的目标是最大化 \(\log p_\theta(x_0)\)，也就是让模型给真实数据打的概率尽量高（等价于最小化负对数似然 NLL）。麻烦在于 \(p_\theta(x_0)\) 要把所有可能的中间路径 \(x_1,\dots,x_T\) 都积分（求和）掉，算不出来。变分下界（ELBO）绕开了这个问题：借助前向过程 \(q\) 这个“辅助分布”，可以证明（用 Jensen 不等式）下面这个能算的量一定大于等于负对数似然。于是最小化它，就是在把负对数似然的一个上界往下压。报告结果时，这个上界本身就被当作 NLL 的估计，所以扩散模型的 NLL 前面常常带一个“≤”。

扩散模型的变分上界可以拆成三类项：

$$L_{\mathrm{vb}}=\mathbb{E}_{q(x_0)}\Big[\underbrace{D_{\mathrm{KL}}[q(x_T\mid x_0)\,\|\,p(x_T)]}_{L_T}+\sum_{t=2}^{T}\underbrace{\mathbb{E}_{q(x_t\mid x_0)}D_{\mathrm{KL}}[q(x_{t-1}\mid x_t,x_0)\,\|\,p_\theta(x_{t-1}\mid x_t)]}_{L_{t-1}}\ \underbrace{-\ \mathbb{E}_{q(x_1\mid x_0)}\log p_\theta(x_0\mid x_1)}_{L_0}\Big]$$
  • \(L_T\)：加噪到最后得到的分布，和生成时的起点分布差多少。它不含网络参数。只要 \(T\) 足够大、并且先验就取平稳分布，它会趋于 0。
  • \(L_{t-1}\)（\(t=2,\dots,T\)）：网络给出的“往回走一步”的分布 \(p_\theta(x_{t-1}\mid x_t)\)，和“既知道 \(x_t\) 又偷看了答案 \(x_0\)”时往回走一步的真实分布 \(q(x_{t-1}\mid x_t,x_0)\) 差多少。后者叫前向过程的后验。这是训练的主体。
  • \(L_0\)：最后一步从 \(x_1\) 恢复出 \(x_0\) 的对数似然，相当于一个“解码”项。

直观地说：网络在每一步只需要学会“像一个偷看了答案的人那样往回走一步”。偷看答案的那个人的行为（后验）是能精确写出来的，所以每一项都是两个已知形式的分布之间的 KL，可以直接算。

2.3 训练对前向过程的两条要求

前向过程 \(q(x_t\mid x_{t-1})\) 理论上可以随便定，但要让训练高效，论文指出它必须满足两条：

  1. 能直接从 \(q(x_t\mid x_0)\) 采样任意一步。这样训练时就不必真的从 \(x_0\) 一步步加噪到 \(x_t\)：每次随机抽一个 \(t\)，一步跳到 \(x_t\)，只优化这一项 \(L_{t-1}\)。\(T\) 是 1000，如果每次都要走 1000 步，训练就慢了 1000 倍。
  2. 后验 \(q(x_{t-1}\mid x_t,x_0)\) 有可算的表达式。否则 \(L_{t-1}\) 里的 KL 根本算不出来。

高斯扩散两条都满足：\(q(x_t\mid x_0)\) 是上面那个闭式高斯；后验也是高斯，均值和方差都有公式；两个高斯之间的 KL 有解析式。另外还有一个让人放心的理论事实：当 \(T\) 趋于无穷、每一步的噪声都很小时，反向过程和前向过程具有相同的函数形式（Feller 1949），所以用高斯来参数化反向的每一步是合理的。

2.4 换到 token 上，卡在哪里

文本里的一个 token 是词表 \(\{1,\dots,K\}\) 中的一个编号。编号只是一个标签：第 1532 号是 “cat”、第 1533 号是 “sat”，两个编号相邻不代表两个词有任何关系。于是高斯扩散的每一个零件都失效了：

  • “把值缩小一点再加一点噪声”没有意义，加完以后得到 1532.3，它不是任何一个 token；
  • “一小步”的概念不存在：从 cat 走到 dog 算一小步还是一大步？编号说明不了；
  • 反向过程用高斯参数化也就没有道理了，因为输出必须落在有限个类别上。

当时有两种绕开的办法。一种是把离散数据嵌入到连续空间再做高斯扩散，论文提到图生成和符号音乐生成上有这样的工作，但都没有用在文本上（一年后的 Diffusion-LM 才把它用到文本，见 Diffusion-LM 精读）。另一种是留在离散空间里，把“噪声”重新定义为按概率把一个类别换成另一个类别。D3PM 走的是第二条路，下一节的任务就是证明：只要把“替换的概率”写成矩阵，上面那两条训练要求都能满足。

3 离散状态空间上的扩散：用转移矩阵加噪

这一节要回答的问题：如果“噪声”是按概率把一个类别换成另一个类别，那么一步加噪怎么写？多步加噪能不能像高斯那样合成一步？反向训练需要的后验 \(q(x_{t-1}\mid x_t,x_0)\) 能不能精确算出来？这一节给出 D3PM 的全部基本公式，并用只有 3 个 token 的词表把每个公式都算一遍。
先补一点背景：one-hot 向量、类别分布与转移矩阵。

设词表有 \(K\) 个 token。一个 token 可以写成一个长度为 \(K\) 的 one-hot 行向量：只有它自己那一格是 1，其余都是 0。比如词表是 {A, B, C}，那么 B 就是 \((0,1,0)\)。

一个类别分布 \(\mathrm{Cat}(x;p)\) 由一个概率行向量 \(p\) 给出，\(p\) 的第 \(j\) 格是“取到第 \(j\) 个类别”的概率，所有格加起来等于 1。比如 \(p=(0.8,0.1,0.1)\) 表示 80% 是 A，B 和 C 各 10%。

一个 \(K\times K\) 的转移矩阵 \(Q\) 描述“一步之内从哪个类别变到哪个类别”：第 \(i\) 行第 \(j\) 列 \([Q]_{ij}\) 是“现在是 \(i\)，下一步变成 \(j\)”的概率。每一行都是一个概率分布，所以每行加起来等于 1（这样的矩阵叫行随机矩阵）。一个 one-hot 行向量乘以 \(Q\)，正好把 \(Q\) 的对应那一行“挑”出来：\((0,1,0)\,Q\) 就是 \(Q\) 的第 2 行，也就是“现在是 B 时，下一步的分布”。

3.1 一步加噪、多步合成、后验

D3PM 用一串转移矩阵 \(Q_1,\dots,Q_T\) 定义前向过程，第 \(t\) 步用 \(Q_t\)：

$$[Q_t]_{ij}=q(x_t=j\mid x_{t-1}=i),\qquad q(x_t\mid x_{t-1})=\mathrm{Cat}\big(x_t;\ p=x_{t-1}Q_t\big)$$

这里 \(x_{t-1}\) 是 one-hot 行向量，\(x_{t-1}Q_t\) 就是 \(Q_t\) 中对应那一行。对一个句子或一张图，论文假设每个位置独立地用同一个 \(Q_t\) 加噪，所以只需要对单个位置写公式，整个序列的概率是各位置的乘积。

多步合成。先从 \(x_0\) 走一步得到分布 \(x_0Q_1\)，再走一步就是 \(x_0Q_1Q_2\)。依此类推，走 \(t\) 步以后：

$$q(x_t\mid x_0)=\mathrm{Cat}\big(x_t;\ p=x_0\overline{Q}_t\big),\qquad \overline{Q}_t=Q_1Q_2\cdots Q_t$$

为什么是矩阵连乘？“第 \(t\) 步是 \(j\)”的概率，要把所有可能的中间状态都加起来：先从 \(x_0\) 到某个 \(k\)，再从 \(k\) 到 \(j\)，对 \(k\) 求和。这个“对中间状态求和”的操作恰好就是矩阵乘法的定义。于是第 1 条训练要求满足了：只要事先把 \(\overline{Q}_t\) 算好，任意一步都能从 \(x_0\) 一次性采样出来。

后验。用贝叶斯公式，加上马尔可夫性质 \(q(x_t\mid x_{t-1},x_0)=q(x_t\mid x_{t-1})\)：

$$q(x_{t-1}\mid x_t,x_0)=\frac{q(x_t\mid x_{t-1})\,q(x_{t-1}\mid x_0)}{q(x_t\mid x_0)}=\mathrm{Cat}\!\left(x_{t-1};\ p=\frac{x_tQ_t^{\top}\odot x_0\overline{Q}_{t-1}}{x_0\overline{Q}_t\,x_t^{\top}}\right)$$

这个式子看起来复杂，其实分子分母各是一个查表：

  • \(x_tQ_t^{\top}\) 是 \(Q_t\) 的第 \(x_t\) 列：对每个候选的 \(x_{t-1}\)，“从它出发一步变成观测到的 \(x_t\)”的概率；
  • \(x_0\overline{Q}_{t-1}\) 是 \(\overline{Q}_{t-1}\) 的第 \(x_0\) 行：“从 \(x_0\) 出发 \(t-1\) 步后是各个候选”的概率；
  • \(\odot\) 表示逐元素相乘；分母 \(x_0\overline{Q}_t x_t^{\top}\) 是 \(\overline{Q}_t\) 的第 \((x_0,x_t)\) 个元素，只是把分子归一化。

于是第 2 条训练要求也满足了。\(L_{t-1}\) 里的 KL 是两个 \(K\) 类分布之间的 KL，对 \(K\) 个取值求和就能算出来；因为每个位置独立，整个序列的 KL 就是各位置之和。

3.2 用 3 个 token 的词表把公式算一遍

算例一：均匀加噪，词表 {A, B, C}，每步 \(\beta=0.3\)

均匀加噪的矩阵是 \(Q=(1-\beta)I+\frac{\beta}{K}\mathbf{1}\mathbf{1}^{\top}\)：以概率 \(1-\beta\) 什么也不做，以概率 \(\beta\) 从整个词表里均匀地重新抽一个（可能抽回自己）。\(K=3\)、\(\beta=0.3\) 时，对角线是 \(0.7+0.1=0.8\)，其余是 0.1。

3.3 逐位置独立，以及它的代价

前面说过，前向过程对每个位置独立加噪。论文同时假设反向过程 \(p_\theta(x_{t-1}\mid x_t)\) 在给定整个 \(x_t\) 的条件下，各位置也相互独立：网络看的是整句话，但给出的是每个位置各自的分布，采样时各位置各抽各的。这样 KL 才能逐位置求和，计算量是“序列长度 × 词表大小”，而不是“词表大小的序列长度次方”。

这个假设在每步只改动很少几个位置时无伤大雅，但如果一步之内要同时决定好几个彼此相关的位置，独立采样就可能拼出互相矛盾的组合。第 6 节讲少步数生成时会回到这个问题。

剩下的工程问题是 \(\overline{Q}_t\) 怎么算。对小词表，可以把 \(T\) 个连乘结果全部预先算好存起来；对大词表和大 \(T\)，存储会爆炸。附录 A.4 给出了解决办法，放在 4.6 节讲。从这里开始，论文把所有离散状态空间上的扩散模型统称为 D3PM。

4 转移矩阵怎么选：四种加噪方式

这一节要回答的问题：连续扩散几乎只有“加高斯噪声”一种选择，而 D3PM 的转移矩阵可以随便设计。设计时有哪些硬性约束？论文实际试了哪几种矩阵，各自代表什么样的“噪声”，各适合什么数据？词表很大时，这些矩阵还算得动吗？

4.1 两条约束与平稳分布

对 \(Q_t\) 只有两条要求。第一，每行加起来等于 1，否则概率不守恒。第二，连乘 \(\overline{Q}_t\) 的每一行在 \(t\) 很大时要收敛到一个已知的平稳分布 \(\pi\)。有了第二条，生成时的起点就可以直接取 \(p(x_T)=\pi\)，变分下界里的 \(L_T\) 自然趋于 0。（如果不知道平稳分布，也可以学一个先验 \(p_\theta(x_T)\)；论文脚注指出，这等价于在前向过程末尾再接一个“忽略输入、输出固定值”的秩一矩阵。）

先补一点背景：双随机矩阵为什么收敛到均匀分布（附录 A.1）。

如果一个矩阵的行和列都加起来等于 1，叫双随机矩阵。设均匀分布 \(\pi=(1/K,\dots,1/K)\)，那么 \(\pi Q\) 的每一格都是“某一列的和 × \(1/K\)”，也就是 \(1/K\)，所以 \(\pi Q=\pi\)：均匀分布是它的不动点。如果矩阵的元素还全部为正，Perron–Frobenius 定理保证从任何起点出发，反复乘这个矩阵都会收敛到这个不动点。算例一里的均匀矩阵就是这样：\(\overline{Q}_2\) 的对角线已经从 0.8 降到 0.66，继续乘下去，每一格都会趋于 1/3。论文进一步说明，即使每一步的 \(Q_t\) 不相同，只要它们都是双随机、不可约、非周期的，平稳分布也只能是均匀分布；实践中让 \(Q_t\) 随 \(t\) 增大加更多噪声，保证 \(\overline{Q}_T\) 已经非常接近均匀。

示意图：四种转移矩阵（6 个状态，单步）
怎么看：每个小方阵是一个 6×6 的单步转移矩阵，行是“现在的状态”，列是“下一步的状态”，颜色越深概率越大（为了让小概率也看得见，颜色深浅按概率的平方根画）。均匀矩阵对角线以外处处一样浅；吸收态矩阵只有对角线和最后一列（[M]）有颜色，[M] 那一行只有自己；离散高斯只在对角线附近有颜色，离得越远越浅；嵌入近邻矩阵沿着近邻图扩散，本例把 a、e、o、t、s、n 排成一条链（a–e–o 是元音，t–s–n 是辅音，o–t 相连），所以颜色集中在对角线附近但比高斯更“胖”。参数是本站选的示意值（均匀与吸收态 \(\beta=0.5\)，高斯 \(\beta=0.1\)，近邻矩阵 \(Q=\exp(R)\)），对应 原文图 1 ↗ 里的矩阵小图。

4.2 均匀（uniform）：多项式扩散

$$Q_t=(1-\beta_t)I+\frac{\beta_t}{K}\mathbf{1}\mathbf{1}^{\top},\qquad [Q_t]_{ij}=\begin{cases}1-\frac{K-1}{K}\beta_t & i=j\\[2pt] \frac{1}{K}\beta_t & i\ne j\end{cases}$$

这是 Sohl-Dickstein 等人二值情形的推广，由 Hoogeboom 等人提出（多项式扩散），论文称为 D3PM-uniform。它是双随机矩阵且元素全为正，所以平稳分布是均匀分布：加噪到最后，每个位置是词表里随机的一个 token。

它的弱点也很直观：一旦某个位置被换过一次，它就变成了一个和原词毫无关系的随机 token，原来的信息全部丢失；更麻烦的是，被换掉的 token 看起来和没被换的 token 一模一样。反向去噪时，网络既要判断“哪些位置是错的”，又要给出“正确的词是什么”。

4.3 吸收态（absorbing）：变成 [MASK]

$$Q_t=(1-\beta_t)I+\beta_t\mathbf{1}\mathbf{e}_m^{\top},\qquad [Q_t]_{ij}=\begin{cases}1 & i=j=m\\ 1-\beta_t & i=j\ne m\\ \beta_t & j=m,\ i\ne m\end{cases}$$

\(m\) 是一个专门的吸收态，\(\mathbf{e}_m\) 是在 \(m\) 处为 1 的向量。每个普通 token 要么保持不变，要么以概率 \(\beta_t\) 变成 \(m\)；一旦变成 \(m\) 就永远停在那里，所以叫“吸收”。平稳分布不是均匀分布，而是全部质量都在 \(m\) 上：加噪到最后整句都是 \(m\)。文本实验里 \(m\) 是放在词表最后（编号 \(K-1\)）的 [MASK]；图像实验里 \(m\) 是灰色像素 (128, 128, 128)，即编号 \(K/2\) 的那个值（\(K\) 为偶数）。

论文说这个设计的灵感来自 BERT 和条件掩码语言模型（CMLM）在文本上的成功。和均匀加噪一样，它不假设类别之间有任何关系；不同的是，被破坏的位置一眼就能认出来：凡是 [MASK] 都是被破坏的，凡不是 [MASK] 的都还是原词。网络只需要回答“空格里填什么”，不需要先找错。后面的实验会显示，这个看似简单的区别让它在文本上大幅领先。

4.4 离散高斯（discretized Gaussian）：只往相近的值跳

对有序的离散数据，比如 8 位图像的 256 个灰度值，“相近”是有意义的：灰度 100 和 101 几乎一样，和 200 差别很大。论文用一个离散化、截断的高斯核来模仿连续扩散：

$$[Q_t]_{ij}=\frac{\exp\!\left(-\frac{4|i-j|^2}{(K-1)^2\beta_t}\right)}{\sum_{n=-(K-1)}^{K-1}\exp\!\left(-\frac{4n^2}{(K-1)^2\beta_t}\right)}\quad (i\ne j),\qquad [Q_t]_{ii}=1-\sum_{l\ne i}[Q_t]_{il}$$

离开对角线越远，概率按高斯形状迅速衰减；分母对 \(-(K-1)\) 到 \(K-1\) 的所有偏移求和，保证每行非对角元素之和小于 1，剩下的概率放回对角线。这样得到的矩阵是对称的、双随机的，平稳分布是均匀分布。\(\beta_t\) 起到“方差”的作用：\(\beta_t\) 越大，一步之内能跳得越远。上图第三个方阵就是 \(K=6\)、\(\beta=0.1\) 时的样子：中间行留在原地的概率约 0.71，跳到相邻值约 0.14，跳两格只有约 0.001（推算）。

附录 A.2.5 还提到一种更硬的“带状对角”矩阵：只允许跳到距离不超过 \(v\) 的值，每个允许的跳法概率 \(\beta_t/K\)。论文没有在实验里用它。

4.5 词向量近邻（token embedding distance）：按意思相近替换

文本没有天然的顺序，但 token 之间可能有语义上的远近。论文的做法是：用一个预训练好的词向量空间，给每个 token 找 \(k\) 个最近邻，得到邻接矩阵 \(G\)（\(w_i\) 是 \(w_j\) 的近邻时 \([G]_{ij}=1\)）；把它对称化成 \(A=(G+G^{\top})/(2k)\)；再构造一个速率矩阵 \(R\)：非对角元素等于 \(A_{ij}\)，对角元素等于该行其余元素之和的相反数，使每行加起来为 0。最后的转移矩阵是它的矩阵指数：

$$Q_t=\exp(\alpha_tR)=\sum_{n=0}^{\infty}\frac{\alpha_t^n R^n}{n!}$$

因为 \(R\) 对称且每行和为 0，\(Q_t\) 是双随机的；只要近邻图是连通的，平稳分布就是均匀分布。\(\alpha_t\) 随 \(t\) 增大，噪声就越来越多。效果是一句话会沿着近邻图“慢慢走远”：在字符级词表里，元音更常被换成别的元音而不是辅音；在词级词表里，dog 会被换成 cat 或 cow，而不是某个无关的词（附录图 4 的例子）。论文所有实验都用预训练好的词向量，没有在训练中动态更新近邻图。

附录 A.2.6 还提到可以把几种矩阵组合起来，例如“吸收态 + 均匀”：\(Q=\alpha\mathbf{1}\mathbf{e}_m^{\top}+\beta\mathbf{1}\mathbf{1}^{\top}/K+(1-\alpha-\beta)I\)，既会被掩掉，也偶尔被换成随机词。第 8 节会看到，BERT 的训练恰好对应这种组合。

4.6 词表很大时怎么算（附录 A.4、A.5）

预先存下所有的 \(\overline{Q}_t\) 需要 \(O(K^2T)\) 的内存。LM1B 实验的词表 \(K=8192\)、\(T=1000\)，那就是 \(8192^2\times1000\approx6.7\times10^{10}\) 个数，用 32 位浮点存约 268 GB（推算），显然不行。即使能按需算出单步的 \(Q_t\)，也不一定能高效算出它们的连乘。论文给了两条出路：

  • 低秩结构。把矩阵写成 \(Q_t=\beta_tA_t+(1-\beta_t)I\)，其中 \(A_t\) 是低秩矩阵。均匀加噪的 \(A=\mathbf{1}\mathbf{1}^{\top}/K\)、吸收态的 \(A=\mathbf{1}\mathbf{e}_m^{\top}\) 都是秩一，连乘仍然保持“单位阵 + 秩一”的形式，所以只需存几个系数。吸收态的闭式上面算过；均匀加噪利用 \(X=\mathbf{1}\mathbf{1}^{\top}/K\) 满足 \(X^2=X\)，可以把连乘当成关于 \(X\) 的一次多项式来乘，每乘一次就用 \(X^2=X\) 把高次项并回一次项，最后得到 \(\overline{Q}_t=\bar\alpha_tI+(1-\bar\alpha_t)X\)。
  • 矩阵指数。如果 \(Q_t=\exp(\alpha_tR)\)，那么 \(\overline{Q}_t=\exp\big(\sum_{s\le t}\alpha_sR\big)\)，连乘变成了指数里的求和。再让每个 \(\alpha_t\) 都是某个公共小量 \(\alpha'\) 的整数倍，预先算好 \(\exp(2^k\alpha'R)\) 这几个矩阵，任何一个 \(\overline{Q}_t\) 都能按二进制展开用其中几个相乘得到，内存从 \(O(K^2T)\) 降到 \(O(K^2\log)\)。这和“快速幂”是同一个技巧。嵌入近邻矩阵就是这样实现的。

附录 A.5 还指出，矩阵指数的形式其实是一个连续时间马尔可夫链的离散化：如果状态以某个随时间变化的速率发生跳变，那么从时刻 \(s\) 到 \(t\) 的转移概率正是速率矩阵积分后的矩阵指数，\(\alpha_t\) 对应一段时间内累计的跳变速率。这为后来把离散扩散做成连续时间（Campbell 等 2022、SEDD 2023）埋下了伏笔。

读的时候容易忽略的代价：低秩结构只覆盖均匀和吸收态两种。嵌入近邻矩阵是稠密的 \(K\times K\) 矩阵，每一步都要做大矩阵乘法，所以在 LM1B 上它生成一条样本要 21.29 秒（1000 步），而均匀和吸收态只要 1.8–1.9 秒（论文表 2、表 7）。“矩阵随便设计”这个自由度，在大词表上是要付钱的。

5 噪声日程：每一步该加多少噪声

这一节要回答的问题：选好了矩阵的形状，还要决定每一步 \(\beta_t\)（或 \(\alpha_t\)）取多大，也就是噪声日程。连续扩散用“噪声方差”来衡量加了多少噪声，可在离散空间里，“加了多少噪声”该怎么衡量？论文提出用互信息来定日程，它和老的 \(1/(T-t+1)\) 日程是什么关系？

论文对不同矩阵用了不同的日程：

  • 离散高斯：在离散化之前，让高斯的方差参数 \(\beta_t\) 线性增加，图像实验沿用 DDPM 的设置，从 \(10^{-4}\) 增加到 0.02。注意单步 \(Q_t\) 线性变化，并不意味着累计噪声 \(\overline{Q}_t\) 线性变化。
  • 均匀：用余弦日程，即让“累计发生过替换的概率”沿一条余弦曲线变化。它由 Nichol 与 Dhariwal 为连续扩散提出，Hoogeboom 等人改造到多项式扩散上。
  • 一般的矩阵（比如嵌入近邻）：老的日程不一定适用，论文提出按互信息定日程。
先补一点背景：熵与互信息。

一个随机变量的熵 \(H(x_0)\) 衡量它有多不确定：一个 token 在词表上分布得越分散，熵越大。两个变量的互信息 \(I(x_t;x_0)\) 衡量“看到 \(x_t\) 以后，对 \(x_0\) 的不确定性减少了多少”。\(x_t=x_0\) 时互信息等于 \(H(x_0)\)（看到 \(x_t\) 就知道了 \(x_0\)）；\(x_t\) 是纯噪声时互信息等于 0（看到它也没用）。所以互信息正好可以当作“\(x_t\) 里还剩多少关于原数据的信息”的度量。

互信息日程的想法是：让每一步都抹掉相同份额的信息，

$$I(x_t;x_0)\approx\Big(1-\frac{t}{T}\Big)H(x_0)$$

为什么不直接数“有多少比例的位置被换过”？对均匀和吸收态，位置一旦被换过一次，关于原 token 的信息就全没了，数“被换过的比例”是合理的。但对嵌入近邻这类有结构的矩阵，一个 token 被换成了它的近邻，新 token 仍然和原 token 高度相关，信息并没有全丢。这时只有互信息能如实反映“还剩多少信息”。

实现上（附录 A.7），\(p(x_0)\) 用训练集里每个 token 的出现频率（unigram 频率）来估计；对 256 个在 \(10^{-4}\) 到 \(10^{5}\) 之间按对数均匀分布的指数 \(\bar\alpha\)，计算 \(\exp(\bar\alpha R)\) 对应的互信息；再用单调三次样条插值，找出让上式成立的那一串 \(\bar\alpha_t\)，并把它们取整为某个公共小量的整数倍（为了 4.6 节的快速幂）。最后令 \(Q_t=\exp\big((\bar\alpha_t-\bar\alpha_{t-1})R\big)\)。

一个漂亮的巧合。对吸收态，互信息日程恰好退化成 Sohl-Dickstein 等人当年给二值扩散设计的 \(\beta_t=1/(T-t+1)\)。推导很短：设到第 \(t\) 步为止某个位置已经被掩掉的概率是 \(m_t\)。因为 [MASK] 在数据里从不出现，可以算出 \(1-I(x_t;x_0)/H(x_0)=m_t\)，所以互信息日程要求 \(m_t=t/T\)，即被掩的比例随时间线性增长。再由 \(1-m_t=\prod_{s\le t}(1-\beta_s)\) 得

$$\beta_t=1-\frac{1-m_t}{1-m_{t-1}}=1-\frac{1-t/T}{1-(t-1)/T}=1-\frac{T-t}{T-t+1}=\frac{1}{T-t+1}$$
示意图：吸收态的 \(1/(T-t+1)\) 日程（以 \(T=10\) 为例）
怎么看：柱子是第 \(t\) 步里“一个还没被掩的 token 这一步被掩掉”的概率 \(\beta_t\)，从 1/10 一路涨到最后一步的 1；折线是到第 \(t\) 步为止被掩掉的累计比例，正好是一条从 0.1 到 1 的直线。两者并不矛盾：越到后面，还没被掩的 token 越少，所以每个幸存者被掩的概率必须越来越大，才能让“每步新掩掉的总量”保持为全体的 1/10。本站按公式画的示意图。

附录 A.6 还给了这个日程的连续时间解释：它对应一个跳变速率为 \(\gamma(t)=1/(T-t)\) 的连续时间过程，直观上就是“在剩下的时间里，均匀地安排这次跳变发生的时刻”。\(T\) 取得越大，只是把同一个连续过程切得越细。

日程有多重要。附录给了两组对照。在 text8 上用一个较小的 6 层模型、1000 步训练均匀 D3PM：\(1/(T-t+1)\) 日程得到 ≤ 2.37 bits/char，余弦日程 ≤ 1.73，互信息日程 ≤ 1.74（附录表 6）。在 CIFAR-10 上，均匀 D3PM 用线性日程（\(\beta_t\) 从 0.02 增加到 1）的 FID 是 79.86，余弦日程是 51.27（附录表 4）。

容易误解的两点：第一，\(1/(T-t+1)\) 日程是为吸收态“量身定做”的：对均匀矩阵，它不等于互信息日程，而且在上面的 text8 对照里明显最差。第二，日程的好坏取决于看哪个指标：CIFAR-10 上线性日程的 FID 差得多，NLL 上界却略好（≤ 4.99 对余弦的 ≤ 5.08，附录表 4）。论文最后用 FID 更好的余弦日程。

6 反向过程怎么参数化：先猜 \(x_0\)，再倒推一步

这一节要回答的问题：神经网络最终要给出 \(p_\theta(x_{t-1}\mid x_t)\)。最直接的做法是让网络输出这个分布的 logits。论文却让网络先猜“原始数据 \(x_0\) 是什么”，再借助前向过程的后验换算成 \(p_\theta(x_{t-1}\mid x_t)\)。这样绕一下有什么好处？它还顺带解决了什么问题？

\(x_0\) 参数化。网络 \(\mathrm{nn}_\theta(x_t)\) 对每个位置输出一个 \(K\) 类分布 \(\tilde p_\theta(\tilde x_0\mid x_t)\)，意思是“我猜这个位置原来是什么”。然后把它和前向过程结合：

$$p_\theta(x_{t-1}\mid x_t)\ \propto\ \sum_{\tilde x_0}q(x_{t-1},x_t\mid\tilde x_0)\,\tilde p_\theta(\tilde x_0\mid x_t)$$

读法：对网络猜的每一个可能的原词 \(\tilde x_0\)，按“假如原词真是它，前向过程从它出发、在第 \(t-1\) 步是 \(x_{t-1}\)、第 \(t\) 步是 \(x_t\) 的概率”加权，再按网络的置信度把各种猜测加权平均。这个思路沿用了 DDPM（预测噪声，等价于预测 \(x_0\)）和 Hoogeboom 等人的做法。

示意图：\(x_0\) 参数化的一步（吸收态，沿用 3.2 节算例二的数字）
\(x_t\)（第 2 步）某个位置是 [M]→神经网络 \(\mathrm{nn}_\theta\)看整句，输出每个位置的 \(\tilde p_\theta(\tilde x_0\mid x_t)\)→猜原词A：0.7，B：0.3→乘上前向过程\(q(x_1,x_2{=}[\mathrm{M}]\mid\tilde x_0)\)→\(p_\theta(x_1\mid x_2)\)A 0.35，B 0.15，[M] 0.5
算法（推算）：对 \(x_1=\)A，只有猜 A 时有贡献：\(0.7\times\underbrace{0.8}_{q(x_1=\mathrm{A}\mid\mathrm{A})}\times\underbrace{0.25}_{q(x_2=[\mathrm{M}]\mid x_1=\mathrm{A})}=0.14\)；对 \(x_1=\)B，\(0.3\times0.8\times0.25=0.06\)；对 \(x_1=\)[M]，无论猜什么都是 \(0.2\times1=0.2\)，加权后仍是 0.2。总和 0.4，归一化得 (0.35, 0.15, 0.5)。读法：“这一步还保持 [M]”的概率 0.5 完全由日程决定，和网络无关；网络只决定“如果这一步揭开，揭成什么”，揭开的那 0.5 按 0.7 : 0.3 分给 A 和 B。

这种参数化有三个好处：

  • 最优解一目了然。如果 \(\tilde p_\theta\) 把全部概率都放在真实的 \(x_0\) 上，那么 \(p_\theta(x_{t-1}\mid x_t)\) 就恰好等于后验 \(q(x_{t-1}\mid x_t,x_0)\)，KL 为 0。网络的任务被归结为一个熟悉的分类问题：猜原词。
  • 自动得到正确的“稀疏模式”。3.2 节的后验公式说明，从 \(x_t\) 往回走只可能走到那些“一步之内能变成 \(x_t\)”的状态，\(Q_t\) 里的 0 会原样出现在理想的反向分布里。\(x_0\) 参数化把 \(q\) 直接写进了 \(p_\theta\)，所以学到的反向分布天然带着同样的 0。以吸收态为例：一个没被掩的位置，往回走只能是它自己（因为普通 token 只能保持或变成 [M]），无论网络输出什么都不会改变它；一个被掩的位置，往回走只能“保持 [M]”或“变成某个原词”，绝不会出现“从 A 变成 B”这种前向过程里不存在的跳法。如果让网络直接输出 \(p_\theta(x_{t-1}\mid x_t)\) 的 logits，这些约束就得靠它自己学。
  • 可以一次跳多步。把公式里的 \(t-1\) 换成 \(t-k\)：\(p_\theta(x_{t-k}\mid x_t)\propto\sum_{\tilde x_0}q(x_{t-k},x_t\mid\tilde x_0)\tilde p_\theta(\tilde x_0\mid x_t)\)。所以一个按 \(T=1000\) 训练的模型，生成或评估时可以只走 256 步、128 步甚至 20 步。论文所有文本实验都是这样做的：训练用 1000 步，评估时均匀地跳过若干步。

实现细节（官方代码与附录 B.1）。后验的乘法在 log 空间里做：\(\log(x_tQ_t^{\top})+\log(\tilde p_\theta\,\overline{Q}_{t-1})\)，其中 \(\tilde p_\theta\overline{Q}_{t-1}\) 一次性完成了对 \(\tilde x_0\) 的加权求和。采样用 Gumbel-max 技巧从每个位置的分布里抽样。生成的起点是平稳分布：吸收态从“全是 [M]”开始，均匀和高斯从每个位置随机取值开始。图像模型直接输出 logits 时，用的是 \(\mathrm{nn}_\theta(\text{归一化后的 }x_t)\) 再加上 \(x_t\) 的 one-hot，相当于默认“保持当前值”，网络只学需要修改的部分。

有序数据的额外选择（附录 A.8）。对图像这种有序数据，网络也可以不直接输出 256 个 logits，而是输出一个截断离散 logistic 分布的位置和尺度：在 \([-1,1]\) 上放一个 logistic 分布，把它切成 256 个等宽的小区间，每个区间的概率就是对应灰度值的概率。这给反向模型加了一个“相邻灰度值概率相近”的归纳偏置，论文说它同时改善了 FID 和似然（第 10 节的“Gauss + logistic”）。

6.1 吸收态模型实际上是怎么生成的

把 \(x_0\) 参数化和 \(1/(T-t+1)\) 日程放在一起，吸收态 D3PM 的生成过程可以说得非常具体（本站根据附录 A.3 的后验推算）：在第 \(t\) 步，每个还是 [M] 的位置，以 \(1/t\) 的概率被“揭开”，揭开时的词从网络的 \(\tilde p_\theta(\tilde x_0\mid x_t)\) 里抽；以 \((t-1)/t\) 的概率继续保持 [M]；已经揭开的位置从此不再改变。从 \(t=T\) 走到 \(t=1\)，第 1 步时所有剩下的 [M] 都会被揭开。平均下来每一步揭开大约 \(N/T\) 个 token（\(N\) 是序列长度）。LM1B 的序列长 128，用 1000 步生成时，平均每步只揭开约 0.13 个 token（推算），绝大多数步什么也没改；用 64 步时，平均每步揭开 2 个。

步数一少，问题就来了。3.3 节说过，反向过程在给定 \(x_t\) 时对各位置独立。同一步揭开的几个位置，是各自从自己的边缘分布里独立抽样的。如果它们恰好彼此相关（比如一个城市名的两个词），独立抽样就可能拼出“New Diego”这种不存在的组合。网络再强也救不了：它给出的每个位置的边缘分布都是对的，错在“同时、独立地”抽。

上面这个交互组件用一张 16 个位置的“订机票”画布演示这件事：画布里有一对强相关的位置（出发城市和到达城市，每个城市名占两个词），其余位置要么确定、要么彼此独立。“模型”是精确的条件分布，所以出错只可能来自“同一步独立抽样”。把步数调小，每步揭开的位置变多，拼出无效组合的概率会明显上升。需要说明的是，组件里的采样器按置信度挑选要揭开的位置（这是后来 LLaDA 等工作的做法），而 D3PM 原文是随机挑选；但“同一步内各位置独立抽样”这一点两者完全相同。

容易误解的一点：“可以一次跳多步”只说明公式上能算 \(p_\theta(x_{t-k}\mid x_t)\)，不说明跳多步不掉质量。跳步本身没有引入新的近似（\(\tilde p_\theta\) 还是同一个网络），但步数越少，每步同时决定的位置越多，独立抽样的误差越大。第 9 节 LM1B 的结果会显示：从 1000 步降到 64 步，吸收态的困惑度上界只从 76.9 升到 83.6，但原文图 2 里降到个位数步数时困惑度会急剧变差。

7 损失函数：变分界加上一个辅助交叉熵

这一节要回答的问题：按理说，直接最小化变分上界 \(L_{\mathrm{vb}}\) 就是在做最大似然，这是最有原则的选择。但连续扩散的经验是，换一个加权方式的损失往往效果更好。D3PM 加的辅助项是什么？它为什么能帮忙？什么情况下它反而有害？
先补一点背景：连续扩散里的损失之争。

DDPM 发现，把 \(L_{\mathrm{vb}}\) 的各项重新加权、只保留“预测噪声”的均方误差（称为 \(L_{\mathrm{simple}}\)），图像质量更好，但似然变差。Improved DDPM（Nichol 与 Dhariwal）用 \(L_{\mathrm{hybrid}}=L_{\mathrm{simple}}+\lambda L_{\mathrm{vb}}\)：一项负责学均值，另一项负责学方差。他们还指出，\(L_{\mathrm{vb}}\) 里不同 \(t\) 的项大小相差悬殊（小 \(t\) 的项大得多），导致随机抽 \(t\) 训练时梯度噪声很大。

受此启发，D3PM 给 \(x_0\) 参数化加了一个辅助的去噪目标：在每一个时间步，都直接要求网络猜对原数据。

$$L_\lambda=L_{\mathrm{vb}}+\lambda\,\mathbb{E}_{q(x_0)}\mathbb{E}_{q(x_t\mid x_0)}\big[-\log\tilde p_\theta(x_0\mid x_t)\big]$$

几点说明：

  • 辅助项就是每个位置上“猜原词”的交叉熵，在 \(t=1\) 时它和 \(L_{\mathrm{vb}}\) 里的 \(L_0\) 是同一项。
  • 两项的最优解一致：由于 \(x_0\) 参数化，\(L_{\mathrm{vb}}\) 里的每个 KL 和辅助交叉熵，都恰好在 \(\tilde p_\theta\) 把全部概率放在真实 \(x_0\) 上时取到最小。所以加辅助项不会把模型“拉向别处”，只是改变了通往最优解的路径和各时间步的相对权重。
  • 报告的似然仍然用 \(L_{\mathrm{vb}}\) 评估，所以表里的 NLL 依旧是合法的上界；只是训练时优化的不再严格是这个上界。

论文给的解释。交叉熵项的梯度噪声随 \(t\) 的变化比较小，而 \(L_{\mathrm{vb}}\) 中各 \(L_{t-1}\) 项的大小在小 \(t\) 时变化剧烈（引用 Nichol 与 Dhariwal 的观察）。加上辅助项，等于给训练信号加了一个在各时间步都比较“平稳”的成分。

本站补充一个更具体的角度（推算）。对吸收态加 \(1/(T-t+1)\) 日程，附录 A.3 的推导表明，第 \(t\) 步的 KL 对每个被掩位置等于 \(\frac{1}{t}\big(-\log\tilde p_\theta(x_0\mid x_t)\big)\)（下一节细讲）。官方文本代码每次计算损失时抽一个 \(t\)，损失是“这一步所有位置的 KL 之和 + \(\lambda\) × 所有位置的交叉熵之和”。于是一个被掩 token 在两项里的权重分别是 \(1/t\) 和 \(\lambda\)。文本实验用 \(\lambda=0.01\)、\(T=1000\)：当 \(t\gt 100\) 时，辅助项的权重就超过了 \(L_{\mathrm{vb}}\) 的权重，而抽到的 \(t\) 有 90% 落在这个范围。换句话说，在“大部分位置都被掩掉、上下文很少”的困难时间步，\(L_{\mathrm{vb}}\) 给每个 token 的权重很小，辅助项把这部分训练信号补了回来。

示意图：吸收态下，一个被掩 token 在两项损失中的权重（推算）
怎么看：横轴是训练时抽到的时间步 \(t\)，纵轴是一个被掩 token 的交叉熵在损失里乘的系数，两轴都是对数坐标。蓝色实线是 \(L_{\mathrm{vb}}\) 给的 \(1/t\)：\(t=1\) 时为 1，\(t=1000\) 时只有 0.001。橙色虚线是辅助项的 \(\lambda=0.01\)，与 \(t\) 无关。两线在 \(t=100\) 相交，右边 90% 的时间步由辅助项主导。这是本站按附录 A.3 的公式与官方代码的损失形式推算的，论文没有画这张图；它只适用于吸收态加线性掩码日程。

实验证据。论文的结论是：辅助项对吸收态有帮助，对均匀加噪反而有害；图像上帮助很大，但 \(\lambda\) 不能大。

  • text8（1000 步，附录表 5）：吸收态从 \(L_{\mathrm{vb}}\) 的 ≤ 1.47 改善到 \(L_{\lambda=0.01}\) 的 ≤ 1.44 bits/char；均匀加噪却从 ≤ 1.61 变差到 ≤ 1.91，论文说训练变得不稳定。
  • LM1B：\(L_{\lambda=0.01}\) 对吸收态最好，对其他模型降低了性能（正文 §5.2，没有给出具体数字）。
  • CIFAR-10（\(\lambda=0.001\) 最好，表 3）：吸收态的 FID 从 41.28 降到 30.97、NLL 上界从 4.83 降到 4.40；离散高斯的 FID 从 15.30 降到 8.34，但 NLL 上界从 3.966 略升到 3.975。更大的 \(\lambda\)，以及只用辅助项训练，前期进步更快，但 NLL 停在更高的位置，FID 后来甚至回升。
读的时候容易误解的地方：“混合损失更好”不是一个普遍结论。它对哪种矩阵、哪个指标有利各不相同：对均匀加噪的文本模型它明显有害；对离散高斯的图像模型，它换来了大幅更好的 FID，代价是似然略差。另外，文本和图像实验用的 \(\lambda\) 相差 10 倍（0.01 对 0.001），说明这个超参数需要按任务调。后来的 MDLM 等工作改用一个更简单的目标，不再需要这个辅助项（见 后来怎么样了）。

8 与已有文本模型的联系：BERT、自回归模型、掩码语言模型

这一节要回答的问题：“把 token 变成 [MASK] 再让网络填回去”，听起来就是 BERT 在做的事。那么吸收态 D3PM 和 BERT、和逐个生成的自回归模型、和 Mask-Predict 这类“从全 [MASK] 开始反复填空”的生成式掩码语言模型，到底是什么关系？论文给出了三个精确的对应，其中第三个（附录 A.3）是后来整条掩码扩散路线的理论起点。
先补一点背景：三种“填空”式的模型。

BERT（2018）的训练方法叫掩码语言模型（MLM）：把一句话里一部分 token 遮住，让双向的 Transformer 根据上下文猜被遮住的词。它是用来学表示的，不是用来生成的。

条件掩码语言模型（CMLM）与 Mask-Predict（Ghazvininejad 等，2019）把这个思路用到非自回归机器翻译：训练时随机选一个数 \(k\)，把目标句里 \(k\) 个词遮住让模型猜；生成时从“整句都是 [MASK]”开始，先一次猜出所有位置，再把最没把握的一些位置重新遮上、再猜，固定迭代若干轮。Wang 与 Cho（2019）也展示了可以直接从 BERT 里采样生成文字。

自回归模型就是从左往右逐个预测下一个词的普通语言模型，训练目标是每个位置“已知前文、猜这个词”的交叉熵。

8.1 BERT 是一步的扩散模型

取一个“吸收态 + 均匀”的组合矩阵 \(Q=\alpha\mathbf{1}\mathbf{e}_m^{\top}+\beta\mathbf{1}\mathbf{1}^{\top}/K+(1-\alpha-\beta)I\)，并且只走一步（\(T=1\)）。如果 \(q(x_1\mid x_0)\) 把 10% 的 token 换成 [MASK]、5% 换成均匀随机的 token，那么 \(L_{\mathrm{vb}}\) 里只剩 \(L_T\) 和 \(L_0\) 两项。\(L_T\) 在先验固定时是常数，与参数无关，于是

$$L_{\mathrm{vb}}-L_T=-\mathbb{E}_{q(x_1\mid x_0)}\big[\log p_\theta(x_0\mid x_1)\big]=L_{\mathrm{BERT}}$$

也就是说，BERT 的训练目标正是一个单步 D3PM 的变分界（去掉常数项）。

细节上的差别：论文举的“10% [MASK] + 5% 随机”是一个示意比例。BERT 原文的做法是先选 15% 的位置，其中 80% 换成 [MASK]、10% 换成随机词、10% 保持不变，折合约 12% [MASK]、1.5% 随机、1.5% 不变（推算）；而且 BERT 只在这 15% 的位置上算损失，单步扩散的 \(L_0\) 则对所有位置算。所以这个等价是“同一类目标”意义上的，不是逐位一致。

8.2 自回归模型是一种确定性的离散扩散

设序列长度为 \(N\)，取 \(T=N\)，前向过程确定性地从右往左每步遮住一个 token：

$$q([x_t]_i\mid x_0)=\begin{cases}[x_0]_i & i\lt N-t\\ {[\mathrm{MASK}]} & \text{否则}\end{cases}$$

因为过程是确定的，后验也是确定的：从 \(x_t\) 退回 \(x_{t-1}\)，只有位置 \(i=T-t\)（当前最左边那个 [MASK]）从 [MASK] 变回原词，其他位置一概不变。于是除了这个位置，所有位置的 KL 都是 0；这个位置的 KL 是 \(-\log p_\theta([x_0]_i\mid x_t)\)，而 \(x_t\) 此时恰好是“前 \(i\) 个原词 + 后面全是 [MASK]”。这正是自回归模型在第 \(i\) 个位置的交叉熵。生成时从全 [MASK] 出发，每步揭开最左边的一个，就是从左往右逐个生成。

这里有一个技术细节：这个过程不是对每个位置独立施加同一个矩阵（遮哪个位置取决于位置编号）。论文的处理是把每个 token 连同它的位置一起看成一个状态，状态空间变成“位置 × 词表”，\(Q\) 是一个 \(N\times|\mathcal{V}|\times N\times|\mathcal{V}|\) 的稀疏矩阵，这样形式上又回到了“对每个元素独立加噪”。

8.3 生成式掩码语言模型是吸收态 D3PM（附录 A.3）

生成式掩码语言模型通常这样训练：抽一个序列 \(x_0\)，按某个日程选一个数 \(k\)，随机遮住 \(k\) 个 token，在被遮的位置上算交叉熵，并按 \(1/k\) 归一化：

$$\min\ -\mathbb{E}_{q(x_0)}\,\mathbb{E}_{k}\,\frac{1}{k}\,\mathbb{E}_{x_k\text{：遮住 }k\text{ 个}}\sum_{i:\,[x_k]_i=m}\log p_\theta([x_0]_i\mid x_k)$$

论文证明，用 \(x_0\) 参数化、按普通变分界训练的吸收态 D3PM，化简以后就是这个目标的一个重新加权版本。推导分三步：

  1. 没被掩的位置不贡献损失。普通 token 只能保持原样或变成 [MASK]，所以一个在 \(x_t\) 里仍是原词的位置，退回 \(x_{t-1}\) 时只能还是原词；\(x_0\) 参数化又保证 \(p_\theta\) 也只能如此（第 6 节的稀疏模式），两者完全一致，KL 为 0。
  2. 被掩的位置，KL 正比于交叉熵。对一个在 \(x_t\) 里是 [MASK] 的位置，后验只有两种可能：在 \(x_{t-1}\) 里已经是 [MASK]，或者是原词 \([x_0]_i\)。“是 [MASK]”这部分的概率与参数无关，只贡献常数；“是原词”这部分的概率是 \(\beta_t\prod_{s\lt t}(1-\beta_s)\) 除以归一化常数。于是 \(L_{t-1}\) 化成被掩位置上 \(-\log\tilde p_\theta([x_0]_i\mid x_t)\) 的加权和。
  3. 用 \(1/(T-t+1)\) 日程，权重恰好是 \(1/t\)。这个日程下第 \(t\) 步被掩的概率是 \(t/T\)，可以算出 \(q([x_{t-1}]_i=[x_0]_i\mid[x_t]_i=m,x_0)=1/t\)（3.2 节算例二的 0.5，正是 \(t=2\) 时的 \(1/t\)），并且 \(L_T=0\)。把所有时间步加起来：
$$L_{\mathrm{vb}}=-\mathbb{E}_{q(x_0)}\Big[\sum_{t=1}^{T}\frac{1}{t}\,\mathbb{E}_{q(x_t\mid x_0)}\sum_{i:\,[x_t]_i=m}\log\tilde p_\theta([x_0]_i\mid x_t)\Big]+C$$

和上面的 MLM 目标对比：两者都是“在被掩位置上算交叉熵，再按被掩数量的倒数加权”。\(1/t\) 和 \(1/k\) 的作用相同，因为第 \(t\) 步被掩数量的期望是 \(Nt/T\)，\(1/t\) 正比于它的倒数。区别只有一处：D3PM 是每个位置独立地以概率 \(t/T\) 被掩，被掩的个数是随机的；MLM 通常是“恰好遮住 \(k\) 个”。论文指出，前者也是一种完全实用的遮法，有些方法本来就这么实现。按 D3PM 的方式，被掩个数 \(k\) 的分布是一族二项分布的混合：

$$\alpha(k)=\frac{1}{T}\sum_{t=1}^{T}\binom{N}{k}\Big(\frac{t}{T}\Big)^{k}\Big(1-\frac{t}{T}\Big)^{N-k}$$
图：吸收态 D3PM 隐含的“被掩个数”分布（\(N=T=50\)，按论文式 (14) 推算）
怎么看：横轴是长度 50 的序列里被掩掉的个数 \(k\)，柱高是 \(\alpha(k)\)，橙色虚线是“\(k\) 从 0 到 50 完全均匀”的 1/51。中间几乎所有的柱子都贴着虚线（约 0.0196），只有两端偏离：\(k=0,1,49\) 略低，\(k=50\) 因为最后一步 \(t=T\) 必然全掩而偏高。所以吸收态 D3PM 的训练分布和 Mask-Predict 那种“均匀地选 \(k\)”几乎一样。论文附录图 6 画的是同一个量，本站按公式自己重算重画；原图见 PDF 附录 A.3 ↗。

一个后来变得非常重要的推论（本站推导）。把上式的求和写成对 \(t\) 均匀抽样的期望，并令 \(\tau=t/T\)：\(\sum_{t=1}^{T}\frac{1}{t}(\cdots)=T\,\mathbb{E}_{t}\big[\frac{1}{t}(\cdots)\big]=\mathbb{E}_{\tau}\big[\frac{1}{\tau}(\cdots)\big]\)。当 \(T\to\infty\) 时 \(\tau\) 变成 \((0,1]\) 上的均匀分布，训练目标就是

$$-\mathbb{E}_{\tau\sim U(0,1]}\ \mathbb{E}_{x_\tau}\Big[\frac{1}{\tau}\sum_{i:\,[x_\tau]_i=m}\log\tilde p_\theta([x_0]_i\mid x_\tau)\Big],\qquad x_\tau\text{：每个位置独立地以概率 }\tau\text{ 被掩}$$

这一行和 2025 年 LLaDA 论文的训练损失（其式 (3)）逐项相同；2024 年的 MDLM 与 MD4 也把掩码扩散的连续时间变分界化简成“掩码语言模型损失的加权混合”。也就是说，后来的大规模掩码扩散语言模型，训练目标就是本节这个结论在 \(T\to\infty\) 时的形式，改进主要在参数化、工程和规模上（见 后来怎么样了）。

9 文本实验：text8 与 LM1B

这一节要回答的问题：四种矩阵在真实文本上谁好谁坏？离散扩散能不能扩展到大词表？和同样大小的自回归模型比差多少，生成速度又如何？读数字之前，要先弄清楚实验的设置和每个指标的含义，最后再看这些比较哪些是对齐的、哪些不是。

9.1 实验设置

数据。text8 是从英文维基百科抽出的字符级数据集，词表只有 27 个符号（a–z 和空格），按惯例切成长度 256 的片段，不做任何预处理，训练/测试/验证集为 9000 万 / 500 万 / 50 万个字符。LM1B（One Billion Word）是一个打乱了句子顺序的大型英文新闻句子集，训练集 30,301,028 句、测试集 306,688 句；论文用 SentencePiece 切成 8192 个 token 的词表，把句子打包成长度 128 的序列。

模型与训练。所有文本模型都是 T5 结构的 Transformer 编码器（双向注意力），12 层、约 7000 万参数（12 个头、MLP 维度 3072、qkv 维度 768），在 TPUv2 或 TPUv3 上以批大小 512 训练 100 万步，学习率 \(5\times10^{-4}\)，前 1 万步预热，之后按步数平方根的倒数衰减，用 JAX/Flax 实现。所有扩散模型都按 \(T=1000\) 训练，评估时可以均匀地跳步。自回归基线是同样结构的 Transformer 解码器（加因果掩码），参数量相同。日程：均匀模型用余弦日程，吸收态和嵌入近邻用互信息日程（按 unigram 频率近似）。按这些设置推算，LM1B 训练了约 \(10^6\times512\times128\approx6.6\times10^{10}\) 个 token 位置，text8 约 \(1.3\times10^{11}\) 个字符位置，相当于把 9000 万字符的训练集过了约 1,456 遍（推算）。

先补一点背景：bits/char 与困惑度。

bits/char（每字符比特数）：模型给整个测试集打的负对数概率（以 2 为底），除以字符总数。1.45 bits/char 意味着平均每个字符要花 1.45 个比特来编码，等价于模型平均给每个正确字符约 \(2^{-1.45}\approx0.37\) 的概率（推算）。越低越好。

困惑度（perplexity）：\(\exp\)(平均每个单位的负对数似然)。困惑度 76.9 可以理解为“模型的不确定程度相当于在约 77 个选项里均匀地猜”。论文的 LM1B 困惑度是按英文单词数归一化的（包括模型预测的句末符号），不是按 SentencePiece token 数。

上界与精确值：扩散模型报告的是变分上界（表里的“≤”），真实的负对数似然只会更低；自回归模型的值是精确的。

9.4 结果的份量

和自回归模型比，对齐了什么。本文的自回归基线和 D3PM 用同样的 12 层结构、同样的参数量（约 7000 万），附录说文本实验的所有模型都训练 100 万步、批大小 512；按这个说法，参数量和训练量也是对齐的（论文没有单列自回归基线的训练细节）。在这个对齐的比较里，差距是实实在在的：text8 上 1.45 对 1.23 bits/char，D3PM 的上界多出约 18%；LM1B 上 76.9 对 43.6，换算成每词的负对数似然是 4.34 对 3.78 nats，多出约 15%（推算）。正文说吸收态“接近同样大小的自回归模型”，这个措辞偏乐观。表里的 Transformer-XL 则不是同等条件：它的 text8 模型有 24 层、2.77 亿参数，LM1B 模型（Large）有 8 亿参数（Transformer-XL 论文表 3、表 4），所以 1.08 和 21.8 只能当作“当时的最好水平”参考，不能拿来衡量方法本身的差距。

上界对精确值。D3PM 的数字是变分上界，自回归是精确值。所以真实差距不会比表里更大，可能更小，但论文没法告诉我们小多少。

速度要连同质量和条件一起看。表里的“生成时间”是生成一条样本（text8 长 256、LM1B 长 128）的时间，论文没有写计时用的硬件，也没有说自回归基线是否使用了 KV 缓存。按表 1 自己的数字：1000 步时 D3PM 吸收态要 3.4 秒，比自回归的 0.357 秒慢约 10 倍；256 步时 0.598 秒，仍然比自回归慢；只有降到 20 步（0.0785 秒）才比自回归快约 4.5 倍，而此时质量是 1.56 对 1.23 bits/char（推算）。正文写的是“比同样大小的自回归 Transformer 快近 20 倍”，这个倍数无法从表 1 的数字算出来，本站推测它可能来自附录图 9 中步数更少的点，但无法核实。LM1B 上，64 步的吸收态（0.10 秒）比自回归（0.26 秒）快约 2.6 倍，困惑度是 83.6 对 43.6（推算）。另外，表 1 里多项式扩散 26.6 秒对本文均匀 D3PM 3.6 秒，用的是同样的 1000 步、本质上同一种模型，差了 7 倍多，说明这类计时很大程度上反映的是实现，而不是方法。只看批大小为 1 的计时也偏向并行生成的方法：批量大时，自回归模型的吞吐量会追上来。

评测范围很窄。文本实验只报告无条件生成的似然和样本，没有下游任务、没有条件生成，也没有对填空、改写这类“扩散天然擅长”的任务做定量评测。附录里的样本在局部通顺，但成段读下来语义不连贯。

规模。7000 万参数的模型，在 2021 年是一个概念验证的规模：同一时期最大的自回归语言模型已经到了 1750 亿参数（GPT-3，2020）。论文自己在讨论里也承认，和许多非自回归模型一样，D3PM 在文本上仍不如强的自回归模型。

后来的重新评估。2024 年的 MDLM 在其 LM1B 表里把 D3PM 吸收态的 76.90 和自己的结果并列（MDLM 1.1 亿参数、训练 330 亿 token 时为 ≤ 27.04）。但这两个数字的单位不同：D3PM 用 8192 词表的 SentencePiece、按单词数归一化，MDLM 用 bert-base-uncased 分词、按 token 归一化，不能直接相减。更有说服力的是 MDLM 的消融（其表 8）：在它自己的训练配方下，把模型退回“离散时间 \(T=1000\)、去掉它新增的两项参数化技巧”，也就是数学上等价于 D3PM 吸收态的版本，困惑度上界是 28.51，只比完整的 MDLM 差约 1.5。这说明吸收态 D3PM 的目标本身并不弱，2021 年的差距主要来自模型、训练配方和规模。

容易误读的地方：“吸收态比均匀好”在这篇论文的设置下是成立的（text8、LM1B 都是），但它是在“按似然评测、70M 模型”的条件下得出的。后来有工作在更大规模上重新审视均匀噪声，认为它在可以反复修改已生成内容等方面有优势，而且不同噪声族的困惑度不宜直接比较（见旧版的 均匀噪声与连续路线）。

10 图像实验：CIFAR-10

这一节要回答的问题：把 8 位图像的每个颜色通道看成 256 个类别，D3PM 能不能和连续的 DDPM 比？三种矩阵里哪种最适合图像？混合损失和 logistic 参数化各带来多少提升？这里和 DDPM 的比较是在什么条件下做的？
先补一点背景：IS、FID 与 bits/dim。

IS（Inception Score）用一个在 ImageNet 上训练好的 Inception 分类网络给生成的图打分：每张图越像某一类、全部图的类别越分散，分数越高。FID（Fréchet Inception Distance）比较生成图和真实图在 Inception 网络特征空间里的分布（均值和协方差）有多接近，越低越好，是最常用的图像质量指标。两者都依赖一个特定数据上训练的网络，论文在讨论里专门提醒了这一点。bits/dim 是负对数似然除以维度数（CIFAR-10 每张图 32×32×3 = 3072 维）再换成以 2 为底，衡量模型给真实图像打的概率，越低越好。

设置。CIFAR-10 无条件生成。三种 D3PM：均匀（余弦日程，比线性日程好）、吸收态（吸收态是灰色像素 (128, 128, 128)，日程 \(\beta_t=1/(T-t+1)\)，即被吸收的概率随时间线性增长）、离散高斯（\(\beta_t\) 沿用 DDPM 的线性日程，从 \(10^{-4}\) 到 0.02）。\(T=1000\)，论文验证了所有模型的前向过程在 \(T\) 步内都已收敛到平稳分布，\(L_T\) 最多约 \(10^{-5}\) bits/dim。

网络完全沿用 DDPM：以 PixelCNN++ 的骨干为基础的 U-Net（Wide ResNet 块，权重归一化换成组归一化），4 种特征图分辨率，每种分辨率 2 个残差块，在 16×16 分辨率加一个自注意力块，时间步用正弦位置编码送进每个残差块。超参数也直接照搬、没有调：dropout 0.1，Adam 学习率 \(2\times10^{-4}\)，批大小 128，评估用衰减率 0.9999 的参数滑动平均，训练时随机水平翻转。作者先用 JAX/Flax 重新实现了 DDPM 并验证能复现原文结果，再在它上面改出 D3PM。参数量：重实现的 DDPM 约 3570 万，和官方 CIFAR-10 检查点一样；直接输出 logits 的 D3PM 约 3660 万；用 logistic 参数化的约 3570 万。所有模型在 TPUv2（4×4 拓扑）上训练 150 万步；IS 和 FID 用 50,000 张样本计算；D3PM 的每个数字是 5 个随机种子的平均和标准差。

10.1 结果的份量

和 DDPM 的比较是对齐得最好的一组。同一套网络结构、几乎相同的参数量（3570 万对 3570–3660 万）、同样的超参数、同样的 \(T=1000\)，而且 DDPM 是作者自己重新实现并验证过的。在这个条件下，“Gauss + logistic”的 NLL 上界 3.435 确实低于 DDPM 的 ≤ 3.70（\(L_{\mathrm{vb}}\) 训练）和 ≤ 3.75（\(L_{\mathrm{simple}}\) 训练），这就是摘要里“似然超过连续 DDPM”的含义。

但只是超过了原始 DDPM。同一张表里，Improved DDPM 用 \(L_{\mathrm{vb}}\) 训练的 NLL 是 ≤ 2.94，Song 等人的 DDPM++（连续时间）是 2.99，自回归的 Sparse Transformer 是 2.80，都比 3.435 低得多。样本质量上，D3PM 最好的 FID 7.34，仍比 DDPM \(L_{\mathrm{simple}}\) 的 3.17 差一倍多，更不及 NCSN++ 的 2.20 和 StyleGAN2 + ADA 的 3.26。论文在讨论里也承认“连续扩散在图像质量上仍然更强”。

其他要注意的条件。图 3 左侧的逐步样本是挑选过的；作者开源的代码不包含 FID 和 IS 的评测部分（代码 README 说明），所以这两个数字目前无法用官方代码直接复现。D3PM 的数字都有 5 个种子的标准差，这一点比许多同期工作更严谨。

容易误读的一点：图像实验里表现最好的是离散高斯，吸收态在这里排第二（FID 30.97 对 7.34）。所以“吸收态最好”只是文本上的结论；对有序数据，“相近状态之间的局部转移”才是关键。后来的 MD4（2024）用改进的掩码扩散在 CIFAR-10 上做到 2.75 bits/dim（据其摘要），说明吸收态在像素上的差距也主要来自当时的参数化与训练，而不是吸收态本身的上限。

11 相关工作与讨论

这一节要回答的问题：D3PM 在当时的研究版图里处在什么位置？作者自己认为它还差在哪里，下一步可以往哪里走？

相关工作。论文把相关工作分成三块。第一块是连续扩散本身：Sohl-Dickstein 等人最早提出扩散生成模型，DDPM 和 WaveGrad 让它在图像和语音上重新受到关注；之后有对变分界做重要性采样、改进噪声日程（Improved DDPM）、隐式扩散（DDIM）等改进，也有工作揭示了它和得分匹配的联系，并在连续时间极限下得到更好的采样算法（Song 等人的 SDE 框架）。第二块是离散数据上的扩散：Sohl-Dickstein 的二值扩散、Hoogeboom 等人的多项式扩散；有些工作把离散数据嵌入连续空间再用高斯扩散（图生成、符号音乐），但没有用在文本上；Seff 等人也用类似扩散的马尔可夫破坏过程生成离散结构。第三块是文本：去噪自编码器在表示学习（包括 BERT）和生成（Wang 与 Cho）上都有很长的历史，它们在特定日程和矩阵下与吸收态 D3PM 非常接近，而 D3PM 的框架额外给出了似然，并允许换别的转移矩阵；非自回归翻译和语音识别里还有插入/删除（Levenshtein Transformer 等）、掩码（Mask-Predict）、迭代精修的序列对齐（Imputer 等）等做法。

作者承认的局限。第一，和很多非自回归生成模型一样，D3PM 在文本上仍然不如 Transformer-XL 这样强的自回归模型；在图像质量上仍然不如连续扩散。第二，评测指标有局限：IS 和 FID 依赖在特定数据上训练的网络，不能代表所有用途，只看平均质量也可能掩盖模型在不同人群和场景上的差异，作者认为这有造成负面社会影响的风险。

作者展望的方向。借鉴连续扩散的进展：试试类似 \(L_{\mathrm{simple}}\) 的重新加权损失、Improved DDPM 的重采样变分界、更多的时间步和更优化的噪声日程；以及探索更丰富的结构化转移矩阵。同一组作者随后还发表了在 D3PM 之上加入插入和删除操作的工作（Johnson 等，“Beyond In-Place Corruption”，ICML 2021 研讨会），代码也放在同一个仓库里。

回头看，哪些展望应验了：“借鉴连续扩散的重新加权与更多时间步”基本应验了，而且走到了极端：后来的工作直接取 \(T\to\infty\) 的连续时间，并把吸收态的目标化简成第 8 节那种加权交叉熵。“更丰富的结构化矩阵”则基本没有成为主流：嵌入近邻在本文里就表现平平，后来的大规模文本扩散几乎都用吸收态，少数回到均匀噪声。

  • 连续时间化。D3PM 的附录 A.5 已经指出矩阵指数对应连续时间马尔可夫链。Campbell 等人（2022）给出了第一个完整的离散数据连续时间扩散框架。SEDD（2023）提出“得分熵”损失，同样比较了吸收态和均匀两种矩阵，结论与本文一致：在 GPT-2 small 规模上，吸收态在 WikiText103 上的困惑度上界为 ≤ 40.62，均匀为 ≤ 49.60，GPT-2 为 41.60；在 text8 上，它把非自回归模型的最好成绩从本文吸收态的 1.45 推进到 1.39 bits/char（SEDD 表 1、表 2）。见 SEDD 精读。
  • 吸收态的简化。MDLM 和同期的 MD4（2024）证明，吸收态扩散的连续时间变分界就是掩码语言模型损失的加权混合，这正是本页 8.3 节那个 \(1/t\) 加权目标在 \(T\to\infty\) 时的样子。MDLM 明确说“掩码扩散是 D3PM 的严格子集”，它相对 D3PM 的改进是三点：一种专门针对掩码的参数化（SUBS）、由此化简出的更简单的目标、以及更好的训练配方。结果是 LM1B 上 1.1 亿参数、330 亿 token 时 ≤ 27.04，327B token 时 ≤ 23.00，同条件重训的自回归模型为 22.32 和 20.86（MDLM 表 1）。MD4 在 CIFAR-10 上做到 2.75 bits/dim（据其摘要），远好于 D3PM 吸收态的 ≤ 4.40。见 MDLM 精读。
  • 规模化。LLaDA（2025）从头训练了一个 80 亿参数的掩码扩散语言模型，训练损失是“对 \(t\sim U[0,1]\)，在被掩位置上算交叉熵并乘以 \(1/t\)”，和 8.3 节推出的连续时间形式逐项相同；其相关工作部分把 Austin 等人（即本文）列为把离散扩散引入语言建模的开创性工作之一。LLaDA 8B 预训练用了 2.3T token，并与 LLaMA3 8B（15T token）等模型对比（LLaDA 表 1）。见 LLaDA 精读，以及同一路线的 Dream 7B、LLaDA2.0。
  • 更一般的离散生成框架。D3PM“矩阵随便设计”的精神，后来以“概率路径”的形式被 Discrete Flow Matching（2024）继承和推广，见 Discrete Flow Matching 精读。
  • 图像 token。VQ-Diffusion（2021-11）在 VQ-VAE 的离散图像 token 上做扩散，用了一种“掩码与替换”的加噪策略（据其摘要）。本站的理解是，它和 D3PM 附录 A.2.6 的“吸收态 + 均匀”组合属于同一思路：既会变成 [MASK]，也会被换成随机 token。
  • 本页提出、后来被反复研究的问题。6.1 节讲的“同一步独立抽样”的误差，以及掩码扩散按随机顺序生成带来的困难子问题，后来成为一个专门的研究方向，见 Train for the Worst, Plan for the Best 精读 和旧版的 顺序与并行的极限。

反过来，D3PM 里有几样东西后来很少再用：嵌入近邻矩阵（本文就证明它几乎没用）、离散高斯之于文本、混合损失里的辅助交叉熵（被更简单的目标取代），以及 1000 步的离散时间（被连续时间取代）。
