0 导读：这篇论文解决什么问题

“门”（gate）是神经网络里最老的部件之一：用一个取值在 0 到 1 之间的数去乘另一路信号，决定这路信号放过多少。LSTM 用门决定记住什么、忘掉什么；今天几乎所有开源大模型的前馈层都是带门的 SwiGLU；Mamba、各种线性注意力（包括本站的 Gated DeltaNet）也都在输出上加了门。可是大模型里最核心的那个部件，标准的 softmax 注意力，在主流模型里一直是“不带门”的。偶尔有新设计在注意力里加了门，门又总是和别的改动（路由、稀疏选择）捆在一起，没人能说清楚：好处到底来自门本身，还是来自那些别的改动。

这篇来自阿里 Qwen 团队的论文，专门把“门”从别的因素里剥离出来研究。作者在标准 softmax 注意力的五个不同位置加门，再改变门的粒度、是否各头独立、乘法还是加法、用什么激活函数，一共比较了 30 多个变体。实验规模在学术论文里很少见：一个总参数 15B、每个 token 激活 2.54B 的混合专家（MoE）模型，以及 1.7B 的稠密模型，训练数据最多 3.5T token。结论非常简单：在每个注意力头的输出（也就是 softmax 加权求和之后、输出投影 \(W_O\) 之前）乘上一个由当前 token 算出来的 sigmoid 门，效果最好。在 MoE 模型上训 400B token，平均困惑度从 6.026 降到 5.761，MMLU 从 58.79 升到 60.82；在 1.7B 稠密模型上，训练时的损失尖峰几乎消失；把学习率加到 8e-3 时，基线严重退化甚至发散，加门的模型不但能稳定训练，效果还更好。

更有意思的是作者对“为什么有效”的解释。第一，注意力里 value 投影和输出投影是两个紧挨着的线性层，中间没有任何非线性，合起来只是一个低秩的线性映射；门在中间插进了非线性。第二，训练出来的门分数大多接近 0，而且随 query 变化，相当于让每个头“这一次可以不发言”。有了这个能力，模型就不再需要靠把注意力堆到第一个 token 上来“假装不发言”：分给第一个 token 的注意力从平均 46.7% 降到 4.8%，这就是标题里的 attention-sink-free（没有注意力汇）；同时残差流里的超大激活值从 1053 降到 94。没有了注意力汇，模型用 YaRN 外推到 128K 上下文时，RULER 分数从 31.65 提高到 58.82。

这是一篇架构论文，但和推理、训练系统关系很深：注意力汇和超大激活正是量化（见 QuaRot 精读、KIVI 精读）和 KV 缓存压缩（见 SnapKV 精读里讲的 StreamingLLM）里那些“特殊处理”的来源；大学习率下的稳定性直接关系到大规模训练会不会中途崩掉；门本身几乎不花算力、不改注意力内核、不增加 KV 缓存。这个设计后来进入了 Qwen3-Next 和 Qwen3.5，和 Gated DeltaNet 一起组成 3:1 的混合架构。不过要先说清楚：论文本身没有做任何量化或 KV 压缩实验，这些方面的好处是本站根据论文的测量推断的，后面会一一标明。

1 引言：门到处都在用，但门本身贡献了多少，没人单独量过

这一节要回答的问题：门控机制在各种网络里都很成功，但大家通常把它当作一个更大设计的一部分加进去，很少单独研究它。作者为什么认为这是个问题？他们拿什么例子说明“门的作用被别的设计掩盖了”？他们打算怎么研究，最后得出了哪些结论？
先补一点背景：神经网络里的“门”是什么。

一个门由两部分组成：一路被调节的信号 \(Y\)，和一路用来算门分数的输入 \(X\)。门分数通常是 \(\sigma(XW_\theta)\)，其中 \(W_\theta\) 是可学习的权重，\(\sigma\) 是 sigmoid 函数 \(\sigma(z)=1/(1+e^{-z})\)，它把任何实数压到 0 和 1 之间。输出是两者逐元素相乘：\(Y'=Y\odot\sigma(XW_\theta)\)。门分数接近 1，信号几乎原样通过；接近 0，信号几乎被抹掉。所以门不能“创造”信息，只能根据 \(X\) 决定 \(Y\) 的每一维放过多少。

几个熟悉的例子：

  • LSTM、GRU：用遗忘门、输入门、输出门控制每一步记住多少旧状态、写入多少新信息。这是门最早的用途，目的是让梯度能穿过很多个时间步。
  • Highway Network：在层与层之间加门，决定这一层的输出和输入各占多少，让非常深的前馈网络也能训练。
  • SwiGLU：今天 LLaMA、Qwen 这类模型的前馈层，算的是 \(\big(\mathrm{SiLU}(xW_1)\odot xW_3\big)W_2\)。其中一路 \(xW_3\) 被另一路 \(\mathrm{SiLU}(xW_1)\) 逐元素调节，这也是一种门（只不过用的是 SiLU，它的取值不限于 0 到 1）。
  • Mamba、线性注意力：这些模型在输出上普遍有一道门。例如 Gated DeltaNet 层的输出是 \(\mathrm{RMSNorm}(o_t)\odot\mathrm{SiLU}(z_t)\)，再乘输出投影（见旧版 Gated DeltaNet 拆解）。

而标准的 softmax 注意力（Transformer 原始论文那一种）没有门：每个头的输出直接拼起来乘 \(W_O\)，再加回残差流。

作者认为，对门的理解不够，会让人误判别的设计到底有没有用。他们举了两个例子。

第一个是 Switch Heads：它把注意力头做成“专家”，每个 token 用 sigmoid 路由从一组 key / value / 输出专家里选 top-k 个。原论文的结论是这种稀疏激活有好处，专家越多越好。但作者在附录 A.1 里做了一组对照（都在 15A2B 的 MoE 模型上训 400B token）：

最好的反而是“1 选 1”：只有一个专家，根本谈不上路由和选择，剩下的只是 sigmoid 路由分数乘在 value 输出上，也就是一道门。这说明 Switch Heads 的收益里，相当一部分可能来自门本身，而不是来自“选专家”。第二个例子是 NSA（原生稀疏注意力，见本站 NSA 精读）：它用三条分支（压缩、选择、滑动窗口）分别算注意力，再用由输入算出的 sigmoid 门把三条分支的输出加权合起来。NSA 的论文展示了整体的提升，但没有把“门”的贡献和“稀疏注意力”的贡献分开。

所以作者回到最简单的情形：标准 softmax 注意力，只加门，不做别的改动。他们比较门放在五个位置（后面第 2 节画了图）：query 投影之后（\(G_4\)）、key 投影之后（\(G_3\)）、value 投影之后（\(G_2\)）、SDPA 输出之后（\(G_1\)）、最后的输出投影之后（\(G_5\)）；还比较了逐元素和逐头、各头独立和各头共享、乘法和加法等变体。主要发现有两条：

  • 在 SDPA 输出上加各头独立的门（\(G_1\)）提升最大：困惑度最多降约 0.2，MMLU 最多提高约 2 分。
  • 这道门还让训练更稳定：损失尖峰几乎消失，可以用更大的学习率，模型的扩展性也更好。

作者把它有效的原因归结为两点。一是非线性：value 投影 \(W_V\) 和输出投影 \(W_O\) 是连续的两个线性层，可以合并成一个低秩的线性映射，在 \(G_1\) 或 \(G_2\) 加门就给这个映射加入了非线性（第 4.1 节）。二是稀疏：有效的门，分数大多接近 0，而且随输入变化，给 SDPA 的输出带来了依赖输入的稀疏性（第 4.2 节）。这种稀疏的门还消除了超大激活和注意力汇（第 4.3 节），并让模型在上下文外推时在 RULER 上提高 10 分以上（第 4.4 节）。

  • 这里的“稀疏”是指门分数的数值大多接近 0，不是稀疏注意力那种“跳过一部分 token 不算”。加门之后，每个 query 仍然和所有 key 算一遍注意力，计算量一点没少，反而多了一点算门的开销。不要把“sparsity”读成“加速”。
  • 这里的门也不是在挑选 token 或挑选专家。它只是对每个头的输出（逐元素或整体）乘一个 0 到 1 之间的数。

2 门控注意力层：门可以加在哪里，可以长什么样

这一节要回答的问题：一个标准的多头注意力层，从输入到输出要经过哪几步？门可以插在其中哪几个位置？除了位置，门还有哪些可以变的地方（粒度、各头是否共享、乘还是加、用什么激活函数）？每种门要多少额外参数？

2.1 先把多头 softmax 注意力拆成四步

先补一点背景：pre-norm、多头注意力和 GQA。

pre-norm。现在的大模型每一层都写成 \(h\leftarrow h+\mathrm{Attn}(\mathrm{Norm}(h))\)、\(h\leftarrow h+\mathrm{FFN}(\mathrm{Norm}(h))\)：残差流 \(h\) 先做一次归一化（通常是 RMSNorm），再送进注意力或前馈层，结果直接加回残差流。论文里的输入 \(X\)，指的就是归一化之后送进注意力的那个隐状态。门分数也用这个 \(X\) 算（论文脚注 1）。

多头。注意力被分成 \(h\) 个头，每个头有自己的一套 query / key / value 投影，各自在一个 \(d_k\) 维的小空间里算注意力（本文所有模型 \(d_k=128\)）。各头的输出拼接起来，再乘输出投影 \(W_O\) 变回模型维度 \(d_{\text{model}}\)。

GQA（分组查询注意力）。为了让推理时的 KV 缓存小一些，很多模型让若干个 query 头共用同一组 key / value 头。论文 MoE 模型有 32 个 query 头、4 个 KV 头，所以每 8 个 query 头共用一个 \(W_V\) 和 \(W_K\)。KV 缓存只按 4 个头存，是不分组时的 1/8。这个细节在第 4.1 节会再出现：共用 \(W_V\) 让“低秩”问题更严重。

给定输入 \(X\in\mathbb{R}^{n\times d_{\text{model}}}\)（\(n\) 个 token），注意力层分四步：

  1. QKV 线性投影：\(Q=XW_Q,\ K=XW_K,\ V=XW_V\)。
  2. 缩放点积注意力（SDPA）：\(\mathrm{Attention}(Q,K,V)=\mathrm{softmax}\big(QK^\top/\sqrt{d_k}\big)V\)。softmax 保证每一行的注意力权重非负、加起来等于 1。
  3. 多头拼接：每个头各算一遍第 2 步，结果拼成 \(\mathrm{Concat}(\mathrm{head}_1,\dots,\mathrm{head}_h)\)。
  4. 输出层：拼接结果乘 \(W_O\in\mathbb{R}^{hd_k\times d_{\text{model}}}\)，得到这一层的输出，加回残差流。

拿论文 MoE 模型的尺寸走一遍（附录表 7）：\(d_{\text{model}}=2048\)，32 个 query 头，所以 \(Q\) 的宽度是 \(32\times128=4096\)，比 \(d_{\text{model}}\) 还宽；4 个 KV 头，所以 \(K\)、\(V\) 的宽度各是 \(4\times128=512\)；SDPA 的输出拼起来宽 4096，乘 \(W_O\)（\(4096\times2048\)）回到 2048。

2.2 门的统一写法，和五个要比较的方面

论文把所有门写成同一个式子：

$$Y'=g(Y,X,W_\theta,\sigma)=Y\odot\sigma(XW_\theta)$$

\(Y\) 是被调节的那一路（比如某一步的输出），\(X\) 是用来算门分数的输入（pre-norm 之后的隐状态），\(W_\theta\) 是门的参数，\(\sigma\) 是激活函数。门分数 \(\sigma(XW_\theta)\) 像一个动态的滤网：根据当前输入，决定 \(Y\) 的每一维保留多少。作者从五个方面比较不同的门：

  1. 位置。\(G_4\)、\(G_3\)、\(G_2\) 分别在 query、key、value 投影之后；\(G_1\) 在 SDPA 的输出之后（拼接和 \(W_O\) 之前）；\(G_5\) 在 \(W_O\) 之后，也就是整个注意力层的输出上。
  2. 粒度。逐头（headwise）：每个头只有一个标量门分数，整个头的输出一起放大或缩小；逐元素（elementwise）：门分数是和 \(Y\) 同样宽的向量，每一维单独调节。
  3. 各头独立还是共享。独立（head-specific）：每个头有自己的门分数；共享（head-shared）：所有头用同一套门分数。论文的共享做法是先算出各头的分数，再沿头的维度取平均。
  4. 乘法还是加法。乘法门 \(Y'=Y\odot\sigma(X\theta)\)；加法门 \(Y'=Y+\sigma(X\theta)\)。
  5. 激活函数。主要比较 sigmoid 和 SiLU。sigmoid 的输出在 0 到 1 之间；SiLU 的输出没有上界，所以只用在加法门里。为了拆解原因，第 4.1 节还会把门换成恒等映射或 RMSNorm。

没有特别说明时，论文默认用各头独立、乘法、sigmoid 的门。

每种门要多少参数？论文表 1 列了“新增参数”一栏，可以按 MoE 模型的尺寸核对一遍（推算，24 层）：

  • \(G_1\) 逐元素：门分数要和 SDPA 输出一样宽（4096），所以 \(W_\theta\) 是 \(2048\times4096\)，每层约 8.39M，24 层约 201M，和表 1 的 201M 一致。
  • \(G_1\) 逐头：每个 query 头一个标量，\(W_\theta\) 是 \(2048\times32\)，24 层约 1.57M，表 1 写 1.6M。
  • \(G_2\) 逐元素：门乘在 value 上，value 只有 4 个头、宽 512，所以是 \(2048\times512\)，24 层约 25.2M，表 1 写 25M；\(G_2\) 逐头只有 \(2048\times4\)，约 0.2M。
  • \(G_5\)：门乘在整个注意力层的输出上，宽 2048，所以是 \(2048\times2048\)，24 层约 100.7M，表 1 写 100M。
  • “各头共享”的 \(G_1\)（表 1 第 12 行）仍记 201M，因为它先按各头独立的方式算出全部分数，再在头之间取平均，参数没少。

官方代码（modeling_qwen3.py）的写法值得一提：它没有单独建一个门的线性层，而是把 \(W_\theta\) 拼进了 query 投影。逐元素门把 q_proj 的输出宽度翻倍，逐头门只多出“头数”那么几列；一次矩阵乘同时算出 query 和门分数，再按头切开。注意力算完以后，执行 attn_output * sigmoid(gate_score)，再进 o_proj。后来 Hugging Face Transformers 里 Qwen3-Next 的注意力也是这样实现的（见“后来怎么样了”）。

容易忽略的一点：\(G_1\) 的门分数由第 \(i\) 个 token 自己的 \(X_i\) 算出，也就是 query 这一侧的信息。它和别的 token 无关，所以既不需要存进 KV 缓存，也不改变注意力本身怎么算。\(G_2\) 不同：它乘在每个被看的 token \(j\) 的 value 上，门分数由 \(X_j\) 算出，是 key/value 这一侧的信息。这个区别在第 4.2 节是关键。

3 实验：15B MoE 和 1.7B 稠密模型上，哪种门最好、稳定性改善多少

这一节要回答的问题：作者用什么模型、什么数据、什么训练设置来比较 30 多个变体？在 MoE 模型上，五个位置、各种粒度和激活函数的门谁好谁坏？好处会不会只是因为“多了参数”？在稠密模型上，门对训练稳定性有什么影响，能不能让模型承受更大的学习率？

3.1 实验设置：三套模型、一份数据、同一套评测

先补一点背景：论文用的 MoE 模型是什么样的。

混合专家（MoE）模型把前馈层换成很多个小前馈网络（“专家”），每个 token 由一个路由器挑出其中几个来算，其余的不参与。这样总参数可以很大，而每个 token 实际用到的参数（激活参数）很少。论文的 MoE 模型记作 15A2B：总参数 15B，每个 token 激活 2.54B。它有 128 个专家，每个 token 用 softmax 路由选 top-8。几个配套技术：细粒度专家（DeepSeekMoE 的做法，把专家切得更小、数量更多）；全局批次负载均衡损失（global-batch LBL，Qwen 团队自己的工作，在整个全局批次上统计各专家的负载，而不是在每个小批次里统计）；z-loss（ST-MoE 提出的，惩罚路由器 logit 过大，防止数值不稳）。注意力部分用 GQA。关于 MoE 的更多背景见本站 DeepSeek-V3 精读。

3.3 稠密模型：门让训练更稳，能吃下更大的学习率

先补一点背景：损失尖峰，以及为什么大家想用大学习率和大批次。

训练大模型时，损失曲线大体平滑下降，但有时会突然往上跳一下，叫损失尖峰（loss spike）。轻的几百步后自己恢复，重的会让训练彻底发散，只能退回较早的检查点、调小学习率或跳过一些数据重新来过。在几千张 GPU 上跑的训练里，每次回退都意味着成百上千 GPU·小时白费（大规模训练系统怎么处理这类故障，见本站 MegaScale 精读）。

另一方面，人们又想用更大的学习率和批大小、更深的网络：更大的学习率往往收敛到更好的结果；更大的批次让每一步能分给更多 GPU 并行算，提高分布式训练效率；更深的网络表达力更强。可这几样恰恰都更容易引发尖峰。所以“能不能在激进的超参下稳定训练”本身就是一项很有价值的性质。

sandwich norm（三明治归一化，来自 CogView）是一种常见的稳定手段：在 pre-norm 的基础上，注意力和前馈层的输出在加回残差流之前再做一次归一化，相当于把子层夹在两次归一化中间。这样，某一层就算算出了特别大的数，也不会原样灌进残差流。

设置和对齐方式。稠密模型的实验沿用 Qwen2.5 技术报告的做法。加门时，作者把前馈层变窄，让总参数量和基线一样。本站核对了官方放出的三个 1.7B（28 层）模型的配置：基线的前馈宽度是 6144，逐元素门版本是 5504，逐头门版本仍是 6144（逐头门每层只多 \(2048\times16\) 个参数，可以忽略）。按此推算，逐元素门每层多出 \(2048\times2048\approx4.19\)M 个门参数，前馈层少了 \(3\times2048\times640\approx3.93\)M 个参数，两者基本抵消。大部分实验用的是为基线调好的超参：28 层模型训 400B token 时，最大学习率 4e-3、批大小 1024；训 3.5T token 时，最大学习率 4.5e-3、批大小 2048。

  • “更稳定”的证据有两类：一类是图 1 右的损失曲线（只有一对曲线，没有量化尖峰的次数或幅度）；另一类是两次基线发散或严重退化（第 6、12 行）。没有多个随机种子，也没有统计“多少次训练里发散了几次”。

4 分析：非线性、稀疏性，以及没有注意力汇

这一节要回答的问题：一个这么简单的门，为什么能同时提高效果和稳定性？作者的分析分四步：先说明门补上了注意力里缺的非线性（4.1）；再说明有效的门分数很稀疏、而且依赖 query（4.2）；然后说明这种稀疏性消除了超大激活和注意力汇（4.3）；最后说明没有注意力汇的模型更容易外推到长上下文（4.4）。本节用的 MoE 模型和第 3.2 节相同（15A2B，400B token），分析数据是测困惑度用的那批测试文本。

4.1 非线性：value 投影和输出投影之间缺了一层非线性

先补一点背景：两个线性层连在一起，等于一个低秩的线性层。

一个线性层就是乘一个矩阵。两个线性层连着乘，\(x\mapsto (xA)B=x(AB)\)，结果只是乘了一个新矩阵 \(AB\)，叠两层并没有比一层更强。而且如果中间那一维很窄，比如 \(A\) 是 \(2048\times128\)、\(B\) 是 \(128\times2048\)，那么 \(AB\) 虽然是 \(2048\times2048\) 的大矩阵，它的秩最多只有 128：不管输入是什么，输出都只能落在一个 128 维的子空间里。秩可以理解为“这个映射真正能独立调动的方向数”。

前馈层为什么不怕这个？因为前馈层的两个矩阵中间夹了激活函数（SwiGLU），\(\big(\phi(xW_1)\big)W_2\) 不能合并成一个矩阵。非线性让“先压窄、再展宽”的结构变成真正有表达力的网络。论文引用了 Montúfar 等人（2014）关于深层网络“线性区域数”的理论工作，来说明在两个线性映射之间加入非线性能提升表达能力。

把多头注意力里第 \(k\) 个头对第 \(i\) 个 token 的贡献写开（论文式 6）：

$$o^{k}_{i}=\Big(\sum_{j=0}^{i}S^{k}_{ij}\cdot X_{j}W_{V}^{k}\Big)W^{k}_{O}=\sum_{j=0}^{i}S^{k}_{ij}\cdot X_{j}\big(W_{V}^{k}W^{k}_{O}\big)$$

这里 \(S^k_{ij}\) 是第 \(k\) 个头里第 \(i\) 个 token 对第 \(j\) 个 token 的注意力权重，\(X_jW_V^k\) 是第 \(j\) 个 token 在这个头的 value，\(W_O^k\) 是输出投影矩阵里对应这个头的那一块（先拼接再乘 \(W_O\)，等于每个头先各乘自己那一块再相加）。因为注意力权重只是一个标量，它可以挪到前面去，于是 \(W_V^k\) 和 \(W_O^k\) 直接相乘，合并成一个 \(d_{\text{model}}\times d_{\text{model}}\) 的矩阵，秩最多是 \(d_k=128\)，远小于 \(d_{\text{model}}=2048\)。在 GQA 下，同一组里的几个 query 头还共用同一个 \(W_V\)（MoE 模型里是 8 个头共用一个），表达力更受限制。

既然缺的是非线性，就有两种补法（论文式 7、式 8）：

$$o^{k}_{i}=\Big(\sum_{j=0}^{i}S^{k}_{ij}\cdot \mathrm{NonLin}\big(X_{j}W_{V}^{k}\big)\Big)W^{k}_{O}\tag{7}$$ $$o^{k}_{i}=\mathrm{NonLin}\Big(\sum_{j=0}^{i}S^{k}_{ij}\cdot X_{j}W_{V}^{k}\Big)W^{k}_{O}\tag{8}$$

第一种在加权求和之前，对每个 value 单独做非线性，对应 \(G_2\)；第二种在加权求和之后、乘 \(W_O\) 之前做非线性，对应 \(G_1\)。这也顺带解释了为什么 \(G_5\) 没用：它在 \(W_O\) 之后，\(W_V\) 和 \(W_O\) 之间还是没有非线性。

  • 加法门的收益来自 SiLU（第 4、7 行）。加法门的门分数要先过 SiLU，这引入了一点非线性，所以它有效（5.821）；把 SiLU 去掉，变成加一个线性项，收益就缩小了（5.882）。

容易误解的地方（本站补充）：
  • 门插在 \(W_O\) 之前，所以每个头最终的输出仍然落在 \(W_O^k\) 那 128 维的行空间里，“输出只能在 128 维子空间里”这件事并没有改变。门改变的是：从输入到这 128 个系数的映射，不再是一个固定的线性映射，而会随当前 token 变化。把“缓解低秩问题”理解成“提高了秩”是不准确的。
  • 逐头门是一个说明问题的反例：它只给整个头乘一个标量，完全不改变输出的方向，非线性程度非常有限，可它的效果（5.792）几乎和逐元素门（5.761）一样好，远好于 RMSNorm（5.847）。“补非线性”解释不了这一点，下一节的“稀疏性”才是主要原因。

4.2 稀疏性：有效的门，分数大多接近 0，而且由 query 决定

作者在测试文本上统计了各种门的门分数（表 4 的“门分数”一栏是所有层的平均值）。原文图 3 画了三种门的门分数分布：SDPA 逐元素门的均值是 0.116，分布高度集中在 0 附近；value 逐元素门的均值是 0.221；各头共享的 SDPA 门均值是 0.271。三种门的大部分分数都小于 0.5，其中 SDPA 输出门最“稀疏”（原图见 原文图 3 ↗）。

结合表 4，作者得出四点：

  1. 有效的门分数是稀疏的。SDPA 输出门（逐元素、逐头）的平均门分数最低（0.116、0.172），效果也最好。
  2. 各头独立的稀疏性很重要。强制各头共享门分数后，门分数整体变高（0.271），收益也变小。这和以往的观察一致：不同的头负责输入的不同方面（有的头做指代，有的头做复制，著名的“归纳头”就是一类），它们在什么时候该“闭嘴”，自然也不一样。附录 A.5 的逐层统计也显示，共享以后大多数层的门分数都升高了。
  3. 依赖 query 很重要。value 门（\(G_2\)）的分数比 SDPA 输出门高（0.221），效果也更差。区别在于门分数由谁决定：SDPA 输出门由当前 query 的 \(X_i\) 决定，value 门由每个被看的 token 的 \(X_j\) 决定。作者的解释是，稀疏的门最好由 query 来决定，这样它才能为这一个 query 过滤掉无关的上下文。为了进一步验证，他们做了一个“与输入无关”的门：一组 \(q\times d_k\) 的可学习参数，零初始化，过 sigmoid 后乘在 SDPA 输出上。它对每个 token 都一样，只提供了非线性，没有依赖输入的稀疏性。结果它比基线好（5.917），但门分数高（0.335），远不如依赖输入的门。
  4. 不稀疏的门更差。作者把 sigmoid 换成 \(\mathrm{NS\text{-}sigmoid}(x)=0.5+0.5\cdot\mathrm{sigmoid}(x)\)，门分数被限制在 0.5 到 1 之间：非线性还在，但门再也不能把输出压到接近 0。结果收益明显变小（5.900），门分数均值 0.653。

4.3 门消除了超大激活和注意力汇

先补一点背景：注意力汇（attention sink）。

softmax 让每个 query 分给所有 key 的权重加起来必须等于 1。可是有些时候，一个头对当前 token 来说根本没有需要读的东西，最好的输出是“什么也不加”。在标准注意力里，它没法把权重总和设成 0，只能找个地方把这 1 份权重“倒掉”。训练出来的模型普遍学会了把这部分权重倒在序列的第一个 token 上：每个位置都能看到它，而模型可以让它的 value 几乎是 0，这样“看了它”就约等于“什么也没看”。StreamingLLM（Xiao 等，ICLR 2024）系统地描述了这个现象，并把这些 token 叫作注意力汇。

注意力汇对推理系统有实实在在的影响。StreamingLLM 发现，只保留最近一段窗口的 KV 时，一旦第一个 token 被挤出窗口，输出就会崩坏；额外留住开头几个 token，模型才能稳定地一直生成（详见 SnapKV 精读 §2）。NSA 选块时固定选中开头那一块，也是同样的原因（见 NSA 精读）。也就是说，很多 KV 缓存的淘汰、压缩策略都得给注意力汇“开特例”。

先补一点背景：超大激活（massive activation），以及它们为什么让量化变难。

Sun 等人（2024）发现，LLM 残差流里有极少数数值大得离谱的激活：它们只出现在固定的几个维度上，只出现在少数几个 token 上（第一个 token、句号或换行这类分隔符），数值比中位数大几个数量级，而且几乎不随输入内容变化，像是模型内部的一组固定偏置。他们还发现，这些 token 正是吸走大量注意力的 token，两种现象紧密相关。论文表 4 的 M-Act 一栏度量的就是它：基线模型每层隐状态最大值的平均是 1053。

超大激活对低精度很不友好，原因和 QuaRot 精读 §1 讲的离群值一样：对称量化的刻度由一组数里绝对值最大的那个决定。举个例子（推算）：用 INT8 对一组激活做逐张量量化，刻度 \(s=\max|x|/127\)。如果这组数里有一个 1053，\(s\approx8.29\)，那么幅度在 1 左右的普通激活全部被舍成 0；如果最大值是 94，\(s\approx0.74\)，幅度 1 的激活被量化成 1，误差 0.26。逐 token 量化能把这个问题局限在那几个 token 的那一行里，但那一行本身照样量不准；而 KV 缓存量化（见 KIVI 精读 §4.1）还要面对 key 里固定通道的离群值。后来的一些量化工作干脆把这些“枢纽 token”的 KV 单独留成全精度（例如 IntactKV）。

训练时也一样。BF16 只有 8 位有效数字（7 位尾数加隐含的 1），在 512 到 1024 之间，相邻两个可表示的数相差 4（推算：\(512\times2^{-7}=4\)）。如果残差流里某一维已经是 1000 左右，再往上加一个大小为 1 的更新，在 BF16 里就被舍掉了。论文引用 Budzinskiy 等人（2025）的数值误差分析，认为超大激活会让 BF16 训练更容易受数值误差影响。

第 4.2 节的发现是：门以依赖输入的方式给 SDPA 输出带来了稀疏性。作者由此假设：这种机制能为当前 query 过滤掉无关的上下文，于是模型不再需要注意力汇。会议版还补充了一个旁证：更早的一项工作（Explicit Sparse Transformer，Zhao 等，2019；Junyang Lin 是作者之一）发现，在只看 top-k 个最相关 token 的显式稀疏注意力里，注意力汇不会出现。为了验证，作者统计了两样东西：分给第一个 token 的注意力比例（F-Attn），以及各层隐状态最大激活值的平均（M-Act）。

  1. 依赖 query、各头独立的 SDPA 输出门（逐头和逐元素），把第一个 token 的注意力从 0.467 压到 0.048–0.073，M-Act 也从 1053 降到 94–98。

作者据此得出结论：依赖输入、各头独立的 SDPA 输出门带来了显著的稀疏性，从而缓解了注意力汇；SDPA 输出越稀疏，模型里的激活就越小。这也可能解释了门为什么让训练更稳定：超大激活少了，BF16 训练中的数值误差影响就小了。

超大激活从哪里来。作者还看了它们在网络里是怎么产生和传播的（会议版附录 A.4，arXiv 版 A.3，附录图 6）。在基线模型里，第 6 层（正文写“例如第 5 层”，可能是从 0 还是从 1 开始数的差别）的前馈层输出了超大的值，这些值被加进残差流后，就一路留在后面所有层的残差里；与此对应，从第 6 层开始出现明显的注意力汇。加门之后，前面几层的输出整体都很小，最大激活随层数逐渐增长（量级在几百以内），任何一层都没有明显的注意力汇。value 门的模型超大激活和 SDPA 门差不多，但仍有一定程度的注意力汇；各头共享和 NS-sigmoid 两个变体，超大激活和注意力汇都和基线相当。附录图 6 里 NS-sigmoid 模型的第一个 token 注意力均值标的是 0.481，而表 4 写的是 0.451，两处数字不一致。

这条传播路径也解释了表 2 里 sandwich norm 为什么能稳定训练：前馈层的输出先归一化，大值就进不了残差流。但附录 A.6 的截断实验（第 3.3 节）表明，单纯把残差流里的值截断并不能解决不稳定，所以“超大激活导致训练不稳定”只是一个可能的解释，不是被证实的因果关系。

会议版还新增了附录 A.7：如果不是从头训练，而是在一个已经训好的模型上继续训练时才加门，那么门既消除不了已经存在的超大激活和注意力汇，对最终效果也没什么影响。作者认为，门的作用主要体现在它对训练动态的影响上，所以对不是从头训练的模型作用有限。

这一节的结论要打几个折扣：
  • “没有注意力汇”是按第一个 token 分到的注意力来度量的。Sun 等人发现超大激活也会出现在句号、换行等分隔符上，这些位置的注意力论文没有统计。
  • 论文只测了激活的大小，没有做任何量化实验。“M-Act 从 1053 降到 94，所以更好量化”是合理的推论，但在这篇论文里没有被验证；最接近的证据来自 Quantizable Transformers（第 5 节），那是在 BERT、ViT 这样的编码器模型上做的。
  • “超大激活不是注意力汇的必要条件”这个结论来自两个变体（value 门和各头共享的门）。会议版 §5.2 把这句话写成了“超大激活是注意力汇的必要条件”，和 §4.3、附录 A.4 以及 arXiv 版都矛盾，应当是笔误。
  • 附录 A.7 意味着这个改动没法改装到现有模型上：想要没有注意力汇的模型，得从预训练开始就带着门。

4.4 没有注意力汇，长上下文外推更好

先补一点背景：RoPE 的底数、YaRN 和 RULER。

RoPE 把位置编码成 query、key 各维度上的旋转角度，不同维度转速不同，转速由一个“底数”（base）控制（见 RoFormer 精读）。模型在 4K 长度上训练后，想处理更长的输入，常见的做法分两步。第一步是把底数调大（论文从 10,000 调到 1,000,000），让各维度转得更慢，再用长文本继续训练一段。第二步是在推理时用 YaRN 这类方法按频率对 RoPE 做插值缩放，不再训练就把可用长度再拉长几倍（插值、NTK 与 YaRN 的原理见 RoFormer 精读 §10.2）。这样外推的代价是：模型看到的位置角度和训练时不一样了，原来学到的注意力模式未必还能照常工作。

RULER（Hsieh 等，2024）是一个合成的长上下文评测，包含多种“大海捞针”式检索、多跳追踪、信息聚合和问答任务，可以把输入拉到任意指定长度，报告平均准确率（百分制）。它比困惑度更能反映模型在长输入里能不能准确找到信息。

实验设置。作者拿训练了 3.5T token 的基线和加门模型，把 RoPE 底数从 10K 调到 1M，用 32K 长度的数据继续训练 80B token，得到上下文长度 32K 的模型；再用 YaRN 把上下文扩展到 128K（不再训练）。两个模型经历的续训数据和步骤完全相同。论文没有明说用的是哪个模型：正文报告过 3.5T token 训练结果的只有第 3.3 节的 28 层 1.7B 稠密模型，但引言又说稠密和 MoE 模型都训到了 3.5T token，所以无法确定。

  • 只用了 RULER 一个基准，而且只测了一对模型；“提高 10 分以上”指的是 64K、128K 这两档，32K 以内几乎没差别。

4.5 结果的份量（第 3、4 节合起来看）

把第 3、4 节的数字放在一起，下面几点决定了它们能说明多少问题。

对齐做得比多数架构论文认真。MoE 的每组比较都用同样的数据、同样的 400B token、同一套学习率计划和批大小；为了排除“多了参数”的解释，专门加了三个扩参数的对照，其中 q=48 和逐元素 \(G_1\) 门新增的参数一样多、而且都在注意力里。稠密模型通过收窄前馈层对齐了参数量，超参是为基线调的，这对基线有利。最有说服力的一点是：逐头的 \(G_1\) 门只多了 1.6M 参数、几乎不增加计算，效果仍排第二。

但统计上的把握有限。每个设置只训了一次，没有误差棒。主效应（加门后困惑度更低）在 MoE 和稠密、400B 和 3.5T token 的每组比较里方向都一致，可信度较高；注意力汇和超大激活的具体数字则只在 MoE 模型上给出。变体之间 0.01–0.06 的困惑度差别（比如逐元素和逐头、sigmoid 和 SiLU），单靠这些实验分不清是不是噪声。下游任务里 HumanEval 这类小测试集的波动尤其大。

规模停在“中等”。大部分消融在 15A2B 上只训了 400B token；正文给出 3.5T token 结果的只有 28 层的 1.7B 稠密模型（基线与逐元素门各一个）；“稳定性”的证据是一对损失曲线和两次基线发散。更大规模上的证据来自 Qwen3-Next 和 Qwen3.5 的采用（见“后来怎么样了”），但那是产品决策，没有公开对应的消融。

机制分析是相关性，不是因果。门分数、F-Attn、M-Act 都是在 MoE 模型、困惑度测试文本上统计的，七个变体七个点；“稀疏性消除了注意力汇”“超大激活不是注意力汇的必要条件”都是从这几个点读出来的。“超大激活导致训练不稳定”被附录 A.6 的截断实验部分否定了，作者自己也说根本原因需要进一步研究。

效率数字几乎没有细节。“墙钟时间开销不到 2%”没有说明硬件、内核、是训练还是推理、哪个模型；论文没有测任何推理延迟或吞吐。第 7 节会按参数量估一下推理时的额外开销（推算）。

5 相关工作：门的来历，以及“去掉注意力汇”的几条路

这一节要回答的问题：在注意力上加门，以前有没有人做过？和这篇论文最接近的是哪项工作，区别在哪？关于注意力汇，前人有哪些解释、提出过哪些消除它的办法？这些办法从系统实现的角度看有什么不同？

门控机制的谱系。LSTM 和 GRU 用门控制每个时间步保留和丢弃的信息，从而缓解梯度消失和爆炸；Highway Network 把门推广到前馈网络，让很深的网络也能训练；SwiGLU 把门引入 Transformer 的前馈层，成为开源大模型的标准部件。状态空间模型（Mamba 系列）和线性注意力（FLASH、RetNet、Lightning Attention、Gated DeltaNet）都用门来调节 token 混合模块的输出。直接在 softmax 注意力输出上加门的工作也有：AlphaFold2（会议版新增的引用）和 Forgetting Transformer；GaAN 在图学习里用门控制每个注意力头的重要性；Attention on Attention（图像描述）用一个依赖 query 的 sigmoid 门调节注意力输出。Switch Heads、NSA、MoSA 用 sigmoid 门做“选择”。作者的观点是：这些工作展示了门的效果，却没有说清楚门为什么有效；那些以“选择”为卖点的方法，最好和“带同样门的标准 Transformer”比一比，才能看出选择机制本身贡献了多少。

先补一点背景：Quantizable Transformers，和这篇论文最接近的工作。

Bondarenko、Nagel、Blankevoort（高通，NeurIPS 2023）的论文副标题是“帮助注意力头什么也不做，从而去掉离群值”。他们研究 BERT、ViT 这类编码器为什么难以量化，发现激活里的极端离群值来自注意力头想要“不更新”时的行为：为了让某个头对当前 token 几乎不产生输出，模型把注意力集中到分隔符、背景图块这类信息量很低的 token 上；而要让 softmax 把几乎全部权重压到一个 token 上，就需要极大的注意力 logit，这又反过来要求残差流里出现极大的数。他们提出两种改动让头可以直接“什么也不做”：一种是允许输出精确 0 和 1 的截断 softmax，另一种就是在注意力输出上加门。这样训出来的模型离群值明显变少，更容易量化。

本文作者自己的定位是：Quantizable Transformers 主要是为了量化去离群值；本文则系统比较了各种门的变体，揭示门通过非线性和稀疏性起作用、并改善训练稳定性，还把门控注意力放大到 15B MoE、3.5T token 的规模上验证。值得注意的是，两篇论文对机制的解释几乎一样（“头需要一种不发言的方式”），只是一个从量化出发，一个从效果和稳定性出发。

关于注意力汇的研究。StreamingLLM 正式提出了注意力汇；在视觉 Transformer 里，Darcet 等人发现一些冗余的图块被模型当作“寄存器”来存放多余的注意力，于是干脆加入专门的寄存器 token；Massive Activation 一文说明这些吸走大量注意力的 token 带有超大激活；Gu 等人把注意力汇刻画为不携带信息的“key 偏置”，认为是 softmax 的归一化迫使模型这样做。本文补充的一点是：value 门消除了超大激活，注意力汇却还在，所以超大激活不是注意力汇的必要条件。

6 结论与局限

这一节要回答的问题：作者怎么总结这项工作？他们承认哪些地方还没弄清楚？

作者的总结是：这项工作系统地研究了 softmax 注意力里的门控机制，揭示了门对效果、训练稳定性和注意力动态的显著影响。在 SDPA 之后加一个 sigmoid 门这样简单的改动，增强了非线性，引入了依赖输入的稀疏性，并消除了注意力汇；它还帮助模型在不重新训练的情况下扩展上下文长度。作者承诺放出“没有注意力汇”的模型，作为后续研究注意力机制的基础（模型已经放在 Hugging Face 上，见“影响力”）。

作者承认的局限有两条：非线性对注意力动态和整个训练过程更广泛的影响，还没有充分研究；虽然观察到消除注意力汇能改善长上下文外推，但没有给出注意力汇如何影响长度泛化的严格理论解释。本站在第 4.5 节补充了另外几条：单次运行没有误差棒、规模停在 15B MoE / 1.7B 稠密、效率数字缺少细节、和量化及 KV 缓存相关的好处没有直接测试。

7.1 实现：内核不动，KV 缓存不变

x_i（pre-norm 之后）→q_proj（加宽一倍）一次矩阵乘同时得到 query 和门分数，每个头的两部分相邻存放→切开：query ｜ gate

本站根据 Hugging Face Transformers 的 Qwen3NextAttention 和论文官方代码整理。官方代码同样把门拼进 q_proj，只是按 KV 组排列。

从系统实现看，SDPA 输出门有三个很“省心”的性质：

  • 注意力内核一行都不用改。门在 SDPA 之后才乘上去，所以 FlashAttention、PagedAttention、各种稀疏或分块的注意力内核都能原样使用。这和第 5 节表里“改 softmax”那一类方法形成鲜明对比，后者要改在线 softmax 的逻辑，每个推理引擎都得重写内核。
  • KV 缓存不变。门分数只由当前 token 的 \(X_i\) 算出，不需要缓存，也不改变 key、value 的形状。解码时每一步只为新 token 算一次门。
  • 张量并行时没有额外通信。Megatron 式的张量并行按头切分注意力：q_proj 按列切，o_proj 按行切。门的列和它所属的头放在一起（官方代码按 KV 组交错，Hugging Face 的 Qwen3-Next 实现按头交错），所以按头切分时门会自然地跟着头走，乘门这一步在每张卡上本地完成。

要多花多少（推算）。门的代价主要是 q_proj 多出来的那部分权重：

  • 论文的 15A2B MoE 模型：逐元素门 24 层共 201M 参数，全部是每个 token 都要用的“激活参数”，约为 2.54B 激活参数的 8%。如果按“批大小 1 的解码主要受读权重的带宽限制”粗算（忽略 KV 缓存的读取），每一步要多读约 8% 的权重字节。逐头门只有 1.6M 参数，可以忽略。
  • Qwen3-Next-80B-A3B：只有 12 层是门控注意力，每层门的参数是 \(2048\times(16\times256)\approx8.39\)M，合计约 101M，相对约 3B 的激活参数大约是 3%。
  • 论文说的“墙钟时间开销不到 2%”没有说明场景，很可能是训练时的测量；训练和长上下文推理时，注意力本身的计算量很大，门那一点矩阵乘的占比会更小。

所以在乎解码延迟的场景，逐头门是一个几乎零成本的选项，而它的效果只比逐元素门差一点（表 1：5.792 对 5.761）。Qwen3-Next 和 Qwen3.5 选的是逐元素门。

7.2 训练：稳定性就是算力

在几千张卡上训练时，一次发散或一次需要回退的损失尖峰，可能浪费成百上千 GPU·小时。论文的稠密实验表明，加门的模型在基线会发散的学习率（8e-3）下仍能收敛，而且大学习率反而带来更好的结果；这意味着同样的算力预算可以用更激进的超参。两点限制：一是附录 A.7 说明门必须从头训练时就加上，继续训练时才加没有用；二是稳定性的证据只来自 1.7B 稠密模型的少数几次训练（第 3.3 节）。

7.3 量化和低精度：值得期待，但这篇论文没测

QuaRot、KIVI 这些量化方法花了很大力气对付离群值：QuaRot 用 Hadamard 旋转把离群值摊平（QuaRot 精读），KIVI 让 key 按通道量化（KIVI 精读），还有一些方法专门把开头几个“枢纽 token”的 KV 留成全精度。这些麻烦有相当一部分来自注意力汇和超大激活。加门之后 M-Act 从 1053 降到 94、第一个 token 的注意力从 47% 降到 5%，按第 4.3 节的推算，激活的量化刻度能细一个数量级。这让人有理由期待门控注意力的模型更容易做 W8A8、FP8 甚至更低比特的推理和训练。但要强调：这篇论文没有任何量化实验，KV 缓存里 key 的通道离群值（KIVI 讨论的那一种）是否也会减少，论文也没有测。这方面的直接证据目前来自 Quantizable Transformers 在编码器模型上的结果。

7.4 KV 缓存与长上下文

StreamingLLM 式的 KV 淘汰必须保留开头几个 token，NSA 选块时固定选中开头那一块，都是在给注意力汇“开特例”。一个没有注意力汇的模型，理论上不再需要这些特例，KV 淘汰和稀疏注意力的策略可以更简单。不过这同样只是推论：论文没有测试任何 KV 淘汰或压缩方法在门控模型上的表现。论文实际测到的是第 4.4 节的结果：没有注意力汇的模型在免训练的 YaRN 外推下掉分少得多。对于长上下文服务来说，这意味着模型在超出训练长度时更“耐用”。

7.5 在混合架构里的位置

Qwen3-Next 和 Qwen3.5 把门控注意力和 Gated DeltaNet 按 1:3 混合：每 4 层里只有 1 层是 softmax 注意力。Gated DeltaNet 层的状态大小固定，不随上下文变长；只有那 1/4 的门控注意力层带着随长度增长的 KV 缓存，负责精确地回看任意位置。所以在这种架构里，门控注意力层既是长上下文能力的关键，也是 KV 缓存和注意力计算开销的主要来源；门让这几层更稳、没有注意力汇，而且不增加它们的 KV 缓存。Gated DeltaNet 层自己的输出上也有一道门（RMSNorm 之后乘 SiLU(z)），两种层都带门，这大概不是巧合。

NeurIPS 2025：Oral 和最佳论文奖

论文被 NeurIPS 2025 接收为 Oral（官方仓库的说明是：5,290 篇录用论文中的 77 篇）。2025-11-26，NeurIPS 宣布了 4 篇最佳论文和 3 篇亚军，这篇是最佳论文之一。评选委员会的评语大意是：论文用 30 多个大规模实验说明，在 SDPA 之后加一个各头独立的 sigmoid 门，能在稠密和 MoE 模型上稳定地提升效果，同时改善训练稳定性、减少注意力汇、帮助扩展上下文；这个建议很容易实现，预计会被广泛采用；委员会还特别称赞了在大模型研究越来越不公开的环境下，作者用工业级算力做实验并公开分享结果。

Qwen3-Next：3:1 混合架构里的门控注意力

2025-09，Qwen 团队发布 Qwen3-Next-80B-A3B。按 Hugging Face 上的模型卡：总参数 80B，每个 token 激活约 3B；48 层，排列方式是 12 组“3 层（Gated DeltaNet → MoE）+ 1 层（门控注意力 → MoE）”；门控注意力有 16 个 query 头、2 个 KV 头，头维度 256，只有 64 维做旋转位置编码；MoE 有 512 个专家，每个 token 激活 10 个，外加 1 个共享专家；原生上下文 262,144，可扩展到约 100 万 token。Transformers 里的实现正是本文的逐元素 SDPA 输出门：q_proj 输出加宽一倍，切出 query 和门，注意力算完乘 sigmoid(gate) 再进 o_proj。模型卡还提到另一项稳定性措施：零中心、带权重衰减的层归一化（实现里 RMSNorm 的缩放参数初始化为 0、使用时加 1）。Qwen 的发布文章称，注意力输出门帮助消除了注意力汇和超大激活等问题，保证了模型的数值稳定（本站未能直接打开官方博客页面，这句依据 AINews 对发布文章的摘录）。

模型卡给出的整体收益是：Qwen3-Next-80B-A3B-Base 在下游任务上超过 Qwen3-32B-Base，训练成本只有后者的 10%，上下文超过 32K 时推理吞吐是后者的 10 倍。要注意，这是整套架构（线性注意力混合、高稀疏 MoE、多 token 预测等）的结果，不是门控注意力单独的贡献。Gated DeltaNet 的原理见 Gated DeltaNet 精读和旧版结构拆解。

Qwen3.5：进入旗舰系列

2026-02 发布的 Qwen3.5 沿用了这套解码器。以旗舰 Qwen3.5-397B-A17B 为例（模型卡与 config.json）：60 层，排列为 15 组“3 层 Gated DeltaNet + 1 层门控注意力”，门控注意力有 32 个 query 头、2 个 KV 头，头维度 256，旋转位置编码 64 维，配置里 attn_output_gate 为 true；原生上下文 262,144。同系列的稠密模型也一样：Qwen3.5-27B 有 64 层，其中 16 层是门控注意力（24 个 query 头、4 个 KV 头）；Qwen3.5-9B 有 32 层，其中 8 层是门控注意力；两者配置里的 attn_output_gate 都是 true（本站查阅 config.json）。更多 Qwen3.5 架构的讨论见旧版 Gated DeltaNet 拆解的 Q25。

Kimi Linear：线性注意力层也用 sigmoid 输出门

月之暗面的 Kimi Linear（2025-10，见 Kimi Linear 精读）在它的线性注意力层 KDA 的输出上，先做逐头 RMSNorm，再乘一个依赖数据的 sigmoid 门，然后才进输出投影；门的投影矩阵做成低秩的，以便和其他设计在参数量上公平比较。论文明确引用了本文，说这样的门在效果上和满秩的门相当，还能缓解注意力汇。它的消融（表 1，训练与验证困惑度）显示：默认的 sigmoid 输出门验证困惑度 5.65；去掉输出门是 5.67；把 sigmoid 换成 swish（Gated DeltaNet 原来的选择）是 5.81，明显更差。他们说这和本文“sigmoid 门更好”的结论一致。这是一个来自其他团队、在不同层类型（线性注意力而不是 softmax 注意力）上与本文结论方向一致的公开消融，不过有门和没门的差距（5.65 对 5.67）很小。

另一条路：gpt-oss 的可学习汇

OpenAI 在 2025-08 开源的 gpt-oss 走了第 5 节表里的第二条路：模型卡写明，每个注意力头在 softmax 的分母里有一个可学习的偏置，类似“softmax 加一”和注意力汇，让注意力可以完全不关注任何 token。会议版的相关工作把它列为“可学习的汇”。两种做法要解决的是同一个问题（让头能“不发言”），区别在于：门在 softmax 之后按 query 调节输出，不碰内核；可学习汇改的是 softmax 的分母，需要注意力内核支持。哪种更好，截至 2026-10 本站没有查到在同等规模下的公开对比。

官方仓库在 2025-12-20 的更新里预告会补充更多关于门为什么有效的分析和可视化。截至 2026-10-20，本站没有查到其他团队在相近规模上对 softmax 注意力输出门做的完整公开复现。
