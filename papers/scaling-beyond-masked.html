0 导读：这篇论文解决什么问题

扩散语言模型不像自回归（AR）模型那样一个词一个词地往后写，而是先放一张“全是噪声”的草稿，再分几轮把整段文字一起改清楚。离散扩散里最常见的一种叫掩码扩散：加噪就是把词换成 [MASK]，生成就是一轮轮把 [MASK] 填回去。掩码扩散在困惑度上一直领先其他离散扩散，LLaDA、Dream 这些大规模扩散语言模型也几乎都用它，它慢慢成了“扩散语言模型”的默认做法。

这篇论文想检验的正是这个默认做法。作者认为，困惑度只是选型的一个维度，而且是在不同扩散族之间并不可比的一个维度：每一族报告的都是自己的前向过程推出来的似然上界，上界松紧本身就不一样；困惑度也完全不反映生成时的行为，比如能不能少步生成、能不能用 KV 缓存。为此，作者在同样的训练算力下，把四类模型放在一起比：自回归、掩码扩散（MDLM）、均匀态扩散（Duo，加噪是把词随机换成词表里任意一个词）、插值扩散（Eso-LM，在自回归与掩码扩散之间插值，支持 KV 缓存）。

论文的主要结果有四条。第一，三族扩散的损失随算力下降的“斜率”和自回归差不多，但“常数”差得很大：要达到自回归的验证损失，MDLM 约需 14–16 倍算力，Duo 约 23 倍，Eso-LM 约 32 倍；三族的计算最优模型都比自回归小一半左右。第二，把 MDLM 的训练损失换成一个不加时间权重的简单交叉熵，算力效率提高约 12%。第三，在“速度—质量前沿”上，自回归样本质量最好但最慢，吞吐量更高的区间则由 Duo 和 Eso-LM 占据。第四，四族模型都扩到 17 亿参数、各训 2.1 万亿 token 之后，自回归在六个按似然打分的基准上全面领先；在 GSM8K 上做监督微调后，验证困惑度更差的 Duo 拿到 65.8%，超过自回归的 62.9% 和 MDLM 的 58.8%。

这些结论各自有前提：前沿上的扩散模型样本质量全都明显差于自回归；GSM8K 上所有模型都是一次只写一个 token、从左到右生成，根本没用到扩散的并行能力；扩展律只在 \(6\times10^{18}\) 到 \(10^{20}\) FLOPs 这段约 1.2 个数量级的小算力上拟合。本页会在 3.4 和 4.3 两处专门把这些条件摆出来。

1 引言：掩码扩散是唯一的方向，还是暂时领先

这一节要回答的问题：扩散语言模型的研究者通常用验证困惑度来选方法、做扩展律分析。作者认为这个做法对扩散模型不够用。那么困惑度到底漏掉了什么？为什么在不同的扩散族之间比困惑度会误导？如果不只看困惑度，掩码扩散还是不是最好的选择？
先补一点背景：困惑度，以及扩散模型为什么只能报一个上界。

困惑度（perplexity，PPL）是语言模型最常用的指标：把模型给真实文本每个 token 的平均负对数概率取指数。直观地说，PPL = 20 表示模型平均在 20 个候选里犹豫，越低越好。对数刻度上的“平均每个 token 的负对数概率”就是验证损失（单位 nats/token），损失 2.37 对应 PPL ≈ 10.7（推算：\(e^{2.37}\)）。

自回归模型能精确算出这个数：它把一句话的概率拆成“每个词在前文条件下的概率”的连乘，每一项都由网络直接给出。扩散模型做不到这一点。它生成一句话要走过许多条“加噪轨迹”的反方向，一句话的真实概率要对所有可能的轨迹求和，这个和算不出来。所以扩散模型训练和评测时用的是证据下界（ELBO）：对数似然的一个下界，取负号就是负对数似然的上界（论文记作 NELBO）。代入 PPL 公式，得到的是一个困惑度上界：真实困惑度只会比它低，不会比它高。推导细节见 SEDD 精读 3.3 和 MDLM 精读 2.1。

关键在于：上界和真实值之间差多少，取决于用的是哪一种前向加噪过程，也取决于网络本身。掩码扩散、均匀态扩散、插值扩散的前向过程不同，推出来的上界形式也不同。

论文的引言围绕这个问题展开，理由有三条。

  • 困惑度不反映生成时的行为。掩码扩散的长处在“推理时多花算力”：采样步数加多、允许把已经写下的词重新遮住再写（例如 ReMDM，Wang 等 2025），质量会稳定变好。均匀态扩散的长处在“少步”：Duo 经过一致性蒸馏后用 8–16 步就能生成可用的文本（见 Duo 精读）。这两种能力都不会体现在验证困惑度里。
  • 不同族的困惑度本来就不可比。上面的示意图说的就是这件事：每一族报告的是自己的上界，上界最低的那一族，不一定是实际用起来最好的那一族。
  • 已经有反例。均匀态扩散的困惑度落后于掩码扩散，但换上更好的采样器之后，它在可控生成（UDLM，Schiff 等 2025）、甚至无条件生成（Duo，以及 Duo 第二章 Ψ-samplers，Deschenaux 等 2026）上都能超过掩码扩散。

在这篇论文之前，扩散语言模型的扩展律研究几乎都只看掩码扩散，最常被引用的是 SMDM（Nie 等 2025a，见 拆解页），结论是掩码扩散要达到自回归的验证损失约需 16 倍算力。这个“16 倍”常被拿来说明扩散模型训练效率低，而均匀态和插值两族连这样一个参照数都没有。所以本文要做的第一件事，就是在同一套设置下把三族都量一遍。

于是作者提出的问题是：掩码扩散是非自回归离散生成的主导范式，还是只是一个更大设计空间里暂时领先的那个？为了回答它，论文挑了三族离散扩散各自最强的代表：掩码扩散选 MDLM（困惑度最好），均匀态扩散选 Duo（少步生成好、适合做引导），插值扩散选 Eso-LM（支持 KV 缓存，解码快）。三者恰好都出自第一作者 Sahoo 参与的工作。

论文列出的贡献有四条：第一次给均匀态扩散（Duo）和插值扩散（Eso-LM）做系统的 IsoFLOP 扩展律研究；证明用一个低方差的训练目标能提高 MDLM 的算力效率，并让计算最优的模型变小；说明困惑度在同一族内有参考价值、跨族可能误导，并用速度—质量前沿展示这一点；把所有方法扩到 17 亿参数，显示均匀态扩散在似然基准上“仍有竞争力”，在微调后的数学推理上最好。

读的时候容易混淆的一点：“插值”（interpolating）这个词在论文里有两个意思。2.2 节说的“插值前向核”，指每个位置的加噪分布是“干净 token”和“一个固定先验”的线性组合，掩码扩散和均匀态扩散都属于这一类。而“插值扩散”（interpolating diffusion）专指 Eso-LM 这一族，意思是在自回归和掩码扩散两种生成方式之间插值。本页用“插值扩散”时只指后者。

2 背景：四类模型各自怎么建模、怎么训练

这一节要回答的问题：后面的扩展律要在同一套骨干网络上比较四类模型，那么这四类模型的数学定义有什么不同？各自的训练目标是什么？论文还在这一节交代了一个后面要用到的小改动：MDLM 训练时去掉时间权重。这个改动为什么能降低方差？

2.1 自回归模型：精确似然，逐词生成

自回归模型把一句话的对数概率写成每个位置在前文条件下的对数概率之和：

$$\log p_{\theta}(\mathbf{x})=\sum_{\ell=1}^{L}\log p_{\theta}\big(\mathbf{x}^{\ell}\mid\mathbf{x}^{<\ell}\big)$$

每一项由一个因果 Transformer 直接给出，所以似然是精确的。代价是生成必须一个一个来：生成长度为 \(L\) 的文本需要 \(L\) 次网络调用（NFE）。它的实用优势是 KV 缓存：因果注意力下，前面位置的 key 和 value 不会因为后面的词而改变，可以存下来复用，每一步只算新词那一行（KV 缓存的来龙去脉见 vLLM 精读 2.2）。论文给每一族都配了一个“优点 / 缺点”框，自回归的是：困惑度在所有语言模型里最好；天生串行，无法并行生成。

2.2 离散扩散的共同框架：每个位置独立地往一个先验里混

离散扩散定义一个前向加噪过程，把干净序列 \(\mathbf{x}\) 逐渐变成一个简单的先验分布，再学一个反向过程把先验变回数据。时间 \(t\in[0,1]\)，\(t=0\) 是干净数据，\(t=1\) 是纯噪声；每个位置独立加噪。本文考虑的加噪方式都是同一个形式：

$$\mathbf{z}_t^{\ell}\sim q_t\big(\cdot\mid\mathbf{x}^{\ell}\big)=\operatorname{Cat}\Big(\cdot\,;\ \alpha_t\,\mathbf{x}^{\ell}+(1-\alpha_t)\,\boldsymbol{\pi}\Big)$$

读法：在时刻 \(t\)，第 \(\ell\) 个位置以概率 \(\alpha_t\) 保持原词，以概率 \(1-\alpha_t\) 从先验 \(\boldsymbol{\pi}\) 里重新抽一个词。\(\alpha_t\) 叫噪声调度，从 \(\alpha_0\approx1\) 单调降到 \(\alpha_1\approx0\)，最常用的是线性调度 \(\alpha_t=1-t\)。先验 \(\boldsymbol{\pi}\) 选什么，决定了是哪一族：

2.2.1 掩码扩散（MDLM），以及去掉时间权重的低方差损失

前向与反向。掩码扩散取 \(\boldsymbol{\pi}=\mathbf{m}\)（[MASK] 的 one-hot），随着 \(t\) 增大，越来越多的词被换成 [MASK]，没被换掉的词保持不变。反向一步（从 \(t\) 退到更早的 \(s\)）的真实后验有一个很方便的形式：如果某个位置已经不是 [MASK]，它就固定不动；如果还是 [MASK]，它要么继续保持 [MASK]，要么变回干净词。训练时用一个双向 Transformer \(\mathbf{x}_{\theta}\) 预测每个位置的干净词分布，把后验里未知的 \(\mathbf{x}\) 换成这个预测，就得到反向模型。负的证据下界是：

$$\mathcal{L}^{\text{MDLM}}_{\text{NELBO}}(\mathbf{x})=\mathbb{E}_{t\sim\mathcal{U}[0,1],\,q_t}\Big[\frac{\alpha'_{t}}{1-\alpha_t}\sum_{\ell\in\mathcal{M}(\mathbf{z}_t)}\log\big\langle\mathbf{x}_{\theta}^{\ell}(\mathbf{z}_t),\mathbf{x}^{\ell}\big\rangle\Big]\qquad\text{（式 7）}$$

这里 \(\mathcal{M}(\mathbf{z}_t)\) 是被遮住的位置，\(\log\langle\mathbf{x}_{\theta}^{\ell},\mathbf{x}^{\ell}\rangle\) 是模型给正确词的对数概率。所以它就是“只在被遮住的位置上算交叉熵，再乘一个随时间变化的权重”（推导见 MDLM 精读 3.6）。论文给掩码扩散的优缺点是：离散扩散里困惑度最好；双向注意力让它用不了 KV 缓存。

权重的问题。线性调度下 \(\alpha_t=1-t\)，\(\alpha'_t=-1\)，权重 \(\alpha'_t/(1-\alpha_t)=-1/t\)；连同对数概率的负号，每个被遮 token 的交叉熵被乘上 \(1/t\)。当 \(t\to0\) 时，权重趋于无穷。Eso-LM 论文（Sahoo 等 2025b）注意到了这一点，提出只在训练时把这个比值换成常数 \(-1\)：

$$\mathcal{L}^{\text{MDLM}}_{\text{low-var}}(\mathbf{x})=-\,\mathbb{E}_{t\sim\mathcal{U}[0,1],\,q_t}\Big[\sum_{\ell\in\mathcal{M}(\mathbf{z}_t)}\log\big\langle\mathbf{x}_{\theta}^{\ell}(\mathbf{z}_t),\mathbf{x}^{\ell}\big\rangle\Big]\qquad\text{（式 8）}$$

也就是一个普通的、不加权的“被遮位置交叉熵”，和 MaskGIT 的训练损失一样。

示意图：两种损失给每个被遮 token 的权重（线性调度，本站按公式画）

为什么去掉权重能降低方差。训练时每条序列随机抽一个 \(t\)。抽到很小的 \(t\) 时，只有约 \(t\) 比例的位置被遮住，参与损失的 token 很少，但每个都被乘上很大的权重 \(1/t\)；这几个 token 预测得好不好带有很大的偶然性，乘上大权重后，这一步的损失和梯度就会大起大落。按期望算，时刻 \(t\) 大约有 \(tL\) 个被遮 token：真 ELBO 下它们的权重加起来约为 \(tL\times1/t=L\)，低方差版本下是 \(tL\times1=tL\)（推算）。也就是说，真 ELBO 给每个噪声水平分到同样多的总权重，小 \(t\) 那一端的这份权重全压在少数几个 token 上，所以噪声很大；低方差版本让被遮 token 多的时刻权重更大，每一步的梯度更稳定。代价是式 (8) 不再是似然的界，所以论文只在训练时用式 (8)，评测仍然用式 (7) 的真 ELBO。

算一个例子（推算）。取一条长 2048 的序列。抽到 \(t=0.01\) 时，平均只有约 20 个位置被遮，真 ELBO 给每个位置乘 100；抽到 \(t=0.5\) 时，约 1024 个位置被遮，每个乘 2。两种情况下权重之和都约是 2048，但前者的损失只由 20 个 token 决定：这 20 个词恰好好猜还是难猜，会让这一步的损失相差好几倍。一个 batch 里各条序列的 \(t\) 是随机抽的，总有几条抽到很小的 \(t\)，它们就成了梯度噪声的主要来源。换成权重恒为 1 以后，\(t=0.01\) 的那条序列总权重只有约 20，对这一步更新的影响很小。

这样做相当于改变了“哪些噪声水平更受重视”，训练出来的模型在真 ELBO 上未必更优；它是否真的更好，只能看评测时的真 ELBO。这和 BD3-LM 精读 6.1 讲的“避开极端掩码率以降低方差”是同一类考虑；而 LLaDA 训练时保留了 \(1/t\) 权重。

论文指出，式 (8) 这种损失在 MaskGIT（Chang 等 2022）和离散流匹配（Gat 等 2024）里就用过，但第一次指出它在算力效率上的实际好处的是 Eso-LM 论文。本文第 3 节会量出这个好处有多大。

2.2.2 均匀态扩散（Duo）：能改字，但似然更难学

前向过程。均匀态扩散取 \(\boldsymbol{\pi}=\mathbf{1}/K\)（\(K\) 是词表大小），被加噪的位置换成词表里均匀随机的一个词，不经过 [MASK]。反向一步的真实后验也有闭式（原文式 10），形式比掩码扩散复杂：因为模型看不出哪些位置被换过，后验要同时考虑“这个词就是原词”和“这个词是随机换来的”两种可能。

能改字。掩码扩散的反向过程里，一个位置一旦从 [MASK] 变成某个词，就再也不会改（上面说的“已经不是 [MASK] 就固定不动”）。均匀态扩散没有这个限制：每一步每个位置都可能被换成别的词，所以前面写错的词后面还能改回来，论文称之为“自我纠错”。这正是它少步生成表现好的原因：步数少时，每一步要同时定下很多位置，相互冲突在所难免；能改，就能补救。论文给均匀态的优缺点是：能自我纠错、适合少步采样；困惑度比掩码扩散差。

先补一点背景：为什么少步时掩码扩散容易出错。

扩散模型每一步对各个位置的预测是独立采样的。如果两个位置强相关（比如城市名的前后两个词），在同一步里分别采样，就可能拼出“New Diego”这种不存在的组合；而掩码扩散写下去就不能改。步数越少，每步同时定下的位置越多，这种冲突越多。下面这个演示（本站已有的玩具模型，按掩码扩散的规则运行）可以直接调步数，看出错概率怎么变。

训练。Duo 论文推出了一个方差更低的均匀态 NELBO，并把它拆成逐 token 的项（原文式 11，各项含义见 Duo 精读 3.4）。和掩码扩散不同，均匀态的去噪网络需要知道当前的扩散时间 \(t\)：掩码扩散数一数有多少个 [MASK] 就能估计出噪声水平（所以 MDLM 可以去掉时间输入，见 MDLM 精读 4.1），均匀态的序列里没有这种标记，告诉网络 \(t\) 能改善困惑度和样本质量。这个差别在第 3 节的实验设置里会体现出来。

2.3 插值扩散（Eso-LM）：让扩散也能用 KV 缓存

它是什么。Eso-LM（Esoteric Language Model）是自回归和 MDLM 的混合：先用 MDLM 部分并行地生成一个“部分被遮住”的序列 \(\mathbf{z}_0\)，再用自回归部分从左到右把剩下的 [MASK] 逐个填上：

$$p_{\theta}(\mathbf{x})=\sum_{\mathbf{z}_0\in\mathcal{V}^{L}}p^{\text{AR}}_{\theta}(\mathbf{x}\mid\mathbf{z}_0)\;p^{\text{MDLM}}_{\theta}(\mathbf{z}_0)$$

两部分共用一个去噪网络。这个边缘似然同样算不出来，Eso-LM 论文推了一个上界：自回归部分在 \(\mathbf{z}_0\) 的被遮位置上算从左到右的交叉熵，MDLM 部分就是式 (7)。超参数 \(\alpha_0\in[0,1]\) 表示期望有多大比例的 token 由 MDLM 部分生成：\(\alpha_0=0\) 时退化成纯自回归，\(\alpha_0=1\) 时退化成纯 MDLM 的 NELBO。Eso-LM 论文发现训练时取 \(\alpha_0=1\) 最好，训出来的模型推理时可以换用各种 \(\alpha_0\)；所以本文只用全扩散模式的 Eso-LM（\(\alpha_0=1\)）。

先补一点背景：掩码扩散和“任意顺序的自回归”。

Ou 等（2025）证明，吸收态（掩码）扩散的训练目标可以改写成：随机抽一个生成顺序，按这个顺序做自回归预测，再对所有顺序取平均，这类模型叫任意顺序自回归模型（AO-ARM）。直观地说，“一轮轮揭开 [MASK]”和“按某个随机顺序一个个写词”是一回事，只是掩码扩散每一轮可以同时写好几个。既然如此，就可以真的用一个自回归式的因果网络来实现它：把序列按随机顺序重排，让网络按这个顺序做因果预测。代价也随之而来：双向注意力里每个已知的词都能看到所有其他已知的词，因果注意力里排在前面的词看不到排在后面的词，网络得到的信息变少了。

怎么做到 KV 缓存。Eso-LM 的前向过程和 MDLM 一样，网络却不是双向的，而是只有一个用因果注意力的解码器，作用在打乱顺序的 \(\mathbf{z}_t\) 上：训练时把序列重新排列，干净词排在前面、[MASK] 排在后面，两部分内部各自随机打乱，位置编码和目标词跟着一起重排。推理时先固定一个生成顺序（祖先采样用位置的随机排列），按这个顺序一批批揭开 [MASK]。因为注意力是因果的，已经揭开的词只看排在它前面的词，不受后面还没生成的词影响，它们的 key 和 value 就可以缓存复用。这让 Eso-LM 在保留并行生成的同时享有 KV 缓存。训练时它用 2.2.1 节的低方差损失（式 8），评测时用式 (7) 的真 NELBO。代价是：因果注意力比双向注意力能看到的信息少，建模能力下降，所以全扩散模式的 Eso-LM 困惑度比 MDLM 差。论文给它的优缺点是：支持 KV 缓存；全扩散模式下困惑度比掩码扩散差。

Block 采样器。Eso-LM 论文发现，块扩散（BD3-LM）在步数很少时会生成退化的样本，原因是同一步里并行解码了相邻的 token，相邻 token 相关性最强、最容易冲突。于是它提出 Block 采样器：每一步只并行解码彼此相隔很远的 token。设上下文长度为 \(L\)、间隔为 \(L'\)，第 \(i\) 步同时解码位置 \(\{i,\,i+L',\,\dots,\,i+(k-1)L'\}\)，一共 \(L'\) 步写完。

3 扩展律：同样的训练算力，四族模型差多少

这一节要回答的问题：在完全相同的骨干网络、数据和算力预算下，四类模型的验证损失怎样随算力下降？下降的速度（指数）一样吗，差在哪里？每个算力预算下，最优的模型应该多大？既然似然不反映生成时的优势，那么把生成速度和样本质量放在一起比，结论又会怎样？
先补一点背景：扩展律、计算最优，以及“斜率”和“常数”。

训练一个 Transformer 语言模型的算力大约是 \(C\approx6ND\)：\(N\) 是参数量，\(D\) 是训练的 token 数，系数 6 来自每个 token 每个参数前向约 2 次、反向约 4 次浮点运算。算力固定时，\(N\) 和 \(D\) 此消彼长：模型大一倍，能喂的 token 就少一半。

扩展律（Kaplan 等 2020；Hoffmann 等 2022，即 Chinchilla）发现：如果每个算力预算都选最合适的 \(N\)，最优损失随算力按幂律下降，\(\mathcal{L}^*\approx A\cdot C^{\alpha}\)（\(\alpha<0\)）。两边取对数，\(\log\mathcal{L}^*=\alpha\log C+\log A\)，在对数—对数坐标里是一条直线。斜率 \(\alpha\) 说明“算力每翻一倍，损失降多少比例”；截距（常数 \(A\)）说明整条线有多高。

比较两族模型时，如果两条直线斜率相同，它们在横向上的距离处处相等：要达到同一个损失，一族总是要比另一族多花固定倍数的算力，这就是论文说的“计算量倍数”（compute multiplier）。如果斜率不同，这个倍数会随算力变化，直线终究会相交或越拉越远。Chinchilla 对自回归模型给出的经验是：计算最优时每个参数大约配 20 个 token。

3.0 实验设置：哪些东西对齐了

  • 骨干网络。四族都用 DiT（扩散 Transformer），加旋转位置编码（RoPE）和带可学习参数的自适应层归一化（adaLN，用来把扩散时间输入网络）。自回归把双向注意力换成因果注意力，用标准的下一词负对数似然训练；为了让参数量和扩散模型一致，自回归保留了时间输入模块，但输入恒为 0。MDLM 用双向注意力，时间输入也置 0。Duo 用双向注意力并真正输入时间 \(t\)（2.2.2 节说过它需要）。Eso-LM 用式 (8) 训练，网络是作用在随机打乱序列上的因果 Transformer。
  • 数据与分词。都在 SlimPajama 上训练（论文说扩展律在数据不足时会被扭曲，而这个数据集对本文的算力范围足够大），都用 Llama-2 分词器，词表加一个 [MASK] 共 32,001 个；上下文长度固定为 2048，batch size 256。

3.1 IsoFLOP：每个算力预算下，找出最优的模型大小

IsoFLOP 是 Chinchilla 用过的方法。做法是：先定几个算力预算 \(C\)；对每个预算，训练一组大小不同的模型，每个模型的训练 token 数 \(D\) 由“算力用满 \(C\)”反推出来；记下每个模型的验证损失 \(\mathcal{L}(N,D)\)。本文的预算是 \(C\in\{6\times10^{18},\,10^{19},\,3\times10^{19},\,6\times10^{19},\,10^{20}\}\) FLOPs。

同一个预算下，损失随模型大小呈 U 形：模型太小，容量不够；模型太大，同样的算力只够训很少的 token。论文在每个预算上，用 \(\log N\) 的二次函数拟合 \(\log\mathcal{L}\)：

$$\log\mathcal{L}(N;C)\approx a_C(\log N)^2+b_C\log N+c_C,\qquad N_C^{*}=\arg\min_{N}\mathcal{L}(N;C),\qquad \mathcal{L}_C^{*}=\mathcal{L}(N_C^{*};C)$$

举个数（推算，按 \(D\approx C/6N\) 粗算）。以最大预算 \(C=10^{20}\) 为例：1 亿参数的模型能训约 1670 亿 token，4 亿参数约 420 亿，8.6 亿参数约 190 亿。前者每个参数分到 1600 多个 token，模型容量是瓶颈；后者每个参数只有 20 来个 token，再大就训不够了。抛物线拟合的作用，是在这些离散的模型尺寸之间找出连续的最低点；之所以对 \(\log N\) 拟合二次函数，是因为这个 U 形在对数横轴上大致对称。

抛物线的最低点给出这个预算下的计算最优参数量 \(N_C^*\) 和计算最优损失 \(\mathcal{L}_C^*\)。四族用完全相同的流程。论文的图 2 显示，三族扩散的 IsoFLOP 曲线都和自回归一样“规整”，每条都是清楚的 U 形。

论文按族给出结论：

  • 自回归。复现了熟悉的计算最优行为：损失和最优参数量都近似服从幂律。论文把它当作比较斜率和常数的参照线。按 \(6ND\) 粗算，表中 AR 的计算最优配比约为每个参数 20–30 个 token（推算），和 Chinchilla 的经验一致，说明这套实验设置本身是正常的。
  • 掩码扩散。损失同样按幂律下降，对数坐标里的斜率和自回归相当。用真 ELBO（式 7）训练时，要达到自回归的验证损失约需 16 倍算力，这复现了 SMDM（Nie 等 2025a）的结论；计算最优的模型比自回归小约一半。换成低方差损失（式 8）训练、仍用式 (7) 评测后，倍数降到约 14 倍，即约 12% 的算力节省（\((16-14)/16\)，推算）；计算最优的模型也更小了：从原文图 6c 读，低方差训练的最优模型在 5 个预算上分别比 ELBO 训练的大约 1%、小约 2%、10%、15%、18%（读图），预算越大越明显。论文强调这一点的意义在于：模型越小，推理时采样越便宜。
  • 均匀态扩散。Duo 和 MDLM 共用双向骨干，在同样的流程下约需 23 倍算力才能达到自回归的困惑度；计算最优模型同样比自回归小约一半。论文强调，似然扩展更差的 Duo 可以靠少步生成换来更快的推理，3.3 节会分析。
  • 插值扩散。全扩散模式的 Eso-LM 约需 32 倍算力；计算最优模型也小约一半。差距虽大，但它是四者中唯一能用 KV 缓存的扩散模型。

常数差从哪里来（本站补充，论文没有分析）。可以从两个方向理解。第一，任务更难：自回归只需要学“给定左边，猜下一个词”这一种条件分布；掩码扩散要学任意遮挡比例、任意遮挡位置下的填空，等价于对所有生成顺序的自回归取平均（2.3 节的背景框），其中很多顺序本来就很难学（见 Train for the Worst 精读第 3 节）；均匀态扩散还要额外判断哪些位置被换过，又难一层；Eso-LM 在掩码扩散的基础上把双向注意力换成因果注意力，网络看到的信息更少。第二，上界的松紧：三族报告的都是上界，上界本身的松弛也算进了“损失”。论文的数据分不开这两部分。

“模型小一半”意味着什么。算力固定时 \(C\approx6ND\)，参数少一半就意味着 token 多一倍。按表中数字粗算，三族扩散的计算最优配比约为每个参数 75–125 个 token，是自回归的 3–5 倍（推算；用 \(6ND\) 近似且未计入注意力开销，绝对值偏高，但相对关系不变）。论文没有讨论原因。上一段说的“任务更难”也能解释这一点：要学的条件分布多得多，同样的参数要看更多数据才学得够（本站的理解）；扩散模型更耐数据重复训练的观察也与此相关，见 数据受限设置的拆解。对推理而言这是好事：同样的训练预算，扩散模型更小，每次前向更便宜。

引言里一句容易读错的话：引言把 MDLM 的改进写成“把计算量倍数降到离 AR 约 12% 以内”。按 3.2.2 节的数字，正确的意思是倍数从约 16 降到约 14，也就是比 ELBO 训练省约 12% 的算力；离自回归仍差约 14 倍，并不是只差 12%。

本站对倍数的核对。用上表的点可以直接检查论文的倍数。MDLM（低方差）在约 \(8.5\times10^{19}\) 时达到 AR 在 \(6\times10^{18}\) 的损失，约 14 倍，和论文一致，而且这是在测量范围内部插值得到的。Duo 和 Eso-LM 在 \(10^{20}\) 时都还没追上 AR 最小预算的损失（2.937、3.010 都高于 2.856），倍数只能往范围外推；按各自的拟合斜率外推，本站得到约 25 倍和 38 倍，比论文的 23 倍、32 倍略大（推算）。论文没有写倍数的具体算法（在哪个损失水平上比、用谁的斜率），差别很可能来自这里。所以这些倍数更适合读作“十几倍、二十几倍、三十几倍”这样的量级。

斜率真的一样吗。本站用读出的点拟合，得到 \(\alpha\) 约为 AR −0.068、MDLM −0.062、Duo −0.067、Eso-LM −0.064（推算）。也就是说，在这段算力里 Duo 的斜率和 AR 几乎一样，MDLM 和 Eso-LM 稍缓。如果这种差别是真的，MDLM 相对 AR 的倍数会随算力缓慢变大（按两条拟合线换算，对应 AR 在 \(6\times10^{18}\) 到 \(10^{20}\) 的各个损失水平，大约从 15 倍涨到 19 倍，推算），而 Duo 的倍数基本不变。但 5 个点只覆盖 1.2 个数量级（\(10^{20}/(6\times10^{18})\approx17\) 倍），斜率上 0.005 的差别远在这种拟合的不确定度之内，不能据此外推到大得多的算力。论文自己说的是“斜率相当”，没有做更细的断言，这是谨慎的。

3.3 速度—质量权衡：把生成时的优势算进来

基于似然的扩展律反映不了采样时的优势：Duo 能少步生成，Eso-LM 能用 KV 缓存。于是论文换一个角度：在每个算力预算下取计算最优的模型，比较它们“生成得多快”和“生成得多好”。

先补一点背景：生成困惑度、熵，以及为什么要用 float64 采样。

生成困惑度（Gen PPL）的做法是：让模型无条件地生成一批文本，再用一个强的自回归模型（本文用 Llama-2 7B）去算这些文本的困惑度。评委模型觉得越通顺，Gen PPL 越低。它有一个众所周知的漏洞：如果模型总生成重复、单调的文本（多样性低），评委也会给出很低的困惑度。所以 Gen PPL 必须和样本熵（衡量一段文本里 token 分布有多分散）一起报告。

Zheng 等（2024）还发现，掩码扩散在低精度（如 float32）下做类别采样时，数值截断会让采样偏向高概率的词，人为压低熵和 Gen PPL。本文因此所有采样都在 float64 下进行，并报告在高精度下熵随步数基本稳定。更多讨论见 MDLM 精读 5.5、Duo 精读 6.5。

怎么测。对每个预算的计算最优模型：自回归按正常方式逐词采样；MDLM 和 Duo 用祖先采样器，通过总步数 \(T\) 控制速度；Eso-LM 用 Block 采样器，通过 \(L'\) 控制步数。每个设置无条件生成 1000 个样本，用 Llama-2 7B 算 Gen PPL；吞吐量（token/秒）在单张 80GB H100 上测，每种模型尺寸用能放下的最大的 2 的幂作为 batch size。然后对每个模型把 Gen PPL 和吞吐量都拟合成步数的函数：

$$\text{Gen PPL}(T)=\alpha_C+\beta_C\,T^{\gamma_C},\qquad \text{Throughput}(T)=\alpha'_C+\beta'_C\,T^{\gamma'_C}$$

为什么要拟合，而不直接用测到的点？因为步数只测了几个值，而前沿要回答的是“要达到某个 Gen PPL 最少要几步”，这个步数通常落在两个测量值之间。拟合形式也有直观的含义：Gen PPL 的指数 \(\gamma_C\) 为负时，步数越多 Gen PPL 越低，并趋近一个下限 \(\alpha_C\)，即无限多步时的质量；吞吐量的指数为负时，步数翻倍、吞吐量大约减半，因为每一步都要对整段序列做一次完整的前向计算，而有 KV 缓存的 Eso-LM 下降得慢得多。

附录图 4 是吞吐量曲线，图 5 是 Gen PPL 与熵。从图 5 读，\(T=2048\) 时 472M 的 Duo、MDLM 的 Gen PPL 分别约 81、96，\(T=512\) 时 472M 的 Eso-LM 约 108（读图）。图上的测量步数是 \(T=32,64,\dots,2048\)（Eso-LM 的质量只测到 512）；同样 \(T=32\) 时，85M 的 Duo 约 730 token/秒、85M 的 MDLM 约 430、Eso-LM 约 650；到 \(T=2048\) 时，Duo 只剩十几 token/秒，而有 KV 缓存的 Eso-LM 仍有约 200（均为读图）。

3.4 结果的份量（扩展律与前沿）

这一小节把上面的数字放回它们的比较条件里。

对齐了什么。骨干网络、参数量、数据、分词器、上下文长度、batch size、优化器和学习率日程都相同，算力按实际的浮点运算量精确计算。这比很多“扩散对自回归”的比较干净得多：没有一方多训了几倍的 token，也没有一方用了更大的模型。MDLM（ELBO 训练）的 16 倍复现了 SMDM 的结论，说明这套实验和前人的掩码扩散扩展律是对得上的。没有对齐的是：每族只用一套超参数，没有分别调学习率和 batch size；而同期的 von Rütte 等（2512.10858）专门强调这两个超参数对扩散模型的扩展行为很关键。

拟合的范围很窄。5 个预算从 \(6\times10^{18}\) 到 \(10^{20}\)，只跨 1.2 个数量级，每族 5 个点，没有重复实验、没有误差棒，论文也没有报告拟合的指数。用这样的数据确定“斜率相当、常数相差 14–32 倍”是合理的；但要据此推测 \(10^{22}\) 以上会怎样，证据不够。Duo 和 Eso-LM 的倍数本身就要外推到测量范围以外才能算出来（3.2 节的核对）。

倍数本身也是跨族比较上界。论文的核心论点是“跨族的困惑度不可比”，而 14 倍、23 倍、32 倍这些数恰恰是拿三族扩散各自的 NELBO 上界去对齐自回归的精确损失。按论文自己的逻辑，这些倍数里有多少来自“模型真的差”，有多少来自“上界松”，同样分不清。只有 MDLM 两种训练方式之间的比较（16 倍对 14 倍）是同一个上界下的比较，结论最干净。

前沿比的是什么质量段。如上所说，扩散模型的所有点质量都明显差于自回归（Gen PPL 约 90–190 对 38–71），前沿只告诉我们“在低质量段谁最快”。而且这是无条件生成 2048 个 token 的小模型（扩散 85M–472M），离实际使用的条件生成、几十亿参数的场景很远。扩散模型用的都是最基础的祖先采样器和 Block 采样器，没有用 Duo 自己的一致性蒸馏（8–16 步）或 Ψ-samplers；自回归也没有用投机解码之类的加速。双方都没用上各自最强的推理手段。

Gen PPL 与熵。采样用 float64、同时报告熵，这一点做得规范。但从原文图 5 读，Duo 的样本熵约 5.96–6.14，MDLM 约 6.05–6.33，Eso-LM 约 6.12–6.26（读图）：Duo 的熵一直最低。熵越低 Gen PPL 越容易低，所以 Duo 相对另外两族的 Gen PPL 优势里，可能有一部分来自多样性更低，论文没有给出熵对齐的比较。自回归样本的熵没有出现在图 5 里。

吞吐量的绝对值不要和别的论文比。吞吐量来自研究代码、float64 采样、每种尺寸用能放下的最大 2 的幂 batch，论文没有写计时包含哪些环节，也没有写自回归是否用了 KV 缓存（官方代码里自回归采样脚本设置了 sampling.kv_cache=True）。几十到一千多 token/秒这个量级，对 1 亿到 8 亿参数的模型来说偏低，只适合在本文内部做相对比较。另外，同样步数下各族的单步开销也不同（例如 \(T=32\) 时 Duo 约 730、MDLM 约 430，读图），论文没有解释差别来源，前沿上 Duo 对 MDLM 的优势同时包含了“需要的步数更少”和“每步更快”两部分。

4 扩到 17 亿参数：似然基准与 GSM8K

这一节要回答的问题：小算力上看到的权衡，到了更接近实用的规模还在不在？作者把四族模型都训到 17 亿参数、2.1 万亿 token，然后在两类任务上比：按似然打分的常识与阅读理解基准，以及要一步步写出推理过程的数学题 GSM8K。困惑度更差的 Duo 为什么能在 GSM8K 上领先？这个领先在什么条件下成立？

训练设置。四族都是 17 亿参数、上下文 2048，在 Nemotron 预训练数据集（Nemotron Nano 2 的数据）第 1、2 阶段的混合数据上训 2.1 万亿 token。论文说数据流程贴近现代 LLM 的做法：网络文本经过人工规则和 LLM 过滤，第 2 阶段含高质量数学数据，没有加任何特殊技巧。每个模型用 64 张 H100。为了让模型适应变长输入，1% 的预训练序列被截成 \(\mathcal{U}[1,2048]\) 里随机的长度（沿用 Gulrajani 与 Hashimoto 2024、LLaDA 的做法）。优化器 AdamW，前 2000 步线性预热到 \(3\times10^{-4}\)，之后保持恒定；训完 1.4 万亿 token 后，在剩下的 0.7 万亿 token 里把学习率降到 \(4\times10^{-5}\)。全局 batch size 256，词表 12.8 万。

先补一点背景：为什么正式模型大多“过训练”。

“计算最优”只回答一个问题：训练预算固定时，怎样分配参数和数据能让损失最低。可是模型训好以后要反复拿来推理，推理成本只和参数量有关、和训练时喂了多少 token 无关。所以实际的 LLM 往往故意用比计算最优小得多的模型、喂远多于计算最优的数据：多花一些训练算力，换来一个更小、更便宜的推理模型。例如 LLaMA3 8B 训了 15 万亿 token，每个参数约 1,900 个（推算），远超 Chinchilla 的 20 个。

按这些数字推算：每步 \(256\times2048\approx52\) 万个 token，2.1 万亿 token 约 400 万步；每个参数约配 1,230 个 token（推算）。官方模型卡给出的累计训练算力是 \(2.14\times10^{22}\) FLOPs，和 \(6ND\) 估算一致。

4.2 数学推理 GSM8K：Duo 领先，但不是靠并行

先补一点背景：GSM8K，以及这里比的是什么。

GSM8K（Cobbe 等 2021）是一套小学数学应用题，测试集 1319 题，每道题要写出几步算术推理才能得到答案，按最终数字是否正确计分。基座模型直接做这类题，通常要靠少样本提示；本文和 SMDM 一样，先在同一份扩充过的训练数据上微调再测。所以这里比的是“同样的基座训练、同样的微调数据，谁学得更好”，而不是基座模型本身的少样本能力。论文把微调的上下文设为 256 个 token，说明每条“题目 + 推理过程”都不长。

怎么评。沿用 SMDM（Nie 等 2025a）的做法，先在增强版 GSM8K 训练集上做监督微调（SFT）。这个数据集（Deng 等 2024）用 GPT-4 把原始 GSM8K 训练集扩充到 38.5 万条。所有模型都用 AdamW、余弦学习率，微调 5 个 epoch，上下文 256；对学习率对 \((\eta_{\max},\eta_{\min})\) 做网格搜索（附录表 3），论文说报告每个方法的最好设置。

怎么生成。前人的扩散 LLM 工作常用“按置信度选位置”的采样，而 LLaDA 论文发现这种采样实际上会退化成从左到右生成。所以本文干脆让所有模型都从左到右、一次生成一个 token。吞吐量在整个 GSM8K 测试集（1319 题）上测，batch size 为 1，只计生成出来的 token（含结束符，不含提示和结束符之后的部分）。

先补一点背景：为什么 batch size 为 1 时，自回归和扩散一样快。

batch size 为 1 时，每一步的计算量很小，时间几乎全花在把 17 亿个参数从显存读到计算单元上，这叫“受显存带宽限制”（memory-bound）。这时，自回归用 KV 缓存只算一个新 token，扩散模型重新算整个 256 长的序列，多出来的计算量 GPU 几乎“免费”就能做完，两者每一步的耗时差不多。既然大家每步都只写一个 token，吞吐量自然相同：表 2 里四个模型都是 24.6–25.6 token/秒。论文引用了 TiDAR（Liu 等 2025）对这一现象的分析；背景可参考 vLLM 精读第 1 节里“批越大越划算”的例子。

4.3 结果的份量（17 亿参数）

和自回归比，对齐得很好。四个模型参数量相同、训练 token 数相同（2.1 万亿）、数据相同、学习率日程和 batch size 相同，SFT 数据和 epoch 数也相同，解码方式也相同（一次一个 token、从左到右）。这比很多头条比较干净：例如 LLaDA 8B 训了 2.3 万亿 token，对照的 LLaMA3 8B 训了 15 万亿 token。这里的自回归基线也不是借来的数字，而是同一套代码、同一份数据训出来的。

Duo 的领先和并行解码无关。GSM8K 上所有模型都一步写一个 token，吞吐量都是约 25 token/秒，扩散模型的少步、并行、自我纠错都没有用上。所以表 2 能说明的是“Duo 学到的条件分布用来从左到右做题，比同条件的自回归略好”，而不能说明“Duo 又快又好”。论文也没有交代均匀态模型如何“从左到右一次一个 token”地生成（右边还没生成的位置放什么），截至 2026-10-20 官方仓库里也没有 SFT 和 GSM8K 评测的代码（Hugging Face 模型卡只附了似然评测脚本），这一步暂时无法独立核对。

差距有多大。Duo 比自回归高 2.9 个百分点。按二项分布粗算，两个独立准确率之差的标准误约 1.9 个百分点（推算），2.9 个点约 1.5 个标准误，算不上很稳的差距；论文每个设置只跑了一次，没有报告多次种子的波动。论文没有提到验证集，学习率看起来是按测试集结果挑的（6 组里取最好），这对每个方法都有乐观偏差，而 Eso-LM 只试了 1 组，它的 33.4 很可能没调好。

表 2 和表 3 对不上。正文说“报告每个方法的最好设置”，自回归的 62.9 确实是它在表 3 里的最好值；但 MDLM 的 58.8 和 Duo 的 65.8 都对应学习率对 (2e-5, 5e-7)，而表 3 里 MDLM 在 (2e-5, 2e-6) 下有 61.7，Duo 在 (2e-5, 5e-8) 下有 66.0（本站核对）。如果统一按“5 个 epoch 的最好值”，排序变成 Duo 66.0 > AR 62.9 > MDLM 61.7：Duo 仍然第一，但 MDLM 和自回归只差 1.2 个点，在噪声范围内。

和似然基准放在一起看。同一批 1.7B 模型，在按似然打分的六个基准上自回归全面大幅领先，在需要生成的 GSM8K 上 Duo 领先。论文用这个反差支持“困惑度不能说明一切”的论点，这个方向是成立的；但 GSM8K 只是一个数据集、一次微调，加上“前人”两行（SMDM、LLaDA）的协议都不同，单凭这一张表还不足以说均匀态扩散在推理任务上普遍更强。

5 讨论与结论：评测扩散语言模型要看三样东西

这一节要回答的问题：作者最后想让读者带走什么？“掩码扩散不一定是未来”这个判断，哪些部分已经被实验支撑，哪些还只是可能性？

作者回到开头的假设：掩码扩散模型，以及基于困惑度的扩展律分析，能不能给出“怎样做好扩散语言模型”的确定答案。他们的回答是：不完整。具体有四点。

  • 离散扩散的扩展指数可以和自回归相当，但常数差距很大，而且强烈依赖扩散族：MDLM 的似然扩展最好，Duo 和 Eso-LM 要多花得多的算力才能追上自回归的困惑度。
  • 本文和同期的 von Rütte 等（2025）是第一批研究均匀态扩散扩展律的工作，也是第一次研究自回归—MDLM 插值扩散的扩展律。
  • 用低方差目标训练 MDLM，比用标准 ELBO 训练更省算力，计算最优的模型更小，采样也更便宜。
  • 困惑度在同一族内部有意义，因为大家共用同一种 NELBO 上界；跨族比较时可能误导。均匀态和插值模型可能似然扩展更差，却因为采样更高效（Duo 的少步生成、Eso-LM 的 KV 缓存）而在实践中更可取。因此评测标准应当同时考虑似然、采样效率和下游表现。

扩到 17 亿参数后，自回归在基于似然的指标上依然最强，而均匀态扩散在 SFT 后的数学推理上可以超过自回归和其他扩散模型。展望部分，作者希望把扩散 LLM 扩到更大规模，去研究涌现能力和长程推理，弄清它们不同的生成机制能否在真实任务中带来一致的优势；更广地说，这类工作也可能帮助回答“现代 LLM 的能力有多少是自回归分解本身带来的”。

后来怎么样了

这篇论文 2026 年 2 月挂上 arXiv，同年 7 月以海报形式发表在 ICML 2026，到 2026 年 10 月只有八个月左右，还谈不上长期影响。下面是截至 2026-10-20 能查到的情况（均经本站在 arXiv、Hugging Face 与 GitHub 上核对）。

  • 代码与权重。官方仓库 s-sahoo/scaling-dllms ↗（Apache-2.0，37 star）提供扩展律实验的训练脚本（四族 × 各模型尺寸 × 5 个算力预算）和 1.7B 模型的预训练脚本。四个 1.7B 基座模型于 2026 年 9 月以 nvidia/SDLLM-{AR,MDLM,Duo,EsoLM}-1.7B-Base 发布在 Hugging Face，许可为 CC BY-NC 4.0（仅限非商业研究），附带采样与似然评测脚本；SFT 后的 GSM8K 模型和对应评测代码没有发布。
  • 被后续工作当作参照。Sumi（arXiv 2606.19005 ↗）是一个从零预训练、训了 1.5 万亿 token 的 70 亿参数开源均匀扩散语言模型。它在正文里写道：在它之前，唯一在“数据充足”条件下训练的均匀扩散模型就是本文的 1.7B 模型。Sumi 的摘要称它在知识、推理、代码基准上与同等 token 预算的自回归模型相当，常识类基准较弱。
  • 同一批作者把比较扩展到连续扩散。RePlaid（arXiv 2605.18530 ↗，Zhihan Yang、Sahoo、Thickstun 与 NVIDIA 的作者）用类似的框架研究连续扩散语言模型的扩展律，摘要称相对自回归的算力差距约 20 倍，参数更少时就能超过 Duo，在过训练区间超过 MDLM。连续扩散的背景见 Diffusion-LM 精读。
  • 同期工作的结论并不完全一致。von Rütte 等（arXiv 2512.10858 ↗）在掩码与均匀噪声之间平滑插值来研究扩展律，并特别调了 batch size 和学习率。摘要的结论是：算力受限时各种噪声收敛到相近的损失；均匀扩散做到计算最优需要更多参数、更少数据，因此在数据受限时更有希望；他们把均匀扩散模型做到 100 亿参数、\(10^{22}\) FLOPs。这和本文“Duo 需要约 23 倍算力、计算最优模型比自回归小一半”的结论在两点上有张力（损失是否收敛、最优模型偏大还是偏小），两者的实验协议也不同，目前还没有工作把两边对齐复现。
  • 工业界也有用均匀噪声的例子。DiffusionGemma（arXiv 2608.00146 ↗）在技术报告里写明采用多项式（均匀）扩散而不是掩码扩散，理由是所有 token 都能互相转移、模型可以持续修正自己的输出。本站检索它的正文没有发现引用本文，所以只能说方向一致，不能说是受本文影响。整理见 旧版拆解：均匀噪声走向工业。
  • 截至 2026-10，本站没有找到对本文 GSM8K 结果或扩展律倍数的独立复现。

在本站的扩散 LLM 精读里，可以接着读：Duo（本文的均匀态代表，扩散对偶与少步蒸馏）、MDLM（掩码扩散代表，以及“加权 BERT 损失”的推导）、SEDD（离散扩散的似然上界从哪里来）、BD3-LM（另一种拿到 KV 缓存的办法）、LLaDA（掩码扩散做到 8B 的样子）、Train for the Worst, Plan for the Best（掩码扩散训练难在哪、推理顺序为什么重要）。均匀态扩散的架构图、伪代码和配套简答题见旧版结构拆解页。
