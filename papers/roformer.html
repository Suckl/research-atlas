0 导读：这篇论文解决什么问题

Transformer 的核心是自注意力：每个词去“看”句子里所有的词，按相关程度取用它们的信息。这个机制有一个先天的缺陷——它本身不知道词的先后顺序。把一句话里的词打乱，自注意力算出来的东西只是跟着换了个顺序，内容一模一样。可是语言离不开顺序，“猫追狗”和“狗追猫”意思完全不同。所以每个 Transformer 都必须另外想办法把“每个词在第几个位置”告诉模型，这就是位置编码。

2021 年之前，位置编码主要有两条路。第一条是绝对位置编码：给第 1、2、3……个位置各准备一个向量，加到对应的词向量上。它简单，但模型真正关心的往往是“两个词隔了多远”，这个距离得让模型自己从两个绝对位置里推出来。第二条是相对位置编码：直接在注意力分数里加一项只和距离有关的东西。它表达距离更直接，但需要改动注意力本身的计算，而且和“线性注意力”这类更省算力的注意力变体合不到一起。

这篇论文提出了第三种做法，叫旋转位置编码（Rotary Position Embedding，RoPE）。它把 query 和 key 向量的每两个维度看成平面上的一个点，然后按这个词的位置 \(m\) 把这个点转过一个角度 \(m\theta\)。两个转过的向量做点积时，结果只取决于它们转过的角度之差，也就是两个词的相对位置。换句话说，RoPE 在每个词上做的是一个只依赖绝对位置的操作，得到的却是相对位置的效果；它不增加任何参数，也不需要改动注意力的计算公式。作者把用了 RoPE 的 Transformer 叫做 RoFormer。

论文本身的实验规模不大（BERT 大小的模型、一个机器翻译任务、一个中文长文本匹配任务），结果也有好有坏。但 RoPE 很快被 EleutherAI 的 GPT-NeoX、Google 的 PaLM、Meta 的 LLaMA 采用，成为后来开源大模型最常见的位置编码；把大模型的上下文窗口从几千个 token 拉长到十几万个 token 的一系列方法（位置插值、NTK、YaRN），也都是在 RoPE 的公式上动手脚。所以这篇论文的价值主要在于它的想法和推导，而不是实验表格。

1 引言：Transformer 为什么需要位置编码（原文 §1）

这一节要回答的问题：循环神经网络按顺序一个词一个词地读，卷积网络每次只看相邻的几个词，它们都或多或少地“知道”顺序。Transformer 放弃了这两种结构，改用自注意力并行处理所有词，换来了训练速度和长距离建模能力，却把顺序信息丢掉了。这一节交代：顺序信息是怎么丢的，之前的人用什么办法补回来，作者认为这些办法还缺了什么。
先补一点背景：自注意力在算什么。

一句话有 \(N\) 个词。每个词先变成一个向量 \(x_n\)（词向量）。自注意力层里，每个词再用三个矩阵分别算出三个向量：query \(q\)（“我想找什么样的信息”）、key \(k\)（“我能提供什么样的信息”的标签）和 value \(v\)（真正携带的内容）。处理第 \(m\) 个词时，拿它的 \(q_m\) 和每个词的 \(k_n\) 做点积，得到 \(N\) 个分数；分数经过 softmax 变成加起来等于 1 的权重；再用这些权重把所有词的 \(v_n\) 加权平均，得到第 \(m\) 个词的输出：

$$a_{m,n}=\frac{\exp\!\big(q_m^{\top}k_n/\sqrt{d}\big)}{\sum_{j=1}^{N}\exp\!\big(q_m^{\top}k_j/\sqrt{d}\big)},\qquad o_m=\sum_{n=1}^{N}a_{m,n}\,v_n$$

这里 \(d\) 是向量的维度，除以 \(\sqrt{d}\) 是为了让分数不至于太大。点积 \(q_m^{\top}k_n\) 越大，第 \(m\) 个词就越关注第 \(n\) 个词。整篇论文讨论的，就是怎样让这个点积里带上位置信息。

再补一点背景：为什么说自注意力“不知道顺序”。

看上面的公式：\(q_m\)、\(k_n\)、\(v_n\) 都只由对应的词向量算出来，求和 \(\sum_n\) 对所有词一视同仁，没有任何一处用到“\(n\) 是第几个”。所以如果把输入的词打乱顺序，每个词算出来的输出向量不会变，只是输出的排列跟着输入一起被打乱。数学上叫置换等变：输入怎么换位置，输出就怎么换位置，内容不变。

后果是：只要两句话由同样的词组成，模型看到的就是同一组向量，它分不清谁在前谁在后。

示意图：没有位置信息时，“猫追狗”和“狗追猫”在自注意力眼里没有区别

作者在引言里把序列模型分成三类来对比。循环神经网络（RNN）沿着时间一步步更新隐状态，顺序天然编码在计算过程里。卷积网络（CNN）常被认为不感知位置，但已有研究发现，卷积里常用的边缘补零（padding）会让网络间接学到位置信息。Transformer 用自注意力替代了这两者，好处是可以并行计算、单层就能直接建立远距离两个词之间的联系，代价就是上面说的：自注意力本身与位置无关。

为了补上位置信息，已有工作分成两大类。一类是绝对位置编码：要么用一个预先定好的函数（原始 Transformer 的正弦函数）生成每个位置的向量，要么干脆把每个位置的向量当作参数去学（BERT、GPT 等）。另一类是相对位置编码：把“两个词相隔多远”的信息写进注意力的计算里（Shaw 等、Transformer-XL、T5、DeBERTa 等）。此外还有用神经常微分方程建模位置、在复数空间里建模位置的尝试。

作者对这些方法的共同批评是：它们都是把位置信息加到词的表示上（或加到注意力分数上）。这种“加法”在普通注意力里没有问题，但会让它们没法用在线性注意力里（本页第 5 节会解释为什么）。RoPE 则改成用乘法，也就是旋转，把位置信息乘进 query 和 key。

论文列出的贡献有三条：一是梳理了已有的相对位置编码，指出它们大多建立在“把位置编码加到表示上再展开”的思路上，进而提出用旋转矩阵乘以表示来编码相对位置；二是研究了 RoPE 的性质，证明了它随距离增大而衰减，并指出以往的相对位置编码与线性注意力不兼容；三是在若干长文本任务上评估了 RoFormer。

2 背景：已有的位置编码是怎么做的（原文 §2）

这一节要回答的问题：为了把位置信息放进注意力，前人到底改了公式里的哪一处？绝对位置编码和相对位置编码在公式上的区别是什么？作者为什么说它们本质上都是在同一个展开式上“改项”，这种做法的局限在哪里？

2.1 一个统一的写法

论文先把所有方法放进同一个框架里：第 \(m\) 个词的 query、第 \(n\) 个词的 key 和 value，分别由某个函数从词向量和位置算出来：

$$q_m=f_q(x_m,m),\qquad k_n=f_k(x_n,n),\qquad v_n=f_v(x_n,n)$$

然后照常用 \(q_m^{\top}k_n\) 算注意力权重、用权重加权 \(v_n\)。这样一来，“设计位置编码”就等价于“选择函数 \(f_q\)、\(f_k\)、\(f_v\)”。后面讨论的每一种方法，都只是这三个函数的一种选法。

2.2 绝对位置编码：给每个位置一个向量，加在词向量上

最常见的选法是：先给词向量加上一个只依赖位置的向量 \(p_i\)，再乘以投影矩阵：

$$f_{t}(x_i,i)=W_{t}\,(x_i+p_i),\qquad t\in\{q,k,v\}$$

\(p_i\) 从哪来，有两种办法。

  • 可学习的位置向量（BERT、ALBERT、ELECTRA、GPT 系列）：准备 \(L\) 个可训练的向量 \(p_1,\dots,p_L\)，\(L\) 是允许的最大长度（BERT 是 512）。缺点很直接：第 \(L+1\) 个位置根本没有向量可用，模型无法处理比 \(L\) 更长的输入。
  • 正弦位置向量（原始 Transformer）：用固定的正余弦函数生成，不需要训练，任意位置都能算。
先补一点背景：正弦位置编码，以及它和“旋转”的关系。

原始 Transformer 让 \(p_i\) 的第 \(2t\)、\(2t+1\) 维分别等于

$$p_{i,2t}=\sin\!\big(i\,\omega_t\big),\qquad p_{i,2t+1}=\cos\!\big(i\,\omega_t\big),\qquad \omega_t=10000^{-2t/d}$$

把相邻两维 \((p_{i,2t},\,p_{i,2t+1})\) 看成平面上的一个点，它正好落在半径为 1 的圆上，所在的角度随位置 \(i\) 均匀增加，每往后一个位置就多走 \(\omega_t\) 弧度。不同的 \(t\) 走得快慢不同：\(t=0\) 时 \(\omega_0=1\)，大约每 6.3 个位置转一圈；\(t\) 越大转得越慢。原始论文说这些波长构成从 \(2\pi\) 到 \(10000\cdot 2\pi\) 的等比数列。

原始 Transformer 的作者选择正弦函数，理由之一是：对任意固定的偏移 \(k\)，\(p_{i+k}\) 都能写成 \(p_i\) 的一个线性函数，他们希望这能帮助模型学会按相对位置去注意。这个“线性函数”其实就是把圆上的点再转过 \(k\omega_t\) 角度，也就是一个旋转。也就是说，正弦编码本来就把位置表示成了角度，RoPE 后面会把这个想法用得更彻底。

问题出在“加法”上。把加了位置的向量代进点积，会展开成四项：

$$q_m^{\top}k_n=\underbrace{x_m^{\top}W_q^{\top}W_kx_n}_{\text{内容-内容}}+\underbrace{x_m^{\top}W_q^{\top}W_kp_n}_{\text{内容-位置}}+\underbrace{p_m^{\top}W_q^{\top}W_kx_n}_{\text{位置-内容}}+\underbrace{p_m^{\top}W_q^{\top}W_kp_n}_{\text{位置-位置}}$$

第一项只看内容，和位置无关。第二、三项把一个词的内容和另一个词的绝对位置混在一起。第四项同时用到两个位置，但中间夹着一个学出来的任意矩阵 \(W_q^{\top}W_k\)，一般也不再只是 \(m-n\) 的函数。所以，虽然正弦编码自身带着“相对位置”的结构，经过“相加再投影”之后，注意力分数里的位置信息就变成了 \(m\) 和 \(n\) 各自的函数，模型要靠学习才能从中提炼出距离。本页第 3 节会用一组具体数字演示这一点。

2.3 相对位置编码：在展开式里把绝对位置换成距离

相对位置编码的各种方案，几乎都是从上面那个四项展开式出发，对其中的某几项动手。论文按时间顺序梳理了几种：

  • Shaw 等（2018）：query 不加位置；key 和 value 各加一个可学习的向量 \(\tilde p^{k}_{r}\)、\(\tilde p^{v}_{r}\)，下标 \(r=\operatorname{clip}(m-n,\,r_{\min},\,r_{\max})\) 是被截断到一个范围内的相对距离。截断的理由是：距离太远以后，精确的距离值已经没什么用了。
  • Transformer-XL（Dai 等，2019）：在四项展开式里，把第 \(n\) 个词的绝对位置向量 \(p_n\) 换成随相对距离变化的正弦向量 \(\tilde p_{m-n}\)，把第三、四项里 query 一侧的位置向量 \(p_m\) 换成两个与位置无关的可学习向量 \(\mathbf{u}\)、\(\mathbf{v}\)，并给位置部分单独配一个投影矩阵 \(\widetilde W_k\)。它和后来的几种方法一样，不再给 value 加位置。
  • T5（Raffel 等，2020）：最简化的一种，只保留“内容-内容”项，再加一个可学习的标量偏置 \(b_{i,j}\)。T5 论文中的具体做法是：把相对距离分进 32 个桶，桶的宽度按对数增长，覆盖到 128 的距离，超过 128 的全部归入同一个桶；偏置在所有层之间共享，同一层里每个注意力头各有一套。
  • TUPE 一类（式 9）：内容和位置用两套不同的投影矩阵分开算，再加上 T5 式的偏置。
  • DeBERTa（He 等，2020）：认为相对位置只需要中间两项（内容-位置、位置-内容）就能完整建模，于是把这两项里的绝对位置都换成相对位置向量 \(\tilde p_{m-n}\)，丢掉“位置-位置”项。

作者的总结是：这些方法都在原始 Transformer 的那个四项展开式上修修补补，而且都是把位置信息“加”进去。RoPE 换了一个出发点：不先假定“加”，而是直接提出要求——点积只能依赖相对位置——然后反过来求满足这个要求的 \(f_q\)、\(f_k\)。下一节就是这个求解过程。

3 提出问题，先解二维情形：为什么“旋转”恰好满足要求（原文 §3.1–3.2.1）

这一节要回答的问题：如果我们要求 query 和 key 的点积只能依赖两个词的内容和它们的相对位置 \(m-n\)，那么 \(f_q\)、\(f_k\) 应该长什么样？作者先在最简单的情形——向量只有两维——里给出答案：把向量按位置旋转。这一节解释为什么旋转能做到这一点，并用一组具体数字把计算走一遍。

3.1 要求写成公式（原文 §3.1）

论文把目标写成一个等式：存在某个函数 \(g\)，使得

$$\big\langle f_q(x_m,m),\,f_k(x_n,n)\big\rangle=g\big(x_m,\,x_n,\,m-n\big)$$

左边是带了位置的 query 和 key 的内积，右边的 \(g\) 只允许看两个词向量和它们的位置差，不允许单独看 \(m\) 或 \(n\)。为什么要这样要求？因为语言里“两个词隔了几个位置”往往比“它们各自在第几个位置”更重要：同一个短语出现在文章开头和出现在第 500 个词，词与词之间的关系应该是一样的。满足这个等式，就意味着把整句话往后平移任意多个位置，注意力分数完全不变。

先补一点背景：复数就是平面上的点，乘以 \(e^{i\varphi}\) 就是旋转。

平面上的点 \((a,b)\) 可以写成复数 \(z=a+bi\)。它到原点的距离叫模长 \(|z|=\sqrt{a^2+b^2}\)，它和横轴正方向的夹角叫辐角。任何复数都能写成“模长 × 方向”：\(z=|z|\,e^{i\alpha}\)，其中 \(e^{i\alpha}=\cos\alpha+i\sin\alpha\) 是单位圆上角度为 \(\alpha\) 的点。

复数乘法有一个很直观的几何意义：两个复数相乘，模长相乘、角度相加。所以 \(z\cdot e^{i\varphi}\) 就是把 \(z\) 绕原点逆时针转过 \(\varphi\) 角，长度不变。

还有一个后面会用到的小事实：两个二维向量 \((a,b)\)、\((c,d)\) 的点积 \(ac+bd\)，等于复数 \(z=a+bi\) 乘以 \(w=c+di\) 的共轭 \(\bar w=c-di\) 之后的实部：

$$z\,\bar w=(a+bi)(c-di)=(ac+bd)+(bc-ad)\,i,\qquad \operatorname{Re}[z\,\bar w]=ac+bd$$

原文用 \(w^{*}\) 表示共轭，和这里的 \(\bar w\) 是同一个意思。

再补一点背景：旋转矩阵。

不用复数，也可以用矩阵描述旋转。把二维向量逆时针转过 \(\varphi\) 角的矩阵是

$$R(\varphi)=\begin{pmatrix}\cos\varphi & -\sin\varphi\\ \sin\varphi & \cos\varphi\end{pmatrix}$$

它有三个性质，后面全靠它们：（1）旋转不改变向量的长度；（2）先转 \(\alpha\) 再转 \(\beta\) 等于一次转 \(\alpha+\beta\)，即 \(R(\beta)R(\alpha)=R(\alpha+\beta)\)；（3）旋转矩阵的转置就是反向旋转，\(R(\varphi)^{\top}=R(-\varphi)\)。由这三条马上得到：

$$\big(R(\alpha)\,u\big)^{\top}\big(R(\beta)\,w\big)=u^{\top}R(-\alpha)R(\beta)\,w=u^{\top}R(\beta-\alpha)\,w$$

也就是说，两个向量各转各的之后再做点积，结果只和两个转角的差有关。这一行就是 RoPE 的全部秘密。

3.2 二维情形的解：按位置旋转（原文 §3.2.1）

论文给出的二维解是：先照常用 \(W_q\)、\(W_k\) 把词向量投影成 query 和 key，再把它们当成复数，分别乘以 \(e^{im\theta}\) 和 \(e^{in\theta}\)：

$$f_q(x_m,m)=(W_qx_m)\,e^{im\theta},\qquad f_k(x_n,n)=(W_kx_n)\,e^{in\theta}$$

其中 \(\theta\) 是一个预先选定的非零常数。用矩阵写，就是

$$f_{\{q,k\}}(x_m,m)=\begin{pmatrix}\cos m\theta & -\sin m\theta\\ \sin m\theta & \cos m\theta\end{pmatrix}\begin{pmatrix}W^{(11)}_{\{q,k\}} & W^{(12)}_{\{q,k\}}\\ W^{(21)}_{\{q,k\}} & W^{(22)}_{\{q,k\}}\end{pmatrix}\begin{pmatrix}x^{(1)}_m\\ x^{(2)}_m\end{pmatrix}$$

右边从右往左读：词向量先乘投影矩阵，得到普通的 query（或 key），再乘一个旋转矩阵，转过的角度是“位置 × \(\theta\)”。第 1 个词转 \(\theta\)，第 2 个词转 \(2\theta\)，第 100 个词转 \(100\theta\)。“旋转位置编码”这个名字就来自这里。

为什么这样就满足要求？用上面复数背景里的事实，点积等于“一个复数乘以另一个的共轭”的实部：

$$\big\langle f_q,\,f_k\big\rangle=\operatorname{Re}\!\Big[(W_qx_m)e^{im\theta}\cdot\overline{(W_kx_n)e^{in\theta}}\Big]=\operatorname{Re}\!\Big[(W_qx_m)\,\overline{(W_kx_n)}\;e^{i(m-n)\theta}\Big]=g(x_m,x_n,m-n)$$

第二个等号是因为共轭会把 \(e^{in\theta}\) 变成 \(e^{-in\theta}\)，和 \(e^{im\theta}\) 相乘得到 \(e^{i(m-n)\theta}\)。最后的式子里，位置只以 \(m-n\) 的形式出现。用钟表打个比方：两根指针各自转了多少圈不重要，它们之间的夹角只取决于一根比另一根多转了多少；点积由两个向量的长度和夹角决定，所以也只取决于这个“多转的部分”。

4 推广到高维：一组转速不同的“指针”（原文 §3.2.2）

这一节要回答的问题：实际模型里每个注意力头的 query 和 key 有几十到上百维（常见的是 64 或 128 维），二维的旋转怎么推广过去？每一组用多大的转速？为什么要一组快、一组慢？

推广的办法很朴素：把 \(d\) 维向量（\(d\) 为偶数）按顺序两两分组，第 1、2 维一组，第 3、4 维一组……一共 \(d/2\) 组；每一组都是一个二维平面，各自按上一节的方法旋转，但第 \(i\) 组用自己的转速 \(\theta_i\)。写成矩阵就是一个分块对角矩阵：

$$f_{\{q,k\}}(x_m,m)=R^{d}_{\Theta,m}\,W_{\{q,k\}}\,x_m,\qquad R^{d}_{\Theta,m}=\begin{pmatrix}\cos m\theta_1 & -\sin m\theta_1 & & & \\ \sin m\theta_1 & \cos m\theta_1 & & & \\ & & \ddots & & \\ & & & \cos m\theta_{d/2} & -\sin m\theta_{d/2}\\ & & & \sin m\theta_{d/2} & \cos m\theta_{d/2}\end{pmatrix}$$

空白处都是 0。转速取

$$\Theta=\Big\{\theta_i=10000^{-2(i-1)/d},\ \ i=1,2,\dots,d/2\Big\}$$

这和原始 Transformer 正弦编码用的频率完全相同：第一组 \(\theta_1=1\)，后面每一组比前一组慢一个固定的倍数，最后一组接近 \(1/10000\)。

为什么高维情形仍然只依赖相对位置？因为 \(d\) 维向量的点积就是 \(d/2\) 个二维点积之和，而每一个二维点积都只依赖 \(m-n\)，加起来自然也只依赖 \(m-n\)。用矩阵写更简洁：\(R^{d}_{\Theta,m}\) 是正交矩阵，满足 \((R^{d}_{\Theta,m})^{\top}R^{d}_{\Theta,n}=R^{d}_{\Theta,n-m}\)，于是

$$q_m^{\top}k_n=\big(R^{d}_{\Theta,m}W_qx_m\big)^{\top}\big(R^{d}_{\Theta,n}W_kx_n\big)=x_m^{\top}W_q^{\top}\,R^{d}_{\Theta,n-m}\,W_k\,x_n$$

和第 2 节的四项展开式对比：加法编码在点积里留下了 \(m\)、\(n\) 各自的痕迹；RoPE 的点积里，位置只以一个夹在中间的旋转矩阵 \(R^{d}_{\Theta,n-m}\) 的形式出现，且只依赖差值。作者还指出，因为旋转矩阵是正交的，它不会放大或缩小向量的长度，编码位置的过程是数值稳定的。

5 RoPE 的两个性质：远程衰减，以及能用于线性注意力（原文 §3.3）

这一节要回答的问题：除了“只依赖相对位置”，作者还声称 RoPE 有两个好性质：注意力会随距离增大而衰减；它能和线性注意力结合，而以往的相对位置编码不能。这两条各是什么意思？为什么成立？摘要里还提到第三条“序列长度灵活”，指的是 RoPE 没有一张长度固定的位置表，任何位置都能算出旋转角度。

5.1 远程衰减：直观的说法

作者沿用 \(\theta_i=10000^{-2i/d}\) 这组频率，并声称它带来一个“远程衰减”的性质：两个词的相对距离越大，它们的 query–key 内积就越小。这符合一个朴素的直觉：隔得越远的两个词，一般关系越弱。

直观上可以这样理解：内积是 \(d/2\) 组的贡献之和，每一组的贡献随着距离增大，以自己的频率在正负之间来回摆动。距离为 0 时，所有组都“同相”，贡献整齐地叠加；距离一大，转速不同的各组摆到了不同的相位上，互相抵消，总和的幅度就变小。严格的证明在第 6.3 节，那里还会说明“衰减”的确切含义只是一个上界在变小。

用一个最小的例子感受一下（推算）。假设只有两组，转速分别是 1 和 0.1，并且 query 和 key 在两组里的内容部分相同、各贡献 1，那么距离为 \(r\) 时的分数就是 \(\cos r+\cos 0.1r\)。距离 0 时两组同相，分数是 2；距离 1 时是 1.535；距离 10 时快组转到了 \(\cos10=-0.839\)，慢组还在 \(\cos1=0.540\)，两者抵消成 \(-0.299\)；距离 20 时几乎完全抵消，只剩 \(-0.008\)。但到距离 50 又回升到 1.249，因为两组的相位碰巧又凑到了一起。这说明两件事：抵消确实来自“转速不同、相位错开”；而只有两组时，相位很容易再次对齐，衰减并不稳定。真实模型每个头有 32 或 64 组，各组的相位很难同时对齐，平均意义上的衰减才明显，但仍然不是单调的。

5.2 和线性注意力结合

先补一点背景：线性注意力。

普通自注意力可以写成更一般的形式：用一个相似度函数 \(\operatorname{sim}(q_m,k_n)\) 给每个 value 加权，再除以权重之和做归一化：

$$\operatorname{Attention}(Q,K,V)_m=\frac{\sum_{n=1}^{N}\operatorname{sim}(q_m,k_n)\,v_n}{\sum_{n=1}^{N}\operatorname{sim}(q_m,k_n)}$$

普通注意力取 \(\operatorname{sim}=\exp(q_m^{\top}k_n/\sqrt d)\)。它的问题是每个 query 都要和所有 \(N\) 个 key 各算一次，总计算量随长度按 \(N^2\) 增长。

线性注意力（Katharopoulos 等，2020）把相似度换成两个非负函数的内积 \(\phi(q_m)^{\top}\varphi(k_n)\)，例如 \(\phi(x)=\varphi(x)=\operatorname{elu}(x)+1\)。好处在于矩阵乘法的结合律：分子可以改写成 \(\phi(q_m)^{\top}\big[\sum_n\varphi(k_n)v_n^{\top}\big]\)，方括号里的东西和 \(m\) 无关，只需对所有词算一次（得到一个 \(d\times d\) 的矩阵），之后每个 query 只要和这个矩阵相乘。这样总计算量随长度线性增长。

为什么以往的相对位置编码和线性注意力合不到一起？因为它们要在每一对 \((m,n)\) 的分数上加一个依赖 \(m-n\) 的项（比如 T5 的偏置 \(b(m-n)\)）。这一项同时依赖 \(m\) 和 \(n\)，没法拆成“只依赖 \(m\) 的部分”乘以“只依赖 \(n\) 的部分”，于是方括号里的求和就不能提前算好，结合律的技巧失效，又回到了 \(N^2\)。

RoPE 的位置信息是分别乘在 query 和 key 上的，第 \(m\) 个词只用到自己的 \(R_m\)，第 \(n\) 个词只用到自己的 \(R_n\)，所以可以在非负函数之后再旋转：

$$\operatorname{Attention}(Q,K,V)_m=\frac{\sum_{n=1}^{N}\big(R^{d}_{\Theta,m}\phi(q_m)\big)^{\top}\big(R^{d}_{\Theta,n}\varphi(k_n)\big)\,v_n}{\sum_{n=1}^{N}\phi(q_m)^{\top}\varphi(k_n)}$$

分子仍然可以写成 \(\big(R^{d}_{\Theta,m}\phi(q_m)\big)^{\top}\big[\sum_n R^{d}_{\Theta,n}\varphi(k_n)\,v_n^{\top}\big]\)，方括号里和 \(m\) 无关，可以提前算好，线性复杂度保住了；同时 \(R_m^{\top}R_n=R_{n-m}\)，分子里的位置依赖仍然是相对的。

示意图：为什么旋转不破坏线性注意力的“先汇总、再查询”
普通注意力每个 qm 与全部 N 个 kn 算分数→softmax→加权求和 vn总计约 N² 次

本站示意图。关键在于位置信息能不能“各管各的”：RoPE 把位置拆成 query 一侧的 \(R_m\) 和 key 一侧的 \(R_n\)，两边各自处理；加在分数上的偏置是一对位置共同决定的，拆不开。
这个做法的两点代价，原文自己也承认了：
  • 分母没有旋转，作者的理由是避免分母出现 0 的风险。这样一来，分子里各项的权重加起来不再等于 1。
  • 非负函数旋转之后，分子里的内积可能出现负数，所以各个 value 的权重不再是严格意义上的概率分布。作者只是认为它“仍能刻画各个 value 的重要程度”，没有给出更强的保证。
另外，“以往的相对位置编码都不能用于线性注意力”是作者的判断；官方仓库的说法是“据我们所知，RoPE 是唯一能用于线性注意力的相对位置编码”。

逐步展开：

  1. 写成极坐标。设 \(f_q(x_q,m)=R_q(x_q,m)\,e^{i\Theta_q(x_q,m)}\)，\(f_k\) 和 \(g\) 同理，\(R\) 是长度（原文叫径向部分），\(\Theta\) 是角度。
  2. 拆成两个方程。“\(f_q\) 与 \(f_k\) 的乘积等于 \(g\)”在极坐标下就是：长度相乘相等，\(R_q(x_q,m)R_k(x_k,n)=R_g(x_q,x_k,n-m)\)；角度相减相等，\(\Theta_k(x_k,n)-\Theta_q(x_q,m)=\Theta_g(x_q,x_k,n-m)\)。
  3. 令 \(m=n\)。此时右边的相对位置是 0，可以用初始条件算出来：长度方程变成 \(R_q(x_q,m)R_k(x_k,m)=\|q\|\|k\|\)；角度方程变成 \(\Theta_k(x_k,m)-\Theta_q(x_q,m)=\theta_k-\theta_q\)，其中 \(\theta_q\)、\(\theta_k\) 是 \(q\)、\(k\) 自身的角度。
  4. 长度部分。一个最直接的解是长度与位置无关：\(R_q(x_q,m)=\|q\|\)，\(R_k(x_k,n)=\|k\|\)。也就是说，编码位置时不改变向量的长度。
  5. 角度部分。把上面的角度方程移项，得到 \(\Theta_q(x_q,m)-\theta_q=\Theta_k(x_k,m)-\theta_k\)。左边只和 query 有关，右边只和 key 有关，两者对任意内容都相等，说明这个差值只能是位置的函数，记作 \(\varphi(m)\)。含义是：每个向量在位置 \(m\) 上被转过的角度 \(\varphi(m)\) 与它的内容无关。
  6. 令 \(n=m+1\)。代回角度方程得到 \(\varphi(m+1)-\varphi(m)=\Theta_g(x_q,x_k,1)+\theta_q-\theta_k\)。右边与 \(m\) 无关，是个常数。相邻两项之差恒定的数列就是等差数列，所以 \(\varphi(m)=m\theta+\gamma\)。打个比方：如果每往后走一个位置，指针总是多转同样的角度，那么第 \(m\) 个位置的指针就转了 \(m\) 倍的这个角度。
  7. 收尾。得到 \(f_q(x_q,m)=q\,e^{i(m\theta+\gamma)}\)。作者取 \(q=W_qx_m\)、\(k=W_kx_n\)（和普通 Transformer 一致），并取 \(\gamma=0\)，就回到了第 3 节的解 \(f_q(x_m,m)=(W_qx_m)e^{im\theta}\)。
这段推导证明了什么、没证明什么：
  • 推导要求的其实是复数乘积（它的实部才是点积）整体只依赖 \(n-m\)，这比“点积只依赖 \(n-m\)”更强。所以它说明的是：在这个更强的要求和初始条件下，旋转是自然的解；并不是说只有旋转能让点积只依赖相对位置。
  • 第 4 步原文的措辞是“一个直接的解”，不是“唯一的解”。本站补充一个例子（推算）：取 \(R_q(m)=\|q\|c^{m}\)、\(R_k(n)=\|k\|c^{-n}\)（\(c\) 为正常数），长度之积 \(\|q\|\|k\|c^{m-n}\) 同样只依赖相对位置，并满足 \(m=n\) 时的条件。也就是说，旋转之外还可以再乘一个随距离指数变化的因子。后来的 xPos（Sun 等，2022）正是“在旋转矩阵上加指数衰减”，见第 10 节。
  • 原文式 (32) 写成 \(q=f_q(x_m,0)=W_qx_n\)，这里的 \(x_n\) 应为 \(x_m\)。

6.2 高效实现：两次逐元素乘法（原文 §3.4.2）

直接按式 (15) 构造一个 \(d\times d\) 的旋转矩阵再去乘，绝大部分都在乘 0，很浪费。利用分块对角的结构，旋转可以改写成两次逐元素乘法和一次加法：

$$R^{d}_{\Theta,m}x=\begin{pmatrix}x_1\\x_2\\x_3\\x_4\\\vdots\\x_{d-1}\\x_d\end{pmatrix}\otimes\begin{pmatrix}\cos m\theta_1\\\cos m\theta_1\\\cos m\theta_2\\\cos m\theta_2\\\vdots\\\cos m\theta_{d/2}\\\cos m\theta_{d/2}\end{pmatrix}+\begin{pmatrix}-x_2\\x_1\\-x_4\\x_3\\\vdots\\-x_d\\x_{d-1}\end{pmatrix}\otimes\begin{pmatrix}\sin m\theta_1\\\sin m\theta_1\\\sin m\theta_2\\\sin m\theta_2\\\vdots\\\sin m\theta_{d/2}\\\sin m\theta_{d/2}\end{pmatrix}$$

这里 \(\otimes\) 表示逐元素相乘。第二个向量是把每组的两个数交换位置、再给前一个取负号，这正是二维旋转公式 \((x\cos\varphi-y\sin\varphi,\ x\sin\varphi+y\cos\varphi)\) 的逐元素写法。每个位置的 \(\cos\)、\(\sin\) 表只和位置有关，可以提前算好、所有层共用。每个向量的额外开销是大约 \(2d\) 次乘法和 \(d\) 次加法（推算），和计算 query、key 本身的矩阵乘法相比可以忽略。

def rope(x, pos, base=10000.0):           # x: [seq, d]，d 为偶数；pos: [seq]
    d = x.shape[-1]
    theta = base ** (-torch.arange(0, d, 2) / d)       # d/2 个转速：1, ..., 约 1/base
    ang = pos[:, None] * theta[None, :]                # [seq, d/2]，每个位置每一组的角度
    cos = ang.cos().repeat_interleave(2, -1)           # [seq, d]：cos mθ1, cos mθ1, cos mθ2, ...
    sin = ang.sin().repeat_interleave(2, -1)
    x_swap = torch.stack((-x[:, 1::2], x[:, 0::2]), -1).flatten(-2)   # (-x2, x1, -x4, x3, ...)
    return x * cos + x_swap * sin

q, k = rope(h @ W_q, pos), rope(h @ W_k, pos)      # h: [seq, d_model]；每一层、每个头都做；v 不旋转
scores = q @ k.T                                     # 只依赖相对位置
论文 vs 代码：维度怎么两两配对

论文（以及 RoFormer 官方的 bert4keras 实现）把相邻的两维配成一组：(1, 2)、(3, 4)……。Meta 官方的 LLaMA 代码也是这样，它用 torch.view_as_complex 把相邻两维看成一个复数再乘以 \(e^{im\theta_i}\)。Hugging Face Transformers 的 LLaMA 实现则用 rotate_half：把向量切成前后两半，第 \(i\) 维和第 \(i+d/2\) 维配成一组。两种配对在数学上等价，只是维度的排列不同；Hugging Face 的权重转换脚本会对 \(W_q\)、\(W_k\) 的输出维度做一次重排（permute），保证转换后的模型输出一致。实际使用时，一份权重必须配它对应的那种实现，混用会让位置编码错乱。

RoPE 只改 query 和 key，还带来一个工程上很重要的好处：每个 key 的旋转只取决于它自己的位置，所以生成文字时缓存下来的 key（KV 缓存）可以存“已经转好的”版本，以后再也不用动；每生成一个新 token，只需要旋转这个 token 自己的 query 和 key。注意力内核本身完全不用改，FlashAttention、分页 KV 缓存这类优化都能直接用。

6.3 远程衰减的证明：衰减的是一个上界（原文 §3.4.3）

先补一点背景：阿贝尔变换（分部求和）。

积分里有“分部积分”，求和里也有对应的技巧。设 \(S_j\) 是另一个数列的前缀和（\(S_{j+1}-S_j\) 是第 \(j\) 项），那么

$$\sum_{i} h_i\,(S_{i+1}-S_i)=-\sum_{i} S_{i+1}\,(h_{i+1}-h_i)\qquad(\text{边界项为 0 时})$$

它把“\(h\) 乘以增量”换成了“前缀和乘以 \(h\) 的增量”。好处是：如果前缀和 \(S\) 本身不大、而 \(h\) 变化平缓，右边就容易估计。

证明分三步。第一步，把 RoPE 的内积写成复数求和：把 \(q=W_qx_m\)、\(k=W_kx_n\) 的每两维看成一个复数，记 \(h_i=q_{[2i:2i+1]}\,\overline{k_{[2i:2i+1]}}\)（第 \(i\) 组的“内容部分”），那么

$$\big(R^{d}_{\Theta,m}W_qx_m\big)^{\top}\big(R^{d}_{\Theta,n}W_kx_n\big)=\operatorname{Re}\Big[\sum_{i=0}^{d/2-1}h_i\,e^{i(m-n)\theta_i}\Big]$$

第二步，令 \(S_j=\sum_{i=0}^{j-1}e^{i(m-n)\theta_i}\)（只和距离有关），并约定 \(h_{d/2}=0\)、\(S_0=0\)，用阿贝尔变换把求和改写，再取绝对值：

$$\Big|\sum_{i=0}^{d/2-1}h_i\,e^{i(m-n)\theta_i}\Big|=\Big|\sum_{i=0}^{d/2-1}S_{i+1}(h_{i+1}-h_i)\Big|\le\Big(\max_i|h_{i+1}-h_i|\Big)\sum_{i=0}^{d/2-1}|S_{i+1}|$$

第三步，看右边的两个因子。第一个因子 \(\max_i|h_{i+1}-h_i|\) 只由 query 和 key 的内容决定，与距离无关。第二个因子 \(\sum_i|S_{i+1}|\) 只由距离 \(m-n\) 和频率决定，与内容无关。作者把第二个因子除以 \(d/2\) 画成曲线（原文图 2），发现它随距离增大而下降。下图是本站按同样的公式自己算出来的。

示意图：上界中只依赖距离的那个因子 \(\frac{1}{d/2}\sum_{j=1}^{d/2}|S_j|\)（d = 128，θi = 10000−2i/d，推算）
本站按原文 §3.4.3 的定义自行计算并绘制，横轴 0–512，纵轴为 \(\frac{1}{d/2}\sum_j|S_j|\)。距离为 0 时所有 64 组同相，值为 \((1+2+\dots+64)/64=32.5\)；随距离增大，转速不同的各组相位错开、互相抵消，值整体下降，但下降不是单调的，带着小幅起伏。原文图 2 画的是同一个量，见 原文图 2 ↗（原文正文没有交代作图用的 \(d\)，所以两张图的数值不一定一一对应）。

读这张图要分清两件事。曲线下降，说明内积绝对值的上界随距离变小。它说的是“远处的词不太可能拿到非常大的分数”，并不是说“远处的词分数一定小”。

关于“远程衰减”，容易过度解读的地方：
  • 衰减的是上界，不是注意力分数本身。如果某个远处的词在内容上和当前词高度匹配，它的分数仍然可以很大，模型照样能关注到它。
  • 上界的另一个因子 \(\max_i|h_{i+1}-h_i|\) 取决于内容，可能很大，所以这个上界本身可能很松。
  • 衰减的快慢由底数（10000）决定。第 10 节会看到，长上下文模型把底数改大，正是为了让这种衰减变慢。
  • RoPE 好用，是不是因为这个衰减？后来的分析并不支持这个说法（见第 10 节 Barbero 等的工作）。论文自己在局限性里也承认，其他位置编码同样有衰减性质，却说不清 RoFormer 为什么在长文本上更好。

7.1 机器翻译：WMT 2014 英德（原文 §4.1）

设置。数据是 WMT 2014 英译德，约 450 万句对。基线是原始 Transformer（base），作者只把自注意力层改成用 RoPE，其余照搬：联合源语言和目标语言的 BPE 词表，大小 37k；用 fairseq 实现；Adam 优化器（\(\beta_1=0.9\)，\(\beta_2=0.98\)），学习率先从 \(10^{-7}\) 线性升到 \(5\times10^{-4}\)，再按步数的平方根倒数衰减；标签平滑 0.1；评估时取最后 5 个检查点的平均，束搜索宽度 4，长度惩罚 0.6。指标是测试集 BLEU。

怎么看这个结果：0.2 BLEU 的差距很小，论文只报告了一次运行，没有方差，不足以说明哪个更好。另外，27.3 恰好是原始 Transformer 论文报告的 base 模型成绩；原文说两者在相同设置下训练，但没有说明 27.3 是自己复现的还是引用的。

8.3 作者承认的局限（原文 §4.5.5）

论文最后坦率地列了两条局限：第一，虽然从数学上把相对位置写成了二维子空间里的旋转，但说不清为什么它比采用其他位置编码的基线收敛得更快；第二，虽然证明了远程衰减，但其他位置编码也有类似性质，RoFormer 为什么在长文本上表现更好，作者也没有找到可信的解释。此外，基于 Transformer 的预训练需要相当的硬件资源。

9 结论：这篇论文真正留下了什么（原文 §5）

作者的结论是：相对位置可以自然地通过自注意力里的向量内积来表达，绝对位置则通过一个旋转矩阵编码进去；这种方法在数学上有好的性质，在英文和中文的基准上都加快了预训练的收敛，在长文本任务上表现更好。

回头看，这篇论文最站得住的是方法本身，而不是实验：

  • 相对性是精确成立的，不是近似。只要按位置旋转 query 和 key，点积就只依赖相对位置，这由旋转矩阵的性质直接保证（第 3、4 节）。
  • 零参数、零改动。RoPE 只在 query、key 上做两次逐元素乘法，不新增参数，不改注意力公式，于是 KV 缓存、各种高效注意力内核都能原样使用；它还能用在线性注意力里（第 5、6.2 节）。
  • 没有长度上限的“表”。任何位置都能算出旋转角度，不像可学习的位置向量那样在第 \(L+1\) 个位置就无从下手。不过“能算出角度”不等于“训练时没见过的长度也能用好”，这正是后来长度扩展研究要解决的问题（第 10 节）。
  • 实验证据偏弱。翻译只高 0.2 BLEU；GLUE 的对比混用了测试集和验证集成绩；长文本的优势很大程度上来自读了更多的输入。真正让 RoPE 站稳的，是后来大量大模型的实际采用。

最后澄清一个常见的困惑：RoPE 到底算绝对位置编码还是相对位置编码？两种说法都能在作者自己那里找到。官方仓库的中文 README 说它是“唯一一种可以应用到线性 Attention 的绝对位置编码”，英文 README 则称它为相对位置编码。区别在于看哪一面：从操作上看，每个 token 只用到自己的绝对位置 \(m\)，不需要知道别的 token 在哪，所以是绝对的；从效果上看，注意力分数只依赖位置差，所以是相对的。正是“操作是绝对的”这一点，让它能和 KV 缓存、线性注意力、各种注意力内核无缝配合；也正是“效果是相对的”这一点，让它具备了相对位置编码在建模上的好处。

10 后来怎么样了

论文在 arXiv 上的首版是 2021-04-20，此后又修订了四次（最后一版 v5 为 2023-11-08），2024 年正式发表在 Elsevier 的期刊 Neurocomputing 第 568 卷（文章号 127063）。官方代码仓库建于 2021-03-22，早于 arXiv 首版。下面按时间顺序列出 RoPE 的主要后续，只列能在原始论文里查到的事实。

10.1 被大模型采用

  • EleutherAI 的独立验证（2021-04）。与 arXiv 首版同一天，EleutherAI 发布博客 Rotary Embeddings: A Relative Revolution ↗，在 OpenWebText2 和 the Pile 上比较了可学习绝对位置、T5 相对偏置和 RoPE。按博客的报告，RoPE 的验证损失最低，收敛速度比可学习绝对位置快约 30%，比 T5 相对偏置快 10%–20%。RoFormer 官方仓库的 README 也引用了这篇博客。
  • GPT-J 与 GPT-NeoX-20B（2021–2022）。GPT-NeoX-20B ↗ 的论文写明用旋转位置编码代替 GPT 的可学习位置向量，并沿用 GPT-J 的做法，只旋转每个向量前 25% 的维度，另外 75% 不加位置信息。
  • PaLM（2022）。PaLM ↗ 采用 RoPE，理由是它在长序列上表现更好。
  • LLaMA（2023-02）。LLaMA ↗ 在架构一节写明：去掉绝对位置编码，在网络的每一层加入 Su 等人提出的旋转位置编码。此后 LLaMA 系列和大量基于它的开源模型都沿用 RoPE，它由此成为开源大模型最常见的位置编码。
  • DeepSeek 的 MLA（2024）。DeepSeek-V2 ↗ 想把 key 压缩成低秩的潜向量来节省 KV 缓存，却发现 RoPE 和这种压缩不兼容：旋转矩阵夹在 query 投影和 key 的上投影之间，而矩阵乘法不能交换顺序，上投影矩阵就没法提前合并进 query 一侧。它的办法是“解耦 RoPE”：另开一组每头 64 维的 query 和一个所有头共享的 key 专门承载 RoPE，其余维度不加位置。详见本站 DeepSeek-V3 拆解页的 MLA 部分。

10.2 把上下文拉长：插值、NTK 与 YaRN

RoPE 没有长度上限的“表”，但这不等于模型能直接用在比训练时更长的输入上。原因在频率上：以每头 128 维、底数 10000、训练长度 4096 为例，64 组频率中有 18 组的波长超过 4096（推算），这些慢速组在整个训练过程中连一圈都没转完，只见过一段有限的角度。最极端的是转得最慢的那一组：位置 4096 时它只转了约 27°，所以训练中它的角度永远落在 0° 到 27° 之间；如果直接把输入放长到 16384，它会转到约 108°（推算）。输入一旦超过训练长度，这些慢速组就会转到从没见过的角度上，模型的行为变得不可预测。

这就是“没有长度上限的表”和“能用在更长的输入上”之间的差别。后来的方法都是在“怎样让新位置落回见过的角度范围”上做文章：

  • 位置插值 PI（Chen 等，Meta，2023-06）。Extending Context Window of Large Language Models via Positional Interpolation ↗：不让位置超出训练范围，而是把位置编号整体按比例缩小，比如要把 2048 的窗口扩到 8192，就把位置 \(m\) 当成 \(m/4\) 来算角度。论文把 LLaMA 7B–65B 的窗口扩到最长 32768，只需不超过 1000 步的微调；他们的理论分析表明，在 LLaMA 7B 的设置下，插值时注意力分数的上界比直接外推小约 600 倍。代价是所有频率一视同仁地被压缩，原本用来分辨相邻词的高速组也被压慢了。
  • NTK-aware 插值（bloc97，2023 年年中）。最早以 Reddit 帖子 ↗ 的形式发表：不改位置，改底数，把 \(b\) 换成 \(b'=b\cdot s^{d/(d-2)}\)（\(s\) 是扩展倍数）。效果是高速组几乎不动、低速组被压得最多。按这个公式可以验证（推算）：最快的一组 \(\theta=1\) 完全不变，最慢的一组恰好被除以 \(s\)，和 PI 对它的处理一样。它不微调时效果明显好于 PI，但部分维度会被轻微外推，微调后反而不如 PI（据 YaRN 论文附录 A.2）。在此基础上还出现了推理时按当前长度动态调整的“Dynamic NTK”。
  • 直接把底数调大。Code Llama ↗（2023-08）在长上下文微调阶段把底数从 10,000 改为 1,000,000，用 16,384 长度的序列微调，能处理到 100,000 个 token；论文指出更大的底数减弱了注意力分数随距离的衰减。Llama 3 ↗（2024）在预训练时就把底数设为 500,000，以更好地支持长上下文。
  • YaRN（Peng 等，2023-08，ICLR 2024）。YaRN: Efficient Context Window Extension of Large Language Models ↗ 按每组在训练长度 \(L\) 内转过的圈数 \(r=L/\lambda\) 区别对待：转了很多圈的高速组（LLaMA 上取 \(r\gt 32\)）完全不动，因为它们只编码相对位置；连一圈都没转完的低速组（\(r\lt 1\)）按 PI 的方式完全插值；中间的线性过渡（这一步叫“NTK-by-parts”）。此外再给注意力的 softmax 加一个温度，推荐 \(\sqrt{1/t}=0.1\ln s+1\)。论文报告它比之前的方法少用 10 倍的 token、2.5 倍的训练步数，并把 Llama 2 7B/13B 扩到 128k。DeepSeek-V2 就用 YaRN 把窗口从 4K 扩到 128K（\(s=40\)，\(\alpha=1\)，\(\beta=32\)）。

10.3 对 RoPE 的再理解

  • xPos（Sun 等，2022）。A Length-Extrapolatable Transformer ↗ 在 RoPE 的旋转矩阵上再乘一个指数衰减，让注意力随距离的变化更平稳，以改善长度外推。这正好对应第 6.1 节里提到的“长度部分不必是常数”。
  • 不用位置编码行不行（Kazemnejad 等，NeurIPS 2023）。The Impact of Positional Encoding on Length Generalization in Transformers ↗ 发现，在他们的推理和数学类任务上，只用因果掩码、不加任何显式位置编码（NoPE）的 decoder-only 模型，长度泛化反而好于 RoPE、ALiBi 等；理论上 NoPE 也能表示绝对和相对位置。
  • RoPE 好用的原因可能不是衰减（Barbero 等，2024）。Round and Round We Go! What makes Rotary Positional Encodings useful? ↗ 分析了训练好的 Gemma 7B，认为“随距离衰减”不太可能是 RoPE 起作用的核心原因：模型用最高频的几组构造依赖位置的注意力模式，而低频的几组更多地被当作承载语义的通道。
  • 同一时期的另一条路：ALiBi。Train Short, Test Long ↗（Press 等，2021-08）不旋转，而是在注意力分数上减去一个与距离成正比的线性偏置。论文报告 13 亿参数的模型用 1024 长度训练，在 2048 长度上测试时，困惑度与直接用 2048 训练的正弦编码模型相当。
