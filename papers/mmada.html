0 导读：这篇论文解决什么问题

过去几年，多模态大模型大致分成两拨。一拨负责“看懂”图像：把图像变成向量交给语言模型，让它回答关于图像的问题，代表是 LLaVA。另一拨负责“画出”图像：根据一段文字生成图片，主流是扩散模型，比如 Stable Diffusion。把两种能力装进同一个模型，叫做统一多模态模型（unified multimodal model）。2024–2025 年的统一模型基本离不开自回归：要么文字和图像都按“下一个 token”逐个生成（Emu3、Janus），要么文字用自回归、图像用扩散，在一个网络里混用两种训练目标（Show-o、Transfusion）。

2025 年 2 月的 LLaDA 证明，一个 8B 参数、用掩码扩散训练的语言模型也能当通用大模型用：它不是从左到右一个字一个字地写，而是先把整段回答都写成“空格”，再一轮轮把空格填上。MMaDA 顺着这个方向又走了一步。图像本来就可以用一个 VQ 编码器切成一串离散的“图像词”，而“遮住一部分词、让模型猜回来”这件事对图像词和文字词一样适用。既然如此，就可以只用一个网络、一个训练目标，同时学会文本推理、看图回答和文生图。在这个统一的底座上，作者把重点放在后训练：先用三类任务格式统一的长思维链数据做微调（Mixed Long-CoT），再用为扩散模型设计的强化学习算法 UniGRPO 继续优化。

论文报告的最终模型 MMaDA-8B 从 LLaDA-8B-Instruct 初始化，图像理解上 POPE 86.1、MMMU 30.2，文生图上 GenEval 总分 0.63、WISE 文化类 0.67，文本上 GSM8K 73.4、MMLU 68.4。读这些数字需要格外小心：文本对照组是从 LLaDA 论文里沿用的预训练基座模型成绩；两个文生图指标（CLIP 分数、ImageReward）既是 RL 的奖励，又是在作者自己的测试集上算的；经过 UniGRPO 的最终权重截至 2026-10-19 仍未公开。第 7 节会把每个比较的条件逐一摊开。

1 引言：统一多模态模型的几种做法，缺的是什么

这一节要回答的问题：统一多模态模型已经有好几种做法，作者认为它们缺的是什么？论文第 1 节用一张表（原文表 1）把现有做法按“语言部分用什么目标、视觉部分用什么目标、有没有后训练”分类，再把 MMaDA 放进去。这一节要弄清楚这张表每一行的含义，以及作者声称的空白，也就是“非自回归模型的后训练”，到底指什么。
先补一点背景：理解与生成，为什么想把它们装进一个模型。

“多模态理解”指输入里有图像、输出是文字，比如问“图里的猫在干什么”。“文生图”反过来，输入文字、输出图像。传统做法是两个独立的模型：理解模型（如 LLaVA）把图像编码成向量喂给语言模型；生成模型（如 Stable Diffusion）用文本编码器读提示词，再用扩散网络画图。两者的参数、数据、训练目标都不一样。

把它们合成一个模型有两个动机。第一是省事：一个网络、一套部署。第二是希望能力互相借用。比如提示词是“伊斯坦布尔人最喜欢的动物”，画图之前得先知道答案是猫，这需要语言模型里的世界知识；反过来，画过大量图片的模型也许对图像内容理解得更细。后一个动机是否成立并没有定论，本站的另一篇精读专门测了“学会画图能不能让统一模型知道得更多”。

先补一点背景：三种生成方式。

自回归（AR）：按固定顺序一个接一个地生成 token，每个 token 都以前面所有 token 为条件，训练目标是“预测下一个 token”的交叉熵，原文记作 \(\mathcal{L}_{\text{NTP}}\)。连续扩散：对图像（或它的压缩表示）逐步加高斯噪声，训练网络预测所加的噪声，记作 \(\mathcal{L}_{\text{Diff-cont}}\)；生成时从纯噪声一步步去噪。离散扩散（这里特指掩码扩散）：数据是离散 token，“加噪”就是把一部分 token 换成特殊符号 [M]，训练网络把被遮住的原 token 猜回来，记作 \(\mathcal{L}_{\text{Diff-disc}}\)；生成时从全是 [M] 的序列开始，一轮轮把 [M] 换成具体的 token。第 2 节会把掩码扩散讲细。

表 1 的采样一栏也值得注意：MMaDA 的文本用“半自回归 + 低置信度重掩码”（来自 LLaDA），图像用“余弦调度 + 重掩码”（来自 MAGVIT-v2 / MaskGIT 一系）。也就是说，训练目标是统一的，推理时两种模态却走两套不同的采样流程（第 5 节）。

读的时候容易混淆的一点：“统一”在这个领域至少有三种意思：共用一个网络（Show-o 也做到了）；共用一套离散 token（Emu3 也做到了）；共用一个训练目标（这是 MMaDA 的卖点）。MMaDA 三者都占，但推理时文本与图像的采样器不同，图像理解也只能看离散码、看不到连续的视觉特征。读后文的比较时，要先分清对手和 MMaDA 是在哪一层“统一”。

2 预训练：把图像变成“词”，和文本共用一个掩码目标

这一节要回答的问题：要让文字和图像共用“遮住再猜回来”这一个目标，前提是两者都是离散 token。文字天然是离散的，图像是像素，怎么变成离散 token？变成之后，一个同时含有文字和图像码的序列具体怎么加噪，损失在哪些位置上算？这一节对应原文 §2.1，并对照了官方代码，因为代码里有几处和公式并不完全一样。

2.1 图像怎样变成离散 token

先补一点背景：VQ 图像编码器。

可以把它想成拼马赛克。先训练一个自编码器：编码器把一张 \(H\times W\) 的图压成 \(\frac{H}{f}\times\frac{W}{f}\) 的特征网格（\(f\) 是下采样倍数），解码器再从网格把图还原出来。向量量化（VQ）在中间加了一步：准备一本有 \(K\) 项的“码本”，网格上每个位置的特征都被替换成码本里离它最近的那一项，只记下那一项的编号。这样一张图就变成了 \(\frac{H}{f}\cdot\frac{W}{f}\) 个整数，每个整数在 \(0\)～\(K-1\) 之间，就像用 \(K\) 种瓷砖拼出来的马赛克，只要记录每个格子用了哪种瓷砖。解码器拿到这串编号，查回对应的向量，就能画回图像。

MMaDA 直接沿用 Show-o 预训练好的、基于 MAGVIT-v2 结构的量化器，训练中不再改动。参数是 \(f=16\)、码本大小 8192，所以一张 512×512 的图变成 32×32 = 1024 个图像码。官方代码里这个量化器是 MAGVIT-v2 提出的“免查表量化”（LFQ）：每个位置的特征被压到 13 维，每一维只保留正负号，13 个正负号恰好组成一个 13 位二进制数，\(2^{13}=8192\) 就是码本大小，所以不需要在码本里找最近邻models/modeling_magvitv2.py LFQuantizer。

文字用 LLaDA 的分词器。官方配置把两套词表首尾相接：LLaDA 的 126,464 个文本 token 在前，8192 个图像码排在后面（编号整体平移 126,464），合成一个 134,656 项的大词表，模型只有一张嵌入表、一个输出头configs/mmada_demo.yaml。对模型来说，“第 130,000 号 token”和“猫”这个字没有本质区别，都只是词表里的一项。代码还加了几个特殊 token 标出任务和图像的起止，比如 <|t2i|>（文生图）、<|mmu|>（图像理解）、<|soi|> / <|eoi|>（图像开始 / 结束）training/prompting_utils.py。整个模型里没有 CLIP 一类的连续视觉编码器（配置项 w_clip_vit: False），理解任务也只能通过这 1024 个离散码“看”图。

容易忽略的一点：图像码在语言模型里的嵌入是从零学起的。量化器的码本是为“能把图还原回来”而训练的，并不保证编号和语义对齐，语言模型得靠大量图文数据自己学会“哪些码组合起来是一只猫”。Show-o 的消融里有一个直接的对照：同样的模型，把输入从 MAGVIT-v2 离散码换成 CLIP-ViT 的连续特征，POPE 从 73.8 升到 84.5，MME 从 948.4 升到 1182.7Show-o arXiv v1 表 4。所以 MMaDA 的图像理解从一开始就背着“只看离散码”的包袱，第 7 节和 LLaDA-V 的对比还会看到这一点。

2.2 掩码扩散：一个目标同时学文字和图像

先补一点背景：掩码扩散怎么训练、怎么生成。

设干净的序列是 \(x_0\)，长度为 \(L\)。训练时先均匀地抽一个“噪声水平” \(t\in[0,1]\)，再让序列里每个 token 独立地以概率 \(t\) 被换成 [M]，得到 \(x_t\)。\(t\) 接近 0 时几乎没被遮，\(t=1\) 时全被遮。网络 \(p_\theta\) 一次读完整个 \(x_t\)（注意力是双向的，每个位置能同时看到左右两边），对所有 [M] 位置同时给出“原来是哪个 token”的概率分布，训练目标是这些位置上的交叉熵。

损失前面要乘 \(1/t\)。直观的理由是：\(t\) 小时被遮的 token 很少，每个被遮 token 的损失要放大，才能和 \(t\) 大时处在同一个量级；严格的理由是，带 \(1/t\) 的这个损失恰好是负对数似然的一个上界（ELBO），所以把它压低就是在提高模型给真实数据的概率。推导见 MDLM 精读和 LLaDA 精读。

生成时从一串全是 [M] 的序列出发：网络预测所有 [M] 位置，挑出其中一部分（通常是最有把握的）定下来，其余继续保持 [M]；再预测，再定一部分，直到全部定完。每一轮叫一步。因为一步可以定多个 token，总步数可以少于序列长度。

MMaDA 的预训练目标（原文式 1）写出来就是上面这件事：

$$\mathcal{L}_{\text{unify}}(\theta)=-\,\mathbb{E}_{t,x_0,x_t}\Big[\frac{1}{t}\sum_{i=1}^{L}\mathbf{1}\big[x_t^{i}=[\mathrm{M}]\big]\log p_\theta\big(x_0^{i}\mid x_t\big)\Big]$$

这里 \(x_0^{i}\) 是第 \(i\) 个位置的真实 token，可能是文字，也可能是图像码；\(\mathbf{1}[\cdot]\) 保证只在被遮住的位置算损失。式子里没有任何“这是文字还是图像”的区分，这就是论文所说的“统一的概率形式”。同一个式子覆盖三类预训练任务，区别只在于序列里哪一段被允许加噪。下图用一个缩小的例子走一遍：

论文 vs 官方代码
  • 图像分支并不是式 1 的字面形式。代码里图像码的掩码率是 \(\cos(\tfrac{\pi}{2}t)\)（MaskGIT 式的余弦调度），按这个比例精确地遮住相应个数的码；损失是被遮位置交叉熵的简单平均，没有 \(1/t\) 加权。文本和理解分支才是线性掩码率 \(t\)、带 \(1/t\) 加权，并按回答长度归一化models/modeling_mmada.py forward_process；training/utils.py mask_or_random_replace_tokens。所以“同一个目标”更准确的说法是“同一种掩码预测任务，掩码率分布和加权方式因模态而异”。
  • 分辨率。第一阶段在 ImageNet 上训练的配置是 256×256（16×16 = 256 个码），后续阶段才是 512×512stage1 配置 resolution: 256；stage3 / stage4 配置 resolution: 512。
  • 为推理时的引导做准备。文生图样本有 10% 的概率把文字条件换成空提示（cond_dropout_prob: 0.1），这样同一个模型既会有条件生成、也会无条件生成，推理时才能用第 5 节讲的无分类器引导。
  • 附录 A.1 介绍的是 Show-o 的“掩码 + 均匀替换”转移矩阵，但 MMaDA 配置里写的是 noise_type: "mask"，实际只用纯掩码。

3 混合长思维链微调：先教会模型“想完再答”

这一节要回答的问题：预训练后的模型能做三类任务，但回答通常很短，没有推理过程。作者希望它在文本数学题、看图几何题和需要世界知识的文生图上，都先写出推理再给结果，并为下一步的强化学习打好底子。这一节（原文 §2.2）回答三个问题：统一的思维链格式长什么样；数据从哪来；微调时损失怎么算。
先补一点背景：思维链、监督微调和“冷启动”。

思维链（chain-of-thought，CoT）指让模型在给出最终答案之前，先把中间推理一步步写出来；“长思维链”是几百到上千 token 的推理过程，常带有验算和回头检查。监督微调（SFT）就是用“问题 → 标准回答”的数据继续训练。

为什么强化学习之前要先做 SFT？GRPO 一类的 RL 只能“放大”模型已经偶尔做对的行为：它对同一个问题采样多个回答，奖励高的被加强。如果模型一开始几乎从不按要求的格式写推理、也几乎答不对，一组回答的奖励就全是 0，组内没有差异，也就没有可学的信号。先用一批高质量的长思维链做 SFT，让模型至少会按格式写、偶尔能答对，这一步叫冷启动。DeepSeek-R1 用的是同一个思路。

4 UniGRPO：给扩散模型做强化学习

这一节要回答的问题：微调之后，作者想用强化学习进一步提高推理正确率和生成质量。大语言模型上最常用的 RL 算法 GRPO 需要算“模型生成某个回答的概率”，这在自回归模型里一次前向就能读出来，在扩散模型里却算不出来。这一节（原文 §2.3、附录 A.2、附录 B、算法 1）先补 GRPO 的背景，再看扩散模型难在哪里、LLaDA 和 d1 各自怎么处理、UniGRPO 改了什么，最后看三类任务的奖励怎么设计。

4.1 先补背景：策略梯度、PPO 与 GRPO

先补一点背景：用强化学习训练语言模型。

把语言模型看成一个“策略” \(\pi_\theta\)：给定问题 \(q\)，它以一定的概率生成回答 \(o\)。强化学习的目标是调整 \(\theta\)，让高奖励回答的概率变大。最朴素的做法叫策略梯度：采样一个回答，算出奖励，然后沿着 \(\nabla_\theta\log\pi_\theta(o\mid q)\) 的方向走一步，步长和“这个回答比平均好多少”成正比，这个量叫优势 \(\hat A\)。好于平均的回答被加强，差于平均的被削弱。

PPO 在此基础上加了一道保险。回答是用更新前的旧策略 \(\pi_{\text{old}}\) 采样的，更新时计算新旧策略对同一个 token 的概率之比 \(r=\pi_\theta/\pi_{\text{old}}\)，用 \(r\cdot\hat A\) 作为目标，但把 \(r\) 截断在 \([1-\varepsilon,\,1+\varepsilon]\) 之内。这样一次更新不会把某个 token 的概率改得太猛，训练更稳。PPO 还需要一个价值网络来估计优势。

GRPO（DeepSeekMath 提出）去掉了价值网络：对同一个问题一次采样 \(G\) 个回答，用组内奖励的均值和标准差把每个回答的奖励标准化，结果直接当作这个回答里每个 token 的优势；另外加一项和参考模型 \(\pi_{\text{ref}}\)（通常就是 RL 开始前的模型）之间的 KL 惩罚，防止模型跑得太远。

$$\hat A_i=\frac{R_i-\operatorname{mean}\big(\{R_j\}_{j=1}^{G}\big)}{\operatorname{std}\big(\{R_j\}_{j=1}^{G}\big)}$$

用 MMaDA 文本任务的奖励规则（答对 2.0、格式正确 0.5，见 4.4 节）举一个 \(G=4\) 的例子：

GRPO 的目标（原文式 16）是对组内每个回答、回答里每个 token 的“截断后的比值 × 优势”取平均，再减去 KL 项。关键在每个 token 的比值 \(r_{i,k}=\pi_\theta(o_{i,k}\mid q,o_{i,<k})\,/\,\pi_{\text{old}}(o_{i,k}\mid q,o_{i,<k})\)。在自回归模型里，把问题和回答拼起来做一次前向，就能读出回答中每个 token 在“前文已知”条件下的概率；链式法则保证这些概率的乘积正好是整个回答的概率。

4.2 难点：扩散模型说不出“这个回答的概率是多少”

扩散模型没有“前文”的概念，也就没有链式法则。它只会回答这样一个问题：给定一个部分被遮住的序列，被遮住的位置分别是什么。作者因此列出三个困难（§2.3.1）：第一，单个 token 的对数概率只在被遮住的位置上有定义，没被遮的位置模型根本不预测；第二，算出来的数值取决于遮了多少、遮了哪些，必须对掩码率取样；第三，没有链式法则，不能把 token 的对数概率直接加成整句的对数概率，严格的序列似然只能借助 ELBO 用蒙特卡洛估计。

此前有两种处理方式（附录 B）：

  • LLaDA（它本身没做 RL，但给出了估计似然的办法）：对一个回答随机抽 \(N\) 个掩码率（原文 \(N=128\)），每个掩码率下遮住回答的相应部分、做一次前向，收集被遮位置的对数概率再平均。估计比较准，但一个回答要 128 次前向；在线 RL 每一步都要对新采样的回答重新估计，这个代价负担不起。
  • d1（diff-GRPO，第一个面向扩散语言模型的 GRPO）：每次只做一次前向。问题部分随机遮掉一些 token，回答部分全部遮掉，用这次前向在回答每个位置上的预测当作 token 概率，随机性来自“问题遮哪些”。MMaDA 的作者认为这有两个问题：真实使用时问题从来不会被遮，遮问题只是为了制造随机性；回答总是全遮，相当于只训练了“从全是 [M] 出发的第一步”，模型被当成一步出结果的预测器，没有用上扩散模型多步去噪的特点。d1 本身的设计见 d1 精读。

4.3 UniGRPO 的三处改动

UniGRPO 可以概括为“问题不遮、回答部分遮、多次更新时换不同的遮法”（§2.3.1、附录 B、算法 1）：

  1. 问题永远完整。这和推理时的真实条件一致。
  2. 回答按随机掩码率部分遮住。对每个回答 \(o_i\) 抽一个掩码率 \(p_i\in[0,1]\)，把回答里相应比例的 token 换成 [M]，得到 \(\tilde o_{i,p}\)。不同梯度步用不同的随机种子，所以模型在 RL 中会见到从“几乎全遮”到“几乎全露”的各种状态，也就是去噪过程的各个阶段。
  3. 用被遮位置的平均对数概率当作整句的对数概率。一次前向之后，只看被遮住的那些回答 token：
$$\log\pi'_\theta(o_i)\;\approx\;\frac{1}{|M_i|}\sum_{k\in M_i}\log p_\theta\big(o_{i,k}\mid q,\tilde o_{i,p}\big)$$

其中 \(M_i\) 是这一次被遮住的位置集合。原文式 3–4 的记号比较随意（例如把对数概率直接记作 \(\pi'\)），这里按其含义改写。新旧策略在同一个加噪输入上各算一次，逐 token 的比值、截断和 KL 项都照搬 GRPO（原文式 5）。下图把三种做法放在一起：

多次内循环的掩码率怎么取。GRPO 通常对同一批采样做 \(\mu\) 次梯度更新。UniGRPO 规定这 \(\mu\) 次的掩码率不是各自独立随机，而是先随机抽一个起点，再在剩下的区间里等距铺开（算法 1，扩散步数 \(T=1000\)）。这样同一批回答在 \(\mu\) 次更新中依次在“少遮”到“多遮”的不同状态下被评估，合起来近似于对掩码率做了一次分层的蒙特卡洛平均，而每次更新仍然只要一次前向。

5 推理时怎么采样：文本分块，图像一次铺开

这一节要回答的问题：训练目标是统一的，但生成文本和生成图像时，模型用的是两套不同的采样流程。为什么文本要“分块、从左到右”，图像却可以整张一起去噪？每一步揭开多少个 token，要走多少步，每一步的计算量有多大？这一节对应原文 §3。
先补一点背景：按置信度揭开、分块，以及无分类器引导。

低置信度重掩码。每一步网络对所有 [M] 位置给出概率分布，每个位置取概率最高的 token 作候选，并记下这个最高概率，叫置信度。然后只保留置信度最高的若干个位置，其余位置的候选作废、重新写回 [M]，留到后面的步骤。这样先定下最有把握的内容，没把握的等上下文更多时再决定。

半自回归分块。把要生成的长度切成若干块，一块一块从左到右生成，块内用上面的方法并行去噪；后一块开始之前，前一块必须全部定完。它介于纯自回归（块长 1）和纯扩散（块长等于全长）之间。

无分类器引导（CFG）。每一步把同一个序列在“有文字条件”和“文字条件为空”两种情况下各算一次，再把有条件的预测朝远离无条件预测的方向推一把，从而强化和文字相关的内容。官方代码写的是 \(\ell=(1+w)\,\ell_{\text{cond}}-w\,\ell_{\text{uncond}}\)，\(w\) 是引导强度models/modeling_mmada.py t2i_generate。代价是每一步要算两遍。

文本。评测时生成长度 \(N=1024\)，共 512 步，块长 64：1024 个位置分成 16 块，每块 32 步，每步揭开 2 个 token（推算）。原文写的是每步揭开块内“置信度最低”的 2 个 token，这与它自己所说的低置信度重掩码（揭开置信度最高的、重掩置信度最低的）方向相反，应是笔误。

为什么一定要分块？作者给了一个对比：同样 1024 长度、512 步，块长设成 1024（不分块）时，模型对“详细描述这幅画”只回答了一句话；块长 64 时回答了一整段。原因是指令微调数据里每个回答后面都补了大量结束符 |EOS|，模型学到“回答后半段大概率是 EOS”，而且对这件事非常有把握。不分块时按置信度挑位置，最先被定下的往往是序列尾部一大片 EOS，回答还没展开就被“封了口”。分块之后，第一块里只有 64 个位置可选，模型必须先把开头写完。LLaDA 论文报告过同样的现象。

下面这个小演示可以直接看到块长的作用。画布只有 16 个位置，块长 B 可以调。它用的是一个能精确计算的玩具分布，不是 MMaDA 本身，但“块越短越接近从左到右、每块分到的步数越少越容易出错”的规律是一样的。

图像。文生图不分块，1024 个图像码作为一整块，从全 [M] 开始走 50 步，按余弦调度决定每一步之后还剩多少个 [M]，每步都用 CFG（引导强度 3.5），同样按置信度挑要定下的码。余弦调度前慢后快：开头几步只定下极少的码，让模型在高度不确定的状态下先确定整体布局；越往后已知的码越多，剩下的位置越好判断，就一次定得越多。下图按官方代码的公式算出每一步之后剩下的 [M] 个数：

数据图：50 步余弦调度下，每步之后还剩多少个图像码是 [M]
推算：按官方 t2i_generate 的规则，第 \(k\) 步之后剩余 \(\lfloor 1024\cos(\tfrac{\pi}{2}\cdot\tfrac{k}{50})\rfloor\) 个 [M]（并保证每步至少定下 1 个）。虚线是同样 50 步的线性调度，作对照。

按这条曲线，50 步里平均每步定下约 20 个码，但分布很不均匀：前 10 步一共只定下 51 个，最后 10 步定下 316 个（推算）。

每一步要算多少。论文没有报告任何墙钟时间或吞吐量，只报告了步数。为了对代价有个数量级的概念，可以这样估算（推算）：文本生成的每一步都要让网络完整地读一遍“提示 + 1024 个位置”（论文没有提到 KV 缓存，官方代码的生成函数每一步也都对整个序列重新计算models/modeling_mmada.py mmu_generate），512 步就是 512 次这样的完整前向；文生图每一步因为 CFG 要算有条件、无条件两份，50 步相当于 100 次对“提示 + 1026 个 token”的前向。相比之下，自回归模型生成 1024 个 token 要 1024 次前向，但借助 KV 缓存，每次只需要处理 1 个新 token。所以“步数少”并不直接等于“更快”。

读的时候容易误解的地方：第 8 节的表 6 说“少步数也能保持质量”，那是步数和质量的关系，不是速度。扩散模型的一步是对整个序列做一次双向计算，和自回归模型带缓存的一步在计算量上不可比。要比较速度，至少需要同样的硬件、同样的批大小、同样的输出长度，并且自回归一方要用 vLLM 一类的优化引擎（见 vLLM 精读）。MMaDA 没有做这样的比较。后来的 Fast-dLLM 等工作才开始给扩散语言模型加近似缓存和按阈值并行解码。

  • 复现情况。截至 2026-10-19，官方只发布了 MMaDA-8B-Base 和 MMaDA-8B-MixCoT 两个权重；表 2–5 最后一行对应的、经过 UniGRPO 的 MMaDA-8B-Max 在 README 里仍标为“coming soon”。官方评测说明还写明，文本评测脚本目前只实现了不带推理的版本，结果“尚未与内部结果对齐”。因此表中最终一行的数字暂时无法用公开权重复现。
  • 第三方测出来的数字。后来有两篇论文自己评测了 MMaDA（都没有写明用的是哪个检查点）。Lavida-O 测得 ChartQA 9.8、DocVQA 10.9、InfoVQA 14.9，说明需要读图中文字的任务它几乎做不了；还测得 DPG-Bench 53.4、MSCOCO 上 FID-30k 32.85（Lavida-O 表 2–3）。Lumina-DiMOO 测得 DPG-Bench 总分 69.97（Lumina-DiMOO 表 4）。两篇论文对同一个基准给出的数字相差 16 个点以上，说明评测设置对 MMaDA 的分数影响很大。

总的来说，MMaDA 证明了一个 8B 的掩码扩散模型可以只用一个训练目标，同时具备文本推理、图像理解和文生图的基本能力，这是它最站得住的结论。至于“在三类任务上都优于专门模型”的说法，在同条件比较下大多不成立，或者无法判断。

8 分析：各阶段的贡献、UniGRPO 的设计、任务协同与少步采样

这一节要回答的问题：三个训练阶段各贡献了多少？UniGRPO 的两个设计（只遮回答的一部分、等距铺开掩码率）比 d1 和完全随机好在哪里？三类任务一起训练有没有互相促进？少用几步采样会掉多少分？扩散模型能不能直接做填空？对应原文 §5。

8.1 消融：每个阶段带来多少（原文表 5）

有一个数字值得停下来想一想。MMaDA 是从 LLaDA-8B-Instruct 初始化的，LLaDA 论文报告这个初始化模型的 GSM8K 是 78.6；经过 Stage 1 的多模态预训练之后，同一个基准只剩 17.4。评测协议不同（例如 MMaDA 要求特定的推理格式），差距不能全部归因于能力下降，但这至少提示 Stage 1 很可能大幅冲掉了原有的文本能力，而第 2 节提到的文本损失权重只有 0.1 也与此相符。后面的 SFT 和 RL 有相当一部分是在把这部分能力“补回来”（本站推论）。所以“Mixed Long-CoT 让 GSM8K 提高了 47.8 个点”不能理解成长思维链本身有这么大的作用。

读这张表时要注意的几点：
  • 表 5 只有“依次叠加”的三行，没有“不做 CoT 直接 RL”或“只用某一类任务做 RL”的对照，分不清各类数据各自的贡献。
  • GSM8K、GeoQA、CLEVR 都是 RL 训练数据的同分布测试集，RL 的提升在这些基准上最容易出现；论文没有单独报告 RL 对未参与训练的基准（如 MMLU、MMMU）的影响。
  • 表 5 的 MATH500 一列和表 4 的 MATH 一列数值相同（36.0），名称却不同；最终行的 CLIP 分数在表 5 是 32.5、在表 3 是 32.46，可以视为四舍五入。

8.2 UniGRPO 的两个设计选择（原文图 3、图 4）

为了控制成本，这两组对比只在 GSM8K 上、用 8 张 A100 做，两边都从同一个 MMaDA 检查点出发。两张图的横轴都是 RL 步数（0 到约 5000），纵轴是训练中的正确性奖励（答对记 2.0）。

只遮回答的一部分 vs d1 的做法（原文图 3 ↗）：UniGRPO 的曲线全程高于 diff-GRPO（d1）。作者的解释是：回答只被部分遮住，输入里还带着一部分已知内容，模型在 RL 中练到了多个去噪阶段，而不只是“从一张白纸出发的那一步”。

等距铺开 vs 完全随机（原文图 4 ↗）：“等距铺开掩码率”的曲线更平滑、更早收敛，“每次完全随机抽”的曲线波动更大、收敛更慢。作者认为等距铺开相当于在 \(\mu\) 次更新里对掩码率做了分层采样，近似蒙特卡洛平均，所以对数概率估计的方差更小。

这两张图能说明什么、不能说明什么：它们只有训练过程中的奖励曲线，没有测试集上的最终准确率，也没有多次运行的误差范围。训练奖励更高说明在训练题上学得更快，不等于测试集上更好。两组实验都只在文本任务上做，UniGRPO 用在图像生成上的效果没有单独的消融。

8.3 三类任务的协同（原文图 5、图 6）

原文图 6 ↗ 把 Stage 2 期间的三项指标（文本的 MMLU、理解的 CLIP 分数、生成的 ImageReward）归一化后画在一起，横轴是训练步数（130K 到 200K），三条线都随训练上升。原文图 5 ↗ 用同一个问题“温室是什么样的”在 1 万步和 10 万步时的回答做定性对比：文字回答变得更具体，图像描述变得更准确，生成的温室图也更贴题。作者把这称为跨模态的协同。

容易被过度解读的地方：三条曲线同时上升，最简单的解释是“同一个模型在继续训练”，并不能证明任务之间互相帮助。要证明协同，需要对照组，比如只用文本数据训练同样的步数，看图像指标会不会也上升；或者去掉某一类数据，看其他指标是否下降。论文没有做这样的对照。另外，这里“多模态理解”用 CLIP 分数衡量，指的是模型写的图像描述和图像之间的 CLIP 相似度，不是常规的理解指标。

8.5 不用微调就能填空（原文图 7）

掩码扩散模型训练时练的就是“补全被遮住的部分”，所以填空类任务不需要额外训练：把已知部分照原样放进序列，把要补的部分写成 [M]，按正常流程去噪即可。Show-o 只在图像上展示过这种能力，MMaDA 展示了三种：补全一句话中间缺失的片段；给定图像和半截回答，补全 VQA 的回答；给定被挖掉一块的图像和文字描述，补全图像（inpainting）。这一节只有定性示例（原文图 7 ↗），没有定量评测。自回归模型做中间填空需要专门的训练格式（比如把后文挪到前面），这是扩散路线一个结构上的优势。

9 相关工作与结论

相关工作（§6）分三条线。第一条是多模态理解模型：LLaVA、MiniGPT-4、InstructBLIP 等把 CLIP 一类视觉编码器的特征投影进语言模型，几乎都是自回归。第二条是视觉生成：连续扩散模型（Stable Diffusion 系列）是主流，另有离散扩散（D3PM、VQ-Diffusion、MaskGIT）和自回归图像生成（LlamaGen、VAR）。第三条是统一模型：SEED-X、DreamLLM、Emu3 等把所有模态都表示成 token 并用一个 Transformer 端到端训练；Transfusion、Show-o 用自回归生成文本、用扩散生成图像。作者认为这些工作都集中在预训练，后训练设计是空白。

结论（§7）重申 MMaDA 是第一个系统探索扩散基础模型设计空间、并提出相应后训练方法的工作，结果与专门模型“相当甚至更好”。作者承认的局限只有一条：模型规模只有 8B，计划扩大。

按本站的阅读，至少还应补上这几条：图像分辨率固定在 512×512（1024 个码），不支持任意分辨率；理解只能依赖为重建训练的离散码，读图中文字和图表的能力很弱（见 7.4 节的第三方数字）；文本生成必须分块，推理时没有 KV 缓存；最终的 RL 权重和长思维链数据都没有公开。

10 后来怎么样了

MMaDA 发表的同一周，还有两篇工作把 LLaDA 扩展到视觉，但走的是另一条路：不把图像离散化，而是像 LLaVA 一样用连续的视觉特征作为不加噪的前缀，只做理解。

  • LLaDA-V（arXiv 2505.16933，人大高瓴与蚂蚁集团）：SigLIP2 视觉编码器 + 两层 MLP + LLaDA-8B-Instruct。它最有价值的是对照设计：AR 基线 LLaMA3-V 和它用同样的视觉部分、同样的数据和训练流程，只把语言塔换成 LLaMA3-8B-Instruct。MMMU 上 LLaDA-V 为 48.6、LLaMA3-V 为 45.4（LLaDA-V 表 2）。见 LLaDA-V 精读页（旧版拆解见此处）。
  • LaViDa（arXiv 2505.16839，UCLA 等）：同样用连续视觉特征，重点解决工程问题。它用互补掩码让每个回答 token 都有监督；推理时让视觉和问题部分只看自己（前缀），从而能缓存它们的 K/V，COCO 描述的延迟从 7.65 秒降到 1.93 秒，CIDEr 从 121.0 降到 117.3（LaViDa 表 3a）；MMMU 为 43.3（表 1）。见 LaViDa 精读页（旧版拆解见此处）。

两条路线的取舍可以这样理解。离散码让图像也能被遮、被生成，一个模型能同时理解和画图，还能对图像生成做 RL；代价是理解只能依赖离散码。连续特征直接复用强大的视觉编码器，理解更强，前缀不加噪也就可以缓存；代价是不能生成图像。旧版拆解页的简答题 Q37专门讨论了这一点。

此后的直接后续（均已核对 arXiv 摘要）：

  • TraceRL / dLLM-RL（arXiv 2509.06949，同一团队）：面向扩散语言模型的 RL 框架，把推理时的生成轨迹纳入训练，并配了一个扩散式的价值模型。MMaDA 的 README 说明 UniGRPO 的实现后来并入了这个仓库。
  • Lavida-O（arXiv 2509.19244）：统一的掩码扩散模型，用 Elastic-MoT 结构把一个较小的生成分支和较大的理解分支耦合，支持 1024 像素文生图、目标定位和图像编辑。它在摘要里直接点名 MMaDA 只支持简单的图像级理解和低分辨率生成，并在表中自测了 MMaDA 的多项指标（见 7.4 节）。
  • Lumina-DiMOO（arXiv 2510.06308）：同样完全基于离散扩散的统一模型，覆盖文生图、图像编辑、inpainting 和理解，支持任意分辨率。它报告 GenEval 0.88，并在正文里拿架构相近的 MMaDA（0.63）作对照。
  • MMaDA-Parallel（arXiv 2511.09611，同一团队，OpenReview 显示为 ICLR 2026 poster）：作者发现“先想后画”的顺序生成会因误差传播反而损害一些任务，于是让文本推理和图像在整个去噪过程中并行、双向地交互，并提出沿去噪轨迹给语义奖励的 ParaRL。

仍未解决的问题：多模态扩散模型的推理速度（缓存与并行解码在图像段上的效果）、离散图像码对理解能力的限制，以及 RL 中对数概率近似的理论基础。纯文本扩散模型上的 RL 可以接着读 d1 精读和旧版的 RL 拆解页。
