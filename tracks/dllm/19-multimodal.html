1. 动机：把视觉接到一个双向去噪器上

AR 多模态模型（LLaVA 一系）把视觉特征当作前缀，再逐 token 生成回答；统一理解与生成的模型（Show-o、Transfusion）则在一个网络里混用“文本自回归 + 图像扩散”两种目标。2025 年 5 月，LLaDA 证明 8B 掩码扩散模型可以当作通用 LLM 用，同一周内出现了三条把它扩展到视觉的路线：

  • MMaDA（普林斯顿、北大、清华、字节 Seed）：把图像量化成离散码，与文本放进同一个序列、同一个掩码预测目标，一个模型同时做文本推理、图像理解和文生图，并提出面向扩散模型的 RL 方法 UniGRPO。
  • LLaDA-V（人大高瓴 + 蚂蚁）：沿用 LLaVA 式“视觉编码器 + MLP + 语言塔”，只把语言塔换成 LLaDA；用与 AR 基线完全相同的流水线做对照。
  • LaViDa（UCLA 等）：同样是 LLaVA 式结构（LLaDA 或 Dream 骨干），重点解决工程问题：回答短导致训练信号稀疏、视觉前缀长导致推理慢、少步采样质量差。
一句话理解 多模态 dLLM 的机制基本是前面各页的组合：掩码目标（03 页）、似然估计与 RL（17 页）、缓存（14 页）。真正新的选择只有一个：图像是离散码，能和文本一起被掩、被生成（MMaDA）；还是连续特征，只作为不加噪的条件（LLaDA-V、LaViDa）。前者换来统一的生成能力，后者换来更强的理解能力和可缓存的前缀。

记号沿用本 track：干净序列 \(x_0\)，掩码率 \(t\in[0,1]\)（\(t=1\) 全为 \([\mathrm M]\)），\(x_t\)，去噪网络 \(p_\theta\)，prompt \(c\)（这里包含问题文本），回答长度 \(L\)，步数 \(N\)，块大小 \(B\)。另记视觉特征为 \(v\)。LaViDa 把步数记作 \(K\)，并用“NFE 百分比” \(K/L\) 衡量效率，即 TPF = \(L/K\)；MMaDA 的 UniGRPO 用离散时间步 \(T=1000\)。

2. 全局架构：图像进入 dLLM 的两条路

图像 / token 画布去噪网络（可训练） 冻结：图像量化器视觉编码器 + 投影（辅助可训练） 前缀 KV 缓存条件：问题、奖励损失[M]

3. 组件拆解

3.1 MMaDA：一个目标覆盖三类任务

MMaDA 从 LLaDA-8B-Instruct 和 Show-o 的量化器初始化，分三个阶段训练MMaDA §4.1：Stage 1 共 60 万步（前 20 万步用 RefinedWeb 文本、ImageNet-1k 类别条件生成和图文描述，后 40 万步把 ImageNet 换成更多样的图文对）；Stage 2 用指令数据与推理数据做 5 万步 Mixed Long-CoT 微调；Stage 3 做 5 万步 UniGRPO。全部在 64 张 A100（80GB）上进行，全局 batch 1280，lr 5e-5。

  • 统一的 CoT 格式：文本推理、多模态推理和文生图都写成“特殊 token | 推理过程 | 特殊 token | 结果”。文生图的推理链由 GPT-4.1 合成，内容是关于科学、文化、地标的事实描述。MMaDA §2.2、§4.1
  • 两种采样器：文本用 LLaDA 的半自回归采样，长度 1024、512 步、块长 64，每步揭开 2 个 token（TPF = 2）。不分块直接生成时，回答会非常短，指令模型还会大量输出 EOS。图像则把 1024 个码当作一个块，50 步，余弦调度，CFG 3.5。MMaDA §3
  • 少步采样：文生图从 1024 步减到 50 / 15 步，CLIP 分数为 32.8 → 32.0 / 31.7；文本 MMLU 从 1024 步到 256 步为 66.9 → 65.7。MMaDA Tab. 6
  • 填空不需要额外微调：文本补洞、带部分答案的 VQA、图像 inpainting 都可以直接写成掩码预测，只有定性示例。MMaDA §5.5、Fig. 7

3.2 UniGRPO：对回答随机部分加噪来估计 \(\log\pi\)

与 d1 的对比（详见 17 页）：d1 随机掩掉问题并把回答全部掩掉，只训练了“从全掩码出发的第一步”。UniGRPO 不掩问题，对回答按 \(p\sim\mathcal U[0,1]\) 部分掩码，只在被掩位置上对 \(\log p_\theta\) 取平均，作为该回答的序列级 \(\log\pi'\)。\(\mu\) 次内循环的掩码率不是独立抽取的：先随机一个起点，再在剩余区间内等距取值（例如在 \(T=1000\) 中取 100、300、500、700、900），使几次梯度步合起来覆盖整个去噪过程。论文称这近似于对似然做蒙特卡洛平均，奖励曲线更稳定（只有图）。MMaDA §2.3.1、§5.2、Alg. 1、Fig. 3–4

与 DiffuCoder 的 coupled-GRPO 对比：两者都用部分掩码代替 d1 的全掩码。UniGRPO 每次只用一个掩码率、依靠多次内循环覆盖不同掩码率；coupled-GRPO 在同一步内用一对互补掩码，保证每个 token 都被覆盖。

3.3 LLaDA-V：只换语言塔的对照实验

LLaDA-V 的价值在于对照设计：AR 基线 LLaMA3-V 与它使用完全相同的视觉塔、投影层、数据和三阶段流程，唯一的区别是语言塔为 LLaMA3-8B-Instruct。三个阶段分别是：Stage 1 用 LLaVA-Pretrain 55.8 万条只训投影层；Stage 2 用 MAmmoTH-VL 的 1000 万单图数据和 200 万 OneVision 数据（含多图与视频）；Stage 3 用 VisualWebInstruct 的 90 万条推理数据，再与 OneVision 数据混合为 300 万条，用 /think 与 /no_think 标记控制是否先推理。LLaDA-V §3.3、§4.1、Tab. 1

  • 数据扩展性：只在单图数据上训练时，LLaDA-V 用 100 万条样本在 MMMU-Pro 上就超过了用 900 万条的 LLaMA3-V；但在 AI2D、RealworldQA 上落后。LLaDA-V §4.2、Fig. 3
  • 18 个基准中 11 个胜过 LLaMA3-V：优势在多学科知识（MMMU、MMMU-Pro、MMStar）以及多图 / 视频（MuirBench、MLVU、VideoMME）；图表、文档（AI2D、DocVQA）和真实场景（RealworldQA）较弱。LLaDA 本身作为纯文本 LLM 就弱于 LLaMA3-8B。LLaDA-V §4.3、Tab. 2–3

3.4 LaViDa：互补掩码、前缀缓存与时间步偏移

互补掩码：VQA 的回答很短，关键词（例如“dog”）可能恰好没被掩，从而得不到梯度。LaViDa 让每个样本生成两份掩码集合互不相交、合起来覆盖整个回答的 \(X_t\) 与 \(X_t^{C}\)。LaViDa §3.2 前缀 DLM：见图 1 ⑥。论文也试过在训练中就使用前缀掩码（Prefix-DLM-FT，4 种实现），最快的版本也比全注意力训练慢 62%，而且精度没有提升（Tab. 10），所以只在推理时使用。LaViDa App. B.4、Tab. 9–10

时间步偏移：线性调度每步揭开 \(L/K\) 个 token，步数少时质量下降明显。LaViDa 借鉴 SD3，取 \(s_\alpha(t)=\alpha t/(1+(\alpha-1)t)\)，\(\alpha=1/3\)，这是一个凸调度：前几步揭开更多 token，后面更细致。这与图像掩码生成（MaskGIT）偏好的凹调度方向相反。离散化时保证每步至少揭开 1 个 token，因此实际的 NFE 等于 \(K\)。LaViDa §3.3、App. A.2

受约束填空：把带 [M] 的草稿直接放进画布，从 \(t=L_M/L\) 开始去噪。LaViDa-FIM 在训练中插入随机长度的 [S]…[S][FIM]，从而支持可变长度的填空。在“每行以指定音节开头”的看图写诗任务上（100 个样本），两个 LaViDa 变体的句子级与样本级约束满足率都是 100%，LLaVA-1.6-7B 为 41% / 37%，Qwen2.5-VL-7B 为 45% / 16%。LaViDa §4.4、Tab. 2(b)需要注意，扩散模型的行首音节是直接写在画布上的固定 token，满足约束几乎是由构造保证的；AR 模型只能靠提示词去遵守。所以这个对比衡量的是“能否硬性施加约束”，而不是诗写得好不好（本页推论）。

5. 训练目标与似然估计

MMaDA 的统一目标（\(x_0\) 是文本 token 与图像码拼成的序列）：

$$\mathcal L_{\text{unify}}(\theta)=-\mathbb E_{t,x_0,x_t}\Big[\frac1t\sum_{i=1}^{L}\mathbf 1\big[x_t^i=[\mathrm M]\big]\log p_\theta(x_0^i\mid x_t)\Big]$$

LLaDA-V / LaViDa 的回答目标：图像特征 \(v\) 与问题 \(c\) 不加噪，只有回答 \(r\) 被掩。LaViDa 再加一份与 \(M\) 互补的掩码：

$$\mathcal L(\theta)=-\mathbb E\Big[\frac1t\sum_{i}\mathbf 1\big[r_t^i=[\mathrm M]\big]\log p_\theta(r_0^i\mid v,c,r_t)\Big],\qquad M\cup\bar M=\{1,\dots,L\},\ M\cap\bar M=\varnothing$$

UniGRPO 的似然近似：对回答 \(o_i\) 按 \(p_i\) 加噪得到 \(\tilde o_{i,p}\)，用被掩位置的平均对数概率作为 \(\log\pi'\)，比值 \(r'_{i,t}=\pi'_\theta/\pi'_{\text{old}}\)，并加 PPO 裁剪与 KL：

$$\log\pi'_\theta(o_i)\approx\frac{1}{|M_i|}\sum_{k\in M_i}\log p_\theta\big(o_i^k\mid q,\tilde o_{i,p}\big),\qquad p^{(n)}=p^{(1)}+\tfrac{n-1}{\mu-1}\big(1-p^{(1)}\big)$$

第二式是 Alg. 1 第 14 行用掩码率改写后的形式：第一次内循环随机取起点，之后等距铺满剩余区间。MMaDA Eq. 3–5、Alg. 1

LaViDa 的时间步偏移：\(t'_i=s_\alpha(t_i)=\alpha t_i/(1+(\alpha-1)t_i)\)，\(\alpha=1/3\)。例如 \(t=0.5\) 时 \(t'=0.25\)：走到一半时只剩 25% 的位置被掩。LaViDa Eq. 3、App. A.2

mm_dllm.py（MMaDA 训练一步 + LaViDa 推理循环，机制示意）
def mmada_train_step(text_ids, image, model, vq):
    img_codes = vq.encode(image) + TEXT_VOCAB      # 1024 个码，平移到联合词表的后 8192 位
    x0 = concat(text_ids, img_codes)               # 文生图：文本在前；理解：图像在前
    t = rand()                                     # 掩码率 ~ U(0,1)
    m = (rand(len(x0)) < t) & is_target(x0)       # 只掩当前任务的目标部分
    xt = where(m, MASK, x0)
    logits = model(xt)                             # 全双向
    return (ce(logits[m], x0[m]) / t).sum() / len(x0)

def lavida_generate(model, image, question, L=32, K=16, alpha=1/3):
    v = projector(siglip(five_views(image)))       # [980, d]，池化之后
    prefix = concat(v, embed(question))
    kv = model.prefill(prefix, attn="prefix")      # 前缀只看前缀，K/V 可缓存
    ans = [MASK] * L
    ts = [s_alpha(1 - k / K, alpha) for k in range(K + 1)]   # 1 → 0，凸调度
    for k in range(K):
        n_keep_masked = floor(ts[k + 1] * L)
        logits = model.decode(embed(ans), kv)      # 回答看前缀 + 自身
        conf, pred = logits.softmax(-1).max(-1)
        conf[ans != MASK] = -inf
        n_new = max(1, count(ans == MASK) - n_keep_masked)   # 每步至少揭开 1 个
        for i in topk(conf, n_new):
            ans[i] = pred[i]                       # 低置信度位置继续保持 [M]
    return ans

def s_alpha(t, a):
    return a * t / (1 + (a - 1) * t)

之前

  • 多模态理解几乎都用 AR 语言塔；统一模型（Show-o、Transfusion）混用 AR 文本 + 扩散图像两种目标。
  • 纯文本 dLLM：LLaDA、Dream；RL：d1；缓存：Fast-dLLM / dKV-Cache。

之后（时间线条目，均核对过 arXiv 摘要）

  • 2025-09 LaViDa-O：Elastic-MoT，把 LaViDa 扩展到 1024px 文生图、目标定位与编辑。
  • 2025-10 Lumina-DiMOO：完全离散的扩散统一模型，覆盖文生图、图像编辑与理解。
  • 2025-11 MMaDA-Parallel：文本与图像在整个去噪轨迹上双向交互，配合 ParaRL。
  • 2025-12 Dream-VL & Dream-VLA：以 Dream 为骨干的 VLM / VLA，LIBERO 平均成功率 97.2%（摘要），作者认为双向骨干适合动作块的并行生成。

简答题

Q37MMaDA 把图像离散成码、与文本共用一个掩码预测目标；LLaDA-V / LaViDa 用连续视觉特征作不加噪的前缀。两条路线各自换来了什么、失去了什么？

离散码让图像也能被掩、被生成：一个网络、一个目标就能同时做理解、文生图和跨模态填空，还能对图像生成做 RL（UniGRPO 的 CLIP 与 ImageReward 奖励）。代价是理解只能依赖 VQ 码，分辨率也固定。码本是为重建训练的，细粒度语义可能较弱（本页推论）。连续特征直接复用强大的 SigLIP 编码器，理解基准更好，前缀不加噪，也就可以被缓存；但模型不能生成图像，视觉 token 数量还受语言塔上下文长度的限制。

  • 理解：MMaDA 的 MMMU 为 30.2，LLaDA-V 为 48.6、LaViDa-L 为 43.3。这三个数来自不同论文的协议，只能看量级。
  • 生成：只有 MMaDA 能出图，GenEval 0.63、WISE 0.67。
  • 缓存：连续前缀在推理时只当作条件，LaViDa 才能用前缀注意力缓存它；MMaDA 文生图时整张图都在画布里，无法做这样的切分。

依据：MMaDA §2.1、§2.3、Tab. 2–3；LLaDA-V §3.1、Tab. 2；LaViDa §3.1–3.3、Tab. 1。

Q38LaViDa 的前缀 DLM 缓存为什么能精确复用视觉与问题的 K/V，却仍然让 CIDEr 下降？它与块扩散的缓存有什么不同？

推理时把前缀改成只能看前缀，前缀的 K/V 就与回答无关，算一次即可，在这个修改后的模型下复用是精确的。但模型训练时用的是全注意力，前缀 token 原本能看到回答。推理时切断这条信息流，就改变了模型计算的函数（训练与推理不一致），CIDEr 从 121.0 降到 117.3。块扩散在训练中就使用块因果掩码，缓存是训练时就有的结构，但每块只能看到块内与过去，失去了全局双向，并需要专门的训练 kernel。

  • LaViDa 试过在训练中就加前缀掩码，训练慢至少 62%，精度却没有提升，于是只在推理时使用。
  • 加速主要来自视觉前缀很长（约 980 个 token），而 COCO 描述的回答只有 32 个 token。
  • 与 Fast-dLLM 的近似缓存不同：前缀 DLM 不复用回答部分，回答每步都重算。

依据：LaViDa §3.3、Tab. 3(a)、App. B.4、Tab. 8–10。
