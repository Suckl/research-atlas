1. 动机：LLM 的能力一定来自左到右吗

到 2024 年，掩码扩散在 GPT-2 规模上已经能和 AR 比困惑度（SEDD、MDLM / MD4、RADD），但没人知道它能否像 LLM 一样随规模变强、做上下文学习、听指令。这一页的三篇来自同一个团队，回答的是同一个问题的三个阶段：SMDM（2024-10）先在 1.1B 以内拟合掩码扩散的扩展律，给出“约 16× 计算才追平 AR”的数字；LLaDA（2025-02）据此把 8B 模型从零训练到 2.3T token，再做 SFT；iLLaDA（2026-06）用同一目标把预训练扩到 12T token，并改了架构、SFT 与评测口径。SMDM 摘要；LLaDA §1；iLLaDA 摘要

LLaDA 的论点是：LLM 的可扩展性、上下文学习等性质来自“最大似然的生成建模原则”，而不是 AR 这一特定分解；而左到右分解本身带来反转推理之类的缺陷。LLaDA §1这是论文的立场，不是被证明的命题——后面的 对照表 与 结果 会给出它能支持到哪里。

一句话理解 把 LLaMA 式 Transformer 的因果掩码拿掉、加一个 \([\mathrm{M}]\) token，用“随机比例 \(t\) 掩码 + 被掩位置交叉熵 ÷ \(t\)”从零预训练；生成时从全 \([\mathrm{M}]\) 的画布出发，每步定稿置信度最高的若干位置，必要时按块从左到右推进。训练配方几乎照搬 AR，难点集中在似然只能估计、生成长度要预设和没有现成 KV cache。

本页记号：干净序列 \(x_0\)（长 \(L\)），腐蚀态 \(x_t\)，\(t\in[0,1]\)、\(t=1\) 为全掩码；去噪网络 \(p_{\theta}(x_0^{i}\mid x_t)\)；prompt \(c\)；块长 \(B\)；步数（NFE）\(N\)；每次前向定稿 token 数 TPF。LLaDA 论文把 prompt 写成 \(p_0\)、回答写成 \(r_0\)，SMDM 用 \(\alpha_t=1-t\) 表示“未被掩”的概率，与本页一致。LLaDA §2；SMDM §2

3. 组件拆解

3.1 从零训练 8B：数据、token 与架构差异

LLaDA 8B 在 2.3T token 上预训练，耗 0.13M H800 GPU 小时，论文称与同规模、同数据量的 AR 相当；序列长度固定 4096。语料约 11% 中文、61% 英文、28% 代码，用人工规则与 LLM 过滤低质量内容，配比由缩小版 AR 模型决定；SFT 用 450 万对数据（100 万人工标注 + 350 万合成）。8B 只训练了一次，没有调超参。LLaDA §2.2–2.3、App. B.1

与 LLaMA 3 8B 的结构对照：层数 32、宽度 4096、注意力头 32 相同；KV 头 32 vs 8；FFN 12,288 vs 14,336；词表 126,464 vs 128,000；总参数 8.02B vs 8.03B，非嵌入参数同为 6.98B。LLaDA Tab. 5按 \(6ND\) 估算预训练计算约 \(6\times 6.98\times10^{9}\times 2.3\times10^{12}\approx 9.6\times10^{22}\) FLOPs（推算），与论文“扩展到 \(10^{23}\) FLOPs”的表述一致。LLaDA §1、App. B.2 的 6ND 口径

3.2 MC-ELBO 似然：选择题怎么打分

AR 给选项打分用精确的条件对数似然；LLaDA 只有上界，于是用蒙特卡洛估计。论文发现训练目标的等价形式更稳：不是按概率 \(t\) 独立掩码，而是均匀抽 \(l\in\{1,\dots,L\}\)、恰好掩 \(l\) 个、权重 \(L/l\)（Eq. 6）。前者需要 1000 次以上估计才稳定，后者 128 次即可；MMLU、CMMLU、C-Eval 只需一个 token 的似然，1 次就够。LLaDA §2.4、App. A.2、B.6每个候选 128 次前向，这是 dLLM 选择题评测比 AR 贵得多的直接原因。

3.3 低置信度重掩码与随机重掩码

在 Base、生成长度与步数均为 256 的设置下，随机重掩码 → 低置信度重掩码：BBH 32.1 → 45.0，GSM8K 21.3 → 70.0，MATH 9.2 → 30.3，HumanEval 11.6 → 32.9，MBPP 21.0 → 40.2。LLaDA Tab. 9论文把它类比为 AR 的退火采样：以多样性换准确率。它也意味着“生成顺序”由模型置信度决定，常常接近左到右，但并不保证（顺序的利弊见 第 16 页）。

3.4 半自回归块采样：为什么 Instruct 需要它

论文比较三种采样：逐 token 的 AR 采样、画布随块增长的 block diffusion、画布定长的“block diffusion LLaDA”（即半自回归），以及纯扩散。Base 上纯扩散整体最好，块越长越好；Instruct 上半自回归在数学题明显更强：GSM8K 77.5 vs 纯扩散 69.4、MATH 42.2 vs 31.9（块长 32），块长 8 时 GSM8K 再到 78.6。原因是 SFT 数据大量 |EOS| 补齐，纯扩散采样容易早早定稿 |EOS|。AR 采样对 Instruct 几乎完全失败（GSM8K 0），因为 SFT 让模型倾向在给定长度内说完一整句。LLaDA §3.2、App. B.4、Tab. 7–8

报告口径LLaDA 正文 Tab. 2 用纯扩散（GSM8K 69.4），附录 Tab. 8 的半自回归（77.5 / 78.6）更高；后续论文引用“LLaDA Instruct”时常取后者。iLLaDA Tab. 3 中的 LLaDA 列是逐基准取两者中更好的一个（GSM8K / MATH 取半自回归，HumanEval / MBPP / MMLU-Pro 取纯扩散）。LLaDA Tab. 2、Tab. 8；iLLaDA Tab. 3比较时要看清是哪一种采样。

3.5 反转诅咒：双向目标带来什么

496 对中文名诗上下句：给一句，补下一句（正向）或上一句（反向），零样本。GPT-4o（2024-08-06）正向 / 反向 82.7 / 34.3，Qwen2.5-7B Instruct 75.9 / 38.0，LLaDA 8B Instruct 51.8 / 45.6。LLaDA Tab. 4、§3.3LLaDA 两个方向接近、反向最好，但正向明显弱于两个 AR——“平衡”有一部分来自正向较弱，不能读成全面更强。论文的解释是：训练目标等价于对所有顺序求平均的任意顺序自回归（AO-ARM，见 §5），模型对各方向没有偏置。LLaDA App. A.2 Eq. 15

3.6 SMDM：第一条掩码扩散扩展律与“16×”

SMDM 用 RADD 的无时间参数化，AR 用 Transformer decoder、MDM 用对应的 encoder，差别只有“多一个掩码 embedding、去掉因果掩码”，其余（深度、宽度、头数）一致；数据 SlimPajama（627B），两者都用 Llama-2 tokenizer，上下文 2048。IsoFLOP 预算 \(6\times10^{18}\)–\(10^{20}\) FLOPs，\(C=6ND\)，对每个预算拟合损失–\(\log N\) 的二次曲线取最优，再拟合 \(\mathcal{L}=e^{\beta^{*}}C^{\alpha^{*}}\)。SMDM §2–3、App. B.2

结论：MDM 的最优验证损失随计算按幂律下降，速率与 AR 相近，但要达到相同验证损失约需 16 倍计算；最优模型大小约为 AR 的一半。作为对照，连续扩散被报告为 64 倍。SMDM §3、Fig. 2这里 MDM 的“验证损失”是 ELBO 的 MC 估计（128 次），AR 是精确 NLL；训练数据只过一遍。这三个口径后来都被挑战，见 Q12 与 第 08 页。

SMDM 还提出无监督 CFG：把条件 \(c\) 换成等长 \([\mathrm{M}]\) 序列就得到“无条件”分布，因此不需要成对数据训练无条件模型（公式见 §5）。在 MT-Bench 上，用 16 倍预训练时间的 1.1B MDM 与带 KV cache 的同尺寸 ARM 对比：128 步得 1.56 分、396 s，ARM 1.57 分、555 s（快约 1.4 倍）；256 步 1.60 分、780 s（慢约 1.4 倍）。SMDM §4、§6、Tab. 4；单卡 A100-40GB

3.7 iLLaDA：12T 重训改了什么

目标与 LLaDA 完全相同，改动都在“配方”上：iLLaDA §2

  • 架构：改回 GQA（8 个 KV 头），理由是 dKV-Cache 等近似缓存已经可用，GQA 能降低缓存显存；输入嵌入与 LM head 共享；词表 155,136；最大长度 8192。总参数 7.62B，非嵌入参数仍为 6.98B。iLLaDA §2.1、Tab. 1
  • 预训练：12T token；以 30% 概率把 8192 长的序列切成两段，用变长 FlashAttention 打包；学习率升到 \(2\times10^{-4}\) 后恒定，loss 停滞时切到余弦衰减至 \(5\times10^{-6}\)。iLLaDA §2.1
  • SFT：不再“prompt 可见、response 补 |EOS|”，而是把指令样本拼成连续语料、按 8192 切段、对整段（含 prompt）随机掩码，与预训练同一处理；约 25B token、12 个 epoch，epoch 越多越好。iLLaDA §2.2、§3.2、Fig. 1
  • 推理：变长生成——每次只追加一个块的 \([\mathrm{M}]\)，块解完若出现停止符就结束，否则再追加；Base 评测最大长度 1024、块长 32（HumanEval 用 512，因为半自回归会伤害该基准）。iLLaDA §2.3、App. A；官方 var_generate
  • 选择题：用确定性的置信度打分代替 ELBO（§5），PIQA / ARC-C / HellaSwag 分别 +1.3 / +0.6 / +2.3。iLLaDA §3.2、Tab. 4

iLLaDA-Instruct 在难题上会陷入“Wait, let me check again”式循环，作者把它归因于 SFT 中推理模型生成的思维链，推理时随生成变长逐步提高 </think> 的 logit。iLLaDA App. A；官方 apply_end_think_logit_boost论文没有报告采样步数或 TPF。iLLaDA 的生成速度与步数设置未核实

5. 训练目标与似然

前向过程逐 token 独立：\(q(x_t^{i}\mid x_0^{i})\) 以概率 \(1-t\) 保持原样、以概率 \(t\) 变成 \([\mathrm{M}]\)。训练目标与它的上界关系：LLaDA Eq. 3–4、Eq. 7–8

$$\mathcal{L}(\theta)=-\mathbb{E}_{t,\,x_0,\,x_t}\Big[\frac{1}{t}\sum_{i=1}^{L}\mathbf{1}\big[x_t^{i}=[\mathrm{M}]\big]\log p_{\theta}(x_0^{i}\mid x_t)\Big]\;\ge\;-\mathbb{E}_{x_0}\log p_{\theta}(x_0).$$

与 BERT 的区别是掩码比例随机且有 \(1/t\) 权重；与 MaskGIT 的区别也是这个 \(1/t\)——没有它就与最大似然失去联系。LLaDA §2.1条件似然的低方差等价形式（选择题打分用）：LLaDA Eq. 6

$$-\log p_{\theta}(r_0\mid c)\;\le\;-\mathbb{E}_{l\sim U\{1,\dots,L\},\,r_l}\Big[\frac{L}{l}\sum_{i=1}^{L}\mathbf{1}\big[r_l^{i}=[\mathrm{M}]\big]\log p_{\theta}(r_0^{i}\mid c,r_l)\Big].$$

同一目标也等价于“对所有 \(L!\) 种顺序平均”的任意顺序自回归，这是双向推理能力的解释：LLaDA Eq. 15

$$-\mathbb{E}_{x_0,\;\pi\sim U_{\pi}}\sum_{i=1}^{L}\log p_{\theta}\big(x_0^{\pi(i)}\mid x_0^{\pi(<i)};\pi\big).$$

SMDM 的无监督 CFG（\(w\) 为强度，把 \(c\) 换成同长度的 \([\mathrm{M}]\) 串）与 iLLaDA 的置信度打分（\(\tilde y_{k-1}\) 为已揭示真值 token、其余为 \([\mathrm{M}]\)）：SMDM Eq. 7；iLLaDA Eq. 2

$$\tilde p_{\theta}(x_0\mid c,x_t)\propto\frac{p_{\theta}(x_0\mid c,x_t)^{1+w}}{p_{\theta}(x_0\mid [\mathrm{M}]^{|c|},x_t)^{w}},\qquad S_{\mathrm{conf}}(y\mid c)=\sum_{k=1}^{|y|}\log p_{\theta}\big(y^{i_k}\mid c,\tilde y_{k-1}\big),\;\; i_k=\arg\max_{i\in\mathcal{M}_{k-1}}p_{\theta}(y^{i}\mid c,\tilde y_{k-1}).$$

\(S_{\mathrm{conf}}\) 是“按模型自己最有把握的顺序逐个揭示真值”时的对数概率之和，论文明确说它不是似然估计，只用于在有限候选间比较。iLLaDA §2.3它与 2026-10 复核 16× 时用的“按解码顺序的精确似然”（DUEL）形似而不同：DUEL 只依据已揭示的 token 决定下一个位置（如模型自身的 top-1 置信度），因而是归一化的分布；iLLaDA 选的是“真值 token 概率最高”的位置，顺序偷看了答案，所以只能作打分用（此对比为本页分析）。2610.17590 §2；iLLaDA Eq. 2

论文 vs 官方代码 ① 定稿数量。LLaDA Alg. 5 第 12 行令 \(n_{un}=\lfloor L(1-s)\rfloor\)（注释为“未掩 token 数”），第 14 行却把“最低的 \(n_{un}\) 个”重新掩上，两处自相矛盾；官方代码按“每步转移 k 个最高置信度位置”实现，k 由块内掩码数在步数上均分。LLaDA App. A.3；官方 generate.py ② MC 似然。Eq. 6 写的是独立均匀抽 \(l\)；官方 get_log_likelihood.py 在一个 batch 内让 \(l\) 等间隔分层（随机起点 + 等距），方差更低。 ③ 训练 \(t\) 的下界。Alg. 1 写 \(t\sim U(0,1]\)；官方示例取 \(t\in[10^{-3},1)\) 以避免 \(1/t\) 发散。官方 GUIDELINES.md

6. 伪代码

llada_generate_and_score.py（按官方 generate.py / get_log_likelihood.py 简化，batch = 1）
MASK = 126336

def generate(p_theta, c, L=256, N=256, B=32):
    x = cat([c, full(L, MASK)])                 # 画布：prompt + L 个 [M]
    n_blocks, steps = L // B, N // (L // B)     # 每块分到的步数
    for b in range(n_blocks):
        lo, hi = len(c) + b * B, len(c) + (b + 1) * B
        ks = split_evenly(count(x[lo:hi] == MASK), steps)  # 每步定稿几个
        for k in ks:
            logits = p_theta(x)                 # 全双向、整张画布、无 KV cache
            x_hat = argmax(logits + gumbel(temp))   # temp = 0 时即贪心
            conf = softmax(logits)[x_hat]
            conf[hi:] = -inf                    # 半自回归：块外不选（B = L 即纯扩散）
            conf[x != MASK] = -inf              # 已定稿的位置不再改
            pick = topk(conf, k)                # 其余位置保持 [M] = 低置信度重掩码
            x[pick] = x_hat[pick]
    return cut_after_eos(x[len(c):])

def log_likelihood(p_theta, c, r, n_mc=128, bs=16):
    L, est = len(r), []
    for _ in range(n_mc // bs):
        l = stratified(1, L, bs)                # 官方实现：batch 内等距分层
        r_l = mask_exactly(r, l)                # 第 j 行恰好掩 l[j] 个
        logp = log_softmax(p_theta(cat([c, r_l])))
        nll = -sum_masked(logp, r) * L / l      # Eq. 6 的权重 L / l
        est.append(mean(nll))
    return -mean(est)                           # 选择题：取估计值最大的选项

def train_step(p_theta, x0, prompt_len=0):
    t = uniform(1e-3, 1.0)                      # 每条序列一个 t
    m = (rand_like(x0) < t); m[:prompt_len] = False   # SFT：prompt 不加噪
    xt = where(m, MASK, x0)
    ce = cross_entropy(p_theta(xt)[m], x0[m])
    return ce.sum() / t / len(x0)               # 被掩位置 CE ÷ t，再按长度平均

简答题

Q11LLaDA 为什么默认用“低置信度重掩码”而非按反向过程随机去掩码？又为什么 Instruct 模型还需要半自回归块？块长取 1、32 或整段时会发生什么？

随机重掩码对应训练目标的反向过程，但贪心时每步会把一些低把握的位置也提前定稿，且同一步内各位置独立决定，错误无法回头改；保留最高置信度的 k 个相当于给采样“降温”，GSM8K 从 21.3 升到 70.0。半自回归针对的是 SFT 的 |EOS| 补齐：纯扩散时 |EOS| 置信度高、会在画布末尾被过早定稿，限制只在当前块里选就绕开了它（GSM8K 69.4 → 77.5，块长 8 时 78.6）。

  • 块长 = 整段即纯扩散，对 Base 整体最好；块越短越接近左到右，Base 上 block diffusion 的分数随块长缩短而下降。
  • 块长 1 的极端论文没有在定长画布上测；它测的“AR 采样”（不带后续 \([\mathrm{M}]\)）对 Instruct 几乎完全失败（GSM8K 0），因为模型被训练成要在给定长度内说完。
  • 低置信度规则不是训练目标推出的采样器，选择顺序依赖模型自身的置信度；因子分解误差与并行上限见 第 16 页。

依据：LLaDA §2.4、App. B.4、Tab. 7–9；官方 generate.py。

Q12SMDM 的“掩码扩散约需 16× 计算”是在什么口径下得到的？哪些因素会改变这个倍数，LLaDA 为什么认为它不妨碍放大？

它是单 epoch（数据不重复）、全序列 decoder-only MDM、以 ELBO 的 MC 估计对比 AR 的精确 NLL、\(C=6ND\) 计 FLOPs、在 \(6\times10^{18}\)–\(10^{20}\) FLOPs 内拟合幂律后读出的“相同验证损失所需计算之比”。每一项口径都可能改变倍数：评测改用按解码顺序的精确似然、训练改为块扩散或编码器-解码器、或者数据不足需要多 epoch。

  • 2026-10 的复核在同一数据与超参下用 ELBO 读出 17.8×，同一批模型换精确似然降到 12.8×，块扩散 + 编码器-解码器在块长 32 / 8 / 4 时为 7.8× / 4.6× / 3.0×（结论很新，尚无复现）。
  • 数据受限时情况反过来：多 epoch 下扩散可以反超 AR（第 08 页），但两篇数据受限论文本身也有方法学争议。
  • LLaDA 的理由是似然只是下游能力的间接指标，且扩散优化的是上界、不可直接比；它把对照范围从 \(10^{18}\)–\(10^{20}\) 扩到 \(10^{20}\)–\(10^{23}\)，看下游任务而非损失。SMDM 自己的 MT-Bench 实验也是“多花 16 倍预训练，换来同质量下 1.4 倍采样速度”。

依据：SMDM §3、§6、App. B.2；LLaDA §3.1；2610.17590 摘要、§4。
