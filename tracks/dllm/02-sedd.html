1. 动机：离散数据没有梯度，score 该怎么定义

连续扩散的核心是 score \(\nabla_x\log p_t(x)\)：学会它就能写出反向过程。文本是离散的，梯度无从谈起。D3PM 一类方法改学去噪分布 \(p_{0|t}\)（“均值预测”），SEDD 认为这条路在语言上一直表现不佳：密度比一般数值更难学，连续时间下目标还要近似SEDD §2.2。另一条路是 Meng 等的 concrete score：把梯度换成“相邻状态的概率比” \(p_t(y)/p_t(x)\)，再用 \(\ell_2\) 损失拟合；可是 \(\ell_2\) 不惩罚负值和零，训练会发散——SEDD 在 GPT-2 规模复现时 \(\ell_2\) 版本的似然损失高 3–4 倍SEDD §2.2 Eq. (4)、附录 D.1。

SEDD（Lou, Meng, Ermon，ICML 2024 最佳论文）提出 score entropy：一个专为正值比值设计的 Bregman 散度损失，既能去噪式地训练，又给出似然上界；吸收态版本在 GPT-2 small / medium 规模上第一次与同尺寸 AR 的零样本困惑度相当SEDD 摘要、§3、Tab. 1。RADD（Ou 等，ICLR 2025）回头分析吸收态 SEDD，发现那个比值可以写成“解析的时间因子 × 干净数据的条件概率”，于是网络可以不看时间、输出可以缓存，训练目标还等价于任意顺序自回归（AO-ARM）的期望负对数似然RADD 摘要、§3。这两步把离散扩散从“学比值”推到了“学条件概率”，直接成为 LLaDA 的参数化。

一句话理解 SEDD 说“学概率比，用 score entropy 学”；RADD 说“吸收态下这个比值 = \(\frac{e^{-\bar\sigma}}{1-e^{-\bar\sigma}}\) × 被掩位置的条件概率”，时间部分是解析的，网络只需学一个与时间无关的 MLM 式分类器。

记号换算：SEDD/RADD 用 \(d\) 表示序列长度、\(n\) 表示词表大小、\(\bar\sigma(t)=\int_0^t\sigma(s)\,\mathrm ds\) 表示累计噪声，单个 token 被掩的概率是 \(1-e^{-\bar\sigma(t)}\)；本 track 的 \(L\) 对应 \(d\)，掩码概率 \(t\) 对应 RADD 的 \(\lambda(t)=1-e^{-\bar\sigma(t)}\)SEDD §3.3、附录 C.1；RADD §3.3。log-linear 调度下 \(\bar\sigma(t)=-\log(1-(1-\epsilon)t)\)，掩码概率正好是 \((1-\epsilon)t\)SEDD 官方代码 noise_lib.py LogLinearNoise。

3. 组件拆解

3.1 concrete score：离散版的 score

SEDD 把前向过程写成连续时间马尔可夫链 \(\frac{\mathrm dp_t}{\mathrm dt}=Q_tp_t\)（列约定：\(Q_t(y,x)\) 是 \(x\to y\) 的速率）。它的时间反演仍是一条马尔可夫链，反向速率只差一个概率比SEDD §2.1 Eq. (1)–(3)：

$$\overline Q_t(y,x)=\frac{p_t(y)}{p_t(x)}\,Q_t(x,y),\qquad s_\theta(x,t)_y\approx\frac{p_t(y)}{p_t(x)} .$$

这组比值就是 concrete score，地位等同于连续扩散里的 \(\nabla_x\log p_t\)。对长度 \(d\) 的序列，若前向过程逐 token 独立加噪，\(Q_t\) 只连接 Hamming 距离为 1 的序列，于是只需学 \(d\times n\) 个比值，网络是一个普通的 seq-to-seq 映射SEDD §3.3 Eq. (11)–(13)。

3.2 score entropy：为正值比值设计的损失

$$\mathcal L_{\mathrm{SE}}=\mathbb E_{x\sim p}\sum_{y\neq x}w_{xy}\Big(s_\theta(x)_y-\frac{p(y)}{p(x)}\log s_\theta(x)_y+K\Big(\frac{p(y)}{p(x)}\Big)\Big),\qquad K(a)=a(\log a-1).$$

它是以 \(-\log\) 为凸函数的 Bregman 散度：非负、凸，在 \(s_\theta=p(y)/p(x)\) 处取 0SEDD §3 Def. 3.1、Prop. 3.2。与 concrete score matching 的 \(\ell_2\) 相比，梯度被 \(1/s_\theta\) 重新缩放，像一道 log barrier，把 \(s_\theta\) 挡在正值区域SEDD §3.1。未知的 \(p(y)/p(x)\) 可以像去噪 score matching 那样换成已知的转移核之比（denoising score entropy），每个样本只需一次前向SEDD Theorem 3.4 Eq. (7)：

$$\mathcal L_{\mathrm{DSE}}=\mathbb E_{x_0,\;x\sim p(\cdot\mid x_0)}\sum_{y\neq x}w_{xy}\Big(s_\theta(x)_y-\frac{p(y\mid x_0)}{p(x\mid x_0)}\log s_\theta(x)_y\Big).$$

3.3 似然上界：把权重设成前向速率

取 \(w_{xy}=Q_t(x,y)\) 并对时间积分，得到 diffusion-weighted DSE，它加上先验项就是负对数似然的上界——SEDD 用它训练，也用它报告困惑度（因此表中都写 “≤”）SEDD Theorem 3.6 Eq. (9)–(10)：

$$-\log p_0^\theta(x_0)\le\int_0^T\mathbb E_{x_t\sim p_{t|0}(\cdot\mid x_0)}\sum_{y\neq x_t}Q_t(x_t,y)\Big(s_\theta(x_t,t)_y-\frac{p_{t|0}(y\mid x_0)}{p_{t|0}(x_t\mid x_0)}\log s_\theta(x_t,t)_y+K(\cdot)\Big)\mathrm dt+D_{\mathrm{KL}}\big(p_{T|0}(\cdot\mid x_0)\,\|\,p_{\mathrm{base}}\big).$$

似然用 1000 个随机时间点做蒙特卡洛估计SEDD 附录 C.6。

3.4 吸收态、均匀态与噪声调度

为了在 \(n=50257\) 的 GPT-2 词表上可算，SEDD 只用两种有闭式的结构：均匀 \(Q^{\mathrm{uniform}}\) 与吸收态 \(Q^{\mathrm{absorb}}\)（多一个 MASK 状态）；一般的稠密 \(Q\) 光存储就要约 20 GBSEDD §3.3 Eq. (15)–(16)。调度试了几何调度（\(10^{-5}\) 到 20）与 log-linear，后者对吸收态困惑度更好SEDD §5.1、附录 C.1。吸收态全面胜出：GPT-2 small 规模五个零样本集上都比均匀态低（例如 1BW：≤ 79.29 vs ≤ 101.37）SEDD Tab. 1。

论文 vs 官方代码：log-linear 调度与 scaling trick
  • 附录 C.1 把 log-linear 写成 \(\bar\sigma(t)=-\log(1-(1-\epsilon t))\)；官方 noise_lib.py 实际是 -log1p(-(1 - eps) * t)，即 \(-\log(1-(1-\epsilon)t)\)，默认 \(\epsilon=10^{-3}\)。按代码，掩码概率恰为 \((1-\epsilon)t\)。
  • 附录 C.2 说“按 \(e^{\bar\sigma}-1\) 缩放有帮助”，没说方向；代码 scale_by_sigma 是 x - log(expm1(sigma)) - log(n)，即除以 \((e^{\bar\sigma}-1)\) 并整体除以 \(n\)，且断言只用于吸收态。复现以代码为准。
SEDD 附录 C.1–C.2；官方代码 noise_lib.py、model/transformer.py

3.5 采样与任意位置条件

反向链的 Euler 模拟每步只能改一个位置，所以 SEDD 用 τ-leaping：所有位置同时、独立地按 \(\delta+\Delta t\,Q^{\mathrm{tok}}s_\theta\) 跳转SEDD §4.1 Eq. (17)。更好的是 Tweedie τ-leaping：利用“知道全部比值就能精确去噪”的离散 Tweedie 定理构造转移概率，在所有“各位置独立同时更新”的策略中 KL 最小SEDD Theorem 4.1–4.2 Eq. (18)–(19)。注意这里的“最优”仍在独立更新这一族里——同步更新相关位置的因子分解误差（01 页）并没有消失。

因为学的是比值，条件分布的比值与无条件分布的比值相同（Bayes 公式中归一化常数抵消），所以无需专门训练就能从任意位置给 prompt：把已知位置固定，只更新其余位置SEDD §4.2 Eq. (21)–(22)、Alg. 3。条件生成上，SEDD 标准 prompt 的 MAUVE 为 0.957、首尾各 25 token 的填空为 0.942，GPT-2 nucleus-0.95 为 0.955（medium 规模，前 50 token 条件生成 50 token）SEDD Tab. 5、附录 C.8。

3.6 RADD：吸收态的概率比 = 时间因子 × 条件概率

设 \(x_t\) 的第 \(i\) 位是 [M]，\(\hat x_t\) 只在第 \(i\) 位换成某个词 \(\hat x\)。吸收态前向逐位独立，未掩 token 就是 \(x_0\) 的原词，所以任一与未掩 token 一致的 \(x_0\) 产生 \(x_t\) 的概率都相同：

$$p_t(x_t)=\big(1-e^{-\bar\sigma}\big)^{|\mathcal M|}\big(e^{-\bar\sigma}\big)^{d-|\mathcal M|}\;p_0\big(x_t^{\mathrm{UM}}\big),$$

\(\mathcal M\) 为被掩位置集合。\(\hat x_t\) 少一个 [M]、多一个未掩 token，代入后相除即得 RADD 定理 1（推导为本页按定义重写，与论文附录 B 结论一致）RADD §3.1 Theorem 1、附录 B：

$$\frac{p_t(\hat x_t)}{p_t(x_t)}=\underbrace{\frac{e^{-\bar\sigma(t)}}{1-e^{-\bar\sigma(t)}}}_{\text{解析时间因子}}\;\underbrace{p_0\big(\hat x\mid x_t^{\mathrm{UM}}\big)}_{\text{与时间无关}} .$$

按本 track 的掩码概率 \(t\)，时间因子就是 \((1-t)/t\)。四个推论：

  • 解释 scaling trick。SEDD 除以 \(e^{\bar\sigma}-1\)，恰好等于乘 \(\frac{e^{-\bar\sigma}}{1-e^{-\bar\sigma}}\)：网络只需输出条件概率那一部分RADD §3.1 Eq. (3.2)。
  • 去掉时间输入。RADD 网络 \(c_\theta(x_t)[i,\hat x]=q_\theta(\hat x\mid x_t^{\mathrm{UM}})\) 不看 \(t\)；同等 DSE 损失、相近参数量下，无时间条件的 RADD-DSE 反而优于 SEDD-ScaleRADD Eq. (3.3)、§4.3、Tab. 1–2。MDLM 同期发现有无时间条件困惑度相近，但它把时间输入置零而保留 adaLN 结构RADD §5「Concurrent works」；MDLM Tab. 12。
  • 缓存输出。画布不变则输出不变；Tweedie τ-leaping + log-linear 下 \(n\) 步生成长 \(l\) 的序列，期望 NFE 为 \(n(1-(1-\tfrac1n)^{l})\)，按此式 \(n=4096,\ l=1024\) 时约 906RADD Eq. (3.4)；数值为本页按式计算。小批量时 RADD 还按样本动态缩小 batch，只把画布变了的样本送进网络RADD 附录 J.4。
  • 与任意顺序 AR 等价。换元 \(\lambda=1-e^{-\bar\sigma(t)}\) 后，DSE 等价于 λ-DCE，再解析积分得到 AO-ARM 在均匀随机顺序上的期望负对数似然（Theorem 2）：吸收态扩散的似然上界可以读成“所有生成顺序的平均似然”RADD §3.3 Eq. (3.5)–(3.8)、Theorem 2。

只对吸收态成立：推导用到了“未掩 token 等于原词、揭开后不再变”。均匀 / 多项式扩散中任何 token 都可能被换过，没有 \(x_t^{\mathrm{UM}}\) 这样的干净子集，RADD 明说不能直接套用RADD §5。

5. 训练目标与似然

RADD 把 SEDD 的目标改写成三种等价形式（\(q_\theta\) 是 RADD 网络给出的条件分布）RADD Eq. (2.15)、(3.5)、(3.6)：

$$\mathcal L_{t\text{-DCE}}=\int_0^T\mathbb E_{x_t}\Big[\sum_{x_t^i=[\mathrm{M}]}-\frac{\sigma(t)e^{-\bar\sigma(t)}}{1-e^{-\bar\sigma(t)}}\log\Big(\frac{e^{-\bar\sigma(t)}}{1-e^{-\bar\sigma(t)}}\,q_\theta\big(x_0^i\mid x_t^{\mathrm{UM}}\big)\Big)\Big]\mathrm dt$$
$$\mathcal L_{\lambda\text{-DCE}}=\int_0^1\frac1\lambda\,\mathbb E_{x_\lambda}\Big[\sum_{x_\lambda^i=[\mathrm{M}]}-\log q_\theta\big(x_0^i\mid x_\lambda^{\mathrm{UM}}\big)\Big]\mathrm d\lambda,\qquad \mathcal L_{\mathrm{AO}}=\mathbb E_{\pi\sim U_\pi}\sum_{l=1}^{d}-\log q_\theta\big(x_0^{\pi(l)}\mid x_0^{\pi(<l)}\big).$$

λ-DCE 与 LLaDA 的 Eq. (3) 只差记号（\(\lambda\leftrightarrow t\)）；LLaDA 评测似然用的“均匀抽被掩个数 \(l\)”形式，也被它标注为来自 RADD 的等价写法LLaDA §2.4 Eq. (6)、附录 A.1。四个损失理论上等价，有限数据下收敛到不同局部最优，困惑度略有差异RADD §4.3。

版本差异与后续复核
  • RADD 的加速倍数随版本变化。v1–v2 摘要写“最高 3.5×”；v3 起摘要不再给倍数，本页读的 v4（2026-03）附录 J.4 写“大步数时 2.5–3×、1024 步约 1.5×”（Tab. 3：batch 16，4096 步 59.56 s vs 18.20 s）；Tab. 5 的 batch 1、4096 步为 109.90 s vs 30.70 s（约 3.6×，本页按表计算）。RADD v1/v2 摘要；v4 附录 J.4 Tab. 3、Tab. 5
  • SEDD 的生成困惑度优势需要打折。SEDD 称无退火时生成困惑度比 GPT-2 好 6–8 倍SEDD 摘要、Fig. 1；Zheng 等指出 fp32 Gumbel 采样被截断、等价于降温，这类优势主要来自数值问题2409.02908 摘要、§5。RADD 用 fp64 复测：SEDD-medium 4096 步的生成困惑度为 81（熵 8.07），fp32 下为 22（熵 7.25）RADD 附录 J.4 Tab. 3–4。零样本困惑度（似然上界）不受此影响。

6. 伪代码

sedd_radd.py（教学重写：SEDD 官方 losses.py / graph_lib.py / noise_lib.py；RADD Alg.（附录 I））
def sedd_absorb_loss(model, x0, n, eps=1e-3):      # x0: [b, d]，MASK = n
    t = (1 - eps) * rand(b) + eps
    sbar = -log1p(-(1 - eps) * t)                    # log-linear：P([M]) = (1-eps)·t
    dsig = (1 - eps) / (1 - (1 - eps) * t)           # sigma(t) = d sbar / dt
    xt = where(rand(b, d) < 1 - exp(-sbar)[:, None], MASK, x0)
    log_s = model(xt, sbar)                          # [b, d, n+1]，带时间条件
    log_s = log_s - log(expm1(sbar))[:, None, None] - log(n)   # scaling trick（代码版）
    m = xt == MASK
    r = 1 / expm1(sbar)[:, None].expand(b, d)[m]     # p(y=x0|x0) / p([M]|x0)
    pos = log_s[m][:, :n].exp().sum(-1)              # Σ_y s_y
    neg = r * log_s[m].gather(-1, x0[m][:, None]).squeeze(-1)
    ent = zeros(b, d)
    ent[m] = pos - neg + r * (log(r) - 1)            # score entropy，含常数 K(r)
    return (dsig[:, None] * ent).sum(-1).mean()      # 乘 sigma(t)：DWDSE

def radd_lambda_dce_loss(model, x0):                 # 同一上界的交叉熵写法
    lam = rand(b)                                    # lam = P([M])
    m = rand(b, d) < lam[:, None]
    logq = log_softmax(model(where(m, MASK, x0)), -1)   # 不输入时间
    nll = -logq.gather(-1, x0[..., None]).squeeze(-1)
    return ((nll * m).sum(-1) / lam).mean()

def radd_sample(model, d, steps):                    # log-linear 下的 Tweedie τ-leaping
    x, out, nfe = full(d, MASK), None, 0
    for k in range(steps, 0, -1):                    # t: k/steps → (k-1)/steps
        if out is None:
            out, nfe = softmax(model(x), -1), nfe + 1
        reveal = (x == MASK) & (rand(d) < 1 / k)     # 仍被掩者此步揭开的概率
        if reveal.any():
            x[reveal] = sample(out[reveal])          # 各位置独立
            out = None                               # 画布变了，下一步重算
    return x, nfe                                    # nfe ≤ min(steps, d)

9. 承上启下

之前

  • D3PM 一类均值预测在语言上明显落后，连续嵌入扩散要 rounding、解码慢（01 页）。
  • concrete score 有了定义，但 \(\ell_2\) 拟合训练发散。

SEDD → RADD 之后

  • 同期的 MDLM / MD4 从 ELBO 一侧推出同一个“加权 MLM 交叉熵”，三篇共同确立掩码扩散的标准目标。
  • LLaDA 直接采用“不输入 \(t\)”的参数化与 RADD 的似然估计写法，把它放大到 8B。
  • 均匀态无法套用 RADD 的分解，这条线由 离散流匹配 与 Duo 继续；SEDD 也是 DiffuLLaMA 的 GPT-2 规模对照。

简答题

Q3SEDD 为什么学“概率比”而不是直接学去噪分布？score entropy 比 ℓ₂ 形式的 concrete score matching 好在哪里？

反向 CTMC 的速率等于前向速率乘以概率比，学比值就是学反向过程本身，并且比值一旦已知，条件生成（任意位置 prompt）可以由 Bayes 公式直接得到。score entropy 是以 \(-\log\) 为凸函数的 Bregman 散度：非负、凸，梯度按 \(1/s_\theta\) 缩放，天然把输出挡在正值区域；\(\ell_2\) 对负值与零惩罚不足，SEDD 复现时似然损失高 3–4 倍。它还有可计算的去噪形式和似然上界。

  • 比值只需在 Hamming 距离 1 的邻居间建模：网络输出 \(d\times n\)。
  • 后来 RADD 证明，吸收态下这个比值本质就是条件概率乘时间因子，所以“学比值”与“学去噪分布”在吸收态殊途同归。
  • Tweedie τ-leaping 只在“各位置独立更新”的族内最优，并不消除同步更新的因子分解误差。

依据：SEDD §2.1–2.2、§3.1、Theorem 3.4、3.6、4.2、§4.2、附录 D.1；RADD Theorem 1。

Q4RADD 的“比值 = 时间因子 × 条件概率”带来了哪些实际后果？为什么它只对吸收态成立，这对 LLaDA 意味着什么？

后果有四：解释了 SEDD 的 scaling trick；网络可以删掉时间输入，只学 \(q_\theta(x^i\mid x_t^{\mathrm{UM}})\)；画布不变时输出可复用，有效 NFE 不超过生成长度；训练目标等价于 λ-DCE 与任意顺序 AR 的期望 NLL。推导依赖“未掩 token 就是原词”，均匀态没有这样的干净子集，所以不成立。LLaDA 正是用这一结论把模型做成不看 \(t\) 的普通双向 Transformer，并用其等价形式估计似然。

  • 无时间条件的 RADD-DSE 在 small / medium 上都优于 SEDD-Scale。
  • 缓存省的是“没有新 token 揭开”的步，不是 KV cache。
  • AO 等价说明：扩散的似然上界 = 对所有生成顺序取平均的 AR 似然，与“任意顺序是否有利”的争论相关（16 页）。

依据：RADD §3.1–3.3、Theorem 1–2、Tab. 1–2、§5；LLaDA 附录 A.1 Eq. (11)、§2.4 Eq. (6)。
