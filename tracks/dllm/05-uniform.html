1. 动机：能改字的扩散，为什么一直输？

掩码扩散一旦揭示就定稿；把先验从 \([\mathrm{M}]\) 换成词表上的均匀分布（D3PM uniform、SEDD Uniform、UDLM），每个 token 在反向过程中都能被反复改写，天然具备自我修正，也更适合引导。但它的困惑度一直明显差于掩码扩散，而少步采样所依赖的蒸馏工具（一致性模型等）又建立在连续空间的概率流 ODE 上，离散扩散没有这样的确定性映射。Duo §1、§2.1

Duo（Cornell Tech / EPFL，ICML 2025）的核心发现是：对一个定义在 one-hot 向量上的高斯扩散取 argmax，得到的离散边缘恰好是一个均匀态扩散。于是高斯一侧的工具可以搬过来——训练时用 softmax 松弛做低方差课程，采样时借高斯的确定性轨迹做一致性蒸馏。2026 年同一作者团队的 Beyond-Masked 把 MDLM、Duo、Eso-LM 放进同一套 IsoFLOP 扩展律实验，论证“困惑度最好的族未必最实用”。Duo 摘要；Beyond-Masked 摘要

本页记号：干净 token \(x\)（Duo 原文记号，即本站的 \(x_0\)），离散加噪 \(z_t\)（本站的 \(x_t\)），高斯隐变量 \(w_t\in\mathbb{R}^K\)，词表大小 \(K\)；离散调度 \(\alpha_t\)、高斯调度 \(\tilde\alpha_t\)；时间方向与本站一致（\(t=1\) 为全噪声）。

一句话理解 \(z_t=\operatorname{argmax}(\tilde\alpha_t x+\sqrt{1-\tilde\alpha_t^2}\,\epsilon)\) 的分布正是“以 \(\alpha_t\) 保留原 token、否则均匀换成任意 token”。训练时把 argmax 软化成 softmax，网络更容易学；蒸馏时固定同一个 \(\epsilon\)，相邻时刻的 \(z_s,z_t\) 就构成一条确定性轨迹，可以像一致性模型那样“把多步压成一步”。

3. 组件拆解

3.1 均匀态扩散：能改字，但更难学

前向：\(q_t(z_t\mid x)=\mathrm{Cat}(\alpha_t x+(1-\alpha_t)\mathbf{1}/K)\)。与掩码扩散的区别在于：被破坏的 token 看上去就是一个普通 token，网络必须同时判断“哪些位置是噪声”和“原来是什么”；反过来，反向过程的每一步都允许任何位置换值，所以早期的错误可以在后续步骤被改掉，不需要额外的 predictor-corrector 步。Duo §2.1、Eq. 1–5这也解释了均匀态模型为何需要时间条件：只有知道噪声水平，网络才知道该怀疑多少个 token。Beyond-Masked §2.2.2

3.2 对偶：均匀态 = 高斯的 argmax

Duo 给出了 argmax 推前分布的闭式（Eq. 10–11），并验证其时间演化满足均匀态扩散的特征 ODE（Eq. 12）。由此得到三条推论：Duo §3

  • 边缘对应，轨迹不对应。每个时刻的边缘相同，但离散化后的高斯轨迹不是一个马尔可夫离散扩散过程（App. A.3）。DCD 正是利用“边缘对、轨迹确定”这一点构造训练对。
  • 离散似然更紧。同一个去噪网络诱导的离散采样器，其对数似然不低于对应的高斯采样器（Thm. 3.2），所以训练与评测都留在离散一侧。
  • 高斯工具可迁移。作者在 v3 的“未来工作”中列出：借高斯侧做分类器引导、把 \(\epsilon\) / \(v\) 参数化搬进离散去噪器。

3.3 课程学习：用有偏换低方差

直觉：词表 3 万级时，\(\tilde\alpha_t\) 只需在 [0.85, 1] 内变化，离散 \(\alpha_t\) 就扫过 [0, 1]；高斯隐变量里其实还留着大量信号，只是被 argmax 抹掉了。把 argmax 换成温度 \(\tau\) 的 softmax，网络能看到“哪个 token 的分量最大、领先多少”，任务变容易、梯度方差变小；\(\tau\to0\) 且 \(t\) 取满 [0,1] 时才回到合法 NELBO。在 LM1B 上的对比：训练 1 万步时，方差最大的 100 个权重的梯度方差合计为 0.30（有课程）vs 11.7（无课程）。课程期结束、再按离散模型微调 1 万步（第 51 万步）时，Duo 困惑度 35.2，已比训满 100 万步的 UDLM 低约 1.5，作者据此称训练至少快 2×。Duo §4.1.2、§5.1、Tab. 4、App. C.7

3.4 离散一致性蒸馏：没有 PF-ODE，就借一条

一致性蒸馏需要一条从噪声到数据的确定性路径（概率流 ODE），掩码扩散的先验是确定的全 \([\mathrm{M}]\)，没有这样的“隐式”性质（Duo §1）。Duo 用最优去噪器下高斯 PF-ODE 的解 \(\tilde\alpha_t x+\sqrt{1-\tilde\alpha_t^2}\epsilon\) 作轨迹，再逐时刻 argmax 投影成离散轨迹 \(\mathcal{P}_{\mathrm{DDT}}\)；相邻两点 \((z_s,z_t)\) 构成蒸馏对。这与 一致性模型 的“相邻两点输出一致”同构，区别是：轨迹来自最优（而非学到的）去噪器，距离换成 KL，并按 SDTT 的多轮方式逐步拉大 \(\delta\)。蒸馏 5 轮后，祖先采样 16 步即达到未蒸馏 1024 步的质量，Greedy-tail（最后一步取 argmax 而不采样）8 步即可，但熵略降。Duo §4.2、§5.2、Fig. 4

为什么均匀态更适合少步：掩码模型少步时每步要独立揭示很多 token 且不能回改，冲突无法修复；均匀态模型下一步还能改。Duo 的数据里，未蒸馏时 8 步的 Duo 生成困惑度 198，MDLM 831；同样蒸馏 5 轮后为 112 vs 193。Duo §5.2、Tab. 7后续 dLLM 的学习式并行解码见 第 15 页。

3.5 Beyond-Masked：扩展律与“困惑度为什么会误导”

设置。AR、MDLM、Duo、Eso-LM（全扩散模式）共用 DiT 骨干、Llama-2 分词器（加 mask 共 32,001）、上下文 2048、batch 256，在 SlimPajama 上做 IsoFLOP 扫描（\(C\in\{6\times10^{18},\dots,10^{20}\}\)），训练 FLOPs 用 calflops 精确计算而非 \(6ND\)。每个预算拟合最优参数量与最优损失，再拟合幂律。Beyond-Masked §3、Eq. 14–16、Tab. 4

结论一：各族斜率相近，常数差很大。要达到 AR 的验证损失：MDLM（用 ELBO 训练）约需 16× 计算（复现 SMDM 的结论），把训练损失换成去掉时间权重的低方差版本后约 14×（约 12% 的改进），Duo 约 23×，Eso-LM 约 32×；各扩散族的计算最优模型都比 AR 小约 2×。§3.2

结论二：困惑度只在族内可比。理由有三：① 真实困惑度不可解，各族报的是各自前向过程诱导的不同上界，上界的松紧程度本身随族而变；② 困惑度不反映推理时行为——Duo 能少步、Eso-LM 有 KV cache；③ 下游任务未必跟随困惑度。作者用速度-质量前沿说明第②点：对每个预算的最优模型拟合“生成困惑度 / 吞吐 vs 步数”，在目标生成困惑度 40–200 区间取最大吞吐。结果是吞吐低于 200 tok/s 时 AR 占优，[200, 400] 与 ≥600 由 Duo 占优，[400, 600] 由 Eso-LM 占优。§1、§3.3、Fig. 1

结论三：1.7B 上，困惑度更差的 Duo 在 GSM8K 上最好。四个模型都在 Nemotron 预训练数据上训 2.1T token（64 张 H100），GSM8K 增强集（38.5 万条）SFT 5 个 epoch 后，Duo 65.8、AR 62.9、MDLM 58.8、Eso-LM 33.4；零样本似然基准则 AR 全面领先，扩散族内部 MDLM 与 Duo 各有胜负。§4、Tab. 1–2

需要带着读的前提。GSM8K 评测里所有模型都“一次一个 token、从左到右”生成（作者理由：置信度采样本来就会退化成左到右），所以 Duo 的优势与并行解码无关，吞吐也都在 25 tok/s 上下（batch 1）；Tab. 2 声称取各方法最好的学习率，但 Tab. 3 的网格里 MDLM 有 61.7、Duo 有 66.0，与 Tab. 2 不符（见 §5 callout）。同期的 von Rütte et al.（2512.10858）在掩码 ↔ 均匀的插值噪声上做扩展律，摘要的结论是：算力受限时各噪声类型收敛到相近损失，均匀态的计算最优配置需要更多参数、更少数据，并把均匀态模型做到 10B / \(10^{22}\) FLOPs——与 Beyond-Masked 的“23× 常数差”并不完全一致，两者实验协议不同。Beyond-Masked §4.2、Tab. 2–3；von Rütte et al. 摘要

3.6 均匀噪声走向工业：DiffusionGemma 与 Sumi

DiffusionGemma 的技术报告写明使用多项式（均匀）扩散而非掩码扩散：前向过程每个位置以 \(\kappa_t\) 保留原 token、否则均匀换成词表中任意 token，画布从均匀随机 token 初始化，理由正是“所有 token 都能互相转移，模型可以持续纠错”；但已经提交的前序画布（块自回归，每块 256 token）是冻结的。它采用 DFM 的 CTMC 写法与离散 Euler 步，并在采样器部分引用了 Duo 第二章（Ψ-samplers）。DiffusionGemma 报告 §2.1.1、§3.1–3.3另一端，Sumi（2606.19005）是首个从零预训练的开放 7B 均匀态扩散 LM（1.5T token），摘要称在知识、推理、代码上与同 token 预算的 AR 相当、常识类基准较弱。Sumi 摘要

5. 训练目标与似然

$$q_t(z_t\mid x)=\mathrm{Cat}\Big(z_t;\ \alpha_t x+(1-\alpha_t)\tfrac{\mathbf{1}}{K}\Big),\qquad z_t=\operatorname{argmax}\big(\tilde\alpha_t x+\sqrt{1-\tilde\alpha_t^2}\,\epsilon\big)\ \Longrightarrow\ \alpha_t=\mathcal{T}(\tilde\alpha_t),$$
$$\mathcal{T}(\tilde\alpha)=\frac{K}{K-1}\Big[\int_{-\infty}^{\infty}\phi\Big(z-\frac{\tilde\alpha}{\sqrt{1-\tilde\alpha^2}}\Big)\,\Phi^{K-1}(z)\,dz-\frac{1}{K}\Big].$$

\(\phi,\Phi\) 为标准正态密度与分布函数。课程损失（Eq. 21）把网络输入换成软化的隐变量，计分仍在离散 \(z_t\) 上：

$$\mathcal{L}_{\mathrm{train}}=\mathbb{E}_{x,\ t\sim U[\beta,\gamma],\ w_t}\sum_{\ell=1}^{L}f_{\mathrm{Duo}}\Big(\operatorname{argmax}(w_t^{\ell}),\ x_{\theta}^{\ell}\big(\mathrm{softmax}(w_t/\tau),t\big),\ \mathcal{T}(\tilde\alpha_t);\ x^{\ell}\Big),$$

只有 \(\tau\to0^+\)、\([\beta,\gamma]=[0,1]\) 时它才等于 NELBO。蒸馏目标（Eq. 23）为 \(\sum_{\ell} D_{\mathrm{KL}}\big(x_{\theta}^{\ell}(z_t,t),\,x_{\theta^-}^{\ell}(z_s,s)\big)\)，\(z_s,z_t\) 由同一 \((x,\epsilon)\) 生成。

为什么跨族比较困惑度会误导（Beyond-Masked §1、§5）：掩码族与均匀族的 NELBO 来自不同的前向过程与反向参数化，都是同一个真实 NLL 的上界，但松紧不同；“上界更高”既可能是模型更差，也可能只是界更松。再加上少步、KV cache 这些不进入困惑度的推理特性，作者主张联合报告似然、采样效率与下游表现。MDLM 一侧的反例同样说明问题：训练时去掉权重 \(\alpha_t'/(1-\alpha_t)\)（它在 \(t\to0\) 时发散），评测仍用 ELBO，计算效率反而提高约 12%——训练目标与评测指标本可分开。Beyond-Masked Eq. 7–8、§3.2.2

6. 伪代码

duo.py（依据 Duo Eq. 17–23、Alg. 1、§5 改写的示意版本）
T_table = precompute_diffusion_transform(K, n=100_000)   # (alpha_g, T(alpha_g)) pairs, Eq. 11

def duo_train_step(x, model, step, tau=1e-3):            # x: [B, L] token ids
    curriculum = step < 500_000
    t = uniform(0.03, 0.15, B) if curriculum else uniform(0, 1, B)   # 2nd-phase range: see text
    a_g = 1 - t                                          # Gaussian schedule alpha~_t = 1 - t
    w = a_g[:, None, None] * one_hot(x, K) + (1 - a_g**2).sqrt()[:, None, None] * randn(B, L, K)
    z = w.argmax(-1)                                     # discrete latent with uniform-state marginal
    a = T_table.interp(a_g)                              # alpha_t = T(alpha~_t)
    inp = softmax(w / tau, -1) if curriculum else one_hot(z, K)    # soft lookup vs. hard lookup
    x_theta = model(inp, t).softmax(-1)                  # bidirectional DiT, conditioned on t
    return f_duo(z, x_theta, a, x).sum(-1).mean()        # Rao-Blackwellized NELBO terms (Eq. 17)

def dcd(student, data, rounds=5, M=10_000, delta=1 / 512):
    for _ in range(rounds):
        teacher = frozen_copy(student)                   # teacher = current student, not EMA
        for _ in range(M):
            x = next(data); t = uniform(0, 1, B); s = (t - delta).clamp(min=0)
            eps = randn(B, L, K)                         # shared noise -> deterministic pair
            z_t = argmax_traj(x, eps, t); z_s = argmax_traj(x, eps, s)
            with torch.no_grad():
                p_teacher = teacher(one_hot(z_s, K), s).softmax(-1)
            loss = kl(student(one_hot(z_t, K), t).log_softmax(-1), p_teacher)   # Eq. 23 order
            loss.backward(); opt.step(); opt.zero_grad(); ema.update(student)
        delta *= 2
    return ema.weights

def argmax_traj(x, eps, u):
    a_g = (1 - u)[:, None, None]
    return (a_g * one_hot(x, K) + (1 - a_g**2).sqrt() * eps).argmax(-1)

采样仍是均匀态的祖先采样（Eq. 4–5），起点为每个位置均匀随机的 token；Greedy-tail 只在最后一步把采样换成 argmax。课程第二阶段 \(t\) 的取值范围论文没有单列 未核实，伪代码按 \([0,1]\) 写。

9. 承上启下

之前

  • MDLM：掩码族困惑度最好，但揭示即定稿，少步时冲突无法修复。
  • SEDD Uniform / UDLM：能改字，困惑度落后；没有 PF-ODE，一致性蒸馏用不上。
  • DFM：把均匀源纳入同一框架，但没有给出让它变强的训练方法。

之后 → 留下的问题

  • Duo 第二章（Ψ-samplers，2026-02，ICLR 2026）：适用于任意噪声的 predictor-corrector 采样器，步数增加时质量继续提升；课程训练时间 −25%、显存 −33%（摘要）。
  • 工业落地：DiffusionGemma 采用均匀噪声 + 块画布 + 采样器蒸馏；开放从零模型 Sumi 7B。
  • 少步的另一条线：掩码模型上的学习式并行（dParallel、d3LLM、CDLM），以及图像侧的 一致性模型。
  • 未决：均匀态的 23× 常数差能否被更好的训练抹平（von Rütte et al. 的结论不同）；“困惑度 + 速度 + 下游”联合口径如何标准化（见 基础页）。

简答题

Q9为什么说均匀态离散扩散是高斯扩散的 argmax？这一对偶让 Duo 在训练和采样上各借到了什么，又有哪些地方并不对偶？

在 \(K\) 维 one-hot 上做高斯扩散 \(w_t=\tilde\alpha_t x+\sqrt{1-\tilde\alpha_t^2}\epsilon\)，argmax 后每个时刻的分布恰为“以 \(\alpha_t=\mathcal{T}(\tilde\alpha_t)\) 保留原 token、否则均匀替换”，且满足均匀态扩散的 ODE。训练上，Duo 把 argmax 软化成低温 softmax 作网络输入，用有偏但低方差的课程加速收敛（约 2×）；采样上，固定 \(\epsilon\) 得到确定性离散轨迹，代替不存在的离散 PF-ODE 做一致性蒸馏，8–16 步即可生成。

  • 只有边缘对偶：离散化的高斯轨迹不是马尔可夫离散扩散过程（App. A.3），DCD 用的是这种“伪轨迹”。
  • 似然不对偶：同一网络下离散采样器的似然不低于高斯采样器（Thm. 3.2），所以评测留在离散侧。
  • 代价：隐变量是 [B, L, K] 的稠密张量，课程阶段显存随词表增长。

依据：Duo §3.1–3.2、§4.1–4.2、Tab. 4、Tab. 7、App. A.3；Duo Ψ-samplers 摘要。

Q10Beyond-Masked 显示均匀态的似然扩展更差（≈23× vs 掩码 ≈14–16×），却在 GSM8K 与速度-质量前沿上占优。为什么跨噪声族比较困惑度会误导？这一结论有哪些前提与漏洞？

各族报告的是各自前向过程诱导的 NELBO 上界，松紧本身不同，上界高不等于模型差；困惑度也不包含少步、KV cache 等推理特性，而这些决定了实际的速度-质量前沿。Beyond-Masked 因此在同 FLOPs 下同时报告扩展律、前沿与下游：Duo 在高吞吐区间与 1.7B 的 GSM8K SFT 上胜出。

  • GSM8K 上所有模型都逐 token 左到右解码，Duo 的优势与并行无关；batch 1 吞吐几乎相同。
  • Tab. 2 与 Tab. 3 的“最好学习率”不一致：按网格最好值 MDLM 是 61.7，Duo 66.0 仍领先 AR 62.9。
  • 前沿依赖生成困惑度（Llama-2 7B 打分，需同时看熵）和吞吐测量方式（最大 2 的幂 batch，AR 推理栈未写明）；同期 von Rütte et al. 的扩展律结论不同。

依据：Beyond-Masked §1、§3.2–3.3、§4.2、Tab. 2–3、Fig. 1；von Rütte et al. 摘要。
