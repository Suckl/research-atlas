1. 动机：转回来时，哪段历史值得占据上下文？

相机刚离开的景物可能不在最近窗口里；把全部历史直接送进注意力又会增加计算并引入无关证据。Context as Memory（下文 CaM）保留历史帧的原始图像形式，按相机 FoV 重叠找出有用帧；WorldPack 则把视角相关性用于历史压缩率分配。前者回答“选哪些历史”，后者回答“每条历史分多少预算”。CaM §1、§3；WorldPack §1、§4

一句话理解 回访时，时间远不代表无关。CaM 把相关旧帧重新拿进窗口；WorldPack 把相关旧帧提到高精度档位，同时保留更多低精度证据。这是两种独立方法，本页合放是为了比较设计轴。

与帧库检索衔接，本页聚焦相机查询怎样改变活动上下文。它们主要处理场景空间一致性；旧帧里的物体状态已经变化时，仅找到相同视角并不足够，见动态与事件记忆。

2. 一次读历史、生成、写回

统一记号：视频时间 \(t\)，扩散时间 \(\tau\)，当前 latent \(x_t\)，近期窗口 \(H_t\)，动作 \(a_t\)，文本 \(c_t\)，相机位姿 \(p_t\)，历史记忆 \(M_t\)，查询 \(q_t\)，读出 \(r_t\)。CaM 的查询是目标段的相机条件，WorldPack Alg. 1 使用当前视角 \(p_t\) 给下一帧预测的历史分配预算。

$$r_t=\mathrm{Read}(M_t,q_t),\qquad x_{t+1}\sim G_\theta(H_t,r_t,a_t,c_t),\qquad M_{t+1}=\mathrm{Write}(M_t,x_{t+1},a_t,p_{t+1}).$$

这是比较骨架：CaM 不另设动作 writer，\(H_t\) 的近期锚已经包含在 context 中；WorldPack 的 Write 是历史追加，compression 发生在条件读取配置中，不能把一次 pack 当作永久覆盖原始库。CaM Alg. 2；WorldPack Alg. 1、§6.5

3. 组件拆解：选择证据与分配精度

3.1 CaM：存图像，读取时才编码

记忆直接保存历史帧和相机条件，不额外把帧库改成特征索引或三维模型。选中的历史 RGB 帧是互不连续的，逐帧经 causal VAE 编码；它们与目标 noisy latent 沿帧维拼接，平等参与注意力，输出时只更新目标。context 的 clean latent 保持不变。CaM §3.2–3.3

目标段的 RoPE 位置维持预训练设置，新增 context 使用新位置。这里“无需外部 control module”指历史注入方式，不是模型不需要相机条件；相机编码器仍将位姿映射到特征通道并加到主干中。CaM §3.1–3.2、Fig. 2

3.2 FoV 重叠是候选过滤，不是精确可见性

CaM 的数据将相机运动限制在水平平面，并只绕竖直轴旋转。方法把 FoV 简化为左右边界射线围出的扇形，检查射线交点及其距离，过滤过近或过远的交叠。它不重建真实表面，因此墙后区域与遮挡仍可能产生错误候选。CaM §3.3–3.4、Fig. 4

通过 FoV 的连续候选组仅随机保留其中一帧，减少相邻重复；必要时补空间或时间距离较远的候选。最终还加入最近帧保证连续性。训练从长 GT 视频中取目标段和剩余帧作 context，而推理只能从已经生成的过去查找；训练采样不能直接当作完全因果的自生成历史训练。CaM §3.3、Alg. 1–2

3.3 WorldPack：几何相关性决定压缩档位

WorldPack 独立采用 action-conditioned CDiT：目标帧做 self-attention，通过 cross-attention 读取历史。它把每条候选历史编码成可变 token 数，几何评分越高，分配的空间精度越高；compression 不是按旧帧年龄单调递减。它借用 FramePack 的 rate-specific input projection 设计，并在自身基座中重现 CaM / WorldMem 式检索作为消融。WorldPack §4.1–4.2、§6.3

$$o_i=\frac{\mathrm{Vol}(V(p_i)\cap V(p_t))}{\mathrm{Vol}(V(p_t))},\quad s_i=w_o o_i-w_t\frac{t-i}{t},\quad \ell_i=\frac{L_f}{\lambda^{d_i}},\quad L_{\mathrm{pack}}=\sum_i\ell_i.$$

\(V(p)\) 是截断视锥；Monte Carlo 估计体积重叠，温和的时间惩罚用于相似几何分数的排序。\(d_i\) 是压缩优先级，\(L_f\) 是完整帧 token 数，\(\lambda\) 控制档位。几何分数本身不学习；各压缩档的 input projection 可以学习。WorldPack Eq. 4–7、§4.2

“所有历史都保留”应限定为所纳入 pack 的候选证据没有直接被丢弃：实验活动配置仍有有限历史名额，不能推出任意长全部历史都以固定精度同时可读。原始候选库和 pose 仍需另计。WorldPack §4.2、§6.5

5. 训练目标与记忆监督

CaM 通过目标段的扩散去噪误差学会用历史，不对 rule-based FoV 检索求梯度。只给 target 加噪，context 保持 clean；目标段和 context 的相机一起注入。论文损失写作噪声预测范数，下式保留该形式，不额外改写成平方：CaM Eq. 1、3、Alg. 1

$$\mathcal L_{\mathrm{CaM}}=\mathbb E\big[\lVert\epsilon_\theta([x_{\mathrm{target}}^\tau,r_t],\tau,c_t,p_{\mathrm{target}},p_{\mathrm{ctx}})-\epsilon\rVert\big].$$

WorldPack 同样通过条件扩散预测下一观测；监督落在目标预测，不是为每条压缩历史做逐帧重建。基座使用数据历史与动作，packing 与 geometric selection 在训练 / 推理中提供活动条件。训练扩散的噪声时间与视频时间是两个轴。WorldPack §3–4、App. D

因此，两者都不能因为推理时把输出写回，就被归为 self-rollout 后训练。CaM 训练从同一长视频的剩余位置找 context；WorldPack 在 LoopNav 先训练基座、再微调压缩 / 检索变体，控制了自身消融的训练来源。CaM §3.3；WorldPack App. D Tab. 9

# video time t != diffusion time tau; archive stores clean evidence
archive = [(initial_frame, initial_pose)]
while not finished:
    p_next, a_t, c_t = next_controls()
    if method == "CaM":
        # Target camera trajectory is available as a control condition
        candidates = fov_ray_filter(archive, p_next)
        candidates = one_per_adjacent_group(candidates)
        old = select_with_far_space_time(candidates, context_limit - 1)
        recent = archive[-1]
        refs = old + [recent]
        r_t = vae_encode_each_frame(refs)  # discontinuous RGB frames
        target = sample_noise_for_segment()
        for tau in diffusion_schedule:
            joint = concat_frame_axis(r_t, target)
            eps = dit(joint, tau, c_t, poses(refs), p_next)
            target = denoise_target_only(target, eps, tau)
        new_frames = vae_decode(target)
    elif method == "WorldPack":
        # Score with current view; original candidate history remains available
        scores = fov_volume_scores(poses(archive), current_pose)
        scores -= temporal_penalty(archive, current_time=t)
        ranked = rank_candidates(scores)
        refs, rates = allocate_discrete_packing_slots(ranked)
        latents = vae_encode(refs)
        r_t = concat_tokens(rate_specific_project(latents, rates))
        target = sample_noise_for_next_frame()
        for tau in diffusion_schedule:
            pred = cdit(target, tau, cross_context=r_t, action=a_t)
            target = denoise(target, pred, tau)
        new_frames = vae_decode(target)
    archive.extend(zip(new_frames, p_next))
    current_pose = last_pose(p_next)
    t += len(new_frames)

简答题

Q17为什么 CaM 的“选历史”与 WorldPack 的“压缩历史”不能当成同一个记忆结构？

CaM 原样存帧，先选子集，再把 clean context 沿帧维拼进视频 DiT；WorldPack 用几何分数分配多精度 token，由 CDiT cross-attention 读 packed history。共享的是相机相关性这一设计依据，不是存储、编码或读取结构。

  • 选择改变证据是否进入活动窗口。
  • 分配改变纳入证据的保真度与 token 成本。
  • WorldPack 的检索消融只重现选择机制，没有沿用 CaM 的内部基座。

依据：CaM §3.2–3.3；WorldPack §4、§6.3。

Q18固定活动预算后，为什么仍会随历史增长变慢，或回忆错误状态？

固定的是送进生成器的证据预算。历史候选库、pose 记录和 FoV 评分仍可增长；几何相关不等于物体状态正确，遮挡会误选，动态变化也会让旧帧过时。

  • 活动 token、总存储和查询成本必须分别测。
  • 高重叠帧可能看到了同一位置的旧状态。
  • 需要估计 pose、遮挡与状态更新的独立实验；回访像素一致不能替代这些检验。

依据：WorldPack §6.5、§7；CaM §3.3、§5。
