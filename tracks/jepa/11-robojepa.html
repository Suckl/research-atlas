1. 动机：世界模型能不能像语言模型一样“可预测地变大”？

语言模型的进步有缩放律指引：给定算力，就能预测损失。机器人世界模型没有这样的工具——V-JEPA 2-AC 只在单一平台（Franka / DROID）、62 小时数据上训练了一个 300M 的预测器；它变大会不会更好、好多少、靠什么指标判断，都没有答案。而真机评测昂贵且噪声大，无法拿来做缩放实验的度量。

一句话理解 RoboJEPA 冻结 V-JEPA 2.1-G 编码器，把 23 个公开机器人数据集（12 种平台）统一成一个训练集，训练 22M 到 8B 的动作条件预测器。它发现潜空间多步 rollout 的误差（“想象误差”）随训练算力服从一条二阶幂律，用 ≤2B 的模型拟合就能准确预测 4B、8B 的误差；而想象误差又与下游规划成功率强相关——于是有了一个可以离线计算、可以外推的“世界模型质量”指标。

3. 组件拆解

3.1 为什么需要“二阶”幂律

论文比较了两种拟合：标准幂律在 4B / 8B 上的外推误差为 2.0×10⁻³（DROID）与 3.7×10⁻³（RoboCasa），二阶幂律为 0.6×10⁻³ 与 1.4×10⁻³。Tab. 2 二阶项让曲线在双对数坐标下逐渐变平，作者认为这反映了拟合区间已接近数据饱和：数据混合固定，模型越大，每单位算力的收益递减更快。论文只拟合了“算力—误差”关系（固定数据、变模型规模），没有单独拟合数据缩放律。

3.2 能力随算力“涌现”

能力（仿真 RoboCasa，§3.2–3.3）大约出现在
贪心到达（reach）10²⁰ FLOPs
抓住物体3×10²⁰ FLOPs
绕障到达（需长视野冷却配方）10²¹ 起飞，10²² 饱和
推物体约 10²² 之前为 0

短视野冷却（K = 2）训练的模型在绕障任务上趋势很弱，换成长视野冷却（K = 10）后趋势变强——训练时 rollout 的长度要与任务的规划视野匹配。论文没有给出“想象误差—成功率”的相关系数，相关性由这些缩放曲线定性展示。

5. 训练目标与防坍塌

$$\mathcal L = \tfrac12\,\underbrace{\frac1T\sum_t\big\lVert P_\phi(z_{\le t}, a_{\le t}, s_{\le t}) - z_{t+1}\big\rVert_1}_{\mathcal L_\text{TF}} + \tfrac12\,\underbrace{\frac{1}{T-T_0}\sum_{t\ge T_0}\big\lVert \hat z_{t+1} - z_{t+1}\big\rVert_1}_{\mathcal L_\text{AR}:\ \hat z\ \text{由自身 rollout 产生}},\qquad z = \mathrm{Enc}_\text{V-JEPA 2.1-G}(o)\ \text{（冻结）}$$

防坍塌靠冻结编码器（与 DINO-WM、V-JEPA 2-AC 相同）。公式中的归一化与 T₀（前缀长度）为本页写法，论文以 Eq. 5 给出 L = ½LTF + ½LAR。

6. 伪代码

robojepa_plan.py（滚动视野 CEM，示意）
def plan(obs_hist, goal_img, robot_id, H, n=..., iters=...):
    z_hist = enc(obs_hist)                                   # 冻结 V-JEPA 2.1-G
    z_goal = enc(goal_img)
    cache = predictor.prefill(z_hist, act_hist, state_hist, robot_id)   # 滚动 KV cache
    A = uniform_sample(n, H, action_space[robot_id])         # 均匀采样，无策略提议
    for _ in range(iters):
        z_pred = predictor.rollout(cache, A, steps=H)        # [n, H, tokens, 1664]
        cost = l1(z_pred[:, -H:], z_goal).mean((-1, -2, -3))
        elite = A[cost.argsort()[:k]]
        A = refit_and_resample(elite, n)
    return elite[0, 0]                                       # 执行一步，然后重新规划

9. 承上启下

V-JEPA 2-AC（2025-06）

  • 冻结 V-JEPA 2 ViT-g；
  • 单一平台，62 小时 DROID；
  • 约 300M 的预测器；
  • 证明“潜空间规划可以上真机”。

RoboJEPA（2026-10）

  • 冻结 V-JEPA 2.1-G（稠密特征是可缩放的前提）；
  • 12 种平台、1.5 万小时、26 种动作空间；
  • 22M–8B 的预测器，第一次给出多本体机器人世界模型的缩放律；
  • 开放问题：规划仍需数秒；长视野多阶段任务仍弱（抓放 27%），可与 层级世界模型结合；与 VLA 的公平比较尚缺。
