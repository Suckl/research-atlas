1. 动机：视频预训练为什么这么贵？

视频自监督的主流方法用两类办法防坍塌：要么在结构上制造不对称——EMA 目标编码器 + stop-gradient + 容量受限的预测器（V-JEPA / V-JEPA 2）；要么绕开问题，在像素空间重建被遮挡内容（VideoMAE）。前者每步要跑两个编码器，后者要预测海量像素，都很贵。LeJEPA 证明了只要用 SIGReg 把嵌入推向各向同性高斯，就可以去掉所有这些启发式——但它只在图像上验证过。

一句话理解 LeVJEPA 把 LeJEPA 搬到视频：只剩一个编码器和一个投影头，损失 = 局部视图向全局视图对齐 + λ·SIGReg，λ = 0.02 是唯一超参。没有了不对称结构之后，两件事变得可行：预训练成本只取决于编码器看到多少 token，于是随机丢掉 95% 的 token 既省算力又涨点；编码器可以直接用块因果注意力，时间顺序成为编码器自身的性质。

3. 组件拆解

3.1 去掉了什么，为什么能去掉

组件V-JEPA 2 里的作用LeVJEPA
EMA 目标编码器提供缓慢变化的目标，防坍塌去掉：目标就是同一编码器对全局视图的输出
stop-gradient阻止目标被“拉向”预测去掉：两边都回传
容量受限的预测器制造不对称；做时空遮挡预测去掉（恒等映射）
防坍塌以上三者的组合，经验性的SIGReg：有理论保证，一个超参
每步编码器前向上下文编码器 + 目标编码器一个编码器（但看多个视图）

3.2 成本由“看到多少 token”决定

去掉目标编码器后，每步的计算几乎全部来自编码器对各视图 token 的前向与反向，成本正比于 token 数。V-JEPA 系列的遮挡只作用于上下文编码器，目标编码器仍要看完整的视频；LeVJEPA 没有这个负担，于是可以激进地丢 token。在 ρ = 0.95 下，前馈成本最多降 (1−ρ)−1 = 20×，而且准确率反而更高——作者的解释是丢弃本身是一种强数据增强。

3.3 视频 vs 图像：同样的帧，用视频训练更好吗？

论文做了一个对照：在同样的视频帧上以相同算力训练 DINOv2（当作图像集）与 LeVJEPA。结果 ImageNet 上 DINOv2 略好（53.8 vs 50.7），而运动为主的 SSv2 上 LeVJEPA 几乎翻倍（30.4 vs 16.9）。LeVJEPA Tab. 4 作者的结论：一旦去掉额外的计算负担，视频是比静态图像更好的通用视觉预训练数据。

5. 训练目标与防坍塌

$$\mathcal L_\text{LeVJEPA} = \underbrace{\frac{1}{V+1}\sum_{v=0}^{V}\big\lVert z_v - z_g\big\rVert_2^2}_{\mathcal L_\text{inv}} + \lambda\cdot\mathrm{SIGReg}\big(\{z\}\big),\qquad \lambda = 0.02$$

\(z_g\) 为全局视图的嵌入（v = 0 即全局视图本身），梯度流经所有项。SIGReg 的定义与 LeWorldModel 页相同（随机一维投影 + Epps–Pulley）。整个目标只有 λ 一个超参，论文所有实验都没有调它。

6. 伪代码

levjepa_step.py
g = global_view(clip, size=224)                          # [B, 3, 16, 224, 224]
locs = [local_view(clip, size=96, aug=True) for _ in range(V)]
def embed(x):
    t = patch_embed(x)                                     # 逐帧 16×16
    t = random_keep(t, keep=0.05)                          # 丢 95%，保留 [CLS]
    return projector(vit(t, block_causal=True)[:, 0])      # [CLS] → 256 维
z_g = embed(g)
zs = [z_g] + [embed(l) for l in locs]
inv = sum(((z - z_g) ** 2).sum(-1).mean() for z in zs) / len(zs)
loss = inv + 0.02 * sigreg(all_gather(cat(zs)), num_dirs=1024, knots=17)
loss.backward(); opt.step()

9. 承上启下

SIGReg 一支此前做到了

  • LeJEPA：图像预训练去掉启发式；
  • LeWorldModel：小规模、像素端到端的世界模型。

LeVJEPA 补上的

  • 视频规模的表征预训练，并在算力上明显优于 EMA 路线；
  • 块因果编码器，为流式世界模型准备好底座；
  • 同组随后把 SIGReg 推进到层级世界模型（H-JEPA）和“世界模型 + 动作”的联合训练（LeWAM，2026-10，见时间线）。
