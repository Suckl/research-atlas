1. 动机：只靠“特征预测”能学好视频吗？

I-JEPA 证明了在图像上“预测被遮区域的表征”可行。视频是更自然的下一步：它天然包含运动、遮挡、物体持续性等时间结构，而这正是世界模型最需要的东西。

当时的视频自监督方法大多是：

  • 像素重建（VideoMAE、Hiera、OmniMAE 等）：要重建每一帧的纹理细节；
  • 借助额外监督或先验：预训练图像编码器、文本、负样本、手工增强。

V-JEPA 问的问题很直接：把“特征预测”作为唯一的训练目标——不用预训练图像编码器、不用文本、不用负样本、不用像素重建——能不能学到通用的视频表征？并且要求在冻结骨干（不微调）的评估下就好用。

答案 可以。而且同样的训练预算下，预测特征比预测像素在冻结评估上更好（K400 73.7 vs 68.6，见 §8），训练也更快。

3. 组件拆解

3.1 Tubelet：把视频切成时空 token

图像 ViT 把 16×16 像素切成一个 patch；V-JEPA 把2 帧 × 16×16 像素切成一个 tubelet。这相当于在时间维度上也做了 2 倍下采样：

$$\underbrace{[B,3,16,224,224]}_{\text{视频}} \xrightarrow{\ \text{Conv3d}(k=s=(2,16,16))\ } [B, D, 8, 14, 14] \xrightarrow{\text{flatten}} [B,\ 1568,\ D]$$

位置编码是 3D sin-cos（时间 t、高 h、宽 w），固定不训练。到了 V-JEPA 2，这里换成了 3D-RoPE。

3.2 时空多块掩码：为什么必须“贯穿时间”

视频在时间上高度冗余：相邻帧几乎一样。如果每帧独立遮挡，被遮的区域在相邻帧里往往是可见的，模型只要“抄邻帧”就能把损失降下来，学不到有用的东西。V-JEPA 的做法是让每个掩码块在时间上延伸到整个片段，同时让被遮面积足够大（约 90%）。

与 I-JEPA 掩码的区别 I-JEPA：先采 4 个目标块，再单独采一个上下文块并去掉重叠（上下文 + 目标 ≠ 全部）。V-JEPA：采目标块的并集，上下文直接取补集；且同一片段采两组不同尺度的掩码，共享一次 y-encoder 前向。

3.3 x-encoder / y-encoder / 预测器

结构上与 I-JEPA 完全同构，只是 token 变成了时空 token：

组件结构输入更新方式
x-encoderViT-L/16（24 层、宽 1024）或 ViT-H/16（32 层、宽 1280）约 10% 可见 token梯度下降
y-encoder同上全部 1568 tokenEMA，0.998 → 1.0
预测器12 层、宽 384 的 Transformer上下文 token + 约 1400 个 mask token梯度下降

注意预测器的序列长度：它要同时处理上下文和所有被遮位置，接近完整的 1568 个 token——这也是预测器必须“窄”的原因之一。

3.4 从 L2 到 L1

V-JEPA 把回归损失换成了 L1：

$$\mathcal L = \frac{1}{|M|}\sum_{k\in M}\big\lVert \hat s_k - \mathrm{sg}(s_k)\big\rVert_1$$

论文给出的理由是“训练更稳定”。直觉上，L1 对少数误差很大的 token 不那么敏感（梯度幅度有界），在约 1400 个目标 token 一起回归时更不容易被个别难预测的区域主导。这个选择一直沿用到 V-JEPA 2。

5. 训练目标与防坍塌

$$\min_{\theta,\phi}\ \frac{1}{2}\sum_{m\in\{\text{短程},\text{长程}\}} \frac{1}{|M_m|}\sum_{k\in M_m}\Big\lVert\, g_\phi\big(f_\theta(x_{\bar M_m}),\ z_{M_m}\big)_k - \mathrm{sg}\big(\mathrm{LN}(f_{\bar\theta}(x))\big)_k \Big\rVert_1$$

其中 \(x_{\bar M}\) 表示掩码补集（可见 token），\(z_{M}\) 是被遮位置的 mask token。防坍塌机制与 I-JEPA 完全一致：EMA 目标编码器 + stop-gradient + 预测器。没有负样本、没有方差/协方差正则。

实现细节 官方代码对 y-encoder 输出做 F.layer_norm 后再取目标；损失写作 torch.mean(torch.abs(z - h) ** loss_exp) / loss_exp，loss_exp = 1 即 L1。学习率、weight decay 等调度按 1.25 倍迭代数计算，实际训练在 90K 迭代处截断。

6. 伪代码

train_step.py（按 app/vjepa/train.py 结构整理）
# clips: [B, 3, 16, 224, 224]
# masks_enc / masks_pred: 两组（短程、长程）索引，由 3D MaskCollator 生成，二者互为补集

def train_step(clips, masks_enc, masks_pred):
    with torch.no_grad():
        h = target_encoder(clips)                       # [B, 1568, D]  只算一次
        h = F.layer_norm(h, (h.size(-1),))

    z = encoder(clips, masks_enc)                       # list[2]: [B, K_ctx, D]
    z = predictor(z, masks_enc, masks_pred)             # list[2]: [B, K_tgt, D]

    loss = 0.
    for zi, mi in zip(z, masks_pred):
        hi = apply_masks(h, mi)                         # 在“输出”上取被遮位置
        loss += torch.mean(torch.abs(zi - hi) ** 1.0) / 1.0   # L1
    loss /= len(masks_pred)

    loss.backward(); optimizer.step(); optimizer.zero_grad()
    ema_update(target_encoder, encoder, m=next(momentum_scheduler))   # 0.998 → 1.0

V-JEPA 证明了

  • “特征预测”可以单独作为视频自监督目标；
  • 冻结特征同时擅长运动（SSv2）和外观（K400、IN-1K）；
  • 比像素预测更好、更省算力。

留下的问题 → V-JEPA 2

  • 规模：200 万视频、6 亿参数、16 帧短片段——远未到上限；
  • 表征能“理解”视频，但还不能“预测动作的后果”：模型里没有动作 → 无法用于规划；
  • 位置编码、训练调度在更大模型上不稳定。
