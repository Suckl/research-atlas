1. 动机：单层世界模型在长视野任务上为什么失败

DINO-WM、V-JEPA 2-AC、LeWorldModel 都在单一时间尺度上规划：每一步预测下一帧的潜表征，用 CEM 搜一串原始动作。任务一长就出两个问题：预测误差逐步累积，几十步之后的潜状态已不可信；搜索空间随视野指数增长，CEM 的样本根本覆盖不到。例如 V-JEPA 2-AC 在真实 Franka 上只用单张目标图像做抓取放置，成功率为 0。

LeCun 2022 年的构想（从头讲起）早就给出了答案：H-JEPA——低层预测短期细节，高层预测更远、更抽象的状态，高层的预测作为低层的子目标。

一句话理解 HWM（2026-04）是“工程上先跑通”的版本：在一个已有的世界模型（共享潜空间）上再训练一个跨多步的高层预测器，并把一段原始动作压成 4 维的“潜宏动作”，高层用 CEM 找子目标、低层再去够子目标。H-JEPA（2026-10）是“原理上补完”的版本：每层有自己学出来的潜空间、只看下层的潜变量，各层都用 SIGReg 端到端训练——高层会自动丢掉快速变化、不可预测的细节。

3. 组件拆解

3.1 HWM：为什么共享潜空间是“捷径”

共享潜空间的最大好处是不用训练新的表征：底座世界模型已经在那里，高层预测器的目标与低层的状态在同一个空间里，子目标可以直接被低层当作规划目标。代价是高层被迫在一个为“单步预测”优化的空间里做长程预测——这个空间里保留了大量对长程无关的细节。论文的结果：

3.2 H-JEPA：每层自己的潜空间（2026-10）

H-JEPA 的问题意识直接针对 HWM：已有的任务无关 JEPA 世界模型要么只在一个时间尺度上预测，要么把多个视野塞进同一个潜空间。H-JEPA 让每层预测器在自己学出来的潜空间里往更远处预测。为了公平比较，论文实现了一个“HWM 式”的基线：与 H-JEPA 完全相同，只是第 1 层以上的编码器都是恒等映射。

Visual AntMaze（H-JEPA Tab. 1，3 个种子）成功率
平层 LeWM18.0 ± 3.5%
两层 H-JEPA39.3 ± 3.7%
三层 H-JEPA73.3 ± 3.5%
四层 H-JEPA63.3 ± 7.7%
  • 三层 H-JEPA 在 AntMaze 上的成功率接近 HWM 式基线的两倍；FourRoom、AntMaze、Cube 上每加一层（到三层为止）都把“成功率–规划算力”的帕累托前沿往左上推。
  • 只把第 1 层的代价投影到高层空间（不做层级规划）也有帮助：两层时 L2 投影 31.3%，原生 L1 代价 23.3%——说明高层空间本身就是更好的“距离度量”。
  • Push-T 上两层持平或略好，三层变差：每多一层，每个 epoch 能用的转移数就少一些（三层只有 LeWM 的 58%），数据成为瓶颈。
  • DROID 真实机器人视频：需要逆动力学损失；层级化在更少规划算力下提升了离线规划的保真度（具体数字见论文 Fig. 9）。

3.3 与 2022 年构想的对照

构想（A Path Towards AMI）

  • 多层 JEPA 堆叠，高层表征更抽象、预测更远；
  • 高层的预测给低层提供子目标；
  • 代价模块在各层评估状态。

H-JEPA（2026）

  • 逐层自有潜空间、端到端训练——构想的直接实现；
  • 防坍塌用 SIGReg（构想时尚无此工具，当时列举的是对比法与正则化法）；
  • 规划自上而下、子目标逐层下传；代价目前仍是到目标表征的距离，而不是学出来的代价函数。

5. 训练目标与防坍塌

$$\text{HWM:}\quad \mathcal L = \sum_t\big\lVert F^{(1)}(z_t, a_t) - z_{t+1}\big\rVert_1 + \sum_i\big\lVert F^{(2)}\big(z_{w_i},\ A(a_{w_i:w_{i+1}})\big) - z_{w_{i+1}}\big\rVert_1,\qquad z = \mathrm{Enc}_\text{frozen}(o)$$
$$\text{H-JEPA:}\quad \mathcal L = \sum_{\ell}\Big[\mathcal L^{(\ell)}_\text{pred} + \lambda_\ell\,\mathrm{SIGReg}\big(Z^{(\ell)}\big)\Big]\ \big(+\ \mathcal L_\text{IDM}\ \text{on DROID}\big),\qquad z^{(\ell)}_t = E^{(\ell)}\big(z^{(\ell-1)}_{\text{窗口}}\big)$$

HWM 靠冻结编码器防坍塌（与 DINO-WM、V-JEPA 2-AC 相同），低层通常直接沿用底座的预测器。H-JEPA 各层的编码器都在训练，每层都需要 SIGReg；所有层共用一个 SIGReg 系数。逆动力学项从相邻潜变量回归（宏）动作，目标做 stop-gradient——论文指出它此前未与 SIGReg 搭配过，两个权重需要联合交叉验证。

6. 伪代码

hierarchical_plan.py（HWM 式两层 MPC）
def hwm_mpc_step(o, o_goal, H=2, h=2, k=1):
    z, z_g = enc(o), enc(o_goal)                             # 共享潜空间，冻结编码器
    def high_cost(M):                                        # M: [N, H, 4] 宏动作
        zt = z
        for j in range(H): zt = F2(zt, M[:, j])
        return l1(zt, z_g)
    M_best = cem(high_cost, shape=(H, 4))
    subgoal = F2(z, M_best[0])                               # 第一个预测航点
    def low_cost(A):                                         # A: [N, h, d_a] 原始动作
        zt = z
        for j in range(h): zt = F1(zt, A[:, j])
        return l1(zt, subgoal)
    A_best = cem(low_cost, shape=(h, d_a))
    return A_best[:k]                                        # 执行前 k 步后重规划

H-JEPA 的版本把两处 cem 换成对动作的梯度下降，并把低层 rollout 经上层编码器抬升后再与子目标比较。

8. 关键结果

  • HWM：Franka 单目标图像抓放 0% → 70%（杯）/ 60%（盒）；抽屉 30% → 70%；Push-T d = 75：17% → 61%；迷宫 44% → 83%；规划算力最多省 3×。HWM 摘要、Tab. 1–3
  • H-JEPA：Visual AntMaze 三层 73.3%（平层 18.0%），且使用更少的规划算力；约为 HWM 式基线成功率的两倍。H-JEPA 摘要、Tab. 1、§4.1

9. 承上启下

单层世界模型

  • 短视野任务表现好；
  • 长视野：误差累积 + 搜索指数爆炸；
  • 真实机械臂上的多阶段任务几乎做不成。

层级世界模型

  • HWM：最小改动、即插即用，在真实 Franka 上把长程任务从 0 做到 70%；
  • H-JEPA：把构想中的层级 JEPA 端到端实现；
  • 开放问题：更深的层级需要更多数据（Push-T 三层退化）；规划仍需要秒级优化；高层的“代价”仍是表征距离。同期的 RoboJEPA 从另一条路——把单层世界模型做大——攻长视野。
