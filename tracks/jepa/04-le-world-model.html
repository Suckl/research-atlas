1. 动机：能不能从像素开始，稳定地端到端训练一个小世界模型？

到 2026 年初，潜空间世界模型大致有三种做法，各有痛点：

路线代表编码器痛点
冻结的基础模型特征DINO-WM冻结 DINOv2（约 1.24 亿张图预训练）每帧用全部 patch 特征（约 200 个 token），规划慢（每次约 47 s）；表征不针对控制优化
冻结的自监督视频编码器V-JEPA 2-AC冻结 ViT-g（1B）每帧 256 个 1408 维 token，规划一步约 16 s；依赖百万小时预训练
端到端 + 方差/协方差正则PLDM与预测器联合训练VICReg 式的 7 项损失、6 个需要调的权重，训练脆弱

端到端训练的根本难题仍然是坍塌：编码器和预测器一起训练时，把所有观测映射成同一个向量就能让预测损失为 0。LeWM 的回答是：不用 EMA、不用 stop-gradient、不用预训练编码器，只加一个有理论依据的分布正则——来自 LeJEPA 的 SIGReg。

一句话理解 预测损失负责“让下一帧可预测”，SIGReg 负责“让嵌入分布保持为各向同性高斯（因此不可能坍塌）”。两项损失、一个超参 λ。

2. 前置：LeJEPA 与 SIGReg

LeJEPA（Balestriero & LeCun, 2025-11）从理论上回答了两个问题：

  1. 嵌入应该服从什么分布？ 论文证明：为了让下游预测任务的风险最小，JEPA 的嵌入应服从各向同性高斯分布。
  2. 怎么高效地把嵌入推向这个分布？ 提出 SIGReg（Sketched Isotropic Gaussian Regularization）。

有了它，LeJEPA 去掉了 stop-gradient、teacher-student（EMA）结构与各种超参调度，只留一个权衡系数；实现约 50 行代码，在 ImageNet-1K 上用 ViT-H/14 冻结线性探测达到 79%。

2.1 SIGReg 的三步思路

① 高维检验太难 → 降到一维

Cramér–Wold 定理：一个分布由它在所有方向上的一维投影唯一决定。所以“Z 是各向同性高斯”⇔“对任意单位向量 u，⟨Z, u⟩ ~ N(0,1)”。

② 方向无穷多 → 随机采样（sketch）

每步随机采 M 个单位方向（LeWM 用 M = 1024），只检验这些投影。不同步采到不同方向，长期看覆盖所有方向。

③ 一维检验 → Epps–Pulley 统计量

比较投影样本的经验特征函数与 N(0,1) 的特征函数 \(e^{-t^2/2}\)，在加权的 t 上积分误差。cos/sin 有界，所以统计量及其梯度都有界、平滑。

为什么不只约束均值和协方差？

VICReg 一类方法约束一二阶矩：方差够大、协方差对角化。但满足这些的分布未必是高斯（例如均匀分布）。SIGReg 比较的是整个分布；基于特征函数也避免了高阶矩带来的梯度爆炸。

2.2 公式

设一批嵌入 \(Z\in\mathbb R^{N\times d}\)，随机方向 \(u^{(m)}\sim\text{Unif}(\mathbb S^{d-1})\)，投影 \(h^{(m)} = Z u^{(m)}\in\mathbb R^N\)：

$$\hat\varphi_N(t;\,h) = \frac1N\sum_{n=1}^{N} e^{\,i t h_n},\qquad \varphi_0(t) = e^{-t^2/2}$$
$$T\big(h\big) = N\int_{-\infty}^{\infty} w(t)\,\big|\hat\varphi_N(t;h) - \varphi_0(t)\big|^2\,dt,\qquad w(t) = e^{-t^2/2}$$
$$\mathrm{SIGReg}(Z) = \frac1M\sum_{m=1}^{M} T\big(Z u^{(m)}\big)$$

其中 \(|\hat\varphi_N - \varphi_0|^2 = \big(\tfrac1N\sum\cos(th_n) - e^{-t^2/2}\big)^2 + \big(\tfrac1N\sum\sin(th_n)\big)^2\)。被积函数关于 t 是偶函数，实现上只在 \(t\ge0\) 上用梯形法则积分再乘 2。

论文 vs 官方代码 LeWM 论文写积分节点均匀分布在 [0.2, 4]；官方 module.py::SIGReg 的默认值是 knots=17、t = linspace(0, 3, 17)、num_proj=1024。下方交互演示按代码实现。

2.3 动手看：SIGReg 怎样“撑开”坍塌的嵌入

选一个初始分布，点「用 SIGReg 梯度下降」——这里直接对点做梯度下降（真实训练中梯度会流进编码器参数）。注意观察：完全坍塌的点云会被撑开，各向异性的会被“揉圆”，均匀方块会被“磨成”高斯。

3. 全局架构

观测编码器（端到端训练） 动作预测器 SIGReg损失
和前作的“同构”对照 JEPA 通用框架下：x = 历史观测，y = 下一帧观测，条件变量 z = 动作，\(s_x = s_y\) 的编码器是同一个（没有 EMA 副本），预测器 \(\hat s_y = g_\phi(s_x, a)\)，能量 \(E = \lVert \hat s_y - s_y\rVert^2\)。防坍塌从“结构不对称”（EMA + sg）换成了“分布约束”（SIGReg）。

4. 组件拆解

4.1 编码器：一帧一个向量

LeWM 刻意让表征极度紧凑：每帧只保留 [CLS] → 投影头后的一个 192 维向量。对比：

每帧 token 数 × 维度编码器
V-JEPA 2-AC256 × 1408冻结 ViT-g（≈1B）
DINO-WM约 200 个 patch token冻结 DINOv2
LeWM1 × 192ViT-Tiny（≈5M），端到端训练

token 少直接带来两个好处：预测器的序列极短（历史 3 帧 = 3 个 token），以及规划时每次 rollout 的计算量很小——这是“规划快 48×”的主要来源。

4.2 投影头与 BatchNorm

ViT 的最后一层是 LayerNorm：它把每个样本的特征各自归一化到固定的均值/方差，会和“让整个批次的分布变成标准高斯”的 SIGReg 目标互相掣肘。LeWM 在 [CLS] 之后加了一个 1 层 MLP + BatchNorm 的投影头，让 SIGReg 有自由度去塑造批内分布。预测器之后也接了同样设计的投影头。

4.3 预测器：因果 Transformer + AdaLN-zero

V-JEPA 2-AC 把动作和状态当作序列里的 token；LeWM 则把动作当作调制信号（与 DiT 中注入扩散时间步/类别的方式相同）：

$$[\beta_1,\gamma_1,\alpha_1,\beta_2,\gamma_2,\alpha_2] = \mathrm{Linear}\big(\mathrm{SiLU}(a_k)\big)$$
$$x \leftarrow x + \alpha_1\odot\mathrm{Attn}_\text{causal}\big(\mathrm{LN}(x)\odot(1+\gamma_1)+\beta_1\big),\qquad x \leftarrow x + \alpha_2\odot\mathrm{MLP}\big(\mathrm{LN}(x)\odot(1+\gamma_2)+\beta_2\big)$$

生成调制参数的线性层零初始化（“-zero”）：训练开始时门控 α = 0，每个 block 都是恒等映射，网络从“什么都不做”平滑地开始学，训练更稳定。调制是逐位置的：第 k 个位置用动作 aₖ 调制。

4.4 SIGReg 在 LeWM 里怎么用

  • 作用对象：编码器侧的嵌入 emb（形状 [B, T, 192]），转置成 [T, B, 192]，对每个时间步的批内样本分别检验，再对时间步平均（step-wise SIGReg）。
  • 随机方向：每次前向重新采 1024 个方向（不是固定参数）。
  • 尺度：统计量乘以批大小 N（Epps–Pulley 的标准形式：在“确实是高斯”的原假设下，其分布不随 N 变化）；默认 batch 128、λ = 0.1。

4.5 规划：在 192 维空间里跑 CEM

$$a^\star_{1:H} = \arg\min_{a_{1:H}}\ \big\lVert \hat z_H(a_{1:H}) - z_g\big\rVert_2^2,\qquad z_g = \mathrm{enc}_\theta(o_g)$$

其中 \(\hat z_H\) 是从当前历史出发、用预测器自回归 rollout H 步的结果。论文设置：CEM 每轮 300 个样本、保留前 30 个 elite、初始方差 1；PushT 迭代 30 轮，其他环境 10 轮；规划视野 H = 5（= 25 个环境步）；以 MPC 方式滚动执行。完整一次规划不到 1 秒。

4.6 诊断工具：探测、惊讶度、解码器

  • 探测（probing）：在冻结的嵌入上训练线性/MLP 探针回归物理量（智能体位置、方块位置与角度），检验潜空间是否编码了物理状态。
  • 违背预期（surprise）：用“预测的未来嵌入”与“实际观测嵌入”的差距作为惊讶度。让物体瞬移时惊讶度显著升高（配对 t 检验 p < 0.01）；只改变颜色时效果较弱且不显著——说明嵌入更关注物理状态而非外观。
  • 解码器：只用于可视化“嵌入里保留了什么”，训练中从不使用重建损失。

6. 训练目标与防坍塌

$$\mathcal L_\text{LeWM}(\theta,\phi) = \underbrace{\frac{1}{|\mathcal K|}\sum_{k\in\mathcal K}\big\lVert g_\phi(z_{\le k}, a_{\le k}) - z_{k+1}\big\rVert_2^2}_{\mathcal L_\text{pred}} + \lambda\cdot\underbrace{\frac1T\sum_{t=1}^{T}\mathrm{SIGReg}\big(\{z_t^{(b)}\}_{b=1}^{B}\big)}_{\text{step-wise SIGReg}},\qquad z = \mathrm{proj}(\mathrm{enc}_\theta(o))$$

7. 伪代码

sigreg.py（按 le-wm/module.py 整理）
class SIGReg(nn.Module):
    def __init__(self, knots=17, num_proj=1024):
        super().__init__()
        self.num_proj = num_proj
        t = torch.linspace(0, 3, knots)
        dt = 3 / (knots - 1)
        weights = torch.full((knots,), 2 * dt)          # 梯形法则，×2 是因为被积函数关于 t 偶对称
        weights[[0, -1]] = dt
        window = torch.exp(-t.square() / 2.0)           # N(0,1) 的特征函数 φ(t)，同时也是权重 w(t)
        self.register_buffer("t", t)
        self.register_buffer("phi", window)
        self.register_buffer("weights", weights * window)

    def forward(self, proj):                            # proj: [T, B, D]
        A = torch.randn(proj.size(-1), self.num_proj, device=proj.device)
        A = A.div_(A.norm(p=2, dim=0))                  # 每次重新采 M 个单位方向
        x_t = (proj @ A).unsqueeze(-1) * self.t         # [T, B, M, K]
        err = (x_t.cos().mean(-3) - self.phi).square() \
            + x_t.sin().mean(-3).square()               # |ECF − φ|²，对批维 B 求均值
        statistic = (err @ self.weights) * proj.size(-2)    # 积分 × N → [T, M]
        return statistic.mean()
lewm_forward.py（按 le-wm/train.py 整理）
def lewm_forward(batch, model, sigreg, ctx_len=3, n_preds=1, lambd=0.1):
    emb = model.encode(batch["pixels"])                 # [B, T, 192]：ViT-Tiny → [CLS] → projector
    act = model.action_encoder(batch["action"])         # [B, T, 192]：5 个原始动作拼成一块

    ctx_emb, ctx_act = emb[:, :ctx_len], act[:, :ctx_len]
    tgt_emb = emb[:, n_preds:]                          # 下一步嵌入 —— 注意：没有 detach
    pred_emb = model.predict(ctx_emb, ctx_act)          # 因果 Transformer + AdaLN → projector

    pred_loss = (pred_emb - tgt_emb).pow(2).mean()
    sigreg_loss = sigreg(emb.transpose(0, 1))           # [T, B, D]：逐时间步
    return pred_loss + lambd * sigreg_loss              # 没有 EMA、没有 stop-grad
adaln_block.py（结构示意）
class ConditionalBlock(nn.Module):
    def __init__(self, dim, heads):
        super().__init__()
        self.norm1, self.norm2 = nn.LayerNorm(dim), nn.LayerNorm(dim)
        self.attn, self.mlp = Attention(dim, heads), MLP(dim)
        self.adaLN_modulation = nn.Sequential(nn.SiLU(), nn.Linear(dim, 6 * dim))
        nn.init.zeros_(self.adaLN_modulation[-1].weight)    # zero-init → 初始为恒等映射
        nn.init.zeros_(self.adaLN_modulation[-1].bias)

    def forward(self, x, c):                            # x: [B, T, dim] 帧嵌入；c: [B, T, dim] 动作嵌入
        s1, g1, a1, s2, g2, a2 = self.adaLN_modulation(c).chunk(6, dim=-1)
        x = x + a1 * self.attn(self.norm1(x) * (1 + g1) + s1, causal=True)
        x = x + a2 * self.mlp(self.norm2(x) * (1 + g2) + s2)
        return x

9. 关键结果

规划

  • PushT：成功率比 PLDM 高 18%，且超过 DINO-WM（即使 DINO-WM 使用了本体感知输入）。
  • Reacher：超过 DINO-WM。OGBench-Cube（3D）：DINO-WM 更好。
  • TwoRoom：LeWM 较弱。作者归因于该任务的内在维度很低——在 192 维里强行要求各向同性高斯，与只有二维位置的真实状态不匹配。
  • 速度：每次规划约 1 s，DINO-WM 约 47 s（最高快 48×），与 PLDM 相当；token 数约为 DINO-WM 的 1/200。

具体成功率见论文 Fig. 6（正文未给出数值表）。

LeWM 说明了

  • JEPA 世界模型可以不靠任何结构性启发式，从像素稳定地端到端训练；
  • 极紧凑的潜空间（每帧 1 个向量）足以支撑规划，并让规划快一个数量级以上；
  • 潜空间编码了物理状态，可用于检测“不合物理”的事件。

开放问题（可作为后续研究方向）

  • 真实世界与复杂视觉：目前在仿真环境验证；后续工作（如 arXiv:2607.16314）开始在真实户外机器人数据上探索 LeWM 式训练；
  • 低内在维度任务：各向同性高斯先验与低维状态的错配（TwoRoom）；
  • 长视野：单层 CEM + 短视野，长程任务可能需要分层（H-JEPA）规划；
  • 规模化：SIGReg 端到端训练能否像 V-JEPA 2 那样扩展到大模型与海量视频。
