1. 动机：在表征空间里“补全”图像

2022 年前后，图像自监督学习主要有两条路：

不变性方法（invariance-based）

SimCLR、BYOL、DINO、iBOT……让同一图像的两个增强视角编码后相同。语义强、线性探测好，但依赖手工设计的数据增强（裁剪、颜色抖动等），这些先验偏向图像分类，换任务、换模态就未必合适。

生成式方法（generative）

MAE、BEiT……遮住一部分 patch 并重建像素。先验少、易扩展到其他模态，但模型要把容量花在纹理、噪声等不可预测的细节上，得到的特征偏底层，线性探测差，通常要微调。

I-JEPA 的回答：保留“遮挡-补全”的任务形式，但补全的不是像素，而是目标区域在另一个编码器里的表征。这样既不需要手工增强，又能让模型自由丢弃不可预测的细节，只预测抽象的、语义层面的内容。

一句话理解 给你一张图的大部分区域（上下文），让你“想象”几块被挡住的区域在概念上是什么——不需要画出来，只需要给出它的表征。

3. 组件拆解

3.1 多块掩码：最关键的设计

掩码策略决定了“预测任务”到底在考什么。I-JEPA 给出的经验法则是：

  • 目标块要足够大（占图像 15–20%），这样被预测的是“一个物体的一部分”这种语义单位，而不是能靠邻域插值猜出来的纹理。
  • 上下文要足够有信息量且空间分散（一个占 85–100% 的大块，去掉目标后仍覆盖大部分图像）。
  • 上下文与目标不重叠，否则直接抄答案。

3.2 上下文编码器与目标编码器

两者是同一种 ViT，区别只在输入和权重来源：

上下文编码器 fθ目标编码器 fθ̄
输入只有上下文 patch（不含 mask token）整张图的全部 patch
权重由梯度下降更新上下文编码器权重的 EMA
梯度有无（no_grad / stop-gradient）
输出用途喂给预测器LayerNorm 后在目标位置取出，作为回归目标
下游评估—论文用它（输出平均池化）做下游评估
为什么掩码加在目标编码器的“输出”上？ 如果目标编码器只看目标块本身（掩码加在输入上），它的输出只包含局部信息；加在输出上，每个目标 token 都经过了全图自注意力，携带的是“在整张图语境下这块是什么”。论文指出这对学到语义表征至关重要。

3.3 预测器与 mask token

预测器是一个比编码器窄得多的 ViT（ViT-H/14 时为 12 层、宽 384）。它的输入序列 = 上下文 token（投影到 384 维并加上其位置编码）+ |Bᵢ| 个 mask token：

$$\text{mask token}_j = \mathbf{m} + \mathrm{pos}(j),\quad j \in B_i \qquad(\mathbf{m}\text{ 为所有位置共享的可学习向量})$$

序列内是全注意力；输出只取 mask token 位置，经 LayerNorm 和线性层投回编码器维度。对 M=4 个目标块，预测器运行 4 次（实现上把上下文复制 4 份沿 batch 维拼接）。

预测器的瓶颈作用 预测器窄（384 维）且只在训练时使用。下游任务只用编码器。直觉上，把“如何从上下文推断目标”的负担交给一个单独的小网络，编码器就能专注于产生好用的表征——这也是 BYOL/SimSiam 以来“非对称结构防坍塌”的关键部件。

3.4 EMA 目标编码器

$$\bar\theta \leftarrow m\,\bar\theta + (1-m)\,\theta,\qquad m: 0.996 \xrightarrow{\text{线性}} 1.0$$

m 越接近 1，目标编码器变化越慢。训练末期 m→1，目标编码器几乎冻结。EMA + stop-gradient + 预测器三者共同构成 I-JEPA 的防坍塌机制——但这是一套经验上有效、缺乏理论保证的启发式，这一点会在 LeJEPA / LeWM 被重新审视。

4. 张量形状追踪

以 ViT-H/14（宽 1280、32 层）、输入 224²、batch B 为例。\(K_\text{ctx}\) 与 \(K_\text{pred}\) 随采样变化，同一 batch 内会截断到最小值以便拼成矩形张量（官方 MaskCollator）。

5. 训练目标与防坍塌

论文中的目标函数（对 M 个目标块、块内每个 patch 求平均 L2 距离）：

$$\mathcal{L}(\theta,\phi) = \frac{1}{M}\sum_{i=1}^{M}\sum_{j\in B_i}\big\lVert \hat s_{y_j} - s_{y_j}\big\rVert_2^2, \qquad \hat s_{y}(i) = g_\phi\big(f_\theta(x),\ \{\mathbf m + \mathrm{pos}(j)\}_{j\in B_i}\big),\qquad s_y = \mathrm{sg}\big(f_{\bar\theta}(\text{image})\big)_{B_i}$$
论文 vs 官方代码 官方 ijepa/src/train.py 中：目标特征先经过 F.layer_norm(h, (h.size(-1),))，损失为 F.smooth_l1_loss(z, h)（而非论文所写的 L2）。复现时以代码为准。

为什么不会坍塌？ 如果编码器把所有图像都映射成同一个常向量，损失就是 0——这是 JEPA 类方法的天敌（见 从头讲起 §4）。I-JEPA 没有负样本，也没有显式的方差/协方差正则，它依赖的是：

  1. stop-gradient：损失不能通过“改变目标”来变小；
  2. EMA 目标编码器：目标缓慢跟随在线编码器，打断“两边一起塌”的捷径；
  3. 预测器：非对称结构，让在线分支有额外的自由度去拟合目标。

这套组合来自 BYOL 一脉，实践中稳定，但对 EMA 系数、学习率调度等很敏感，且缺少保证。

6. 伪代码

按官方实现结构整理（省略了分布式、混合精度和学习率调度）：

train_step.py
# imgs: [B, 3, 224, 224]
# masks_enc:  1 组上下文索引  [B, K_ctx]   （由 MaskCollator 在 dataloader 中生成）
# masks_pred: M=4 组目标索引 [B, K_pred] × 4

def train_step(imgs, masks_enc, masks_pred):
    # ---- 目标路径：看全图、不求梯度 ----
    with torch.no_grad():
        h = target_encoder(imgs)                  # [B, 256, D]
        h = F.layer_norm(h, (h.size(-1),))        # 对特征维做 LayerNorm
        h = apply_masks(h, masks_pred)            # [4B, K_pred, D]  在“输出”上取目标块
        h = repeat_interleave_batch(h, B, repeat=len(masks_enc))

    # ---- 上下文路径 ----
    z = encoder(imgs, masks_enc)                  # 只编码可见 patch: [B, K_ctx, D]
    z = predictor(z, masks_enc, masks_pred)       # [4B, K_pred, D]

    loss = F.smooth_l1_loss(z, h)                 # 论文写 L2
    loss.backward(); optimizer.step(); optimizer.zero_grad()

    # ---- EMA 更新目标编码器 ----
    m = next(momentum_scheduler)                  # 0.996 → 1.0
    with torch.no_grad():
        for p, p_tgt in zip(encoder.parameters(), target_encoder.parameters()):
            p_tgt.mul_(m).add_((1 - m) * p.detach())
predictor.py（结构示意）
class Predictor(nn.Module):
    def forward(self, x, masks_x, masks):
        B = x.size(0)
        x = self.predictor_embed(x)                          # Linear D → 384
        x = x + apply_masks(self.pos_embed.repeat(B, 1, 1), masks_x)

        # 每个目标块一组 mask token：共享向量 + 目标位置编码
        pos = apply_masks(self.pos_embed.repeat(B, 1, 1), masks)   # [4B, K_pred, 384]
        pred_tokens = self.mask_token.expand_as(pos) + pos

        x = x.repeat(len(masks), 1, 1)                       # 上下文复制 M 份
        x = torch.cat([x, pred_tokens], dim=1)               # [4B, K_ctx + K_pred, 384]
        for blk in self.blocks:                              # 12 层，全注意力
            x = blk(x)
        x = self.norm(x)[:, -pred_tokens.size(1):]           # 只取 mask token 位置
        return self.predictor_proj(x)                        # Linear 384 → D

9. 承上启下

I-JEPA 解决了什么

  • 第一次把 LeCun 的 JEPA 构想在大规模视觉任务上跑通；
  • 证明“表征空间里的遮挡预测”无需手工增强也能学到语义特征；
  • 多块掩码 + 只编码可见 patch，训练效率高。

留下的问题 → 下一步

  • 只有静态图像：没有时间、运动与因果 → V-JEPA 把同样的思路搬到视频；
  • 条件变量 z 只是“位置”，还不是“动作” → V-JEPA 2-AC；
  • 防坍塌依赖 EMA/stop-grad 启发式 → LeJEPA / LeWM 用 SIGReg 替代。
