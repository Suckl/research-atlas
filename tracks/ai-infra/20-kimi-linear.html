1. 动机：让线性注意力的“遗忘”更精细

Gated DeltaNet 用一个标量门 αt 让整个状态矩阵一起衰减：一个头里 128 个键通道，要么一起记住，要么一起淡忘。而不同通道承载的信息寿命往往不同。GLA 有逐通道的衰减但没有 delta 规则的“定点改写”；Mamba2 两者都没有。

一句话理解 KDA = Gated DeltaNet 的标量门换成逐通道对角门 Diag(αt)：每个键通道有自己的遗忘速度，同时保留 delta 规则。为了让它训得快，作者把分块算法特化为一种受约束的 DPLR 形式，比通用 DPLR 内核快约 2×。再按 3 层 KDA : 1 层 MLA 混合、全注意力层干脆不加位置编码——在相同配方下首次全面超过全注意力基线，1M 上下文解码最多快 6×。

3.2 分块算法：DPLR 的受约束特化

线性注意力的训练靠分块并行：块内用矩阵乘并行算，块间只传递状态。delta 规则让状态转移矩阵变成“对角 + 低秩”（DPLR）形式 D − abᵀ，通用 DPLR 的分块算法需要两次二级分块，并要除以累积衰减 Γ（数值上不稳定）。KDA 的转移恰好是受约束的 DPLR：a = βk、b = k ⊙ α、D = Diag(α)。利用这个结构（WY 表示 + UT 变换），二级分块的矩阵计算从 4 次降到 2 次、再省掉 3 次额外矩阵乘，并避开了 1/Γ 项。实测在 64K 以内的序列长度上比通用 DPLR 内核快近 2×。Kimi Linear §3.1–3.2、§6.2、Fig. 2 内核已开源在 flash-linear-attention（fla/ops/kda），并提供 vLLM 实现。

3.3 为什么全注意力层可以不要位置编码

在纯 Transformer 里，NoPE 层只能从因果掩码间接感知顺序，长度外推也不可靠。但在混合模型里，每个 MLA 层之前都有 KDA 层：递归按顺序处理 token，衰减随距离累积，相当于已经把“相对位置”编码进了隐状态。于是 MLA 层只负责基于内容的精确检索。这与 Qwen3-Next / Qwen3.5 不同——它们的全注意力层仍保留（部分）RoPE。对比与讨论见 RoPE 页 Q24。

3.4 规模化：Kimi K3（2026-07）

Kimi K3 是 2.8T 总参、104B 激活的 MoE，原生视觉、1M 上下文，沿用 Kimi Linear 的思路并加了几件新东西：Kimi K3 报告 §2–5

方面设计
层结构93 层，宽 7168：每组 3 层 KDA + 1 层门控 MLA（NoPE、全秩输入相关的输出门），末尾再加 1 层门控 MLA；共 69 层 KDA、24 层 MLA。KDA 的衰减设下界 gmin = −5，使分块计算保持在 BF16 范围内

KDA 系统FlashKDA（CUTLASS 实现的分块内核）；KDA 上下文并行（KCP）：每段的影响拆成“累积转移 + 本地状态”，各卡一次固定大小的 all-gather 即可还原入口状态
前缀缓存KDA 状态与 MLA 的 KV 共用一个分页池；6144 token 的物理块里按 512 token 做哈希；KDA 的递归状态只在稀疏的边界（通常是对话轮次边界）存只读快照，命中时复制为请求私有状态
专家并行MoonEP：根据路由结果在线规划冗余专家，使每张卡恰好收到 S×K 个 token（完全均衡），通信缓冲区与形状静态化

论文称这些改动合起来让整体缩放效率比 Kimi K2 提高约 2.5×。递归状态的前缀缓存是混合架构特有的系统问题：注意力的 KV 按 token 存，任意前缀都能复用；递归状态只是某个位置上的一个快照，只能在事先存了快照的边界上复用。

4. 伪代码

kda_decode_step.py（单头，逐 token 递归）
def kda_step(S, x, p):                                   # S: [d_k, d_v]
    q = l2norm(swish(p.conv_q(p.Wq @ x)))                # 短卷积带自己的小缓存
    k = l2norm(swish(p.conv_k(p.Wk @ x)))
    v = swish(p.conv_v(p.Wv @ x))
    alpha = f(p.Wa_up @ (p.Wa_down @ x))                 # [d_k]，逐通道，取值 [0, 1]
    beta = sigmoid(p.Wb @ x)                             # 标量
    S = alpha[:, None] * S                               # Diag(α) S：按键通道衰减
    S = S - beta * outer(k, k @ S) + beta * outer(k, v)  # 沿 k 擦除旧值、写入新值
    o = S.T @ q
    g = sigmoid(p.Wg_up @ (p.Wg_down @ x))
    return S, p.Wo @ (g * rmsnorm(o))

6. 简答题

Q40KDA 相比 Gated DeltaNet 改了什么？Kimi Linear 的全注意力层为什么可以不用位置编码？

结构上只改了一处：GDN 的遗忘门是每头一个标量 αt，整个状态一起衰减；KDA 改成逐通道的对角门 Diag(αt)，每个键通道有自己的遗忘速度，delta 规则保留。代价在算法层：状态转移变成受约束的 DPLR 形式，作者据此重写了分块算法，比通用 DPLR 内核快约 2×，并避开了数值不稳定的 1/Γ 项。

  • NoPE 的理由：每个 MLA 层前都有 KDA 层，递归按序处理、衰减随距离累积，隐状态里已经带着相对位置信息；MLA 只负责基于内容的检索。
  • 工程好处：没有 RoPE，MLA 的投影可以完全吸收、推理时等价于 MQA；长上下文扩展无需调整 RoPE 频率。
  • 对照：Qwen3-Next / Qwen3.5 的门控全注意力层仍保留（部分）RoPE，GDN 层不加位置编码；Kimi K3 延续了 NoPE 的门控 MLA。

依据：Kimi Linear §2.2、§3、§4、§6.2；Kimi K3 §2.1。
