这条路线在讲什么

LLM 系统的几乎所有问题都来自一个事实：decode 每步读一遍权重和 KV 却只算一个 token。围绕它，这条路线按层级拆开 14 篇论文 / 概念——内核怎么少搬数据（FlashAttention / FlashInfer），引擎怎么不浪费显存、不重复计算（vLLM / SGLang / 投机解码 / PD 分离），训练怎么切分与压精度（Megatron / FP8 / DeepSeek-V3），模型怎么从结构上压 KV（RoPE / Gated DeltaNet / DSA），以及数值一致性与 AMD 硬件。每页末尾附简答题，用论文作答。

贯穿路线的几条线索

线索 1

带宽受限是一切的起点

decode 的算术强度 ≈ batch 大小。投机解码（用算力换延迟）、PagedAttention（塞更多请求）、FP8（字节减半）、MLA / DSA / 线性注意力（少读 KV）都是在推这个数。

线索 2

统一抽象胜过专用内核

vLLM 的块表、SGLang 的基数树、树状投机解码——FlashInfer 用“块稀疏矩阵”一个抽象覆盖；DistServe 用 goodput 一个指标统一 TTFT/TPOT 的权衡。

线索 3

精度与范围的交易

E4M3 vs E5M2 → 逐张量缩放 → DeepSeek 的 1×128 分块缩放 + FP32 累加 → 批不变内核：数值问题从“能不能收敛”走到“能不能逐位复现”。

线索 4

长上下文的两条路

Qwen 用 3:1 的 Gated DeltaNet 混合换 KV 恒定；DeepSeek / GLM 用 MLA + DSA 保留精确检索。两者对“位置编码是否必须”的回答也不同。
