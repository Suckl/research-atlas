1. 动机：FP8 之后，再减一半

FP8 让矩阵乘的吞吐翻倍、字节减半，DeepSeek-V3 证明了它能用于超大规模预训练。Blackwell 的张量核又加入了 FP4：数学吞吐是 FP8 的 2×（GB200）到 3×（GB300），对 BF16 则是 4× 到 6×。NVFP4 论文 §2、Tab. 1 问题是 4 bit 太粗：E2M1 只有 0、0.5、1、1.5、2、3、4、6 及其负数共 15 个值，一个离群值就能把整块的其余元素都压成 0。

一句话理解 FP4 能用于训练，靠的是“缩放做细 + 误差做无偏”：块越小、缩放因子越精细，离群值的影响就被关在越小的范围内（NVFP4：16 个元素一个 E4M3 缩放，再加一级 FP32 张量缩放）；再用随机 Hadamard 变换打散离群值、用随机舍入让梯度的量化误差期望为 0、让少数敏感层留在高精度。

3. 组件拆解

3.1 两级缩放怎么算

设张量 X 的绝对值最大为 amax，E2M1 的最大值为 6，E4M3 的最大值为 448。NVFP4 先取张量级缩放 \(s_g\)，使“块最大值 / 6”除以 \(s_g\) 后不超过 448；再对每个 16 元素块取 \(s_b = \mathrm{amax}_b/6\)，以 E4M3 存储 \(s_b/s_g\)：

$$s_g = \frac{\mathrm{amax}(X)}{6\cdot 448},\qquad \hat s_b = \mathrm{E4M3}\!\Big(\frac{\mathrm{amax}_b}{6\,s_g}\Big),\qquad \hat x_i = \mathrm{E2M1}\!\Big(\frac{x_i}{\hat s_b\, s_g}\Big)\cdot \hat s_b\, s_g$$

公式按格式定义推导（NVFP4 论文 App. B 给出两级缩放的结构），具体实现细节以 Transformer Engine 为准。

3.2 为什么梯度用随机舍入、权重和激活不用

就近舍入是有偏的：一个总落在两个可表示值之间同一侧的量，每次都被往同一个方向推，累积到参数更新上就是系统性偏差。随机舍入按距离比例随机向上或向下取整，满足 \(\mathbb E[\mathrm{SR}(x)] = x\)，代价是引入方差。梯度要在大量样本与步数上累积，无偏比低方差更重要；权重和激活在前向里只用一次，额外的方差只会增加噪声，所以论文只在梯度上用随机舍入。

4. 伪代码

nvfp4_linear.py（训练时的一个线性层，示意）
def quant_nvfp4(t, block=(1, 16), stochastic=False):
    s_g = t.abs().max() / (6 * 448)                       # 张量级 FP32 缩放
    blocks = t.reshape_blocks(block)
    s_b = to_e4m3(blocks.abs().amax(-1) / (6 * s_g))      # 块级 E4M3 缩放
    q = round_e2m1(blocks / (s_b * s_g), stochastic)      # 随机舍入或就近舍入
    return q, s_b, s_g

def forward(X, W):
    Wq = quant_nvfp4(W, block=(16, 16))                   # 二维块：转置后仍是同一份量化
    return gemm_fp4(quant_nvfp4(X), Wq)                   # FP32 累加

def backward(dY, X, Wq):
    dX = gemm_fp4(quant_nvfp4(dY, stochastic=True), Wq.T) # Dgrad：复用前向的量化权重
    H = random_hadamard(16)                               # 沿归约维（token）分块旋转
    dW = gemm_fp4(quant_nvfp4((dY.T) @ H, stochastic=True),
                  quant_nvfp4(H.T @ X))                   # Wgrad：H 正交，乘积不变
    return dX, dW

5. 关键结果

  • 12B 混合 Mamba-Transformer、10T token：稳定阶段验证损失与 FP8 相差 1% 以内，学习率衰减后略高于 1.5%；MMLU-Pro 62.58（FP8 62.62）、MMLU 76.57（77.36）、MBPP+ 55.91（59.11）。NVFP4 论文 §3、Tab. 2
  • 8B / 1T token：MXFP4 相对损失误差约 2.5%，NVFP4 约 1.5%；MXFP4 需多 36% token 才追上。NVFP4 论文 §5
  • 吞吐（相对 BF16）：NVFP4 在 GB200 上 4×、GB300 上 6×；MXFP8 两者均为 2×。NVFP4 论文 Tab. 1

6. 简答题

Q38NVFP4 与 MXFP4 的格式差异是什么？为什么块更小、缩放更精细对训练更重要？

两者元素都是 E2M1。MXFP4 每 32 个元素共享一个 E8M0 缩放（只能是 2 的幂）；NVFP4 每 16 个元素一个 E4M3 缩放（带尾数），外加一个 FP32 张量级缩放。平均位宽 4.25 vs 4.5 bit。

  • 块小：E2M1 只有 15 个值，块内最大值决定缩放，一个离群值会把同块其他元素挤到 0 附近。块从 32 缩到 16，受“污染”的元素减半。
  • 缩放精细：2 的幂缩放向上取整时，块最大值可能只用到可表示范围的一半左右，相当于丢掉近一个二进制量级；E4M3 缩放能贴合实际最大值。
  • 为什么训练更敏感：推理只需前向误差可接受；训练中梯度的量化误差会在万亿 token 上累积成偏差。实测 8B / 1T token 下 MXFP4 的损失误差约 2.5%、NVFP4 约 1.5%，MXFP4 需要多 36% 的数据才追上。

依据：NVFP4 论文 §2、§5、App. B。

Q39FP4 预训练配方中哪些环节必须保留高精度或引入随机化？各自解决什么问题？

四个组件各管一个误差来源：少数层留高精度（敏感层的前向误差）、Wgrad 输入做随机 Hadamard 变换（块内离群值）、权重二维块缩放（前向与反向看到的量化权重不一致）、梯度随机舍入（舍入偏差的累积）。

  • 高精度层：约 15% 的线性层（以网络末端为主）用 BF16 / MXFP8；12B 模型为前 2 个 + 后 8 个块。
  • RHT：16×16 随机 Hadamard，只用在 Wgrad 的两个输入上；正交变换不改变乘积，却把离群值摊平。
  • 2D 缩放：权重用 16×16 块，转置后量化结果不变，保证链式法则用的是同一个函数。
  • 随机舍入：只用于梯度，使量化误差期望为 0；权重与激活用就近舍入以免增加方差。
  • 此外始终保留 FP32 累加、FP32 主权重与优化器状态；学习率衰减阶段可切回高精度前向进一步缩小差距。

依据：NVFP4 论文 §4.1–4.4、App. D、App. E。
