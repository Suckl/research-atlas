1. 动机：把“迭代”从推理挪到训练

扩散 / 流模型把“噪声分布 → 数据分布”这个难的推前映射拆成很多小步，在推理时一步步走完；本 track 的前几页都在想办法把这些步压少——要么蒸馏一个教师（DMD、一致性蒸馏），要么从零训练时去近似 ODE 轨迹（sCM、MeanFlow）。Drifting 换了一个角度：神经网络的训练本来就是迭代的，每次 SGD 更新都会让同一个噪声 \(\epsilon\) 对应的输出移动一点，于是生成分布 \(q_i\) 在训练过程中本来就在演化。只要设计一个“样本该往哪漂”的场，让网络去追它，推理时就只剩一次前向 论文 §1、§3.1。

一句话理解 对每个生成样本 \(x\)，在一个冻结特征空间里算一个漂移向量 \(V=V^+_p-V^-_q\)：被附近的真实样本吸引、被附近的其他生成样本排斥，两者都是核加权的 mean-shift 向量；当生成分布等于数据分布时吸引与排斥正好抵消，\(V\equiv0\)。训练目标就是把 \(x\) 回归到冻结的 \(x+V\)。没有教师、没有判别器、没有 ODE，ImageNet 256 一步 FID 1.54（潜空间）/ 1.61（像素空间）论文 Tab. 5、Tab. 6。
它不是蒸馏，为什么放在这个 track Drifting 从零训练、不需要任何预训练扩散教师，所以它不属于“蒸馏”；但它回答的是同一个问题——怎样用 1 次网络评估达到多步模型的质量——论文直接拿 iCT、Shortcut、MeanFlow、iMF 等一步方法作对照 论文 Tab. 5。更重要的是它开启了本 track 的最后一条泳道“表征空间匹配”：RDM 把“在冻结编码器特征里匹配分布”变成后训练配方，可以把 4 步 FLUX.2 [klein] 压成 1 步（参考集来自教师的离线采样，相当于不在线调用教师的蒸馏）；ViRDM 再把它带到少步因果视频，替代 DMD 的教师 + critic。

3. 组件拆解

3.1 训练时的推前分布

记生成器输出分布为推前 \(q=(G_\theta)_\#p_\epsilon\)。第 i 次迭代的参数更新让同一个 ε 的输出移动 \(\Delta x_i=G_{\theta_{i+1}}(\epsilon)-G_{\theta_i}(\epsilon)\)，作者把它称为样本的“漂移”。于是问题变成：设计一个只依赖 \(p\) 与当前 \(q_i\) 的场 \(V_{p,q}\)，让 \(x_{i+1}=x_i+V_{p,q_i}(x_i)\)，并且在 \(q=p\) 时所有样本都停下来 论文 §3.1–3.2。与扩散的对照：扩散在推理时执行 \(x_{i+1}=x_i+\Delta x_i\) 若干次；Drifting 在训练时执行它，迭代的“步数”被摊进了几十万次优化步里。注意本页不存在噪声水平 t：ε 直接映射到样本。

3.2 漂移场：吸引、排斥与反对称

反对称是保证数据分布成为平衡点的充分条件。若 \(V_{p,q}=-V_{q,p}\)，则 \(q=p\Rightarrow V=-V\Rightarrow V=0\)（论文 Prop. 3.1）。作者用 mean-shift 构造满足它的场：\(V^+_p\) 是以核为权重的“正样本均值减 x”，\(V^-_q\) 是“负样本均值减 x”，两者相减后 x 被消掉，得到只含 \(y^+-y^-\) 的形式（式 11），交换 p、q 恰好变号。反过来 \(V=0\Rightarrow q=p\) 并不总成立；论文附录 C.1 只给出一个可辨识性启发式论证（有限基展开下零漂移给出大量双线性约束，非退化时迫使 p = q）。 Drifting §3.2–3.3、Tab. 1/2/11

反对称不是装饰：故意打破它，ImageNet 消融（B/2，100 epoch）立刻崩溃 论文 Tab. 1——

3.3 在特征空间里漂移

把损失写到特征 \(\varphi_j\) 上（式 13–14），正负样本也取特征。与感知损失的区别：感知损失要求 \(\lVert\varphi(x)-\varphi(x_\text{target})\rVert^2\) 有配对的目标；这里的目标是 \(\varphi(x)+V\)，不需要配对，本质是在匹配 \(\varphi_\#q\) 与 \(\varphi_\#p\) 论文 §3.4。实现细节决定成败：

  • 多尺度、多位置、多统计量。ResNet 每 2 个残差块取一次特征图，对每张图取 (a) 每个位置的向量、(b) 全局均值和标准差、(c) 2×2 块均值 / 标准差、(d) 4×4 块均值 / 标准差，每个向量单独算一个漂移损失。(a,b) 9.58 → (a–c) 9.10 → (a–d) 8.46 论文 §A.5。
  • 特征与漂移归一化。每个特征按批内平均距离缩放到 \(\sqrt{C_j}\)，温度相应设为 \(\tau\sqrt{C_j}\)；漂移再按 \(\sqrt{\mathbb E\lVert V_j\rVert^2/C_j}\) 归一化，使上百个损失项量级一致 论文 §A.6。
  • 多温度。单独用 τ = 0.02 / 0.05 / 0.2 分别为 10.62 / 8.67 / 8.96，三者相加 8.46，且之后不再调 论文 §A.6。
  • 编码器质量很关键。公开的 SimCLR / MoCo-v2（ResNet-50，需先过 VAE 解码到像素）分别 11.05 / 8.41；潜空间 MAE 宽 256 为 8.46，加宽到 640 并训 1280 epoch 为 4.28，再做分类微调 3.36 论文 Tab. 3。作者的解释：好的特征让语义相近的样本足够近，避免核“处处平坦”。像素空间更依赖编码器：同一 MAE 下像素版 32.11（潜空间 8.46），加入 ConvNeXt-V2 后 3.70 论文 Tab. 9。

3.4 训练时的 CFG

负样本不只来自生成分布，还按比例 γ 混入无条件真实数据：\(\tilde q(\cdot|c)=(1-\gamma)q_\theta(\cdot|c)+\gamma p_\text{data}(\cdot|\varnothing)\)。平衡时 \(\tilde q=p_\text{data}(\cdot|c)\)，解出 \(q_\theta(\cdot|c)=\alpha p_\text{data}(\cdot|c)-(\alpha-1)p_\text{data}(\cdot|\varnothing)\)，\(\alpha=1/(1-\gamma)\)，正是 CFG 的外推形式 论文 §3.5。实现上给 Nunc 个无条件样本核权重 w，由 α 反解；α 在 [1, 4] 内按幂律采样并作为网络条件（B/2 与像素模型 \(p(\alpha)\propto\alpha^{-5}\)；L/2 一半取 α = 1、一半按 \(\alpha^{-3}\)；消融按 \(\alpha^{-3}\)），推理时任意指定 论文 §A.7、Tab. 8 官方 configs 一致。L/2 的最佳 FID 出现在 α = 1.0（扩散里相当于“不用 CFG”），B/2 在 α = 1.1 论文 §B.3。

3.5 与 MMD、mean-shift、对比学习、GAN 的关系

  • MMD。任何在 p = q 处取最小的差异都诱导一个漂移场 \(V\propto-\partial\mathcal L/\partial x\)。对 MMD²，\(V_\text{MMD}(x)=\mathbb E_p[\partial_x\xi(x,y^+)]-\mathbb E_q[\partial_x\xi(x,y^-)]\)，对应的（未归一化）核是 \(-2\xi'\)。所以“未归一化核 + 特定 ξ”的 Drifting 就是 MMD 的梯度流；区别在于 Drifting 用归一化核 \(k/Z\)（mean-shift 形式，MMD 推不出来）、可以对 V 做归一化与步长缩放、自然支持 CFG。作者明确说：在 MMD 框架下他们得不到合理结果 论文 §C.2。五个月后 RDM 给出相反结论——MMD 本身不弱，弱在估计方式。
  • mean-shift 与对比学习。\(V^\pm\) 就是 mean-shift 向量；softmax 归一化的核与 InfoNCE 的形式相同，正负样本也对应对比学习的正负对 论文 §2、§3.3。
  • GAN。同样是“一个单次前向的生成器 + 一个分布层面的损失”，但没有对抗优化，损失的平衡点由构造保证 论文 §2。
  • 与 DMD 的分数差。后续理论工作指出：在高斯核下，漂移算子恰好是两个平滑后分布的分数之差 Turan 等 2603.09936 摘要——形式上接近 DMD 的 \(s_\text{real}-s_\text{fake}\)，只是两项都由样本的核估计给出，而不是由教师与 fake score 网络给出。论文本身用的是拉普拉斯型核 \(\exp(-\lVert\cdot\rVert/\tau)\)，这一对应关系对它是否精确成立未核实。

3.7 DriftWorld：漂移第一次用于视频（2026-07）

DriftWorld（Lu, Chen, Ye, Du）把 Drifting 用于动作条件的视频世界模型：给定当前帧、3 帧历史和 T 个动作，一次前向生成 T 帧未来；作者称这是漂移生成首次用于条件视频生成 DriftWorld §II、§IV-A。图像版的三个假设在这里都要改：

  • 只有一个正样本。类别条件下每类有很多真实图像，而“这段历史 + 这串动作”在数据集里只对应一段真实未来。于是 \(V(x)=\tilde k(x,y^+)\,Z\,(y^+-\hat y^-)\)：方向是从“核加权的负样本中心”指向唯一的真值；与 MSE 不同，每个样本的更新依赖其他 N − 1 个生成样本，这一机制区别于独立 MSE 回归；它本身不保证不坍塌，但论文在语言条件实验中观察到同一指令能生成多条不同轨迹 DriftWorld 式 (2)、§III-C、§IV-E。
  • 模型会忽略动作。把当前真实帧 \(o_t\) 也加作负样本（权重 \((\alpha-1)(N-1)\)，α 在 [1, 4] 内对数均匀采样并作为条件），把预测推离“什么都不变”。RT-1 上 FVD 191.05 → 62.84（α = 2.5）DriftWorld §III-D、Tab. V——这是 CFG 式负样本思想的直接迁移。
  • 特征空间与静态背景。真实场景在 SD3 VAE 潜空间生成，漂移损失在 DINOv3 的逐帧 16×16 patch 特征上计算；背景 patch 占多数，于是按“目标帧与当前帧特征变化”的 tanh 加运动权重。Bridge-V2 单步预测：不用特征 FID 34.24 / FVD 168.34，DINOv3 0.62 / 6.20。之后再加一阶段 Self Forcing 式训练（以自己的预测为条件），自回归 rollout 更稳 DriftWorld §III-D、Tab. V（见 Self Forcing）。

结构上它是带时空分解卷积的 U-Net、FiLM 注入动作，而不是 DiT。速度是主要卖点：Bridge-V2 每帧 0.0242 s，IRASim 1.1031 s；FID / FVD 4.86 / 46.05 对 10.46 / 91.55；但 RT-1 上 FID 8.99 不如 IRASim 的 4.60（FVD 62.84 对 93.02 更好）DriftWorld Tab. IV。用它给 Push-T 策略的 50 个候选动作打分（GPC-RANK），IoU 0.635 → 0.772；作为离线评估器，与真实成功率的 Pearson 相关 0.9755 / 0.9958 / 0.9618（Push-T / Lift / Can）DriftWorld Tab. III、§IV-D。

5. 训练目标

符号：论文记生成器为 f，本页统一写作本 track 的 \(G_\theta\)；生成样本 \(x=G_\theta(\epsilon)\sim q_\theta\)，真实样本 \(y^+\sim p\)，生成负样本 \(y^-\sim q\)。

$$x_{i+1}=x_i+V_{p,q_i}(x_i),\qquad \mathcal L=\mathbb E_{\epsilon}\Big\lVert G_\theta(\epsilon)-\mathrm{sg}\big(G_\theta(\epsilon)+V_{p,q_\theta}(G_\theta(\epsilon))\big)\Big\rVert^2$$
$$V_{p,q}(x)=V^+_p(x)-V^-_q(x)=\frac{1}{Z_pZ_q}\,\mathbb E_{p,q}\big[k(x,y^+)\,k(x,y^-)\,(y^+-y^-)\big],\qquad k(x,y)=\exp\!\Big(-\tfrac{1}{\tau}\lVert x-y\rVert\Big)$$
$$\mathcal L_\text{feat}=\sum_j\mathbb E\Big\lVert\tilde\varphi_j(x)-\mathrm{sg}\big(\tilde\varphi_j(x)+\tilde V_j\big)\Big\rVert^2,\qquad \tilde V_j=\sum_{\tau\in\{0.02,0.05,0.2\}}\frac{V_{j,\tau}}{\lambda_{j,\tau}}$$

\(Z_p, Z_q\) 是核的归一化常数（实现为 softmax）；\(\tilde\varphi_j=\varphi_j/S_j\) 是按批内平均距离归一化的特征；\(\lambda\) 是漂移的均方根 论文式 (6)、(11)、(12)、(14)、(18)–(26)。平衡性质指总体场；有限批量估计仍有采样误差。−2V 是对样本坐标的梯度，更新共享网络参数时还要经过生成器的 Jacobian，不保证每个输出严格执行 x←x+V（本页数学限定）。损失值等于 \(\mathbb E\lVert V\rVert^2\)，作者观察到它的下降与生成质量的提升相关 论文 Fig. 1、Fig. 4。

论文内部不一致 ① 特征编码器的残差块类型：§A.3 写“全部是 basic block（两个 3×3 卷积）”，Tab. 3 也标 basic，但 Tab. 8 的配置表写 “ResNet: block type — bottleneck”。② 批量定义：Tab. 2 标题写 \(B=N_c\times N_\text{pos}\)（4096），但左半表 Npos 从 1 变到 64 时 B 始终是 4096，与 Tab. 8 的 \(B=N_c\times N_\text{neg}\) 一致——标题应为 Nneg。③ 官方 JAX 仓库 README 用发布权重复测：潜空间 L/2 1.53、B/2 1.74，像素 L/16 1.62、B/16 1.73（论文 1.54 / 1.75 / 1.61 / 1.76），差异在评估噪声量级。仓库中 drift_loss.py 的实现与 Alg. 2 一致（双轴 softmax 几何平均、自身屏蔽、按温度归一化后相加）。

6. 伪代码

drifting_step.py（据论文 Alg. 1–2、§A.5–A.9 与官方 drift_loss.py 简化）
def compute_V(x, y_pos, y_neg, T):            # 论文 Alg. 2，单一温度
    N = x.shape[0]
    d_pos, d_neg = cdist(x, y_pos), cdist(x, y_neg)   # [N, N_pos], [N, N_neg]
    d_neg[:, :N] += eye(N) * 1e6               # y_neg 的前 N 个就是 x 本身：屏蔽自己
    logit = cat([-d_pos / T, -d_neg / T], dim=1)
    A = sqrt(logit.softmax(dim=-1) * logit.softmax(dim=-2))  # 对 y、x 两轴归一化
    A_pos, A_neg = A[:, :d_pos.shape[1]], A[:, d_pos.shape[1]:]
    W_pos = A_pos * A_neg.sum(1, keepdim=True)   # k(x,y+) · Σ k(x,y-)
    W_neg = A_neg * A_pos.sum(1, keepdim=True)
    return W_pos @ y_pos - W_neg @ y_neg        # ≈ E[k k (y+ − y−)]，p = q 时为 0

def train_step(G, phi, labels):                 # 论文 §A.9 的训练循环
    loss = 0.0
    for c in labels:                            # N_c 个类别，各自独立
        alpha = sample_alpha()                  # [1,4] 内幂律采样（Tab. 8）；作为条件输入
        eps = (randn(64, 32, 32, 4), randint(64, size=(64, 32)))  # 高斯 + 风格下标
        x = G(eps, c, alpha)                    # 一次前向
        y_pos = class_queue[c].sample(N_pos)    # 同类真实样本
        y_unc = global_queue.sample(32)         # 无条件真实样本（核权重 w(α)，此处省略）
        for fx, fp, fu in multiscale_features(phi, x, y_pos, y_unc):   # 也含原始空间一项
            S = stopgrad(mean_pairwise_dist(fx, fp, fu)) / sqrt(fx.shape[-1])
            fx, fp, fu = fx / S, fp / S, fu / S # 特征归一化：平均距离 ≈ √C
            V = 0
            for tau in (0.02, 0.05, 0.2):
                Vt = compute_V(fx, fp, cat([fx, fu]), tau * sqrt(fx.shape[-1]))
                V = V + Vt / stopgrad(sqrt((Vt ** 2).mean()))   # 漂移归一化
            loss = loss + mse(fx, stopgrad(fx + V))   # 值 = ‖V‖²，梯度 = −2V
    loss.backward()                             # 穿过冻结的 φ 回到 G
    opt.step()

9. 承上启下

之前

  • 一步生成要么蒸馏教师（DMD、一致性蒸馏），要么从零训练时近似 ODE 轨迹（iCT、Shortcut、MeanFlow：最好 1.72）。 Drifting §C.1–C.2 各后续 arXiv 摘要
  • GAN 能一步出图，但依赖对抗训练；MMD / 矩匹配生成网络（2015）被认为太弱。 Drifting §C.1–C.2 各后续 arXiv 摘要

Drifting 之后 → 留下的问题

  • 用反对称核场在训练时演化分布，不要 ODE、不要对抗，一步 1.54 / 1.61。 Drifting §C.1–C.2 各后续 arXiv 摘要
  • 离不开好的特征编码器；参考样本每批重采、批量受限 → RDM 改用冻结的全数据 Nyström 参考 + MMD，并用多编码器防“刷分”。
  • \(V\to0\Rightarrow q\to p\) 无一般保证 → 得分匹配视角、Sinkhorn 视角的理论补全。
  • 计算从推理挪到训练（大批量 cdist）→ DriftXpress 用低秩 RKHS 投影加速；只能一步 → Drift Flow Matching 允许按需多步细化。
  • 视频：DriftWorld 做动作条件一步视频；文本条件的少步因果视频则走了 RDM 这一支，见 ViRDM。

已核实的后续工作（无单独页面）：Generative Drifting is Secretly Score Matching（2026-03，高斯核下漂移 = 平滑分布的分数差）；Sinkhorn-Drifting（2026-03，与 Sinkhorn 散度梯度流的联系）；Drift-AR（2026-03，把熵当作反对称漂移场初始状态的方差，让 AR-扩散混合模型的视觉解码一步完成，报告 3.8–5.5× 加速）；DriftXpress（2026-05）；Drift Flow Matching（2026-05）。 Drifting §C.1–C.2 各后续 arXiv 摘要

简答题

Q29Drifting 的损失 ‖x − sg(x + V)‖² 实际在优化什么？为什么要 stop-gradient，反对称怎样保证数据分布是平衡点？

这个损失的数值就是 \(\lVert V\rVert^2\)，对样本 x 的梯度是 \(-2V\)：一次梯度下降等于让每个生成样本沿漂移场移动一小步，即训练时执行不动点迭代 \(x\leftarrow x+V\)。V 依赖整个生成分布 \(q_\theta\)（所有其他生成样本都在核里），对它反传意味着对“分布”求导，既复杂也会改变目标的含义；stop-gradient 把 V 当作本次迭代的冻结指示，只让网络去追它。反对称保证 p = q 时 V ≡ 0，也就是数据分布是这个迭代的平衡点；打破它，平衡点就移到别处。

  • 消融：\(1.5V^+-V^-\) 时 FID 8.46 → 41.05，只留吸引项 177.14——没有生成样本之间的排斥，样本只会挤向核加权的数据均值。 Drifting §3.2–3.4、§5.2–5.3、Tab. 1/3 DriftWorld Tab. V
  • 反方向（V = 0 ⇒ p = q）没有一般保证，论文只给可辨识性启发式；损失下降与 FID 改善在实验上相关。
  • 与 MMD 梯度流的差别在于归一化核与对 V 的归一化——这些让“步长”可以独立于特征量级来设定。

依据：论文 §3.2、Prop. 3.1、Tab. 1、§C.1–C.2。

Q30Drifting 与 MMD、与 DMD 的“分数差”分别是什么关系？为什么它在 ImageNet 上离不开冻结特征编码器，在机器人动作上却可以不用？

任何在 p = q 处最小化的差异都诱导一个漂移场；MMD² 诱导的场是“真实样本处核梯度的均值 − 生成样本处核梯度的均值”，Drifting 的场与它同形，但用的是归一化核（mean-shift），并对漂移做归一化、支持训练时 CFG——作者在纯 MMD 框架下没能训出好结果。与 DMD 相比，二者都是“把样本往数据方向推、往自身分布反方向推”：DMD 用教师分数与在线 fake score 的差在加噪空间给出方向，Drifting 用两组样本的核估计在特征空间给出方向，不需要任何网络去拟合分数。核方法完全依赖“近”的度量是否有语义：在高维潜变量 / 像素空间，L2 距离让核几乎处处平坦、漂移信号消失，所以 ImageNet 必须在 SSL 特征里算（编码器越好 FID 越低：11.05 → 3.36）；机器人动作维度低、欧氏距离本身有意义，直接在原始表示上算即可。 Drifting §3.2–3.4、§5.2–5.3、Tab. 1/3 DriftWorld Tab. V

  • 理论后续指出：高斯核下漂移恰为平滑后两分布的分数差，这把它与 DMD 一族联系起来（论文本身用的是拉普拉斯型核）。
  • DriftWorld 在视频上沿用这一点：真实场景用 DINOv3 特征，FID 34.24 → 0.62。 Drifting §3.2–3.4、§5.2–5.3、Tab. 1/3 DriftWorld Tab. V

依据：论文 §3.4、§5.2、§5.3、Tab. 3、§C.2；DriftWorld Tab. V；Turan 等 2603.09936 摘要。
