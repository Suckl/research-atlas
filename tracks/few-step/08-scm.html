1. 动机：把有限差分改成真正的切向量

Consistency Models要求同一条概率流轨迹上的不同状态映射到同一个干净终点。离散训练比较相邻时刻的输出，既要选择间隔及其退火日程，又会继承构造相邻状态时的数值积分误差。让间隔趋近零，理论上可以直接要求沿轨迹的全导数为零；早期连续时间训练却很不稳定论文 §2.2。

sCM 先用 TrigFlow 把噪声日程、网络预条件与一致性映射写得简单，再沿切向量的计算链追查不稳定：时间变换、嵌入频率、时间调制层、梯度尺度和半精度 JVP 都会影响优化。它修复的是训练连续一致性模型的条件，而不是另加一个在线生成分布 score 网络论文 §3–§5.1。

一句话理解连续一致性要求“沿生成轨迹移动一点，预测终点不变”。sCM 把这个要求变成可稳定计算的 JVP，再用切向量归一化和自适应加权控制训练；sCT 与 sCD 仅在轨迹方向的来源上不同论文 Eq. 2–8、Alg. 1。

3. 组件拆解

3.1 离散误差与连续目标解决的是哪一层问题

$$ \mathcal L_{\rm discrete}=\mathbb E\!\left[w(t)d\!\left(f_\theta(x_t,t),f_{\theta^-}(x_{t-\Delta t},t-\Delta t)\right)\right],\qquad \frac{df(x_t,t)}{dt}=\nabla_x f\,v_t+\partial_t f. $$

离散目标在有限间隔上比较函数值。CD 用数值求解器构造前一状态，存在积分误差；CT 用同一数据与噪声构造相邻状态，间隔也控制近似和优化。间隔太大，局部一致性不够精确；极小间隔又容易发生精度损失。论文同配置实验中，离散网格超过 1024 个间隔后质量下降，连续版优于所比较的离散网格论文 §2.2、Fig. 5(c)、App. E。这消除了训练监督中的有限差分，不意味着任意少步采样都没有误差。

3.2 TrigFlow：让 EDM 与 flow matching 用同一种坐标

令数据标准差为 \(\sigma_d\)，标准正态为 \(\epsilon\)，\(z=\sigma_d\epsilon\)。时间是角度 \(t\in[0,\pi/2]\)，干净数据在起点、噪声在终点。三角插值和样本速度为论文 §3、Eq. 3–4：

$$ x_t=\cos(t)x_0+\sin(t)z,\qquad v_t^{\rm sample}=\cos(t)z-\sin(t)x_0,\qquad \frac{dx_t}{dt}=\sigma_d F_{\rm DM}(x_t/\sigma_d,t). $$

通过重缩放和时间变换，EDM 的 \(\sigma\) 坐标可写成 \(\sigma_{\rm EDM}=\sigma_d\tan t\)。TrigFlow 保留 EDM 的输入 / 目标方差控制，又是三角 stochastic interpolant 的 flow-matching 特例。它统一的是参数化与坐标关系，不是声称三角路径与常见线性 \(x_t=(1-t)x_0+t\epsilon\) 具有相同的数值采样轨迹论文 App. B.1–B.2。

$$ f_\theta(x_t,t)=\cos(t)x_t-\sigma_d\sin(t)F_\theta(x_t/\sigma_d,t),\qquad f_\theta(x,0)=x. $$

上式保证一致性边界；网络 \(F_\theta\) 与完整映射 \(f_\theta\) 要分开。扩散预训练时 \(F\) 拟合速度，连续一致性训练后 \(f\) 要预测整条轨迹的干净终点论文 Eq. 4–5。

3.3 不稳定的来源：时间导数的放大链

在 TrigFlow 中，切向量包含 \(\sin(t)\partial_tF_{\theta^-}\)。作者把它分成时间变换、时间嵌入、网络对嵌入的响应三个因子，然后逐项改造论文 Eq. 6–7、§4.1：

  • Identity time transformation：EDM 对数时间变换 \(c_{\rm noise}(t)\propto\log(\sigma_d\tan t)\) 的导数经 \(\sin(t)\) 缩放后仍随 \(1/\cos(t)\) 发散；改成 \(c_{\rm noise}(t)=t\)论文 §4.1、Eq. 7。
  • Positional time embedding：大尺度 Fourier 特征的导数随频率放大，并快速振荡。低频 positional embedding 限制这一放大；论文把它描述为近似 Fourier scale 0.02论文 §4.1、Fig. 4。
  • Adaptive double normalization：AdaGN 的 scale 与 bias 直接依赖时间，可能放大时间导数；对二者各做 pixel normalization，保持调制能力并控制幅度。
$$y=\operatorname{norm}(x)\odot\operatorname{pnorm}(s(t))+\operatorname{pnorm}(b(t)).$$

这些改动服务于输入方向导数的稳定性；不能只检查普通扩散 loss 是否下降，就断言网络适合连续一致性训练论文 §4.1、Fig. 4。

3.4 目标尺度：归一化、裁剪、warmup 与自适应权重

结构稳定后，原始切向量仍有较大方差。正文比较原始切向量、逐元素裁剪到 [−1,1]，以及范数归一化；后两者都改善训练，默认使用归一化常数 \(c_{\rm norm}=0.1\)论文 §4.2、Fig. 5(a)。

Tangent warmup 让较不稳定的 \(\sin(t)(x_t+\sigma_d\,dF/dt)\) 项从零逐步开启，前 10k 迭代线性增大系数；并不关闭整个学习信号。自适应权重 \(w_\phi(t)\) 再均衡不同时间的误差，与采样时间的 proposal distribution 是不同的机制论文 §4.2、Alg. 1、App. D、G.2。完整实现先缩放及 warmup，后归一化，公式见下节。

3.5 JVP 与 FlashAttention：扩规模不能只靠公式正确

JVP 同时沿状态与时间求导，不显式构造高维 Jacobian。半精度中若先算未经缩放的 \(dF/dt\)，中间层仍可能溢出，即使最终再乘 \(\cos(t)\sin(t)\) 也来不及；因此把小系数提前乘进 JVP 的输入方向论文 §5.1。

论文当时的 FlashAttention 接口不支持所需 JVP。作者在块式在线 softmax 内同时累计输出与方向导数，复用归一化统计，不保存完整注意力矩阵。若 \(P=\operatorname{softmax}(A)\)，方向导数满足 \(\dot Y=\dot P V+P\dot V\)，其中 \(\dot P=P\odot[\dot A-\operatorname{rowsum}(P\odot\dot A)]\)论文 App. F；矩阵写法由逐行公式整理。这才让带 JVP 的训练保留注意力内存优势，并扩到 ImageNet 512×512 的 1.5B 模型论文 §5.1、Tab. 2。

5. 从连续目标到稳定 MSE

当离散二次损失的时间间隔趋零，目标参数梯度可写成下面的形式。这里 \(\theta^-=\operatorname{sg}(\theta)\)，\(v_t\) 是 PF-ODE 方向，\(w_{\rm prior}(t)\) 是手工先验权重；外层反传不穿过目标切向量论文 Eq. 2、§4.2：

$$ \nabla_\theta\mathbb E\!\left[w_{\rm prior}(t)f_\theta(x_t,t)^\top \frac{df_{\theta^-}(x_t,t)}{dt}\right],\qquad \frac{df_{\theta^-}}{dt}=\nabla_{x_t}f_{\theta^-}v_t+\partial_t f_{\theta^-}. $$

取 \(w_{\rm prior}(t)=1/(\sigma_d\tan t)\)，将线性内积梯度转换成 MSE 的目标偏移。令 \(a=\cos t\)、\(b=\sin t\)，Alg. 1 真正使用的稳定化目标为论文 §4.2、Eq. 8、Alg. 1：

$$ r=\min(1,\mathrm{Iters}/H),\qquad g_{\rm raw}=-a^2(\sigma_dF_{\theta^-}-v_t)-rab\left(x_t+\sigma_d\frac{dF_{\theta^-}}{dt}\right), $$ $$ g=\frac{g_{\rm raw}}{\|g_{\rm raw}\|_2+c_{\rm norm}},\qquad \mathcal L_{\rm sCM}=\mathbb E\!\left[ \frac{\exp[w_\phi(t)]}{D}\left\|F_\theta-F_{\theta^-}-\operatorname{sg}(g)\right\|_2^2-w_\phi(t) \right]. $$

没有归一化与 warmup 时，\(g_{\rm raw}=a\,df_{\theta^-}/dt\)。\(F_\theta-F_{\theta^-}\) 前向为零，参数导数却不为零；MSE 对 θ 的导数因此由目标偏移驱动。归一化和 warmup 是有意修改优化尺度的稳定技巧，不能将它们说成未经修改目标的代数恒等变换论文 §4.2、Alg. 1。

$$ v_t= \begin{cases} \cos(t)z-\sin(t)x_0,&\text{sCT},\\ \sigma_dF_{\rm pretrain}(x_t/\sigma_d,t,c,w),&\text{sCD}, \end{cases} \qquad \tau\sim\mathcal N(P_{\rm mean},P_{\rm std}^2),\quad t=\arctan(e^\tau/\sigma_d). $$
论文内部不一致：采用 Alg. 1 的可执行定义Eq. 8 后的文字把 proposal 写成 \(e^{\sigma_d\tan t}\sim\mathcal N\)，但 Alg. 1 定义的是 \(\tau\sim\mathcal N\)、\(t=\arctan(e^\tau/\sigma_d)\)，即 \(\log(\sigma_d\tan t)=\tau\)。本页按后者采样论文 Eq. 8 后文字、Alg. 1。§5.1 的重排 JVP 公式也存在尺度记号问题：若输入是 \(x_t/\sigma_d\)，方向取 \((abv_t,ab\sigma_d)\)，结果应为 \(\sigma_d ab\,dF/dt\)。下方伪代码按链式法则与 Alg. 1 保留这项 σ_d由论文 §5.1、Eq. 6、Alg. 1 核算。

6. 伪代码：先缩放 JVP，目标停止梯度

依据 Alg. 1，以正确的输入尺度展开 §5.1 的 JVP 重排。F_stop冻结参数，允许对输入求方向导数；jvp不是对外层损失求梯度。

F = initialize_from_diffusion_ema()  # 本文报告实验的初始化
for iteration in training:
    x0 = sample_data()
    z = sigma_d * randn_like(x0)
    tau = normal(P_mean, P_std)
    t = atan(exp(tau) / sigma_d)
    a, b = cos(t), sin(t)
    xt = a * x0 + b * z
    y = xt / sigma_d
    with no_grad():
        v = a * z - b * x0 if is_sCT else sigma_d * teacher(y, t, c, w)

    F_stop = stop_parameter_gradient(F)  # 同权重，非 EMA
    # 结果 J = sigma_d * a * b * dF_stop/dt
    value, J = jvp(F_stop, primals=(y, t),
                   tangents=(a * b * v, a * b * sigma_d))
    r = min(1, iteration / H)
    raw = -a * a * (sigma_d * value - v) - r * (a * b * xt + J)
    g = (raw / (l2norm(raw) + c_norm)).detach()
    target = (value + g).detach()
    log_weight = weight_net(t)
    error = sum_over_sample_dims((F(y, t) - target) ** 2) / D
    loss = mean(exp(log_weight) * error - log_weight)
    update(F, weight_net, loss)
    update_sampling_ema(F)  # 用于采样，非训练目标分支

8.1 与 VSD / DMD 式方法的多样性比较

论文在同一 EDM2-M 基座、ImageNet 512×512 上比较一阶段 VSD、两步 sCD、两者损失相加及教师，并扫 guidance。作者观察到 VSD 提高 precision 但降低 recall，guidance 更大时可严重丢失模式；sCD 的 precision / recall 更接近教师论文 Fig. 7、§5.2、App. C、Tab. 7。

这说明分布级 score 监督在该配置中有质量—多样性取舍；一致性保留逐轨迹约束，是另一个监督来源。但该实验不是完整 DMD2 的 TTUR+真实数据 GAN 配方，也比较了不同采样步数，不能由它推出“所有 DMD 变体都必然坍塌”。DMD2自身也报告相对教师的轻微多样性下降sCM §5.2、App. C；DMD2 §6。

9. 承上启下：连续一致性与分布匹配汇合

离散一致性

  • CM / iCT用相邻时刻输出相等建立全局映射；间隔与离散化影响监督。
  • 连续极限更直接，但时间导数和数值实现曾使训练失稳。

sCM 的稳定配方

  • TrigFlow 简化坐标，改进时间条件，控制切向量与加权。
  • FlashAttention JVP 让连续目标可扩规模；不需要在线 fake score 才能训练基本 sCM。

sCM 已在附录研究与 VSD 相加的组合。后续 rCM把 score 蒸馏作为长跨度正则与连续一致性结合，并向大型视频模型扩展；视频端还要处理长序列 JVP、并行训练和感知质量，不能仅复制图像超参sCM App. C、Tab. 7；rCM 原论文摘要。这也是与 DMD / DMD2 在监督层面的汇合：轨迹约束和输出分布约束可以互补。

简答题

Q15连续时间 CM 消除了什么误差？为什么让离散时间间隔很小仍不足以得到稳定训练？

连续目标用沿 PF-ODE 的全导数替代有限间隔比较，避免相邻状态求解和有限差分带来的离散误差；它仍需稳定的输入方向导数，不能靠缩小间隔自动解决数值问题。

  • JVP 同时包含状态变化和时间偏导，只对 t 求偏导不够。
  • EDM 时间变换近噪声端放大导数，大 Fourier 频率和时间调制层继续放大波动。
  • sCM 用 TrigFlow、identity 时间条件、positional embedding、double normalization 与切向量控制共同稳定训练。

依据：论文 §2.2–§4.2、Eq. 2、Eq. 6–8、Fig. 4–5。

Q16sCT 与 sCD 的方向来自哪里？这怎样影响规模、多样性及与 DMD 式方法的比较？

sCT 由同一数据与噪声的插值导数估计方向，sCD 由冻结扩散教师给出 PF-ODE 方向；小尺度 sCT 有效，高分辨率 sCD 更稳定地继承教师缩放和多样性。

  • 无需教师训练信号不等于论文实验没有预训练初始化；本文两种版本都从扩散 EMA 权重出发。
  • 连续一致性要求轨迹终点不变；VSD / DMD 式 score 差主要约束输出分布，监督对象不同。
  • 论文同基座 VSD 对照显示 recall 下降，但不覆盖所有 DMD2 组件；组合监督是后续 rCM 的方向。

依据：论文 §2.2、§5.2、Fig. 6–7、Tab. 1–2、App. G.2。
