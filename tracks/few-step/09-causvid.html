1. 动机：双向视频模型为什么不能“边生成边播放”

2024 年的主流视频扩散模型（CogVideoX、MovieGen 等）都是双向 DiT：一段视频的所有帧在每一步去噪时互相可见，所以必须把整段视频的全部去噪步跑完，第一帧才能拿出来。论文测得自家 10 秒双向教师生成一段 120 帧视频要 219.2 s论文 Tab. 3。这种结构天然不适合流式播放、交互式生成（按用户输入改后续内容）和世界模型。

自回归（因果）视频扩散可以逐块生成，但当时从头训练的因果模型质量明显落后，且有误差累积：后面的帧建立在前面可能有瑕疵的帧上。论文在同一架构上的对照：100 次前向的多步模型里，双向版 Temporal / Frame / Text 为 94.6 / 62.7 / 29.6，因果版只有 92.4 / 60.1 / 28.5论文 Tab. 4。CausVid 的问题是：能不能不从头训练因果模型，而是把一个强的双向模型“改造 + 蒸馏”成又快又因果的学生？

一句话理解 拿预训练的双向视频 DiT，把注意力改成块因果（chunk 内双向、chunk 间因果），先用教师 ODE 轨迹做回归把它“扶正”，再用 DMD2 式的分布匹配蒸馏成 4 步生成器——关键是监督它的仍是双向教师（非对称蒸馏）。推理时逐 chunk 生成、把已生成 chunk 的 K/V 缓存起来，首帧延迟从 219.2 s 降到 1.3 s论文 Tab. 3。

3. 组件拆解

3.1 块因果注意力：粒度为什么是 chunk

改造的第一步只动注意力掩码，不动任何权重形状，所以学生可以直接继承双向教师的全部参数。chunk 内部保持双向，是因为 3D VAE 把若干帧压成一个 latent chunk，像素必须等整个 chunk 解码；chunk 内做因果既不能提前出图，又会损失质量。论文设定一个 chunk = 5 个 latent 帧（16 个视频帧）论文 §5；官方开源的 Wan2.1 版本用 3 个 latent 帧一块官方代码 configs/wan_causal_dmd.yaml num_frame_per_block: 3。

3.2 非对称蒸馏：为什么评委必须是双向的

直觉上应当“因果学生配因果教师”，但论文认为因果教师本身就弱、而且自带误差累积，蒸馏会把这两点一起传给学生。双向教师在评估第 i 个 chunk 时能参考整段视频，因而能给出“全局合理”的分布级信号；DMD 只需要教师在学生样本上给出 score，不要求师生输入一一对应，这使得“学生因果、教师双向”在数学上是允许的。

3.3 ODE 初始化：回归只当起点，不当损失

上表第 3、4 行给出两个方向的消融：去掉 ODE 初始化，Frame 从 64.4 掉到 60.6；只做 ODE 回归、不做 DMD，Frame 只有 48.1——回归出来的学生很糊。这与图像侧的经验一致：轨迹蒸馏式的直接回归在少步下容易给出“条件均值”式的模糊结果，DMD2 甚至把 DMD 的回归项整个拿掉了。CausVid 把回归降格为“初始化”，只用来让改了掩码的网络先能生成可辨认的视频，再交给分布匹配。 CausVid §4.3、Tab. 4 Causal Forcing §3.2–3.3

后来 Causal Forcing 给出了更尖锐的解释：ODE 轨迹来自双向教师，第 i 个 chunk 的终点还取决于未来 chunk 的噪声，而因果学生看不到未来，所以这个回归目标对学生而言根本不是一个函数，只能学到条件期望。

3.4 推理：逐 chunk 去噪 + KV cache

推理时每个 chunk 从纯噪声出发走 4 步（每步预测 x̂₀ 再加噪到下一个时刻），去噪完成后再以 t = 0 把干净的 chunk 前向一次，把它的 K/V 写入缓存，后续 chunk 只读缓存论文 Alg. 2、§4.4。因为缓存只包含过去，推理时不再需要块因果掩码，可以直接用快速的双向注意力内核。

论文报告单张 H100 上 10 秒视频首帧延迟 1.3 s、吞吐 9.4 FPS（含文本编码、扩散与 VAE 解码）论文 Tab. 3。论文也指出瓶颈在 VAE：必须攒满 5 个 latent 帧才能出第一批像素，逐帧 VAE 可以再降延迟论文 §6。

3.5 长视频：滑动窗口与误差累积

CausVid 只在 10 秒片段上训练。更长的视频用滑动窗口：上一个 10 秒段的最后几帧作为下一段的上下文论文 §5.1。开源实现里这一步是“新开一段 rollout、重新预填重叠帧的 KV”：把上一段末尾几帧解码再编码，以 t = 0 写入新缓存，然后继续生成官方代码 minimal_inference/longvideo_autoregressive_inference.py。论文在约 30 秒的对比中取得 94.9 / 63.4 / 28.9（Temporal / Frame / Text），高于 StreamingT2V、FIFO-Diffusion 等论文 Tab. 2，并展示了 14 分钟的样例（有轻微过曝）论文 Fig. 9。论文把“双向教师的分布匹配”视为抑制误差累积的主要原因，但也承认极长视频仍会退化论文 §6——训练时的历史是带噪真值而非自己的输出，这个缺口留给了 Self Forcing。

3.6 从图像到视频：DMD2 搬到因果视频时改了什么

DMD2 在图像上给出了一套成熟配方：去掉回归项、用 fake score 的 TTUR（5 : 1）稳定分布匹配、多步生成器配固定时间表、可选 GAN 项与 backward simulation（训练时用学生自己的多步采样产生中间输入）。CausVid 继承了 DMD 损失、TTUR、4 步固定时间表与 CFG 教师；但把它搬到“因果视频”时，有四处假设失效，必须改： CausVid §4–6、Tab. 1–4 官方推理代码

5. 训练目标

阶段 0（ODE 初始化）：\(\{x^i_{t^i}\}\) 是教师 ODE 轨迹上各 chunk 在各自时刻 \(t^i\) 的状态，\(x_0\) 是轨迹终点论文 Eq. 6：

$$\mathcal L_\text{ODE}(\theta)=\mathbb E_{x,\{t^i\}}\Big\lVert G_\theta\big(\{x^i_{t^i}\}_{i=1}^{N},\{t^i\}\big)-\{x^i_0\}_{i=1}^{N}\Big\rVert^2$$

阶段 1（非对称 DMD）：\(\hat x_0=G_\theta(\{x^i_{t^i}\})\) 由带噪真实视频产生，\(\hat x_t\) 为其按共享 t 加噪的结果论文 Eq. 4：

$$\nabla_\theta\mathcal L_\text{DMD}\approx-\mathbb E_{t,\epsilon}\Big[\big(s_\text{real}(\hat x_t,t)-s_\text{fake}(\hat x_t,t)\big)\,\frac{\partial \hat x_0}{\partial\theta}\Big],$$
$$\mathcal L_\text{fake}(\psi)=\mathbb E_{t,\epsilon}\big\lVert \hat\mu_\psi(\hat x_t,t)-\mathrm{sg}(\hat x_0)\big\rVert^2\quad\text{（x₀ 参数化的普通去噪；Wan 版代码用等价的流匹配损失）}$$

\(s_\text{real}\) 用双向教师（带 CFG），\(s_\text{fake}\) 是双向、可训练的网络；两者都只在“整段视频共享一个噪声水平”的输入上被调用。

论文 vs 官方代码 论文结果来自内部的 CogVideoX 式双向教师（352×640、12 FPS、10 秒，chunk = 5 个 latent 帧）；开源代码基于 Wan2.1-T2V-1.3B（480×832、81 帧，chunk = 3 个 latent 帧）。两者的若干数值不同：
  • 步数：论文 4 步 [999, 748, 502, 247]；wan_causal_dmd.yaml 为 3 步 [1000, 757, 522]，另有 wan_causal_dmd_warp_4step_cfg2.yaml（4 步 [1000, 750, 500, 250]、CFG 2.0）。 CausVid Eq. 4–6 官方 configs、causvid/dmd.py
  • ODE 初始化：论文 1000 条轨迹、lr 5e-6；README 生成 1.5K 条，wan_causal_ode.yaml 的 lr 为 2e-6。 CausVid Eq. 4–6 官方 configs、causvid/dmd.py
  • CFG：代码写作 cond + 3.5·(cond − uncond)，按常见写法 uncond + w·(cond − uncond) 相当于 w = 4.5（推算）；论文只写“CFG 3.5”。 CausVid Eq. 4–6 官方 configs、causvid/dmd.py
  • 代码对 DMD 与 fake score 的 t 做了 shift 并截到 [0.02, 0.98]·1000，论文未提。 CausVid Eq. 4–6 官方 configs、causvid/dmd.py

6. 伪代码

causvid_train.py（依据论文 Alg. 1 与 causvid/dmd.py，简化）
steps = [999, 748, 502, 247]                  # 论文的 4 步时间表；k = chunk 长度
# ---- 阶段 0：ODE 初始化（ode_regression.py）----
for traj, c in ode_pairs:                     # traj: [B, len(steps)+1, F, C, H, W]，最后一项为 x0
    idx = randint(0, len(steps), (B, F // k)).repeat_interleave(k, 1)   # 每个 chunk 独立取时刻
    x_in = gather(traj, idx)                  # 不同 chunk 处在不同噪声水平
    loss = mse(G(x_in, steps[idx], c, mask=block_causal(k)), traj[:, -1])
    loss.backward(); opt_G.step()

# ---- 阶段 1：非对称 DMD（dmd.py，backward_simulation=False）----
for it, (x0, c) in enumerate(video_loader):   # x0: 真实视频 latent
    t_in = steps[randint(0, 4, (B, F // k))].repeat_interleave(k, 1)
    x_in = add_noise(x0, randn_like(x0), t_in)            # 历史 = 带噪真值
    train_G = (it % 5 == 0)                               # TTUR：fake 5 次 / 学生 1 次
    with set_grad_enabled(train_G):
        x_hat = G(x_in, t_in, c, mask=block_causal(k))    # 整段一次前向
    if train_G:
        with no_grad():
            t = sample_shifted_t_then_clamp(20, 980)       # Wan 版：均匀采样 → shift → 截断；全片共享 t
            x_t = add_noise(x_hat, randn_like(x_hat), t)
            p_c, p_u = real(x_t, t, c), real(x_t, t, null)
            p_real = p_c + 3.5 * (p_c - p_u)              # 双向教师 + CFG
            p_fake = fake(x_t, t, c)
            g = (p_fake - p_real) / abs(x_hat - p_real).mean(dim=(1, 2, 3, 4), keepdim=True)
        loss_G = 0.5 * mse(x_hat, (x_hat - g).detach())
        loss_G.backward(); opt_G.step()
    x_s = x_hat.detach()                                  # fake score：学生样本上的普通去噪
    t = sample_shifted_t_then_clamp(20, 980); n = randn_like(x_s)
    loss_fake = denoise_loss(fake(add_noise(x_s, n, t), t, c), x_s, n, t)
    loss_fake.backward(); opt_fake.step()

9. 承上启下

CausVid 确立了

  • “双向预训练 → 改块因果掩码 → ODE 初始化 → 双向教师做 DMD”的改造配方，后续 Self Forcing、Causal Forcing 都沿用其主体；
  • 4 步 / chunk + KV cache 的流式推理，首帧延迟进入秒级； CausVid §6 Self Forcing §1 Causal Forcing §3
  • “非对称”这一观点：因果学生可以由双向教师在分布层面监督。

留下的问题 → 下一步

  • 训练历史是带噪真值，推理历史是自己的输出（暴露偏差）→ Self Forcing 在训练中自回归展开；
  • ODE 初始化的目标来自双向教师，对因果学生不是函数 → Causal Forcing 先训练自回归教师；
  • GAN 路线的自回归蒸馏 → APT2；一致性路线 → rCM / Causal-rCM；
  • 反向 KL 导致多样性下降、VAE 限制首帧延迟、超长视频仍退化。

Q17CausVid 为什么用双向教师去蒸馏因果学生，而不是先训练一个因果教师？这种“非对称”在数学上为什么可行？

因果教师本身比双向教师弱（同架构多步对照 92.4 / 60.1 / 28.5 vs 94.6 / 62.7 / 29.6），而且自带误差累积，蒸馏会把这两点一并传给学生；实测换成因果教师后学生从 94.7 / 64.4 / 30.1 降到 91.9 / 61.7 / 28.2。非对称之所以可行，是因为 DMD 只要求教师在学生生成的整段视频上给出 score（分布层面的反向 KL 梯度），不需要师生对同一输入做逐样本对齐；双向教师看得到未来帧，能对“这段视频整体是否合理”打分，信号反而更强。 CausVid §4.2–4.3、Tab. 4 Causal Forcing Prop. 3.3

  • 代价：教师与 fake score 都按“全片同一噪声水平”评估，学生却按 chunk 生成——两者的输入分布不同，所以需要重新加噪这一步做桥接。
  • 这个观点后来被保留：Self Forcing 与 Causal Forcing 的 DMD 阶段仍用双向教师；Causal Forcing 只是指出 ODE 回归阶段不能用双向教师。

依据：CausVid §4.2、Tab. 4；Causal Forcing §3.2–3.3。

Q18把 DMD2 从图像搬到因果视频时，CausVid 为什么要额外加 ODE 初始化？去掉它、或者只用它，各会怎样？

DMD2 在图像上直接从教师权重开始做分布匹配，因为学生与教师架构相同、起点已经能出图。CausVid 把注意力改成块因果后，网络从未在这种掩码下工作过，直接 DMD 不稳定；于是先用 1000 条教师 ODE 轨迹做 3000 步回归，把学生拉到“能生成可辨认视频”的起点，再交给 DMD。去掉它，Frame 质量从 64.4 降到 60.6；只用它（不做 DMD），Frame 只有 48.1——单纯回归在 4 步下会给出模糊的均值式结果。 CausVid §4.2–4.3、Tab. 4 Causal Forcing Prop. 3.3

  • 所以回归只当起点、不当长期损失，这与 DMD2 去掉回归项的判断一致。
  • 更深的原因由 Causal Forcing 指出：双向教师的 ODE 终点依赖未来 chunk 的噪声，对因果学生不是输入的函数，回归只能学到条件期望——因此 ODE 初始化“有用但有偏”。

依据：CausVid §4.3、§5、Tab. 4；DMD2 §4.1；Causal Forcing Prop. 3.3。
