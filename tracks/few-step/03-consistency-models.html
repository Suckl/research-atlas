1. 动机：不学每一段路，直接识别共同终点

轨迹蒸馏教学生用大跳跃替代教师小步。Consistency Models（CM）换了监督对象：一条 probability-flow ODE 轨迹上，所有状态都对应同一个数据端终点，能否让 \(f_\theta(x_t,t)\) 无论在哪个噪声尺度观察它，都给出相同答案？这种映射在最高噪声处直接预测样本，从而天然允许单次前向生成CM §3、Fig. 2。

关键在于终点在哪里被固定。仅要求输出一致，常数输出也能让损失很小；因此数据端必须有恒等边界。另一个关键是邻近状态从哪里来：可以用冻结扩散教师走局部 ODE，也可以直接从数据与共享噪声构造训练对。前者叫 consistency distillation（CD），后者叫 consistency training（CT）CM §3–5。CT 本身是生成建模方法，不必有预训练教师。

一句话理解 CM 把“同一轨迹的状态应预测同一终点”变成学习规则，用数据端的恒等映射把答案锚住。LCM 再把这条规则迁到 Stable Diffusion 的 latent，连教师 CFG 一起吸收进学生。

3. 组件拆解

3.1 一致性与恒等边界必须一起成立

原 CM 使用噪声标准差作为时间 t，\(x_t=x_0+t\epsilon\)，从大噪声 T 向小正数 \(\sigma_{\min}\) 积分，最终样本近似数据端。论文用 T=80、\(\sigma_{\min}=0.002\)CM §2；这里把原论文表示截止时间的小写 ε 改记为 \(\sigma_{\min}\)，保留 ε 表示高斯噪声。一致性函数满足：

$$f(x_t,t)=x_{\sigma_{\min}},\qquad f(x_t,t)=f(x_s,s)\ \text{若两状态属于同一 ODE 轨迹},\qquad f(x,\sigma_{\min})=x.$$

CM §3 用跳连参数化实现边界，不需要网络自己学会恒等映射：

$$f_\theta(x,t)=c_\mathrm{skip}(t)x+c_\mathrm{out}(t)F_\theta(x,t),\qquad c_\mathrm{skip}(\sigma_{\min})=1,\quad c_\mathrm{out}(\sigma_{\min})=0.$$

CM Eq. (5) 若只有一致性而没有边界，所有输入输出同一个常数也能得到零距离。边界将“沿路相同”锚定到真实端的输入；它防的是全局常数解，不代替对误差累积、目标质量和优化稳定性的设计。

CM §4–5、Alg. 2–3、Thm. 1–2；iCT §3.2 “不跑教师完整轨迹”并不等于“不需要数据”；原始 CD 与 CT 都使用真实数据的加噪边缘。CD 的 target 也不是教师直接给出的数据样本，而是 EMA 学生对局部邻居的终点预测。

3.3 多步采样：每次都跳回终点，再重新加噪

单步为 \(\hat x=f_\theta(T\epsilon,T)\)。多步时先预测终点，然后按较低噪声尺度重新加噪，再预测终点：

$$\hat x\leftarrow f_\theta\!\left(\hat x+\sqrt{\tau^2-\sigma_{\min}^2}\,\epsilon,\tau\right),\qquad \tau\ \text{逐次降低}.$$

CM Alg. 1 这不是普通 DDIM 逐段积分；每次前向都预测数据端。重新加噪允许修正初次输出，带来质量—计算量取舍，也能支持编辑与逆问题。原论文选择多步噪声尺度时用生成质量搜索，不能假定训练用离散网格的等距子集就是最优推理时间表CM §3 Sampling。

3.4 iCT 与 ECT：稳定自举，再利用已有扩散模型

iCT 指出 CT 的目标参数 EMA 会在细时间间隔的极限中引入问题，改为 \(\theta^-=\mathrm{sg}(\theta)\)；同时用 Pseudo-Huber 距离替换 LPIPS、采用 lognormal 噪声采样与逐阶段加密网格iCT §3、Tab. 1。移除的是一致性损失的 EMA target，不等于禁止为最终采样维护参数 EMA。它避免把“EMA 总有帮助”当作所有自举目标的通用结论。

ECT 从预训练扩散模型出发，把较松的终点约束逐渐收紧到一致性条件：起初较大时间间隔的目标接近去噪训练，之后逐渐缩短间隔。这是扩散预训练 + consistency tuning，不需要在线教师 score 来生成 CD 邻居ECT §3.2–3.3。论文的快速实验在单张 A100 上调优一小时得到两步 CIFAR-10 FID 2.73，该时间不包括已有扩散模型的预训练ECT 摘要、§4.1。

3.5 LCM：latent、guidance 条件与跳步监督

高分辨率文生图不能只把像素 CM 放大。LCM 用冻结 VAE 将图像 \(x_0\) 编码为 latent \(z_0\)，在 Stable Diffusion 的 VP 路径 \(z_t=\alpha_t z_0+\sigma_t\epsilon\) 上蒸馏。沿用教师的 ε 或 v 参数化得到数据预测，再用 c_skip / c_out 包装成一致性函数；学生从教师权重初始化LCM §4.1、Eq. (9)、App. D。VAE 与文本编码器不随一致性目标训练。

LCM 用 \(f_\theta(z_t,t,c,w)\) 直接预测 guided ODE 的终点，把 guidance 强度也编码进学生。为避免混淆，本页统一使用 \(s_w=s_u+w(s_c-s_u)\)；LCM 论文记作 \((1+\omega)s_c-\omega s_u\)，两者关系为 \(w=1+\omega\)（代数换算）。训练时教师仍有条件与无条件分支，学生推理则只需自身的一次前向LCM §4.2、Eq. (12)–(17)、§5.1。

直接监督相邻的细网格时，两个预测本就很近，监督信号弱。LCM 用 skipping-step 扩大训练时间跨度，主实验跳过 k=20 个离散间隔；这表示训练邻居的跨度，不是推理要做二十步LCM §4.3。更大跳跃也会放大求解器误差，需要同时选择教师求解器。其局部更新可写为：

$$\hat z_s=z_t+(1+\omega)\Psi_\phi(z_t,t,s,c)-\omega\Psi_\phi(z_t,t,s,\varnothing),\qquad \mathcal L_\mathrm{LCD}=\mathbb E\,d\!\left(f_\theta(z_t,t,c,w),\mathrm{sg}(f_{\theta^-}(\hat z_s,s,c,w))\right).$$

LCM Eq. (16)–(17)，w=1+ω 重写 这里 Ψ 表示教师求解器的位移增量。它不是最终端点，也不意味着任意非线性多步求解器的两个完整解可被精确线性组合为 guided ODE 解；论文在此使用数值近似。

3.6 LCM-LoRA：把加速能力装成可迁移的参数增量

LCM-LoRA 保留预训练矩阵 \(W_0\)，只学习低秩增量 \(\Delta W=BA\)，仍用 latent consistency distillation。训练好后把这份“加速增量”加到同一基座的微调模型，或与风格 LoRA 组合，省去逐个定制模型重新蒸馏的成本LCM-LoRA §3.1–3.2、Eq. (1)。

“training-free”描述的是已有加速模块向定制模型的应用，模块本身仍要蒸馏训练。原版 LCM 支持 guidance 条件化，而 LoRA 报告 Fig. 2 的模型是在固定 \(\omega=7.5\) 下蒸馏，并展示四步采样；部署时不能默认两者拥有同样的强度条件接口LCM-LoRA Fig. 2。不同基座、微调幅度与适配器组合的泛化是实验结论，不是所有权重相加都成立的保证。

5. 原始 CD / CT 损失与代码差异

$$\mathcal L_\mathrm{CD}=\mathbb E\!\left[\lambda(\sigma_l)\,d\!\left(f_\theta(x_h,\sigma_h),\mathrm{sg}(f_{\theta^-}(\hat x_l,\sigma_l))\right)\right],\qquad \hat x_l=x_h+(\sigma_l-\sigma_h)(-\sigma_h s_\mathrm{real}(x_h,\sigma_h)).$$

CM Eq. (6)–(7)，此处展示 Euler 邻居 低噪声状态的估计必须停梯度；在线学生与 target 输出在同一数据表示空间比较。\(\lambda\) 是损失权重，与 guidance 系数无关。

$$\mathcal L_\mathrm{CT}=\mathbb E\!\left[\lambda(\sigma_l)\,d\!\left(f_\theta(x_0+\sigma_h\epsilon,\sigma_h),\mathrm{sg}(f_{\theta^-}(x_0+\sigma_l\epsilon,\sigma_l))\right)\right],\qquad \theta^-\leftarrow\mu\theta^-+(1-\mu)\theta.$$

CM Eq. (8)、Alg. 3 这是原始 CT，不能把 iCT 的无 EMA target 更新又写进同一算法。两端若用独立噪声，局部关联会被破坏；这不是“噪声只要各自服从高斯即可”。

论文 vs 官方代码 LCM 原论文的训练范围为 ω∈[2,14]、EMA µ=0.999943LCM §5.1。核对的官方 LCM_Training_Script/consistency_distillation/train_lcm_distill_sd_wds.py 默认 w_min=5.0、w_max=15.0、ema_decay=0.95；其参数帮助称采用 Imagen 约定，但实际目标仍写 cond + w * (cond - uncond)官方脚本 parse_args、训练步骤 20.4.11（2026-10-13 核对）。这是帮助文字与实现的内部不一致。复现这份脚本时按实际表达式理解其 w，不能仅按帮助文字把论文系数平移；默认参数也不是原论文实验配置。

def f(model, x, sigma):
    return c_skip(sigma) * x + c_out(sigma) * model(x, sigma)

target.load_state_dict(online.state_dict())
for step, x0 in enumerate(data_loader):
    low, high = adjacent_noise_levels(grid_for(step))
    eps = randn_like(x0)
    x_high = x0 + high * eps
    with no_grad():
        if mode == "CD":
            x_low = local_teacher_ode(x_high, high, low)  # 冻结 score；Euler / Heun
        else:                                           # 原始 CT
            x_low = x0 + low * eps                       # 同一份噪声
        endpoint_target = f(target, x_low, low)
    endpoint_pred = f(online, x_high, high)
    loss = time_weight(low) * distance(endpoint_pred, endpoint_target)
    optimizer.zero_grad()
    loss.backward()
    optimizer.step()
    with no_grad():
        ema_update(target, online, mu_for(step))
# iCT：上面的 target 改为 stop-gradient 在线参数，不用此目标 EMA

def consistency_sample(model, descending_scales):
    x = f(model, sigma_max * randn_sample(), sigma_max)
    for sigma in descending_scales:
        noise = sqrt(sigma**2 - sigma_min**2) * randn_like(x)
        x = f(model, x + noise, sigma)
    return x

9. 承上启下

从轨迹回归到共同终点

  • 局部教师即可传递全程生成能力；CT 进一步不依赖 score 教师。
  • LCM 把恒等边界、latent 与 guidance 条件组合成文生图少步接口。

留下的训练与质量问题

  • sCM继续处理连续时间目标的稳定性与扩展。
  • rCM继续探索大模型与视频的递归一致性训练。
  • ADD与DMD用分布级监督改善一步细节。

迁到视频时，冻结 VAE 的 latent 多了时间维，还要保持运动与外观的一致性。VideoLCM / AnimateLCM / T2V-Turbo分别追踪 latent 蒸馏、图像与视频一致性解耦、奖励后训练；它们继承的是 CM / LCM 的训练思想，而不是简单复用一份图像检查点就完成视频生成。

简答题

Q5只让两个噪声尺度的输出相同够不够？CD 与 CT 的训练对有哪些区别？

不够，常数输出也满足相同，必须用数据端恒等边界锚住答案。CD 用教师 ODE 的局部邻居，CT 用同一数据、同一噪声的两个加噪状态；后者是局部估计器，不能叫精确同轨迹点。

  • 目标 CM 与冻结扩散教师是两个不同的网络角色。
  • CT 可从数据直接训练，但目标更新、间隔与损失仍需稳定设计。
  • iCT 移除目标 EMA 的结论属于 CT 配方，不自动覆盖原始 CD。

依据：CM §3–5、Alg. 2–3、Thm. 2；iCT §3.2。

Q6LCM 的 latent、guidance 条件与 skipping-step 各解决什么，LCM-LoRA 为什么还要训练？

latent 降低高分辨率建模成本；guidance 条件化让学生吸收双分支教师的引导；跳步扩大训练邻居的时间跨度，增强监督。LCM-LoRA 训练一份低秩加速增量，再将它应用到兼容的定制模型。

  • 跳步跨度属于教师训练监督，不能当推理步数。
  • guidance 系数先统一约定；代码帮助、表达式与默认配置需要核对。
  • 无需为每个定制模型额外训练，不代表加速模块本身无需蒸馏。

依据：LCM §4.1–4.3、§5.1；LCM-LoRA §3.1–3.2、Fig. 2；官方训练脚本。
