1. 动机：网络学会了方向，为什么还要走很久

扩散模型把数据 \(x_0\) 逐渐变成噪声，再学习如何逆转这个过程。DDPM 常用噪声预测损失训练去噪网络；给定噪声尺度，噪声预测可以换算成 score，即带噪分布对输入的对数密度梯度。它回答的是“当前位置往哪里走”，而不是“从这份噪声最终生成哪张图”DDPM §3.2、Eq. (11)；Score SDE §3。DDIM 则给出共享训练目标的确定性采样过程：固定初始噪声，就能定义一个可蒸馏的噪声到图像映射DDIM §4、Eq. (12)，η = 0。

Flow Matching 直接回归连续流的速度场，也通常需要积分后才能生成。训练用的条件路径可以是直线，但各路径在同一时刻会混合；网络学习的是条件速度的平均，实际 ODE 轨迹因此未必直Flow Matching §3–4；Rectified Flow §2.2。本 track 统一把数据端记为 \(t=0\)、噪声端记为 \(t=1\)，在线性路径下 \(x_t=(1-t)x_0+t\epsilon\)、\(v=\epsilon-x_0\)，生成从噪声端向数据端积分；这是对原论文记号的重写Flow Matching §4；Rectified Flow §2.1，时间反向重写。

一句话理解 少步生成把“推理时反复修正方向”的工作搬进训练。可以教学生跳过一段轨迹，可以教它识别同一条轨迹的共同终点，也可以只要求它生成的整批样本具有正确分布。三种监督约束不同，所需教师、数据和训练成本也不同。

3. 组件拆解：速度场、积分器、监督信号

3.1 score 与速度场：同一个生成过程的不同参数化

对前向 SDE \(\mathrm dx=a(x,t)\mathrm dt+b(t)\mathrm dW_t\)，score 为 \(s_\text{real}(x_t,t)=\nabla_{x_t}\log p_t(x_t)\)。对应的 probability-flow ODE 与 SDE 具有相同时间边缘分布，方向场为Score SDE §4.3、Eq. (13)：

$$\frac{\mathrm dx_t}{\mathrm dt}=a(x_t,t)-\frac12 b(t)^2s_\text{real}(x_t,t).$$

这里“相同”指边缘分布，不是每个随机 SDE 样本的路径。Flow Matching 则直接训练 \(v_\theta\)，用每个训练对的条件速度作可计算监督；线性路径的总体最优速度是 \(\mathbb E[\epsilon-x_0\mid x_t,t]\)Flow Matching §3–4；Rectified Flow Eq. (2)，按本页时间约定改写。学到了真实速度场，也仍然需要数值求解 ODE。

3.2 NFE 为什么高：弯曲、截断误差与 guidance

NFE 是采样时网络评价次数。ODE 求解器只在离散状态计算方向：若轨迹弯曲，大步 Euler 就沿切线切过弯道，偏离真实轨迹。EDM 明确把截断误差与轨迹曲率联系起来，并用预条件、时间表和 Heun 校正改善效率EDM §3、Fig. 3。所以“把原采样器的步数直接调小”和“训练一个适合大跳跃的新映射”是不同操作。

步数也不一定等于 NFE。Heun 的预测与校正通常各需一次速度评价，最后落到数据端的步骤可退回 EulerEDM Alg. 1。普通 classifier-free guidance（CFG）还要分别评价条件与无条件分支；把两支并进一个 batch 不能消除这两份样本计算量CFG §3、Alg. 1。本页统一写 \(s_w=s_\text{uncond}+w(s_\text{cond}-s_\text{uncond})\)；原 CFG 论文的系数比这里少一，后文遇到另一种约定会明确换算CFG Alg. 1，代数重写。

演示里是环形排列的八个高斯模式，用解析后验算出精确速度场，再用 Euler 从噪声端采样；参考线也是数值解，使用四十八次评价，并非精确 ODE 端点组件 assets/js/widgets/fewstep2d.js：post、vel、euler、draw。改变滑块看的是离散化误差，网络本身没有训练误差。演示的单步输出恰好是原点来自其独立配对与对称数据分布，不能外推为所有扩散模型单步都会精确输出均值。

5. 目标决定失败方式

5.1 为什么直接回归会学到模糊均值

$$\underset{G}{\arg\min}\ \mathbb E\|G(\epsilon,c)-x_0\|^2=\mathbb E[x_0\mid\epsilon,c].$$

这是平方损失的条件期望性质（数学推导）。若噪声与真实图像独立，同一输入对应很多互不相容的目标，最优解就是条件下的平均图像。教师 ODE 配对 \(x_0=\Phi_\phi(\epsilon,c)\) 则把目标变成确定函数，理论最优解可以保留所有模式PD §3；Rectified Flow §2.2。仍有模糊时，应区分学生容量不足、配对映射过复杂、损失偏好平均与学生漏掉教师条件；不能把所有回归失败归为独立配对。

5.2 mode-seeking 与 mode-covering 是哪一种 KL

$$D_{\mathrm{KL}}(q_\theta\|p)=\mathbb E_{x\sim q_\theta}\log\frac{q_\theta(x)}{p(x)},\qquad D_{\mathrm{KL}}(p\|q_\theta)=\mathbb E_{x\sim p}\log\frac{p(x)}{q_\theta(x)}.$$

反向 KL 在生成分布 \(q_\theta\) 上取期望，强烈惩罚样本落入教师低密度区，但漏掉一个数据模式未必立即付出大代价；有限容量或优化不充分时常表现为 mode-seeking。正向 KL 在目标分布取期望，漏掉目标模式会被惩罚，因而常称 mode-covering。在可表达且全局优化的理想情形，两者的最优解都是匹配目标分布，反向 KL 并非必然坍塌DMD §3 的 KL 方向；性质按 KL 定义推导。

DMD/VSD 在带噪分布上比较 score；教师 CFG 又改变了有效目标。GAN 与核匹配也有各自的估计误差和覆盖问题，不能仅按名称给它们贴同一个 KL 标签。生成多样性需要另看 recall、条件覆盖和多随机种子结果，单项质量分不足以判定。

def guided_velocity(x, t, c, w):
    v_cond = teacher_velocity(x, t, c)
    if guidance_is_disabled:
        return v_cond
    v_uncond = teacher_velocity(x, t, null_condition)
    return v_uncond + w * (v_cond - v_uncond)

def teacher_endpoint(eps, c, descending_times):
    x = eps
    for t, s in adjacent_pairs(descending_times):
        v = guided_velocity(x, t, c, guidance_scale)
        x = x + (s - t) * v              # Euler 教学示意；实际可用高阶求解器
    return x

9. 承上启下

多步生成的工作方式

  • 学习局部方向，推理时重复积分。
  • 质量依赖曲率、求解器、时间表与 guidance。

把工作搬进训练

  • 轨迹回归学习大跳跃；一致性学习共同终点。
  • DMD、对抗与表征匹配重新约束生成分布。

从图像到视频为什么更难

视频不是把图像的噪声多复制几份。三维 latent 带来时间维存储、更多 token 与较大的注意力开销；一致的对象身份、运动和遮挡也要求整段联合建模。教师完整采样更贵，离线端点数据集的生产成本随之上升。这里的开销关系来自上面的形状推导，而非某篇论文的硬件测量。

为了降低首帧延迟，可以把双向整段去噪改成因果 / AR 生成。新的历史条件却改变了训练问题：训练看真实历史、推理看自己输出的历史，会导致 exposure bias 和误差累积；因果学生还可能看不到双向教师目标依赖的未来噪声Self Forcing §1、§3；详见 Causal Forcing。因此要同时比较少步质量、时间一致性、首帧延迟和长时间 rollout。

简答题

Q1速度场已经学准了，为什么直接把采样器改成单步仍会失败？

速度场是局部方向，单步需要整段流的积分；轨迹弯曲时局部切线不能代表全程位移。学生要学习适合大跳跃的映射，或重新设计可单步生成的目标。

  • 数值误差与模型误差分开：解析速度场也可能有大步积分误差。
  • 条件训练直线不保证边缘 ODE 轨迹直；配对和条件平均决定实际场。
  • 步数与 NFE 还受求解器和 CFG 分支影响。

依据：Score SDE §4.3；EDM §3；Flow Matching §3–4；Rectified Flow §2.2；CFG Alg. 1。

Q2端点回归与分布匹配各需要什么监督，学生指标超过教师意味着什么？

回归需要确定的输入—目标配对，分布匹配允许重排噪声与样本的关系，依赖 score、判别器或特征参考。超过教师的某个指标是协议内的结果，不能自动推广为整体分布更准确。

  • 独立配对的平方回归会给出条件均值；ODE 配对在理论上可避免这一点。
  • 分布目标可能额外使用真实数据或编码器，也可能偏向容易获得高分的模式。
  • 检查相同采样协议、条件覆盖、多样性、留出指标和时间成本。

依据：PD §3；DMD §3；Drifting §3；RDM §3、Tab. 2；GenEval §3；VBench §3。
