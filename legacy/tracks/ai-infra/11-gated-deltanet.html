1. 动机：线性注意力的状态是一块固定大小的“记忆矩阵”

softmax 注意力的 KV cache 随序列线性增长，decode 每步要读完整个 cache。线性注意力把 \(\sum_j \phi(q_t)^\top\phi(k_j) v_j\) 改写成 \(\phi(q_t)^\top S_t\)，其中 \(S_t = \sum_{j\le t} k_j v_j^\top\) 是一个 d_k × d_v 的矩阵——状态大小与序列长度无关，decode 每步只读写这块矩阵。问题是怎么往这块固定大小的矩阵里“写”：

更新规则公式能做什么缺什么
线性注意力（累加）S_t = S_{t−1} + v_t k_tᵀ记永远不忘，旧键值互相干扰
Mamba2 / 门控线性注意力S_t = α_t S_{t−1} + v_t k_tᵀ整体遗忘（标量门 α_t ∈ (0,1)）只能“均匀衰减”，不能定点改某个键的值
DeltaNet（delta 规则）S_t = S_{t−1}(I − β_t k_t k_tᵀ) + β_t v_t k_tᵀ定点改写：先擦掉键 k_t 上的旧值，再写新值不会整体遗忘，过期信息清不掉
Gated DeltaNetS_t = S_{t−1}(α_t(I − β_t k_t k_tᵀ)) + β_t v_t k_tᵀ两者兼有固定大小状态的精细检索上限 → 需要混合全注意力
一句话理解 delta 规则是“按键查找并覆盖”的联想记忆更新（在线梯度下降一步），门控是“随时间整体淡忘”。Gated DeltaNet 把两个乘起来，并给出一个把这种递归写成分块矩阵乘的训练算法，速度接近 Mamba2。

3. 组件拆解

3.1 训练：分块并行（chunkwise）

逐 token 递归在训练时太慢（串行）。DeltaNet 的关键是把 T 步的 (I − β k kᵀ) 连乘写成 WY 表示（Householder 乘积的紧凑形式），从而一个 chunk（如 64 token）内部可以用矩阵乘并行计算，chunk 之间再串行传递状态。Gated DeltaNet 把门控 α 的累积乘积并入这套 WY / UT 变换，“只带来边际开销”。实测 GDN 与 DeltaNet 的训练吞吐比 Mamba2 低 2–3K token/s，换来更强的表达力。推理（decode）就是上图的逐 token 递归，每步 O(d²) 而不是 O(L·d)。

3.3 另一条路：GLM-5 为什么没选线性注意力

GLM-5 报告在 GLM-9B（GQA，40 层）上比较了交错滑窗注意力、搜索得到的滑窗模式、Gated DeltaNet 与去掉 Conv1d 和门控的 SimpleGDN：滑窗交错在 128K 的 RULER 上掉约 30 分；GDN 质量更好但加参数；SimpleGDN 折中最好但“所有这些方法在细粒度检索任务上都有固有的精度差距”（RULER@128K 最多掉 5.69 分，RepoQA@128K 掉 7.33）。他们最终选择 MLA + DeepSeek 的 DSA（token 级稀疏，“构造上无损”）。这是 2026 年两条主流路线的分野：Qwen 用混合线性注意力换 KV 恒定，DeepSeek / GLM 用稀疏注意力保留精确检索。

4. 伪代码

gated_deltanet_decode.py（单头，逐 token）
def gdn_layer_step(x_t, S, conv_state, params):
    qkv, z, a, b = project(x_t, params)                 # 线性投影
    qkv, conv_state = causal_conv1d_step(qkv, conv_state, k=4)   # 短卷积（唯一的局部位置信息）
    q, k, v = silu(qkv).split(...)
    q, k = l2_normalize(q), l2_normalize(k)
    alpha = exp(-exp(params.A_log) * softplus(a + params.dt_bias))   # 遗忘门 ∈ (0,1]
    beta = sigmoid(b)                                                 # 写入强度

    S = alpha * S                                       # 1) 整体衰减
    err = v - S.T @ k                                   # 2) 键 k 处的预测误差
    S = S + beta * outer(k, err)                        # 3) delta 规则：沿 k 写入修正
    o = S.T @ q / sqrt(d_k)                             # 读出
    y = out_proj(rmsnorm(o) * silu(z))                  # 输出门
    return y, S, conv_state                             # 状态大小固定，与 t 无关

5. 简答题

Q23线性注意力混合路线（Qwen3.5）与稀疏注意力路线（DeepSeek / GLM）各自的取舍是什么？

两条路线在回答同一个问题——长上下文下 KV 的内存与带宽——但选了相反的取舍：线性注意力混合（Qwen3-Next / 3.5）把大部分层换成状态恒定的递归层，KV 与上下文长度无关、decode 每步成本固定；DeepSeek 系列保留 softmax 注意力的精确检索，用 MLA 压 KV、DSA 稀疏化计算、V4 再压缩 KV 序列。

Qwen3-Next / 3.5（GDN 3:1 混合）DeepSeek V3 → V3.2 → V4（MLA + DSA）
长上下文内存3/4 的层 KV 恒定（每头 128×128 状态）；1/4 全注意力层仍有 KVMLA 每 token 576 个数；V4 再按 m 倍压缩序列，1M 上下文 KV 仅为 V3.2 的 10%
长上下文计算GDN 层 O(L·d²)；全注意力层 O(L²)DSA：索引器 O(L²) 但极轻，核心注意力 O(L·k)，k = 2048
检索精度固定状态有容量上限，靠全注意力层兜底；GLM-5 的实验显示纯线性变体在 128K 细粒度检索上有固有差距top-k 选择保留精确 token 级注意力，GLM-5 称“构造上无损”；V3.2 与 V3.1 质量持平
训练分块并行算法，吞吐接近 Mamba2；需 FLA 类专用内核需 DSA 索引器的 KL 对齐预热 + 稀疏训练；FP8 细粒度训练框架
推理工程递归状态 + 少量 KV，适合极长输出；需要混合层的调度需 top-k / 稀疏内核（FlashMLA、TileLang），KV 仍随长度增长但很小
位置编码GDN 层无 RoPE；全注意力层 RoPE解耦 RoPE 维度（64）单独缓存

一句话：Qwen 路线的优势是常数级的 decode 成本与极简的 KV，DeepSeek 路线的优势是不牺牲精确检索的长上下文。两家都用 MoE；差别在序列混合层。

依据：GDN 论文 §4–5；Qwen3.5 HF 文档；DeepSeek-V3 §2.1、V3.2 §2、V4 §2；GLM-5 报告 §2.1.2。

Q24RoPE 怎样用绝对位置的旋转得到相对位置的效果？递归式的线性注意力层还需要位置编码吗？

对 GDN 层不是：递归按顺序扫描，α_t 的衰减就是随距离减弱的相对位置先验，再加上核 4 的因果卷积提供局部顺序；Qwen3.5 的实现里 GDN 层不加 RoPE。对每 4 层一次的全注意力层仍然加 RoPE。完整讨论见 RoPE 页 Q24。

Q25Qwen3.5 的混合架构长什么样？GLM-5 为什么没有选线性注意力？GDN 层能否去掉位置编码？

Qwen3.5 系列（含 Flash 这类小 / 快版本）沿用 Qwen3-Next 的解码器：3 层 Gated DeltaNet + 1 层门控全注意力（GQA + RoPE + 输出门）周期堆叠，MLP 为 MoE（旗舰 397B-A17B：512 专家、60 层、262K 上下文）或稠密（9B / 27B）。GLM-5 不是 GDN 架构：它是 744B-A40B 的 MoE，注意力用 MLA 并采用了 DeepSeek 的 DSA 稀疏注意力；GDN / SimpleGDN 只出现在它的对比实验里并被放弃（细粒度检索有差距）。

  • GDN 层可以去掉位置编码：原论文与 FLA / HF 实现都不在 GDN 层用 RoPE；位置信息来自递归顺序 + 因果卷积 + 门控衰减。
  • 全注意力层不建议去掉：softmax 注意力需要显式位置（或依赖因果掩码的隐式泄露，即 NoPE，实践中长上下文检索更弱）；Qwen3-Next 的做法是只旋转部分维度（partial_rotary_factor 0.25），留一部分“无位置”通道。
  • 注意“Qwen3.5-Flash”的具体层数 / 专家配置以官方模型卡为准——本页能核实的是 Qwen3.5 家族的共同架构（HF 文档），Flash 变体的细节未逐一核对。

依据：Qwen3.5 HF 文档（3:1 混合、conv 核 4、线性层头配置）；GDN 论文；GLM-5 技术报告 §2（MLA + DSA；效率注意力对比实验）。
