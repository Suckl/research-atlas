1. 动机：模型装不进一张卡，又不想为了切分付出太多通信

2019 年 8.3B 参数的 GPT-2 已经放不进一张 32 GB 的 V100。数据并行只复制模型、不切模型；流水并行按层切但引入气泡；朴素地把矩阵乘切开则每个算子都要通信。Megatron-LM 的观察：Transformer 层的结构允许一种切法，使得每个子块只在末尾通信一次。

一句话理解 MLP 的第一个矩阵按列切、第二个按行切，中间的 GeLU 逐元素所以不用通信，只在第二个矩阵乘后 all-reduce 一次；注意力按头切（天然的列切），输出投影按行切，同样只 all-reduce 一次。于是每层前向 2 次 all-reduce、反向 2 次，不需要新编译器。

3. 把三种并行叠起来：PTD-P

3.1 流水并行与气泡

张量并行每层通信两次、量大，只适合 NVLink 节点内（论文建议 TP 度数 = 每节点 GPU 数，DGX A100 即 8）。跨节点用流水并行：按层切成 p 段，batch 切成 m 个 micro-batch 流过各段。

调度做法气泡占比激活显存
GPipe先做完 m 个前向，再做 m 个反向(p−1)/m要存 m 个 micro-batch 的激活
1F1B（PipeDream-Flush）预热后每个 worker 交替做一个前向、一个反向(p−1)/m（相同）最多 p 个 micro-batch 在飞，m ≫ p 时显著更省
交错 1F1B（Megatron）每个 GPU 持有 v 个不连续的层块（“虚拟流水段”）(1/v)·(p−1)/m通信量增加 v 倍；要求 m 是 p 的倍数

3.2 序列并行：把 all-reduce 拆成 reduce-scatter + all-gather

张量并行组内，LayerNorm、dropout 这些逐元素 / 按 token 的算子的输入是完整复制的——激活显存白白乘以 TP 度。Korthikanti 等（2022）注意到 all-reduce = reduce-scatter + all-gather：在 g 处只做 reduce-scatter（每卡得到序列的 1/t 段），LayerNorm / dropout 按序列段各算各的，下一个 f 处再 all-gather 回来。通信量不变，但这些算子的激活只剩 1/t；配合“选择性重算”（只重算注意力里便宜但占内存的部分），激活显存降 5×、重算开销降 90% 以上，530B 模型在 2240 张 A100 上 MFU 54.2%。

量大小说明

5. 伪代码

column_row_parallel.py（f / g 算子与 MLP）
class f(torch.autograd.Function):              # 恒等 / 反向 all-reduce
    @staticmethod
    def forward(ctx, x): return x
    @staticmethod
    def backward(ctx, grad): return all_reduce(grad)

class g(torch.autograd.Function):              # all-reduce / 反向恒等
    @staticmethod
    def forward(ctx, x): return all_reduce(x)
    @staticmethod
    def backward(ctx, grad): return grad

def parallel_mlp(X, A_i, B_i):                 # 每张卡持有 A 的列分片 A_i、B 的行分片 B_i
    X = f.apply(X)                             # 前向：什么都不做
    Y_i = gelu(X @ A_i)                        # 列切：各卡独立
    Z_i = Y_i @ B_i                            # 行切：部分和
    return g.apply(Z_i)                        # all-reduce ②：Z = Σ Z_i

6. 关键结果

  • Megatron-LM（2019）：8.3B GPT-2 在 512 张 V100 上 15.1 PFLOPs，相对单卡 39 TFLOPs（峰值 30%）扩展效率 76%；指出 BERT 规模化时 LayerNorm 位置的重要性。
  • PTD-P（2021）：1T 参数模型在 3072 张 A100 上 502 PFLOP/s，单卡 163 TFLOP/s（峰值 52%）；交错调度；scatter/gather 优化让跨节点流水通信降 t 倍，吞吐最高 +11%。
  • 序列并行 + 选择性重算（2022）：激活显存降 5×，重算开销降 >90%；530B 模型 MFU 54.2%（原 42.1%）。

7. 简答题

Q17除数据并行与张量并行之外还有哪些并行维度？它们在训练与推理中的角色有何不同？

训练里的五种（DP、TP、PP、SP/CP、EP）在推理里都有对应，只是权衡变了：推理没有反向和优化器状态，瓶颈是延迟与 KV 显存。

并行切什么通信推理里的角色
DP（数据）复制整模型，分请求无（训练时是梯度 all-reduce）多副本扩吞吐；DeepSeek 式“注意力 DP + MoE EP”让每卡各自处理不同请求的注意力
TP（张量）每层的矩阵按列 / 行切，注意力按头切每层 2 次 all-reduce（NVLink 内）把 70B+ 塞进多卡、降低单步延迟（每卡读 1/t 的权重）；也分摊 KV 显存
PP（流水）按层切成段段边界点对点跨节点扩容量；推理里用微批流水，有气泡与首 token 延迟代价
SP / CP（序列 / 上下文）按序列维切（LN/dropout 段，或整个注意力的 KV：Ring Attention）reduce-scatter + all-gather / 环形传 KV超长 prompt 的 prefill（百万 token 级）把序列分到多卡
EP（专家）MoE 的专家分到不同卡all-to-all（dispatch / combine）MoE 推理主力：DeepSeek-V3 用 EP + DP，不用 TP；详见 DeepSeek-V3 Q22

还有两个推理特有的“维度”：PD 分离（按阶段切）与投机解码（按时间步并行验证），常和上面组合使用。

依据：Megatron-LM §3；PTD-P §2；序列并行论文 §4；DeepSeek-V3 §3.4。

Q18单机 8 卡张量并行时，一层 Transformer 的计算如何拆分、在哪里聚合？

单机 8 卡最常见是 TP=8（走 NVLink）。以一层为例，一次 decode 步的数据流是：

  1. 输入：当前 token 的隐状态 [B, h] 在 8 卡上各有一份（上一层 all-reduce 的结果）。
  2. 注意力：每卡持有 1/8 的头的 W_Q、W_K、W_V（列分片）和 W_O（行分片）以及这些头的 KV cache。各卡独立算自己头的 QKV、注意力、输出投影 → 得到 [B, h] 的部分和。
  3. 聚合 ①：all-reduce（NCCL 环 / 树）把 8 个部分和相加，每卡得到完整的注意力输出；各自加残差、做 RMSNorm（冗余计算）。
  4. MLP：每卡持有 W_up / W_gate 的列分片和 W_down 的行分片；各算 SiLU(X W_gate_i) ⊙ (X W_up_i) 再乘 W_down_i → 部分和。
  5. 聚合 ②：第二次 all-reduce，加残差，进入下一层。最后一层后 lm_head 也可按词表列切，用 all-gather 拼 logits（或各卡算局部 max/sum 后归约）。

通信量：每层 2 次 [B, h] 的 all-reduce，B 小时是延迟敏感（几十微秒级），所以 TP 必须在 NVLink 内；跨节点改用 PP（只传段边界的 [B, h]）。KV cache 随头切分自然分到各卡，8 卡合起来能放更多请求。

依据：Megatron-LM §3 的列/行切分与 f/g 算子；PTD-P §2.1 关于 TP 限制在节点内的讨论。

Q19All-Reduce 与 All-Gather 有什么区别？它们与 Reduce-Scatter 是什么关系？

All-Reduce 对各卡的数据做归约（如求和），每张卡最后得到同样大小的归约结果；All-Gather 不做运算，只把各卡的分片拼接，每张卡最后得到 N 倍大的完整张量。

  • 结果：All-Reduce 输出 = Σ_i x_i（与输入同形）；All-Gather 输出 = [x_0; x_1; …; x_{N−1}]。
  • 关系：Ring All-Reduce = Reduce-Scatter（每卡拿到一块的和）+ All-Gather（把各块的和拼回去）。两段各发 (N−1)/N × D，合计 2(N−1)/N × D。
  • 用途：TP 层末的部分和相加、DP 的梯度平均用 All-Reduce；ZeRO / FSDP 前向前拼回分片权重、Megatron 序列并行从“序列段”恢复完整序列、按词表切的 lm_head 拼 logits 用 All-Gather；FSDP 反向用 Reduce-Scatter 得到自己分片的梯度。
