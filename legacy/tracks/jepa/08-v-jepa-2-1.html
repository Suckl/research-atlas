1. 动机：全局理解很强，逐 patch 的特征却“糊”

V-JEPA 2 的视频理解与规划能力很强，但把它的 patch 特征拿去做分割、深度估计这类稠密任务时表现很差：PCA 可视化噪声大、碎片化，ADE20K 线性分割只有 22.2 mIoU，NYUv2 深度线性探测 RMSE 0.682。V-JEPA 2.1 §2.2 原因藏在损失函数里：V-JEPA 2 只对被遮挡的 token 计算损失，可见（上下文）token 的输出不受任何直接约束。作者的假设是：模型于是把可见 token 当作“寄存器”，用它们汇聚全局信息，而不是保持各自位置的局部语义。

一句话理解 V-JEPA 2.1 的核心改动只有一句话：可见 token 也要预测自己的目标表征（离掩码越近权重越大），再把这个监督施加到编码器的多个中间层上。配合图像 / 视频分用的分词器和更大的数据与模型，稠密特征从“不能用”变成接近甚至超过 DINOv3，而全局理解没有损失。

3. 组件拆解

3.1 为什么“只监督遮挡 token”会损害稠密特征

预测遮挡区域需要全局上下文，而 Transformer 很容易学会把全局信息存放在一些“无人监督”的 token 里——ViT 的寄存器（register）研究观察到过同样的现象。V-JEPA 2 中可见 token 的输出只作为预测器的输入，任何内容都不会被惩罚，于是它们的特征不再忠实于自身位置。对全局任务（动作识别、预测）这无所谓，对需要逐像素对应的任务（分割、深度、跟踪）就成了问题。

3.3 规模化与蒸馏

  • 模型：ViT-g（1B）与 ViT-G（2B）；再蒸馏出 ViT-L（300M）与 ViT-B（80M）。蒸馏时用冻结的大模型代替 EMA 目标，只在教师的最后一层上计算损失，不做深度自监督。
  • 训练日程：135,000 次迭代（视频 16 帧 256²、图像 256²），再冷却 12,000 次迭代（视频 64 帧 384²、图像 512²）。
  • 作为基础：RoboJEPA 用冻结的 V-JEPA 2.1-G 作编码器，并报告用 V-JEPA 2 时缩放规律不可预测、换成 2.1 后才可预测。

5. 训练目标与防坍塌

$$\mathcal L_\text{2.1} = \sum_{\ell=1}^{4}\Bigg[\underbrace{\frac{1}{|M|}\sum_{i\in M}\big\lVert \hat s^{\,\ell}_i - \mathrm{sg}(\bar s^{\,\ell}_i)\big\rVert_1}_{\mathcal L_\text{predict}} + \underbrace{\frac{1}{|C|}\sum_{i\in C}\frac{\lambda}{\sqrt{d_\text{min}(i, M)}}\big\lVert \hat s^{\,\ell}_i - \mathrm{sg}(\bar s^{\,\ell}_i)\big\rVert_1}_{\mathcal L_\text{ctx}}\Bigg]$$

\(\hat s^{\,\ell}\) 为预测器在第 ℓ 个层级上的输出，\(\bar s^{\,\ell}\) 为 EMA 目标编码器对应层级的特征。公式按论文 Eq. 2 与 §2.3 的描述整理（层级求和与归一化方式为本页的写法）。防坍塌与 V-JEPA 2 相同：EMA 目标 + stop-gradient + 容量有限的预测器。新增的上下文损失本身也有一点“锚定”作用：可见 token 必须与目标编码器的同位置输出一致。

6. 伪代码

vjepa21_step.py
tok = video_tokenizer(x) if is_video(x) else image_tokenizer(x)     # 3D / 2D 分词
tok = tok + modality_token[kind]
ctx_idx, msk_idx = multiblock_mask(tok.shape)
feats = context_encoder(tok[:, ctx_idx], return_layers=(a, b, c, -1))  # 4 个层级
h = fuse_mlp(cat(feats, dim=-1))
preds = predictor(h, ctx_idx, msk_idx, kind)        # [B, N, 4, D]：所有位置
with torch.no_grad():
    tgts = target_encoder(tok, return_layers=(a, b, c, -1))         # EMA，完整输入
w = lam_schedule(epoch) / sqrt(dist_to_mask(ctx_idx, msk_idx))      # 上下文损失权重
loss = l1(preds[:, msk_idx], tgts[:, msk_idx]).mean() \
     + (w[:, None] * l1(preds[:, ctx_idx], tgts[:, ctx_idx])).mean()
loss.backward(); opt.step(); ema_update(target_encoder, context_encoder)

9. 承上启下

V-JEPA 2

  • 只监督被遮挡 token；
  • 只在最后一层计算损失；
  • 图像复制成视频；
  • 全局理解强，稠密特征弱。

V-JEPA 2.1

  • 可见 token 也监督（距离加权）；
  • 4 个层级的深度自监督；
  • 图像、视频各用各的分词器；
  • 一个模型同时适合全局与稠密任务，并成为 RoboJEPA 的视觉底座。原理化一支的 LeVJEPA 则从另一个方向挑战它：去掉 EMA 与预测器，用 SIGReg 训练视频编码器。
