1. 动机：视觉里嵌入空间目标更好，语言为什么只做重建？

视觉自监督的经验是：在嵌入空间里预测（JEPA）比在输入空间里重建（MAE 式）学到的表征更抽象、更好用。而 LLM 的预训练、微调、评估全都建立在“预测下一个 token”这种输入空间的重建上。难点在于语言没有天然的“视图”：图像可以裁剪、遮挡出两个视图，一段文本该怎么造出“同一内容的另一个视图”？

一句话理解 LLM-JEPA 借用数据里天然成对的视图——自然语言描述与对应的正则表达式、问题描述与 SQL、GitHub issue 与代码改动——在保留 next-token 损失的同时，加一项：用同一个 LLM 分别编码两个视图，并让它（追加几个 [PRED] token 后）从 Text 的嵌入预测 Code 的嵌入。不需要新模块、不需要 EMA，推理时完全不变。

2. 全局架构

视图（token）LLM（编码器 = 预测器，共享权重） [PRED] token损失

3. 组件拆解

3.1 表征发生了什么：Text → Code 近似线性

论文分析了 Enc(Text) − Enc(Code) 的奇异值：LLM-JEPA 的前 100 个奇异值比基线低几个数量级。用最小二乘拟合从 Text 嵌入到 Code 嵌入的线性映射，误差为：基础模型 3953.11、普通微调 3035.01、LLM-JEPA（k = 1）4.47、（k = 0）4.04。LLM-JEPA Tab. 14 也就是说，JEPA 项让两个视图的表征之间形成了几乎线性的对应——这与视觉 JEPA 学到“可线性探测”的表征是同一种现象。

3.2 抗过拟合

论文报告：随训练继续，普通微调开始过拟合，LLM-JEPA 则保持稳定（§4.1、附录 A.5）。直观解释：嵌入空间的一致性约束是一个与任务输出无关的“结构性”正则，它限制了模型通过记忆表面形式来降低生成损失。

3.3 后续：Semantic Tube Prediction（2026-02）

LLM-JEPA 需要成对的视图，而大多数语料没有。同一作者组的 STP 提出“测地线假设”：一段 token 序列在平滑的语义流形上走的是测地线，因此局部近似直线。由此不需要第二个视图——只要求同一个序列的隐状态轨迹局部平直：

$$\mathcal L = \mathcal L_\text{NTP} + \lambda\,\mathcal L_\text{STP},\qquad \mathcal L_\text{STP} = 1 - \cos\big(h_t - h_r,\ h_r - h_s\big),\quad s < r < t\ \text{随机采样}$$

h 取末层隐状态。它把轨迹约束在测地线周围的一个“管”里，只需算一个余弦，几乎不增加开销、不需要额外前向。λ 很小（各设置最优值在 0.0025–0.04 之间，附录建议约 0.01）。在 NL-RX-SYNTH 上用 1/16 的数据即可达到普通微调用全量数据的准确率；正则生成的多样性也明显更好（“.*” 后缀 88.5% vs 普通微调 29.9%、LLM-JEPA 68.9%）。STP §3–4、Tab. 1–2、Fig. 1

5. 训练目标与防坍塌

$$\mathcal L_\text{LLM-JEPA} = \sum_{\ell=2}^{L}\mathcal L_\text{LLM}\big(\text{Text}_{1:\ell-1},\ \text{Text}_\ell\big) + \lambda\cdot d\big(\mathrm{Pred}(\mathrm{Enc}(\text{Text})),\ \mathrm{Enc}(\text{Code})\big)$$

与视觉 JEPA 不同，这里没有专门的防坍塌机制：没有 EMA、没有 stop-gradient、没有方差正则。防止所有嵌入塌成一点的，是始终存在的 next-token 损失——它要求隐状态必须保留足够的信息去生成具体的 token。作者明确把 JEPA 项定位为正则项；单独使用时模型退化。这也是后续工作（STP）同样以 \(\mathcal L_\text{NTP} + \lambda\cdot\) 正则的形式出现的原因。

6. 伪代码

llm_jepa_step.py
def llm_jepa_loss(model, text, code, k=1, lam=1.0, loss_dropout=0.0):
    ntp = model(cat(text, code), labels=mask_prompt(text, code)).loss        # 前向 ①
    if random() < loss_dropout:
        return ntp
    pred_tokens = full((len(text), k), PRED_ID)
    seq = cat(text, pred_tokens, code)                                       # 打包
    mask = block_causal([len(text) + k, len(code)])                          # 两块互相屏蔽
    h = model(seq, attn_mask=mask, output_hidden_states=True).hidden_states[-1]
    z_pred = h[:, len(text) + k - 1]                                         # 最后一个 [PRED]
    z_tgt  = h[:, -1]                                                        # Code 的末 token
    return ntp + lam * (1 - cosine_similarity(z_pred, z_tgt)).mean()         # 两边都回传

9. 承上启下

视觉 JEPA

  • 视图来自遮挡 / 裁剪；
  • 独立的预测器网络；
  • EMA 目标编码器 + stop-gradient 防坍塌；
  • JEPA 是唯一的训练目标。

LLM-JEPA

  • 视图来自数据中天然成对的表述；
  • 预测器 = 同一 LLM + [PRED] token；
  • 无 EMA，靠 next-token 损失作锚；
  • JEPA 是附加的正则项。之后的 STP 进一步去掉了“需要成对视图”的要求；VL-JEPA 则把“在嵌入空间回答”推到视觉-语言模型。
