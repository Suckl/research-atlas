1. 动机：世界模型能不能不重建像素、不要奖励、测试时再定任务？

LeCun 的构想（从头讲起）里，世界模型应当在表征空间里预测“动作的后果”，再用规划在测试时决定做什么。2024 年之前的主流世界模型（Dreamer、TD-MPC、IRIS 等）大多与在线策略学习绑在一起：需要奖励、需要与环境交互，且很多要重建像素。DINO-WM 提出三条要求：

  1. 能只用离线、预先采集的轨迹训练（不需要专家示范、不需要奖励）；
  2. 能在测试时通过优化动作来完成目标（而不是训练一个固定策略）；
  3. 是任务无关的：换目标只换一张目标图像。
一句话理解 DINO-WM 把“学表征”这件事整个外包给冻结的 DINOv2：每帧变成 196 个 patch 特征，只训练一个预测器去预测下一帧的 patch 特征。编码器不动，所以根本不存在坍塌问题；规划就是在这个特征空间里，用 CEM 搜索一串动作，让预测的最终特征尽量接近目标图像的特征。

操作类任务（推 T 形块、绳索、颗粒）需要精细的空间信息，单个全局向量（CLS）丢失太多。这也说明了后来 LeWorldModel 面对的难题：每帧只用一个向量要想够用，就必须端到端为控制任务学表征，而不能拿现成的全局特征。

3.2 冻结编码器的利与弊

好处

  • 不可能坍塌：目标固定，不需要 EMA / stop-gradient / 正则；
  • 只训练 19M 的预测器，数据需求小（每环境 1000–20000 条轨迹）；
  • 继承大规模预训练的通用视觉表征，跨形状、跨布局泛化（WallRandom 0.82 vs DreamerV3 0.76）。

代价

  • 表征不针对控制优化：与动作无关的视觉细节也要被预测；
  • 每帧约 200 个 token，规划时 rollout 很贵（LeWM 测得每次规划约 47 s，LeWM 约 1 s）；
  • 依赖一个外部大模型，世界模型的上限受制于它。

3.3 PLDM：端到端的另一条路（2025-02）

同组（NYU）的 PLDM 走了相反的方向：编码器与预测器一起训练（JEPA 式），因此必须自己防坍塌。它的问题设定也更“RL 化”：比较目标条件 RL、零样本 RL 与“潜动力学模型 + 规划”在离线、无奖励、质量参差的数据上的表现。

$$\mathcal L_\text{PLDM} = \mathcal L_\text{sim} + \alpha\,\mathcal L_\text{var} + \beta\,\mathcal L_\text{cov} + \delta\,\mathcal L_\text{time-sim} + \omega\,\mathcal L_\text{IDM}$$
  • \(\mathcal L_\text{sim}\)：预测潜变量与编码潜变量的平方距离（多步、对预测器集成求和）；
  • \(\mathcal L_\text{var}\)：hinge 惩罚，让每个维度在时间上的标准差不低于阈值（鼓励随时间变化的特征）；
  • \(\mathcal L_\text{cov}\)：惩罚协方差矩阵的非对角元（去相关）；
  • \(\mathcal L_\text{time-sim}\)：相邻时刻潜变量的平方差（时间平滑）；
  • \(\mathcal L_\text{IDM}\)：逆动力学——从相邻潜变量预测动作，迫使表征包含可控信息。

规划用 MPPI，代价 = 到目标的潜空间距离 + 预测器集成之间的方差（不确定性惩罚）。主要结论：无模型 RL 最依赖大量高质量数据；基于潜动力学的规划更省数据、对次优数据更鲁棒，并且只有 PLDM 能泛化到训练时没见过的迷宫布局（即使只用 5 张训练地图）。

两篇论文的描述不一致 PLDM 论文正文给出的是 5 项损失、4 个系数（α, β, δ, ω）；LeWorldModel 论文把 PLDM 概括为“7 项损失、6 个需要调的权重”（见 LeWM 页的对照表），可能计入了多步预测、集成等实现细节。本页以 PLDM 论文为准。无论哪种数法，结论一致：多项矩约束式的正则需要逐环境调权重，训练脆弱——这正是 SIGReg 要解决的问题。

3.4 CEM 规划演示

4. 张量形状追踪

以 Push-T 为例：batch B = 32，历史 H = 3，frameskip 5。动作维度按环境而定，记为 da（打包 5 个原始动作）。

步骤形状说明
观测（H + 1 帧）[B, 4, 3, 224, 224]最后一帧只作目标
DINOv2 patch 特征[B, 4, 196, 384]冻结，no_grad
动作 → φ[B, 3, 5·da] → [B, 3, 10]广播到每个 patch
预测器输入[B, 3·196, 384 + 10]拼接动作嵌入（有本体感知时再拼）
预测器输出[B, 3·196, 384]帧级因果，teacher forcing
目标[B, 3·196, 384]帧 2–4 的特征
规划 rollout（每轮）[N = 100, 196, 384] × T 步每条候选动作序列一份

5. 训练目标与防坍塌

$$\mathcal L_\text{DINO-WM}(\phi) = \sum_{t}\big\lVert p_\phi\big(z_{t-H+1:t},\ \varphi(a_{t-H+1:t})\big) - z_{t+1}\big\rVert_2^2,\qquad z = \mathrm{DINOv2}(o)\ \text{（冻结）}$$

防坍塌靠的不是任何正则，而是目标不可训练：编码器冻结，预测器不可能通过“把所有表征压成常数”来降低损失。这是 JEPA 家族四种防坍塌策略（见 从头讲起）中最简单的一种，V-JEPA 2-AC 的第二阶段也用了同样的办法。

6. 伪代码

dino_wm.py（训练与规划，示意）
enc = dinov2_vits14().eval().requires_grad_(False)       # 冻结
for obs, act in loader:                                   # obs: [B, H+1, 3, 224, 224]
    with torch.no_grad():
        z = enc.patch_tokens(obs)                         # [B, H+1, 196, 384]
    a = act_mlp(act)                                      # [B, H, 10]
    x = cat([z[:, :-1], a[:, :, None].expand(-1, -1, 196, -1)], -1)
    z_hat = predictor(x.flatten(1, 2), mask=frame_causal(H, 196))
    loss = ((z_hat - z[:, 1:].flatten(1, 2)) ** 2).sum(-1).mean()
    loss.backward(); opt.step(); opt.zero_grad()

def plan(o0, og, T, n=100, k=10, iters=10):               # CEM + MPC
    z0, zg = enc.patch_tokens(o0), enc.patch_tokens(og)
    mu, sigma = zeros(T, d_a), ones(T, d_a)
    for _ in range(iters):
        A = mu + sigma * randn(n, T, d_a)
        cost = ((rollout(predictor, z0, A)[:, -1] - zg) ** 2).mean((-1, -2))
        elite = A[cost.argsort()[:k]]
        mu, sigma = elite.mean(0), elite.std(0)
    return mu[:k_exec]                                    # 执行前几步后重规划

9. 承上启下

DINO-WM / PLDM 确立了

  • “离线轨迹 → 潜空间预测器 → 测试时 CEM / MPPI 规划”的范式；
  • 两种防坍塌取向：冻结现成编码器（DINO-WM） vs 端到端 + 多项矩约束（PLDM）。

之后

  • V-JEPA 2-AC：同一配方，把编码器换成自己预训练的 V-JEPA 2，上真实机械臂；
  • LeWorldModel：端到端 + 单一 SIGReg 正则，每帧 1 个向量，规划快约 48×；
  • HWM：把 DINO-WM 与 PLDM 当作低层，在上面加高层预测器做层级规划。
