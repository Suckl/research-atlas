1. 动机：视觉-语言模型为什么要逐字生成答案？

经典 VLM（LLaVA、Qwen-VL 等）把视觉特征接到 LLM 上，用 next-token 交叉熵训练：答案必须一个 token 一个 token 地写出来。这有两个代价：

  • 表面形式的方差：同一个正确答案可以有许多种措辞，token 空间的目标分布是多峰的，模型要花大量容量去拟合“怎么说”，而不只是“说什么”；
  • 推理成本：哪怕只是做分类或检索，也要跑自回归解码；对流式视频，每秒都生成描述既昂贵又冗余。
一句话理解 VL-JEPA 把 JEPA 的思想用到视觉-语言：看视频、读问题，然后预测答案文本的嵌入，而不是答案的 token。训练在抽象的嵌入空间里进行，措辞差异被目标编码器抹平；需要文字时才调用一个轻量解码器把嵌入“翻译”出来。分类、检索、判别式 VQA 直接在嵌入空间里完成，不用解码。

2. 全局架构

输入冻结 / 慢速更新的编码器预测器 目标文本编码器损失按需解码

3. 组件拆解

3.1 严格对照：嵌入空间 vs token 空间

为了排除编码器和数据的影响，作者做了一个严格对照：同一个冻结的 Perception Encoder ViT-L-14（336²、16 帧），同样的 batch（128）、学习率计划和数据；唯一的区别是训练目标——VL-JEPA 用 0.5B 的预测器预测嵌入，VLM 用 1B 的 LLM 做 next-token 生成（这就是摘要里“可训练参数少 50%”的来源）。

3.3 放回 JEPA 谱系看

与 I-JEPA / V-JEPA 的对应

x = 视觉 + 查询，y = 答案文本，z = 查询（条件变量）；预测器在嵌入空间里预测 y 的表征。不同的是：x 与 y 来自不同模态，目标编码器是一个独立的文本模型而不是上下文编码器的 EMA。

与 CLIP 类模型的区别

CLIP 对齐的是“图像 ↔ 描述”这一固定配对；VL-JEPA 的预测条件于查询——同一段视频，问不同的问题，预测不同的答案嵌入，所以能做 VQA。防坍塌同样靠对比学习的负样本。

5. 训练目标与防坍塌

$$\mathcal L = \frac12\Big[\mathrm{CE}\big(\mathrm{softmax}_j(\langle \hat s_i, s_j\rangle/\tau),\ i\big) + \mathrm{CE}\big(\mathrm{softmax}_i(\langle \hat s_i, s_j\rangle/\tau),\ j\big)\Big],\qquad \hat s = \frac{\hat S_Y}{\lVert\hat S_Y\rVert},\ s = \frac{S_Y}{\lVert S_Y\rVert}$$

预测器与 Y 编码器联合优化。防坍塌来自 InfoNCE 的“均匀性”：批内其他样本的答案嵌入是负样本，模型不能把所有嵌入压成一点。论文的原话是只有 InfoNCE 带有防坍塌正则、可以配合不冻结的 Y 编码器使用；若改用 L2 / 余弦回归，就必须冻结目标编码器（相当于 DINO-WM 式的防坍塌）。温度 τ 的取值正文未给出，公式为 InfoNCE 的标准形式。

6. 伪代码

vl_jepa_step.py
with torch.no_grad():
    v = vjepa2_vitl(video)                                # 冻结 X 编码器
q = llama_embed(query_tokens)                             # 查询词嵌入
h = predictor(cat(proj_in(v), q), causal=False)           # Llama-3.2-1B 末 8 层，双向
s_hat = normalize(head_p(masked_mean(h, ~is_pad)))        # [B, 1536]
s     = normalize(head_y(embedding_gemma(answer_tokens))) # Y 编码器：lr × 0.05
logits = s_hat @ s.T / tau
loss = (cross_entropy(logits, arange(B)) + cross_entropy(logits.T, arange(B))) / 2

# 推理：分类 = 与各类名嵌入比余弦；生成 = decoder(s_hat)（仅在需要时）

8. 关键结果

  • 零样本视频分类（8 个数据集平均 top-1）：VL-JEPABASE 52.5；PE-Core-G 44.7、SigLIP2 ViT-g 39.8、CLIP ViT-L 30.7。Tab. 1

  • VQA（VL-JEPASFT）：GQA 61.5、TallyQA 69.9、POPE 85.7、POPEv2 86.3，与 InstructBLIP、Qwen-VL 相当，而总参数只有 1.6B。Tab. 2
  • WorldPrediction-WM：BASE 63.9%、SFT 65.7%，论文称为新的最佳，并高于 GPT-4o、Claude-3.5、Gemini-2.0。Tab. 3
  • 选择性解码：解码次数减少约 2.85×，性能与均匀解码相当。§4.6

9. 承上启下

之前

  • V-JEPA 2 的视频理解靠“冻结编码器 + 接 LLM”做 VQA，仍是 token 空间的生成；
  • LLM-JEPA 证明语言模型也能从嵌入空间目标中受益，但只作为正则项。

VL-JEPA

  • 把嵌入预测变成视觉-语言模型的主训练目标，生成退化为可选的后处理；
  • 一个嵌入同时服务分类、检索、VQA、描述；
  • 流式场景里按语义变化解码，指向“持续感知、按需表达”的智能体形态。
