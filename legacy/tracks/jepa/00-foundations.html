1. 为什么需要 JEPA：预测什么、在哪里预测

自监督学习的核心是：从数据的一部分预测另一部分。关键分歧在于在哪个空间里预测。LeCun 在 2022 年的立场论文《A Path Towards Autonomous Machine Intelligence》里把自监督架构归为三类：

输入 x / y编码器目标侧编码器 预测器 / 解码器能量 / 距离 D
架构预测目标优点缺点
联合嵌入（JEA）不预测，只要求 \(s_x\approx s_y\)表征语义强依赖手工增强；要用负样本或正则防坍塌；没有“预测”能力
生成式像素 \(y\)任务定义简单，可扩展到任何模态要重建不可预测的细节；容量浪费在纹理/噪声上，表征偏底层
JEPA表征 \(s_y\)可以丢弃不可预测的细节；条件变量 z 让它能表达“如果…会怎样”平凡解（坍塌）：两边都输出常数时 D = 0
JEPA 的核心主张 好的世界模型不需要预测每个像素——人不会去预测树叶如何摆动，但能预测“球会落地”。在表征空间预测，编码器可以自己决定丢掉什么（不可预测的细节），把容量留给可预测的、抽象的结构。

2. JEPA 的形式化定义

给定一对相关输入 \((x, y)\)（同一张图的两个区域、视频的过去与未来、当前观测与动作后的观测……）：

$$s_x = \mathrm{Enc}_\theta(x),\qquad s_y = \mathrm{Enc}_{\theta'}(y),\qquad \hat s_y = \mathrm{Pred}_\phi(s_x,\ z),\qquad E(x,y) = \min_z D(\hat s_y,\ s_y)$$
  • \(\mathrm{Enc}_\theta\)、\(\mathrm{Enc}_{\theta'}\)：两个编码器，可以共享权重、可以一个是另一个的 EMA、也可以完全相同的一份（LeWM）。
  • \(z\)：潜变量 / 条件变量，携带“仅看 x 无法确定、但预测 y 需要”的信息。在 I-JEPA / V-JEPA 里它是要预测的位置；在 V-JEPA 2-AC / LeWM 里它是动作。
  • \(E(x,y)\)：能量。能量模型的视角：相容的 \((x, y)\) 能量低，不相容的能量高。训练 = 降低数据对的能量，同时防止所有对的能量都变低（见 §4）。

本路线四个模型与这组符号的对应：

模型xyz\(\mathrm{Enc}_{\theta'}\)D

3. 能量模型视角：为什么 JEPA 能处理“不确定的未来”

未来往往是多模态的：同一个 x 可以对应多个合理的 y。生成式模型要么输出模糊的平均（MSE），要么引入复杂的采样（扩散）。JEPA 用两种方式吸收不确定性：

  1. 编码器丢弃细节：如果 y 中某些信息从 x 根本无法预测（树叶的摆动方向），编码器可以学会在 \(s_y\) 中不表示它——只要防坍塌机制阻止它把所有信息都丢掉。
  2. 潜变量 z：剩下的不确定性由 z 承担。对每个 y，在 z 上取最小能量（或训练时直接把 z 当作已知条件给出，如动作）。

4. 坍塌与四类对策

JEPA 的损失 \(D(\hat s_y, s_y)\) 有一个平凡解：让编码器对任何输入都输出同一个常向量，预测器输出同一个常向量，损失恒为 0。更隐蔽的是维度坍塌——嵌入只占据一个低维子空间，信息量极低。整条研究路线的技术史，很大一部分就是“怎么防坍塌”的历史：

直觉：为什么 EMA + stop-gradient 有用 坍塌需要“两边一起塌”。stop-gradient 切断了“改变目标以迎合预测”的捷径；EMA 让目标变化得比在线分支慢得多；预测器给在线分支额外自由度去拟合目标，而不是直接改编码器。三者共同让动力学的不动点不再是常数解——但这是一个关于优化动力学的经验论断，而非对损失函数的保证。LeJEPA 把保证加回来了。

6. 路线图：接下来读什么

四个模型共享同一套骨架，改变的是三样东西：x/y 是什么（图像块 → 视频 token → 动作后的下一帧）、z 是什么（位置 → 动作）、怎么防坍塌（EMA/sg → 冻结 → SIGReg）。

建议阅读顺序：I-JEPA（把骨架看清楚）→ V-JEPA（时空 token 与掩码）→ V-JEPA 2（规模化 + 动作条件 + 规划）→ LeWorldModel（SIGReg 与端到端）。每页都有同样的结构：动机 → 架构图（可点击、可逐步讲解）→ 组件拆解 → 张量形状 → 目标函数 → 伪代码 → 超参 → 结果 → 承上启下。
