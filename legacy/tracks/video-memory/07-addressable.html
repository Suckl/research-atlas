1. 动机：存着记忆，为什么还会忘？

保留被逐出的 KV解决了“没有证据”，但“证据在库里”与“query 能读到它”仍是两回事。WorldTrace 诊断时间 RoPE 地址超出训练分布，以及对不同旋转相位直接平均造成的信号抵消；Learning to Retrieve（L2R）则研究怎样从固定形状的循环状态中，按当前相机视角读回历史。WorldTrace §2；L2R §3.2

一句话理解 WorldTrace 修复 KV 的“地址与内容坐标”；L2R 学习循环状态的“读什么、何时读”。两篇解决不同的读失败，共页比较不表示架构或权重继承。

本页沿用视频时间 \(t\)、去噪时间 \(\tau\)、latent \(x_t\)、近期窗口 \(H_t\)、动作 \(a_t\)、文本 \(c_t\)、相机 \(p_t\)、记忆 \(M_t\)、查询 \(q_t\)、读出 \(r_t\)：

$$r_t=\mathrm{Read}(M_t,q_t),\quad x_{t+1}\sim G(H_t,r_t,a_t,c_t),\quad M_{t+1}=\mathrm{Write}(M_t,x_{t+1},a_t,p_{t+1}).$$

WorldTrace 的 \(M_t\) 是 summary/recent KV，\(q_t\) 是注意力 query；L2R 的 \(M_t\) 是内部 state，camera features 调节其访问。下面用 token 索引 \(j\) 表示 L2R 的扫描顺序，用 \(g_j\) 表示 trigger，避免把论文的 token 时间与视频时间、论文的 trigger \(r_j\) 与本轨道读出 \(r_t\) 混淆。

3. 组件拆解：两种“读失败”

3.1 WorldTrace：地址超界与相位抵消

时间 RoPE 的 attention logit 含有 \(q^\top R(\iota_q-\iota_k)k\)。复制旧 key 到新 cache 位置，却不修正其旋转相位，并不会改变真实相对地址。反过来，只把远程 offset 截到上限，也可能让不同 summary 槽位拥有相同位置，失去区分。WorldTrace §2.1、Rem. 1

$$\iota_s^v=\iota_q-(L_{\mathrm{attn}}-1-s),\quad s=0,\ldots,N_s-1,\quad N_s+N_r=L_{\mathrm{attn}}.$$

此处 \(\iota\) 是视频位置索引，\(N_s,N_r\) 分别是 summary 与 recent 槽位数。虚拟位置只随当前 query 和槽位 rank 变化，历史延长不会扩大它的相对 offset。WorldTrace Def. 1

$$\bar K_s^0=\frac{1}{|\mathcal B_s|}\sum_{m\in\mathcal B_s}R(-\iota_m)\widetilde K_m,\qquad \widetilde K_s=R(\iota_s^v)\bar K_s^0,\qquad \bar V_s=\frac{1}{|\mathcal B_s|}\sum_{m\in\mathcal B_s}V_m.$$

Field 在 canonical 域平均，Landmark 相当于取单一来源，不做平均。这里简写旋转频率，原式按 RoPE frequency pair 定义。所谓平均 attention 保留，只是把来源 keys 放在同一虚拟位置后的平均 pre-softmax 分数，不是完整 attention 权重或输出的精确保真定理。WorldTrace Eq. 3–4、Rem. 2、App. C

3.2 Learning to Retrieve：从 GLA / GDN 状态中读什么、何时读

L2R没有外部历史帧 Top-k。它将部分 self-attention 替换为持久状态层，保留一部分 softmax 层处理局部空间结构。相机 Plücker 特征调制 gate \(\gamma_j\)，trigger \(g_j\) 决定何时激活这个相机条件访问。gate 是内部状态的调节算子，不是返回旧帧 ID 的可解释索引。L2R §3.2–3.3

GLA 的写入是 value–key 外积；GDN 额外用 delta correction 抑制已记住方向的旧分量。下式采用 Appendix B 的方向，\(S_j\in\mathbb R^{d_v\times d_k}\)，\(\Gamma_j\) 为门控向量的对角矩阵，\(\beta_j\) 为 GDN 写入强度：

$$S_j^{\mathrm{GLA}}=\begin{cases}\Gamma_j S_{j-1}+v_jk_j^\top,&g_j=1,\\S_{j-1}+v_jk_j^\top,&g_j=0,\end{cases}$$
$$S_j^{\mathrm{GDN}}=\begin{cases}\Gamma_j(S_{j-1}-\beta_jS_{j-1}k_jk_j^\top)+\beta_jv_jk_j^\top,&g_j=1,\\S_{j-1}+\beta_jv_jk_j^\top,&g_j=0.\end{cases}$$

trigger 关闭时仍保留既有状态并写入新 token，并不是“没有上下文”。GLA 与 GDN 的额外修正不同，不能将 L2R 归成一种通用的帧库检索。L2R Eq. 3、App. B Eq. 18–19

Re-visibility trigger：训练时离线预测深度，将旧表面反投影后用已知相机轨迹投到目标帧；曾经离开视锥或被遮挡、现在重新出现的有效 token 赋正标签。推理用学到的 trigger，无需在线显式几何库。这个监督面向静态表面再可见，离屏动态状态预测仍是开放问题。L2R Fig. 2、Eq. 5、App. D

3.3 与 VMem 的对照：显式证据与内部状态

VMem按 surfel 可见性与覆盖关系索引历史视图，生成器实际读取的是挑出的旧 views。L2R 用 recurrent state 取代外部取帧路径，减少在线几何维护，但无法直接展示“读回了哪一帧”，也有固定状态容量瓶颈。VMem §3.1–3.2；L2R §3.2、§4.4

对照实现的开销，不能当作原方法定义L2R §4.5 所测 VMem 实现每步对全部 stored frames 重建 surfel index；原 VMem §3.1 使用新生成视图与 retrieved views 联合构建 point-map，App. C 冻结旧深度并保存新深度。L2R 的耗时曲线绑定其评测实现，不能概括为 VMem 必然每步重建全部历史。

5. 训练目标：位置修复无需训练，读回策略需要监督

WorldTrace 不训练新模块；Field/Landmark 的选择规则及槽位位置直接用于推理。L2R 则把 memory layer 的 Q/K/V/output 投影从原 attention 初始化，相机依赖路径零初始化，再联合优化 target-frame flow loss 与 trigger 监督。参考帧、上下文帧不进入生成目标损失。WorldTrace §3；L2R §3.3

$$\mathcal L=\mathcal L_{\mathrm{denoise}}+\lambda_g\mathcal L_g,\qquad \mathcal L_g=\frac{1}{|\mathcal V|}\sum_{j\in\mathcal V}\mathrm{BCE}_{w_+}(\hat g_j,y_j).$$

\(\mathcal V\) 仅含有效 target tokens；默认 \(\lambda_g=0.05\)、正例权重 \(w_+=3\)。BCE 从 logits 计算，trigger 二值化不可导，其离散决策停止梯度；camera gate 与生成主干由联合目标训练。L2R Eq. 5–6

训练用几何构造监督与推理在线维护几何是不同成本条件。L2R 省去外部 retrieval pathway，但训练数据仍需要相机轨迹与离线深度标签；“无显式 3D 推理条件”不意味着训练不需要几何。L2R Fig. 2、§3.2

# L2R: alternative token-level memory block, not a WorldTrace successor
# S is supplied by the model's state protocol for this forward pass.
for j, token in enumerate(tokens_in_scan_order):
    k, v, query = project(token)

9. 承上启下

保存与读取之间的缺口

  • KV 归档 / archive扩大可供读取的历史，位置与噪声条件仍可能失配。
  • 循环记忆用固定状态压缩历史，但容量存在不等于查询知道如何读取。

读失败需要分别验证

  • WorldTrace：固定内容 writer、改变位置，再固定位置、改变 writer，分开检验地址与内容。§4.2–4.4
  • L2R：camera gate、trigger 与 re-visibility 监督逐项消融。与 VMem是主要 baseline 对照，非权重继承。Tab. 1、Tab. 3
  • 帧库与空间查询让取回的证据可检查；离屏动态状态还要求正确更新。

简答题

Q13旧 KV 明明还在，为何读不出？只缩短 RoPE 距离或只在 canonical 空间平均，各有什么不足？

旧 key 的相对时间旋转可能超出训练分布；直接平均不同时间旋转过的 key 又会抵消内容信号。只截短距离可能让多个远程摘要共用同一地址；只做 canonical 平均则仍可能把保真的摘要放到不可读的位置。WorldTrace 同时用 canonical writer 和按槽位 rank 分配的训练范围内位置。

  • 比较时固定缓存内容改变地址，才能隔离地址贡献。
  • Field 的平均 pre-softmax 分数保留不等于完整 attention 输出无损。
  • Landmark 保留关键帧细节，但容量满后仍会删事件。

依据：WorldTrace §2、Def. 1–2、Rem. 1–2、§3.4、Tab. 1。

Q14L2R 的 camera gate 与 re-visibility trigger 各决定什么？为什么不能把它理解成 VMem 的帧检索或 WorldTrace 的后继？

camera gate 决定内部状态哪些方向被访问，trigger 决定何时启用这个访问，并由旧表面重新可见的标签训练。VMem 则用几何索引取回具体历史视图，WorldTrace 修复 KV 虚拟位置。三者的保存对象、查询返回物和监督都不同；论文没有给出 WorldTrace 到 L2R 的继承关系。

  • trigger 关闭仍保留、更新状态，不表示完全丢弃历史。
  • GLA / GDN 固定矩阵没有旧帧地址；干扰、覆盖不能靠地址重编号恢复。
  • 离线深度监督与推理无外部几何读取可以同时成立，二者的信息成本应分别报告。

依据：L2R §3.2–3.3、App. B–D；VMem §3.1；WorldTrace §3。
