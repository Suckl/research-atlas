1. 动机：全序列扩散的三个短板

BD3-LM 的论文开头列出了离散扩散的三个限制：① 只能生成固定长度，聊天这类场景需要任意长度；② 双向注意力使已算过的东西无法用 KV cache 复用；③ 困惑度仍落后于 ARBD3-LM §1。MDLM 已经把掩码扩散的目标化简为加权 MLM，但这三点都没有改变。

BD3-LM 的办法是把序列切成块：块与块之间按 AR 分解，块内用离散扩散建模。于是块间有精确 KV cache、可以一直往后生成；块内仍可并行采样。块长从 1 到整条序列，正好在 AR 与 MDLM 之间插值BD3-LM §3。Eso-LM（同一研究组，2025-06）走另一条路：不切块，而是让掩码扩散的去噪器本身使用因果注意力，从而在全序列并行的同时获得精确 KV cache 与精确似然Eso-LM 摘要。

一句话理解 BD3-LM：\(\log p(x)=\sum_b\log p(x^b\mid x^{\lt b})\)，每个条件项都是一个小型掩码扩散；块长是旋钮，1 对应 AR，\(L\) 对应 MDLM。它额外发现，即使块长为 1、目标期望上等于 AR，扩散目标仍因梯度方差大而训练得更差，于是用“裁剪”的掩码率分布来降低方差。

记号：本页统一用 \(B\) 表示块长、\(L/B\) 表示块数。BD3-LM 论文把块长记作 \(L'\)、块数记作 \(B\)，正好与本轨道相反；它与 Eso-LM 都用 \(\alpha_t\) 表示保留概率（掩码率为 \(1-\alpha_t\)），Eso-LM 把带掩码的序列记作 \(z_t\)、干净序列记作 \(x\)BD3-LM §3.1；Eso-LM §2。

3. 组件拆解

3.1 块长：从 AR 到全序列扩散的旋钮

B = 1 时，每块只有一个 token，扩散目标在期望上等于 AR 的 NLL；B = L 时就是 MDLM。论文证明 NELBO 随块长单调变松：\(-\log p(x)\le\mathcal L_{B}\le\mathcal L_{B+1}\)BD3-LM App. B.4–B.5。在 LM1B 与 OWT 上，块越小困惑度越好，越接近 AR；但块越小，每步能并行的 token 越少，生成越接近逐 token 串行BD3-LM Tab. 3–4、§7 Limitations。所以 B 同时决定三件事：似然界的松紧、每步最多定稿多少 token、多大比例的上下文能用精确 KV cache。

3.2 B = 1 仍比 AR 差：梯度方差

在 LM1B 上训练 16B tokens，AR 的困惑度为 22.88，B = 1 的 BD3-LM 为 ≤ 25.56，尽管二者目标在期望上相同BD3-LM Tab. 1。原因在于：线性调度下每个 token 平均只有一半时间被掩码，扩散目标相当于用一半的 token 估计梯度，表现与“随机 batch 大小”的 AR（24.37）相近。把 B = 1 的调度改为“总是全掩码”，目标就与 AR 完全一致，困惑度回到 22.88；训练 328M tokens 后测得损失方差从 1.52 降到 0.11BD3-LM §4.2、Fig. 2。对 B > 1，作者提出裁剪调度 \(1-\alpha_t\sim\mathrm U[\beta,\omega]\)，并发现每个块长都有自己最优的区间：B = 4 偏好重掩码，B = 16 偏好轻掩码BD3-LM §5、Tab. 2、Tab. 8。

论文 vs 官方代码论文写作把 \(t\) 线性映射到掩码率 \(\beta+(\omega-\beta)t\)，权重为 \(-\alpha_t'/(1-\alpha_t)\)。官方代码中，log-linear 调度的损失权重为 −1 / 掩码率（乘在 \(\log p\) 上），并且 ① 若某块实际掩码比例落在 [β, ω] 之外就重采样该块；② 当 \(\beta>0.5\) 时把权重直接设为常数 −1。复现时以代码为准。BD3-LM App. C.4；diffusion.py 中 _sample_t、_resample_q_xt、_forward_pass_diffusion

3.3 KV cache 与可变长度

推理时一次采样一块：当前块在已缓存的 K/V 条件下去噪 \(T'\) 步，定稿后再前向一次写入 K/VBD3-LM Alg. 2。这里的缓存是精确的：前面各块不会再变，且训练时它们本就以干净形式、块因果地被编码，与推理一致。但块内的扩散步骤没有缓存，每步都要重算整块。块的数量不受训练上下文限制，OWT 上能生成到 9982 tokenBD3-LM Tab. 6。论文的采样沿用 MDLM 的缓存技巧：已解码的 token 不会被重新掩码，因此 NFE 不超过生成长度；生成困惑度用 \(T=5\mathrm K\) 步、nucleus \(p=0.9\)、64 位 Gumbel 与 first-hitting 采样器BD3-LM App. C.5。

3.4 Eso-LM：让掩码扩散使用因果注意力

Eso-LM 把生成拆成两段：MDM 阶段并行生成一个部分掩码的序列 \(z_0\)，期望比例为 \(\alpha_0\)；AR 阶段再从左到右填完剩下的 [M]。\(\alpha_0=1\) 是纯 MDM，\(\alpha_0=0\) 是纯 AR，插值的旋钮是“由扩散生成的 token 比例”，而不是块长Eso-LM §3.1、式 (6)(7)。

关键在注意力。掩码扩散等价于对随机顺序做 AR：只要按去噪顺序把输入重排成“干净 token 在前、待去噪的 [M] 在后”，再用普通因果注意力，那么已经定稿的 token 就不依赖之后才去噪的 token，它们的 K/V 便可以一直缓存Eso-LM §3.2、§4.1.1。采样前先预计算整个去噪调度 \(\mathcal S\)；第 k 步只前向“上一步刚定稿的 token + 本步要去噪的 [M]”，其余从缓存读取。新定稿的 token 要到下一步才写入缓存，因此有一步的延迟Eso-LM §4.2、§6 KV Caching。

同样的因果结构让任意顺序 NELBO \(\mathcal L_{\text{AO}}\) 只需一次前向即可估计（一个排列对应一整条扩散轨迹），再取 K 个排列构造重要性加权界，就得到随 K 增大而收敛的精确似然：\(-\log p_\theta(x)\le\mathcal L^K_{\text{AO}}\le\mathcal L_{\text{MDM}}\)Eso-LM §3.3、定理 3.1。在一条 OWT 序列上重复 100 次，\(\mathcal L_{\text{MDM}}\)（每次 10 个 MC 样本）的标准差为 0.56，\(\mathcal L_{\text{AO}}\)（每次 1 个排列）为 0.03Eso-LM Tab. 2。

版本与对照协议本页读的是 Eso-LM v5（2026-08，ICML 2026 camera ready），早期版本的数字与变体可能不同。Eso-LM 表中的 BD3-LM OWT 困惑度（B = 16 / 8 / 4：23.57 / 22.04 / 20.96）是作者用 250K 步从头重训得到的；BD3-LM 原文的 22.27 / 21.68 / 20.73 则是从 MDLM 微调、共 524B tokens 的结果。两组数字不能混用。Eso-LM Tab. 1、App. C.3；BD3-LM Tab. 4、App. C.3

5. 训练目标与似然

BD3-LM 对每个块应用 MDLM 的简化 NELBO 并求和（\(\alpha_t'\lt 0\)，所以每一项都是正的）：

$$-\log p_\theta(x)\le\mathcal L_{\text{BD}}(x;\theta)=\sum_{b=1}^{L/B}\mathbb E_{t\sim\mathrm U[0,1]}\,\mathbb E_{q}\,\frac{\alpha_t'}{1-\alpha_t}\log p_\theta\big(x^b\mid x_t^b,x^{\lt b}\big).$$

NELBO 本身与调度无关，但它的 MC 估计及梯度的方差依赖调度，所以作者用 \(\min_{\beta,\omega}\mathrm{Var}_{X,t}[\mathcal L(X;\theta,\beta,\omega)]\) 来选调度；评测时仍按均匀掩码率报告似然BD3-LM §4.3、§5.3、§6。Eso-LM 的混合界：

$$-\log p_\theta(x)\le\mathbb E_{z_0\sim q_0}\Big[-\!\!\sum_{\ell\in\mathcal M(z_0)}\!\!\log p_\theta\big(x^\ell\mid z_0\odot x^{\lt\ell}\big)\Big]+\mathbb E_{t,z_t}\Big[\frac{\alpha_t'}{1-\alpha_t}\sum_{\ell\in\mathcal M(z_t)}\log p_\theta(x^\ell\mid z_t)\Big],\quad \alpha_t=\alpha_0(1-t).$$

第一项是 AR 阶段的交叉熵（\(z_0\odot x^{\lt\ell}\) 表示把 \(z_0\) 的前 \(\ell-1\) 个位置换成干净 token），第二项是 MDM 阶段的 NELBO。纯扩散训练（\(\alpha_0=1\)）时，作者把系数 \(\alpha_t'/(1-\alpha_t)\) 换成常数 −1，以降低方差Eso-LM 式 (7)、§5.1。精确似然用 K 个随机排列的重要性加权界，LM1B 取 K = 5000，OWT 取 K = 1000Eso-LM 定理 3.1、§5.1。

6. 伪代码

bd3lm_step.py（训练依据 Alg. 1 + 官方代码；采样依据 Alg. 2）
def train_step(model, x, B, beta, omega):              # x: [K, L] 干净 token
    K, L = x.shape
    nb = L // B
    u = low_discrepancy_uniform(K, nb)                  # 每块一个时间
    rate = (beta + (omega - beta) * u).repeat_interleave(B, dim=1)   # 掩码率 [K, L]
    x_t = where(rand(K, L) < rate, MASK, x)
    x_t = resample_blocks_outside(x_t, beta, omega)     # 官方代码：实际比例越界的块重采样
    inp = cat([x_t, x], dim=1)                          # [K, 2L]
    pos = cat([arange(L), arange(L)])                   # 两半共享位置
    logits = model(inp, pos, mask=block_diff_mask(L, B))[:, :L]   # 只取噪声半边
    logp = log_softmax(logits).gather(-1, x[..., None]).squeeze(-1)
    w = 1.0 / rate                                      # log-linear 调度：-α'/(1-α) = 1/掩码率
    if beta > 0.5:
        w = ones_like(w)                                # 官方代码：重掩码区间用常数权重
    loss = -(w * logp * (x_t == MASK)).sum() / K
    loss.backward()

def block_diff_mask(L, B):                              # True = 允许注意
    def allow(q, k):
        qc, kc = q >= L, k >= L                         # 是否属于干净半边
        bq, bk = (q % L) // B, (k % L) // B
        if not qc and not kc: return bq == bk           # M_BD：噪声块内部
        if not qc and kc:     return bk < bq            # M_OBC：看前面的干净块
        if qc and kc:         return bk <= bq           # M_BC：干净半边块因果
        return False                                    # 干净 -> 噪声：屏蔽
    return [[allow(q, k) for k in range(2 * L)] for q in range(2 * L)]

def sample(model, B, T_block, max_blocks):
    out, cache = [], KVCache()
    for b in range(max_blocks):
        blk = [MASK] * B
        for s in reversed(range(1, T_block + 1)):       # 块内去噪，已解码的不再掩码
            logits = model(blk, cache=cache)
            blk = mdlm_ancestral_update(blk, logits, s / T_block, (s - 1) / T_block)
        cache.append(model.encode_kv(blk))              # 定稿后一次前向写 K/V
        out += blk
        if EOS in blk or mean_entropy(out[-256:]) < 4:  # 变长停止条件
            break
    return out

9. 承上启下

解决了什么

  • 相对 MDLM：获得变长生成与跨块的精确 KV cache，困惑度也更好（部分来自优化后的调度，作者称这一改进同样可用于 MDLM）。
  • 相对 SSD-LM 等高斯块扩散：有可计算的似然上界，NFE 少一个数量级。
  • Eso-LM 进一步让块内（乃至全序列）也有缓存，并首次给出 MDM 的精确似然。

留下的问题 → 下一步

  • 两者都只在 110M 规模、无条件生成上验证。把块扩散用到大模型的主流做法是从 AR 权重转换：SDAR、Fast-dLLM v2、WeDLM（WeDLM 也用因果注意力），以及 LLaDA2.0 的块长 WSD。
  • 块扩散天然适合给 AR 当草稿器或与 AR 共享一个模型：TiDAR、Nemotron-Labs-Diffusion、DFlash。
  • 块小时并行解码相邻 token 容易冲突（Eso-LM §5.2）；阈值类并行解码与缓存技巧见 KV cache 页。

简答题

Q21为什么说块长 B 是从 AR 到全序列扩散的旋钮？B = 1 时 BD3-LM 在期望上等价于 AR，为什么实测困惑度仍更差，裁剪调度又如何补上差距？

块分解 \(\log p(x)=\sum_b\log p(x^b\mid x^{\lt b})\) 中，B = 1 时每个条件项就是 next-token 预测，B = L 时只剩一个块，即 MDLM。B 越大，块内并行度越高，但 NELBO 越松，可用精确 KV 的上下文比例越小。B = 1 时目标虽在期望上与 AR 相同，但线性调度让每个 token 平均只有一半时间被掩码、参与损失，梯度估计的方差明显更大，困惑度为 ≤ 25.56，AR 为 22.88。

  • 把 B = 1 的调度改为“总是全掩码”，目标就与 AR 一模一样：困惑度回到 22.88，损失方差从 1.52 降到 0.11。
  • B > 1 时用 \(1-\alpha_t\sim\mathrm U[\beta,\omega]\) 去掉极端掩码率，并周期性地按 NELBO 方差网格搜索 β, ω：B = 4 时 U[0.45, 0.95] 的困惑度 29.21，优于线性的 30.18。
  • NELBO 与调度无关，但它的 MC 估计方差与调度有关；裁剪调度改变的是优化，而不是目标本身。
  • 块长不同，最优区间也不同（小块偏好重掩码），所以每个 B 需要单独调。

依据：BD3-LM §4.2–5.3、Tab. 1、Tab. 2、Tab. 8、App. B.4–B.5。

Q22BD3-LM 与 Eso-LM 都声称支持 KV cache——二者缓存的粒度有何不同？Eso-LM 为什么能给出精确似然，代价是什么？

BD3-LM 只缓存已定稿的块；块内每个去噪步都要重算整块，因为块内是双向注意力。Eso-LM 把输入按去噪顺序重排（干净在前、待去噪在后）后用因果注意力，已定稿 token 不再依赖之后的 token，所以每个 token 的 K/V 在定稿后的下一步写入缓存，并且之后保持不变。因果结构也让一个排列就对应一整条扩散轨迹的 AR 分解，一次前向就能得到 \(\mathcal L_{\text{AO}}\)；对 K 个排列做重要性加权，界随 K 增大收敛到 \(-\log p_\theta(x)\)。

  • 速度（A6000、batch 1、NFE = L）：L = 8192 时 Eso-LM 82.1 s，BD3-LM B = 16 为 268.1 s，MDLM 为 5438.3 s，AR 为 54.0 s。
  • 代价一：干净 token 之间也只用因果注意力，\(\alpha_0=1\) 时 NELBO 困惑度比 MDLM 差约 4（LM1B 36.12 对 31.78）。消融中只把 [M] 改成因果的变体能追平 MDLM，但失去了扩散阶段的缓存。
  • 代价二：\(\alpha_0\lt 1\) 时序列阶段要用 2L 的输入，训练慢 1.37 倍；缓存延迟一步，同 NFE 下略慢于 AR。
  • 代价三：精确似然需要 K 次前向（K = 1000–5000）；对标准 MDM 而言同一个界需要 K × L 次前向，一般不可行。

依据：BD3-LM Alg. 2；Eso-LM §3.2–3.3、§4、§5.1、§5.3、§6、Tab. 1–2、Tab. 11。
