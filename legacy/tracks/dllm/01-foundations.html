1. 动机：为什么要离开从左到右

自回归（AR）模型按链式法则 \(p_\theta(x_0)=\prod_{i=1}^{L}p_\theta(x_0^i\mid x_0^{<i})\) 逐个生成：每次前向只产出一个 token。DiffusionGemma 技术报告把它的代价说得很直白：大批量服务时可以靠合批拿到吞吐，但单请求或低并发时解码是访存受限的，搬运权重与 KV cache 的时间远多于计算，算力闲置；投机解码在草稿长度 8 时大约每次前向得到 3–6 个 tokenDiffusionGemma §1（3–6 TPF 引自 Li et al. 2026）。

扩散语言模型（dLLM）换了一种生成方式：先放一张长度为 \(L\) 的画布，全部是噪声（最常见是掩码 \([\mathrm{M}]\)），再反复调用同一个去噪网络，每次前向看整张画布、给每个位置一个预测，挑一部分定稿。它带来三个卖点：并行（一次前向可以定稿多个 token）、双向（能看见右侧上下文，天然支持填空）、可修改（部分噪声族允许改写已写的 token）。也带来三笔代价：没有精确似然（只能优化与报告上界）、没有现成的 KV cache（画布每步都在变，LLaDA 明说它与 KV caching 不兼容LLaDA §2.2）、以及并行采样带来的因子分解误差（同一步内各位置独立采样，只匹配边缘分布）。本 track 的 19 页都可以看成在这六项之间重新做交易。

一句话理解 掩码扩散 = “随机比例的 BERT 式填空”训练 + “每次填一部分”的迭代解码。训练目标几乎和 MLM 一样简单；难点全部转移到了解码：每一步填哪些、填几个、能不能改。

本 track 的统一符号：干净序列 \(x_0\)，长度 \(L\)；腐蚀后的画布 \(x_t\)，\(t\in[0,1]\)，\(t=1\) 表示完全腐蚀；掩码 token \([\mathrm{M}]\)；去噪网络给出逐位分布 \(p_\theta(x_0^i\mid x_t)\)；块长 \(B\)；采样步数 / 网络前向次数 NFE 记作 \(N\)；每次前向定稿的 token 数 TPF；置信度阈值 \(\tau\)；prompt（条件）\(c\)。MDLM 用保留概率 \(\alpha_t=1-t\)，SEDD/RADD 用累计噪声 \(\bar\sigma(t)\)（掩码概率 \(1-e^{-\bar\sigma(t)}\)），D3PM 用离散步 \(t\in\{1,\dots,T\}\)；各页遇到时会换算MDLM §3.4；SEDD 附录 C.1；RADD §3.3；D3PM §3。

3.1 前向过程三族：每一步画布长什么样

3.2 采样器：谁先定稿、一次定几个

祖先采样：从 \(t\) 走到 \(s<t\) 时，每个被掩位置以概率 \((t-s)/t\) 揭开并从 \(p_\theta(x_0^i\mid x_t)\) 采样，否则保持 \([\mathrm{M}]\)LLaDA 附录 A Eq. (10)；MDLM §4.1。由于网络不看 \(t\)，画布没变时可以直接复用上一次输出（MDLM、RADD 的缓存）；Zheng 等进一步证明可以先解析采样“下一个揭开的时刻”，每次只揭一个，等价于原过程，称为 first-hitting samplerMDLM §4.1；2409.02908 §4.2。

按置信度选位置：LLaDA 每步预测全部被掩位置，只保留置信度最高的一部分、其余重新掩上（low-confidence remasking），在其消融里一致优于随机选位置LLaDA §2.4、附录 B.4 Tab. 9；Token Ordering 比较了最大概率与前两名之差（margin），后者在多个候选接近时更可靠Token Ordering §4.1；Dream 的代码提供 maskgit_plus（最大概率）、topk_margin、entropy 三种选位置方式Dream README alg。阈值法不再固定每步个数：Fast-dLLM 把置信度 \(\ge\tau\) 的位置全部定稿，若没有则至少定稿最高的一个，默认 \(\tau=0.9\)Fast-dLLM §3.3、§4.1；EB-Sampler 按熵排序累加，直到误差上界触及容差EB-Sampler 摘要。

重掩与编辑：ReMDM 允许把已定稿 token 重新掩上，从而在推理时多花计算换质量ReMDM 摘要；均匀噪声的 DiffusionGemma 在每步把未接受位置重新换成均匀随机 tokenDiffusionGemma §3.3「Entropy-bounded token refinement」；LLaDA2.1 的 T2T 编辑见 09 页。半自回归块：把画布切成长度 \(B\) 的块，块间左到右、块内扩散。SSD-LM 最早采用逐块生成SSD-LM 摘要；LLaDA 不重训即可这样采样：其指令模型用块长 32 的半自回归采样时 GSM8K 为 77.5、块长 8 时 78.6，高于纯扩散采样的 69.4，原因是减轻了 SFT 数据中大量 EOS 填充造成的提前收尾LLaDA §3.2 末段、附录 B.4 Tab. 8；把块结构写进训练就是 BD3-LM。

NFE 与 TPF：NFE 是整张画布（加 prompt）的网络前向次数；TPF = 生成 token 数 / NFE。二者必须成对报告：同一模型换阈值就能换 TPF，而每次前向的代价随画布长度和是否有缓存变化，TPF 高不等于墙钟快（第 8 节）。

交互里的“模型”是精确条件分布，P(无效) 由递归枚举采样器的全部随机结果精确算出组件 assets/js/widgets/dllmdecode.js：exact、select。在这张 16 位画布上：固定步数 \(N=16\)（TPF 1）时 P(无效) = 0；\(N=8\)（TPF 2）时 16.98%；\(N=4\) 时 92.79%。阈值法 \(\tau=0.4\) 时 P(无效) 仍为 0、平均 NFE 仅 3.00，而 \(\tau=0.35\) 跳到 16.98%、\(\tau=0.3\) 为 68.99%（以上为组件精确计算值，玩具分布，不代表真实模型）。原因是 9 个固定词置信度为 1，可以“免费”一起定稿；代价只发生在相关位置被挤进同一步时。

3.3 因子分解误差：两个 token 的例子

设某处只可能是 “New York” 或 “San Diego”，各 1/2。两个位置的边缘分布都是 1/2 对 1/2，而且任何一个位置单看都无法提高置信度。若同一步从边缘分布独立采样：

$$q_{\mathrm{par}}(x^1,x^2)=p(x^1)\,p(x^2)\;\Rightarrow\;P(\text{New Diego})+P(\text{San York})=\tfrac14+\tfrac14=\tfrac12 .$$

即使网络完美，也有一半概率生成不存在的城市；先定稿一个、再条件采样另一个则完全正确。一般地，一步并行解码集合 \(S\) 的最小 KL 下界是条件全相关 \(\mathcal C(X_S\mid x_t)=\sum_{i\in S}H(X_i\mid x_t)-H(X_S\mid x_t)\)（本例为 \(\ln 2\)）；ParallelBench 把它推广到 \(T\) 步，并证明下界随步数减少单调增大ParallelBench §4 Theorem 1–2（一步情形引 Huang et al. 2022）。这个例子说明三件事：

  • 误差来自相关性，不是不确定性。独立的位置（交互里的日期、座位）置信度再低，同时定稿也不出错；高度相关的位置即使模型完美也会出错。
  • 置信度阈值是间接防线。Fast-dLLM 证明：若 \(n\) 个位置的边缘置信度都 \(>1-\epsilon\) 且 \((n+1)\epsilon\le1\)，贪心并行解码与联合分布的 argmax 一致Fast-dLLM §3.3 Theorem 1；但它看的是单点置信度，ParallelBench 发现阈值类方法无法按任务难度自适应地调整并行度ParallelBench 摘要。
  • 度量决定结论。Feng 等证明：以困惑度（逐 token 误差）为目标时，掩码扩散的步数可以与长度无关；以序列错误率为目标时，最坏情况下步数必须随长度线性增长2502.09622 §4 Theorem 4.2、4.4。2609.20539 用对偶全相关刻画三类扩散所需的前向次数，并证明在一类分布上均匀 / 高斯扩散只需 \(\widetilde\Theta(\sqrt d)\) 次，而掩码扩散存在需要 \(\widetilde\Omega(d)\) 次的近似打分器2609.20539 摘要、§1。

5. 训练目标与似然

5.1 掩码扩散 ELBO = 1/t 加权的 MLM 交叉熵

前向过程逐位独立：\(q(x_t^i=[\mathrm{M}]\mid x_0^i)=t\)，\(q(x_t^i=x_0^i\mid x_0^i)=1-t\)。MDLM 与 MD4 同期证明，连续时间负 ELBO 化简为掩码位置交叉熵对时间的加权积分MDLM §3.4–3.5 Eq. (12)–(13)；MD4 §3 Eq. (4)：

$$\mathcal L_{\mathrm{NELBO}}=\int_0^1\frac{\alpha_t'}{1-\alpha_t}\,\mathbb E_{q}\sum_{i=1}^{L}\log p_\theta(x_0^i\mid x_t)\,\mathrm dt,\qquad \alpha_t=1-t\;\Rightarrow\;\frac{\alpha_t'}{1-\alpha_t}=-\frac1t .$$

未掩位置的 \(\log p_\theta\) 恒为 0（网络直接复制，MDLM 称 carry-over unmasking），于是得到 LLaDA 的训练目标MDLM §3.2.3；LLaDA Eq. (3)–(4)：

$$-\mathbb E_{p_{\mathrm{data}}}\log p_\theta(x_0)\;\le\;\mathcal L(\theta)=-\,\mathbb E_{t,x_0,x_t}\Big[\frac1t\sum_{i=1}^{L}\mathbf 1\big[x_t^i=[\mathrm{M}]\big]\log p_\theta(x_0^i\mid x_t)\Big].$$

直观上，\(t\) 小时被掩的 token 少、每个都很好猜，乘 \(1/t\) 把它们放大；BERT 的固定比例与 MaskGIT 的无权重目标都缺这一项，因而不是似然的界LLaDA §2.1。

5.2 为什么网络可以不看 t

对被掩位置 \(i\)，真实后验只依赖未被掩的 token \(x_t^{\mathrm{UM}}\)：它们就是 \(x_0\) 的对应位置；给定“哪些位置被掩”之后，\(t\) 不再携带关于 \(x_0^i\) 的任何信息。所以

$$p\big(x_0^i\mid x_t\big)=p_{\mathrm{data}}\big(x_0^i\mid x_t^{\mathrm{UM}}\big),\qquad x_t^i=[\mathrm{M}] .$$

RADD 从 SEDD 的 concrete score 出发给出这一结论（score = 条件概率 × 解析的时间因子），LLaDA 附录直接引用它说明“\(t\) 不必作为输入”RADD §3.1 Theorem 1；LLaDA 附录 A.1 Eq. (11)；MDLM 的消融也发现有无时间条件困惑度相近MDLM §5.1 Tab. 12。完整推导与“输出可缓存”的推论见 02 页。

5.3 蒙特卡洛估计与方差

上式要对 \(t\) 和掩码取期望，单样本估计方差大。LLaDA 评估条件似然时改用一个等价但方差更低的形式：先均匀抽被掩个数 \(l\in\{1,\dots,L\}\)，再无放回地掩 \(l\) 个LLaDA §2.4 Eq. (6)：

$$-\,\mathbb E_{l,\,r_l}\Big[\frac{L}{l}\sum_{i=1}^{L}\mathbf 1\big[r_l^i=[\mathrm{M}]\big]\log p_\theta(r_0^i\mid c,r_l)\Big].$$

这个方差在偏好优化与 RL 里会被放大，因为要估计两个似然之差；LLaDA 1.5 的 VRPO 给出最优 MC 预算分配与对偶采样LLaDA 1.5 摘要，见 17 页。

似然与评测口径
  • ELBO 只是上界。扩散模型报告的困惑度都带“≤”，AR 是精确值SEDD Tab. 3 注；不同前向过程的界松紧不同，跨族比较困惑度会误导Beyond-Masked 摘要。
  • 生成困惑度必须与熵一起看。fp32 下 Gumbel 采样被截断，等价于降低有效温度：RADD 复测 SEDD-medium 4096 步，fp64 时生成困惑度 81、熵 8.07，fp32 时变成 22、熵 7.252409.02908 §5.2；RADD 附录 J.4 Tab. 3–4。生成困惑度与熵是对参考分布 KL 的两部分Generative Frontiers 摘要；仅调采样器锐化，旧 MDLM 16 步即可在生成困惑度上胜过自己 1024 步2609.33947 摘要。
  • 选择题怎么打分会改变分数。LLaDA 用 Eq. (6) 的 MC 似然；iLLaDA 改用基于置信度的打分LLaDA §2.4；iLLaDA 摘要。比较前先对齐。

def train_step(model, x0, c):                    # x0: [b, L] 干净 token；c: prompt
    b, L = x0.shape
    t = rand(b, 1).clamp(min=1e-3)                # 每条序列一个掩码比例
    masked = rand(b, L) < t                       # 逐位独立掩码
    xt = where(masked, MASK_ID, x0)
    logits = model(cat(c, xt))[:, -L:]            # 双向注意力；不输入 t
    nll = cross_entropy(logits, x0, reduce=False) # [b, L]
    return ((nll * masked) / t).sum(1).mean() / L # 1/t 加权 → NLL 上界

def decode(model, c, L, mode="threshold", N=L, tau=0.9, B=None):
    B = B or L                                    # B == L：全序列；B < L：半自回归块
    x, nfe = full(L, MASK_ID), 0
    for start in range(0, L, B):
        blk = list(range(start, start + B))
        budget = split_evenly(B, max(1, N * B // L))   # steps 模式：块内每步定几个
        while any(x[i] == MASK_ID for i in blk):
            p = softmax(model(cat(c, x))[-L:])    # 一次前向 = 1 NFE
            nfe += 1
            cand = [i for i in blk if x[i] == MASK_ID]
            conf = {i: p[i].max() for i in cand}  # 也可用 margin 或 -entropy
            order = sorted(cand, key=lambda i: -conf[i])
            if mode == "threshold":
                pick = [i for i in order if conf[i] >= tau] or order[:1]
            else:
                pick = order[:budget.pop(0)]      # LLaDA：其余“重新掩上”
            for i in pick:                        # 同一步内独立采样
                x[i] = sample(p[i])               # 或 argmax（贪心）
    return x, L / nfe                             # 返回 TPF

简答题

Q1掩码扩散的训练目标为什么能写成按 1/t 加权的 MLM 交叉熵？网络为什么可以不输入 t，这对采样有什么好处？

吸收态前向逐位独立，连续时间负 ELBO 化简为“被掩位置交叉熵 × \(\alpha_t'/(1-\alpha_t)\)”对时间的积分，线性调度下权重就是 \(1/t\)，未掩位置贡献为 0。被掩位置的真实后验只依赖未掩 token（它们就是 \(x_0\)），与 \(t\) 无关，所以去掉时间输入不损失表达力；画布不变时输出可直接复用，NFE 上限变为生成长度。

  • 去掉 \(1/t\)（固定比例或 MaskGIT 式）就不再是似然的界。
  • RADD 从 concrete score 推出“条件概率 × 时间因子”，LLaDA 据此不输入 \(t\)。
  • 缓存只在“本步没有新 token 揭开”时成立；与 KV cache 是两回事。

依据：MDLM §3.4 Eq. (13)；MD4 Eq. (4)；LLaDA Eq. (3)–(4)、附录 A.1；RADD §3.1–3.2。

Q2同一步并行定稿多个位置时误差从哪里来？为什么提高阈值或改用块解码只能缓解，这与 TPF 和墙钟加速是什么关系？

一步内各位置从边缘分布独立采样，丢掉了它们之间的相关性；即使网络完美，误差下界也是这些位置的条件全相关。阈值看的是单点置信度，块看的是位置，二者都不直接度量相关性，只能降低“相关位置被挤进同一步”的概率；代价是 TPF 下降。TPF 高也不等于墙钟快，还要看每次前向的代价、缓存和 batch。

  • 两 token 例子：New York / San Diego 各 1/2，同步采样一半无效。
  • 交互：\(\tau\) 从 0.4 降到 0.35，P(无效) 从 0 跳到 16.98%；块内固定步数还可能把相关对强行挤在一起。
  • 以序列正确率为目标，最坏情况步数随长度线性增长。

依据：ParallelBench §4 Theorem 1–2；Fast-dLLM Theorem 1；2502.09622 Theorem 4.4；How Efficient 摘要；本页交互组件精确计算。
