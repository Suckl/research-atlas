1. 动机：既然 AR 模型已经训好了

LLaDA 证明了从零训练的路线可行，但代价是 2.3T token、0.13M H800 GPU 小时；SMDM 还给出“同验证损失约需 16 倍计算”的估计。另一方面，开源社区已经花巨资训好了大量 AR 模型。DiffuLLaMA（2024-10）的问题是：能否只做一段继续预训练，就把 AR 权重变成扩散模型？难点在于两者有两处结构性不匹配——AR 用因果掩码、位置 \(i\) 的输出预测第 \(i+1\) 个 token；掩码扩散用双向注意力、在被掩位置原地预测。DiffuLLaMA §1；LLaDA §2.2；SMDM §3

Dream 7B 把这条路线推到 7B 的实用水平：从 Qwen2.5-7B 初始化，继续预训练 580B token，加上一个按上下文给每个被掩 token 重新定权的技巧（CART）。它最早在 2025-04-02 以博客发布、04-05 放出权重，技术报告直到 2025-08-21 才上 arXiv（报告首页仍写 April 2, 2025）。Dream 官方博客；官方 README News；arXiv 2508.15487v1

一句话理解 不改网络形状、不加时间嵌入，只做三件事：把因果掩码换成全双向（可选地逐步退火），保留 AR 的“错位一格”预测（位置 \(i-1\) 的输出负责预测 \(x_i\)），再用掩码扩散目标继续训练。Dream 再把序列级的 \(1/t\) 权重换成按“附近有多少已知 token”计算的 token 级权重。

记号同本 track：\(x_0\)、\(x_t\)（\(t=1\) 全掩）、\([\mathrm{M}]\)、\(p_{\theta}(x_0^{i}\mid x_t)\)、prompt \(c\)、步数 \(N\)。DiffuLLaMA 用离散时间 \(T\) 与 \(\alpha_t\)（未被掩概率）推导，取 \(\alpha_t=1-t\)，与本页一致；Dream 用 \(N\) 表示序列长度，本页改记为 \(L\)。DiffuLLaMA §2–3；Dream §3

3. 组件拆解

3.1 AR 与掩码扩散差在哪：两个目标的对照

DiffuLLaMA 把两者写成同一形式：掩码扩散是“带 \(1/t\) 权重、只在被掩位置计算”的交叉熵，网络看见带噪的整段序列；AR 是“所有位置、看见干净前缀、目标右移一格”的交叉熵。AR 也可以看成一种特殊扩散：前向过程从右往左确定性地逐个掩掉 token，反向就是逐个从左到右生成。DiffuLLaMA §3.2、Eq. 7–8于是转换只需处理两件事：注意力从因果到双向、预测目标的位置对齐。

3.2 注意力掩码退火

在 GPT-2 上微调 GSM8K-symbolic 的消融里，去掉退火损失很小（GPT2-M：49.7 → 47.2），去掉 shift 损失很大（49.7 → 34.5）；训练终点的 ELBO 也是 0.015 / 0.019 / 0.028。DiffuLLaMA Tab. 3、Tab. 5因此 7B 直接用全双向注意力，以便使用 FlashAttention-2——退火需要逐元素的任意掩码矩阵，FlashAttention-2 只原生支持因果或全注意力（后半句为推断）。DiffuLLaMA §4.1、§4.5

论文 vs 官方代码：退火怎么“退”论文写“每步从右侧采样一定量的上下文，并逐步增加直到全注意力”；官方 DiffuGPT 代码不是按“右侧连续一段”打开，而是对整个上三角逐元素以概率 \(\rho\) 打开（Bernoulli），\(\rho\) 随步数线性升到 1。两者都让模型逐渐看到未来，但前者保持连续的上下文窗口、后者是随机稀疏的。DiffuLLaMA §3.3；官方 LLaMA-Factory/src/llamafactory/train/ddm/trainer.py

3.3 shift：为什么不能省

预训练 AR 的 LM head 读的是“预测下一个 token”的表征。若直接让位置 \(i\) 预测自己的原 token，相当于要求网络整体换一种表征约定，初始权重的价值大打折扣。保留错位后，扩散训练只需让网络学会“在双向上下文里预测下一个位置被掩掉的 token”，与 AR 的输出约定一致。Dream 的图示把这称作“最大程度的结构对齐”。DiffuLLaMA §3.3；Dream §4.1、Fig. 2副作用：位置 \(i\) 的预测由位置 \(i-1\) 的隐状态给出，而后者本身可能就是 \([\mathrm{M}]\)；第一个位置没有左邻，代码直接复制它自己的 logits。

3.4 CART：上下文自适应的 token 级噪声重排

标准训练对整条序列用同一个 \(t\) 和同一个权重 \(1/t\)。Dream 认为学习发生在 token 级，每个被掩 token 实际面对的“噪声”取决于它附近的已知上下文，于是把权重改成 \(w(t,x_t,n)\)（§5）。\(p\) 越小，已知 token 对远处的贡献越均匀；\(p\) 越大，只有近邻有贡献。Dream §4.2论文没有给出 7B 预训练用的 \(p\)；开源的 SFT 脚本用 time_reweighting=cart、默认 cart_p=0.1（而函数内默认值是 0.8）。官方 sft_trainer.yaml、run_sft_tulu3.sh、fsdp_sft_trainer.pyDream 预训练阶段的 cart_p 未公开

3.5 AR 初始化与学习率

Dream 先在 1B 规模做设计选择，确认了 AR 初始化（Qwen2.5、LLaMA3 均试过）和 CART 两个组件，再训 7B；7B 预训练 580B token，数据来自 Dolma v1.7、OpenCoder、DCLM-Baseline，全部开源数据；博客称训练平稳、没有不可恢复的 loss spike。Dream 博客 Training；Dream §4.3学习率是关键：太高会迅速冲掉左到右的知识，使初始化失去意义；太低又阻碍扩散训练。Dream §5.4DiffuLLaMA 7B 用恒定 2e-5，GPT-2 版用 3e-4 余弦。DiffuLLaMA App. B.2

3.6 DiffuLLaMA：转换配方的源头

DiffuGPT：在 FineWeb 中随机取 30B token，对 GPT-2 small / medium 继续训练（多 epoch，有效 token 超过 100B），8 张 A100-80G；DiffuLLaMA：从 SlimPajama 与 Starcoder 按 7:3 采样 65B token，对 LLaMA-2-7B 继续训练，上下文 2048，16 个 4×GH200 节点，每卡 batch 60、梯度累积 4。DiffuLLaMA §4.1、App. B.1–B.2数据选择刻意贴近原 AR 的预训练分布，以减少分布漂移（GPT-2 ↔ OpenWebText 近似的 FineWeb；LLaMA-2 ↔ TinyLlama 式配比）。DiffuLLaMA App. B.1

能力上，DiffuLLaMA 能做少样本上下文学习（MAWPS 零样本 9.7 → 4-shot 31.3），自洽投票再升到 33.1；但在 TriviaQA（18.5 vs LLaMA2 45.4）等知识类任务上掉得厉害，作者归因于 65B token 不足以保住原模型的知识。DiffuLLaMA Tab. 1、Tab. 2、§4.3同期对照：只在同一语料上对 GPT-2 继续做 AR 训练没有提升，说明 DiffuGPT 的收益不是“多看了数据”。DiffuLLaMA App. C.4、Tab. 9

论文内部不一致：DiffuLLaMA 的 token 数§4.1 一处写“随机采样 65B token”，同段又写“train DiffuLLaMA on 60B tokens”；App. B.1、B.2 都是 65B。摘要的“少于 200B token”是对所有模型的上界。本页取 65B。DiffuLLaMA §4.1、App. B.1–B.2、摘要

3.7 成本：转换 vs 从零

扩散阶段的 token：DiffuLLaMA 65B，Dream 580B，LLaDA 2.3T，iLLaDA 12T。各论文Dream 说自己“只用了 LLaDA 1/4 的训练数据”，但这只计扩散阶段；Qwen2.5 的 18T 预训练已经发生，iLLaDA 的对比表就把 Dream 记为“18T + 0.6T”。Dream §5.2；iLLaDA Tab. 2所以准确说法是：在已有 AR 模型的前提下，得到一个同级扩散模型的边际成本低一到两个数量级；若把 AR 预训练算进去，转换路线的总计算并不低。Dream 未公开训练硬件与时长。Dream 7B 的 GPU 小时未核实

3.8 残留了哪些 AR 偏置

  • 结构上：shift 让每个位置的输出仍然“看左邻、报下一个”，这是 AR 的输出约定，只是注意力变成了双向。Dream §4.1
  • 有意保留的知识：Dream 的学习率调节目标正是“不要冲掉左到右知识”，作者认为它能加速任意顺序能力的学习。Dream §5.4
  • 解码顺序：DiffuCoder 用 local / global AR-ness 度量解码顺序，发现两类 dLLM 都偏向左到右，而由 AR 转换的模型（数学任务上的 Dream、代码上的 DiffuCoder）比从零训练的 LLaDA 更“AR”；提高采样温度会让顺序更随机。DiffuCoder §4.2–4.3、Fig. 3、Fig. 5Dream 自己的 README 也提示纯随机顺序（alg="origin"）在部分任务上会掉分。Dream 官方 README
  • 但并不妨碍规划类任务：同协议下 Dream 的 Sudoku 81.0、Countdown 16.0，高于 LLaDA 的 46.0、13.2 与 Qwen2.5 的 21.0、6.2。Dream Tab. 1

5. 训练目标与似然

DiffuLLaMA 的扩散损失（对每条序列抽一个 \(t\)）与 AR 损失并排写，差别一目了然：DiffuLLaMA Eq. 7–8

$$\mathcal{L}_t=\frac{1}{t}\,\mathbb{E}_{q(x_t\mid x_0)}\Big[-\sum_{n=1}^{L}\mathbf{1}\big[x_t^{n}=[\mathrm{M}]\big]\log f_{\theta}(x_t)_{n}[x_0^{n}]\Big],\qquad \mathcal{L}_{\mathrm{AR}}=-\sum_{n=1}^{L}\log f_{\theta}(x_0^{1:n-1})_{n-1}[x_0^{n}].$$

带 shift 实现时，扩散一侧的“第 \(n\) 个输出”实际取自位置 \(n-1\)。Dream 把 \(1/t\) 换成逐 token 的 \(w\)：Dream Eq. 4–5

$$\mathcal{L}(\theta)=-\mathbb{E}_{x_0,\,t,\,x_t}\sum_{n=1}^{L}\mathbf{1}\big[x_t^{n}=[\mathrm{M}]\big]\,w(t,x_t,n)\log p_{\theta}(x_0^{n}\mid x_t),\qquad w(t,x_t,n)=\frac12\sum_{j=1}^{L}\mathbf{1}\big[x_t^{j}\neq[\mathrm{M}]\big]\,p(1-p)^{|n-j|-1}.$$

\(w\) 只通过“哪些位置被掩”依赖 \(t\)；两侧几何级数之和都不超过 1，所以 \(w\le 1\)。

CART 之后还是 ELBO 吗Dream 称 Eq. 3（权重 \(1/t\)）是 ELBO 的等价改写，并把 CART 描述为“\(w(t)\) 的推广”。但 \(1/t\) 来自前向过程的推导，而 CART 的权重有上界 1、与 \(1/t\) 不成比例，按本页推断它不再是负对数似然的上界，而是一个重加权的去噪目标；因此 Dream 的训练损失不能直接当作似然或与 ELBO 类数字比较。论文没有讨论这一点。Dream §3.2、§4.2；推断另外，官方 SFT 代码在 original（\(1/t\)）、linear、cart 三种权重间切换，开源脚本选的是 cart。官方 fsdp_sft_trainer.py、run_sft_tulu3.sh

似然评测：DiffuLLaMA 对选择题计算每个选项的扩散损失（按 token 平均）取最小者，离散步数 \(T\) 会影响结果（HellaSwag：\(T=32\) 时 58.7，\(T=8\) 时 47.1）。DiffuLLaMA App. B.3、Tab. 11Dream 的选择题评测基于 lm-evaluation-harness 的似然任务脚本。Dream README EvaluationDream 似然估计的 MC 次数未核实

6. 伪代码

ar_to_diffusion.py（按 Dream fsdp_sft_trainer.py、generation_utils.py 与 DiffuGPT ddm/trainer.py 简化）
def anneal_mask(L, step, anneal_steps=10_000):          # DiffuGPT；7B 与 Dream 直接全 1
    rho = min(1.0, (step + 1) / anneal_steps)
    return tril(ones(L, L)) | (rand(L, L) < rho)

def cart_weight(masked, p=0.1):                          # masked: [B, L] bool
    d = abs(arange(L)[:, None] - arange(L)[None, :])
    W = 0.5 * p * (1 - p) ** (d - 1); W[d == 0] = 0       # [L, L]
    return ((~masked).float() @ W) * masked              # 只在被掩位置有值

def train_step(model, x0, step, prompt_len=None, mode="cart"):
    t = rand(B)                                          # 每条序列一个 t
    masked = rand(B, L) < t[:, None]
    if prompt_len is not None:
        masked[:, :prompt_len] = False                   # SFT：prompt 不加噪
    xt = where(masked, MASK_ID, x0)
    attn = ones(L, L) if mode != "diffugpt" else anneal_mask(L, step)
    logits = model(xt, attn_mask=attn)                   # 全双向，无时间输入
    logits = cat([logits[:, :1], logits[:, :-1]], dim=1) # shift：位置 i-1 预测 x_i
    ce = cross_entropy(logits, x0, reduction="none") * masked
    w = cart_weight(masked) if mode == "cart" else 1.0 / t[:, None]
    return (ce * w).sum() / masked.sum()                 # 按被掩 token 数平均

def diffusion_generate(model, c, L_new=512, N=512, eps=1e-3, alg="entropy"):
    x = cat([c, full(L_new, MASK_ID)])
    ts = linspace(1, eps, N + 1)
    for i in range(N):
        logits = model(x)
        logits = cat([logits[:, :1], logits[:, :-1]], dim=1)   # 推理同样右移
        m = (x == MASK_ID)
        conf, x0 = score(logits[m], alg)                 # maskgit_plus / topk_margin / entropy
        k = int(m.sum() * (1 - ts[i + 1] / ts[i])) if i < N - 1 else m.sum()
        top = topk(conf, k)                              # alg="origin" 则按概率随机转移
        x[m][top] = x0[top]
    return x[len(c):]

9. 承上启下

解决了什么

  • 证明 AR 权重可以“几乎不改结构”地转成掩码扩散模型，成本从 LLaDA 的 2.3T token 降到 65B–580B。
  • Dream 7B 成为最常用的开源 dLLM 底座之一：Fast-dLLM、CDLM、Dream-Coder、LaViDa 都以它为起点或对照。

留下的问题 → 下一步

  • 全序列双向仍没有精确 KV cache、画布仍定长：SDAR / Fast-dLLM v2 / WeDLM 改为转成块扩散，只用约 1B token 级别的数据（见该页）。
  • AR 偏置是资产还是包袱：DiffuCoder 量化 AR-ness，第 16 页讨论任意顺序的代价；规模上 LLaDA2.0 用同一思路转到 100B。
  • “转换比从零便宜”只在不计 AR 预训练时成立；从零路线的 iLLaDA 在 12T 后 Base 平均反超 Dream。

简答题

Q13把 AR 权重改造成扩散模型时，“注意力掩码退火”和“shift”各自弥合哪一种不匹配？为什么 DiffuLLaMA 7B 可以省掉退火，却不能省掉 shift？

退火处理的是注意力模式的不匹配：AR 只见过左侧上下文，突然全开会让表征分布突变，所以逐步打开未来位置。shift 处理的是输出约定的不匹配：AR 的位置 \(i\) 表征服务于预测 \(x_{i+1}\)，若改成原地预测，整个 LM head 与表征都要重学。GPT-2 上的消融显示前者影响小（49.7 → 47.2）、后者影响大（49.7 → 34.5），所以 7B 为用 FlashAttention-2 直接全双向，而 shift 一直保留，Dream 也照搬。

  • Dream 1B 实验里 AR 初始化在开头同样出现“因果 → 全注意力”的损失升高，但始终低于从零训练——不退火的代价是暂时的。
  • 官方退火实现是逐元素随机打开上三角，与论文“从右侧取一段上下文”的描述不同。
  • shift 让每个位置仍按“左邻报下一个”工作，这是转换模型保留 AR 结构偏置的一个来源。

依据：DiffuLLaMA §3.3、§4.1、Tab. 3、Tab. 5；Dream §4.1、Fig. 4；官方 ddm/trainer.py。

Q14Dream 声称只用了 LLaDA 约 1/4 的训练 token 就更强——这笔账该怎么记？转换后的模型残留了哪些 AR 偏置，怎样检测？

0.6T 只是扩散阶段的继续预训练；Qwen2.5 本身已用 18T token 预训练，iLLaDA 的对比表就记为“18T + 0.6T”。所以结论应是“已有强 AR 模型时，转换的边际成本远低于从零训练”，而不是扩散更省数据。残留偏置包括：shift 保留的错位输出约定；刻意用小学习率保住的左到右知识；以及更偏左到右的解码顺序。

  • 检测方法：用 DiffuCoder 的 local / global AR-ness 统计解码顺序（它报告 Dream 比 LLaDA 更 AR）；比较随机顺序与置信度顺序解码的分差；看反转、填空、规划类任务（Dream 的 Sudoku 81.0 说明偏置并未抹去规划优势）。
  • 公平的成本比较应同时给出“含 AR 预训练的总计算”和“扩散阶段计算”，并注明数据是否同源。
  • Dream 训练用 CART 权重，其损失不是 ELBO，不能拿训练损失与从零模型的似然直接比（本页推断）。

依据：Dream §5.2、§5.4；iLLaDA Tab. 2；DiffuCoder §4.2、Fig. 3；Dream README。
