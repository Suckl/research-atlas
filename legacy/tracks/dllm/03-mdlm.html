1. 动机：掩码扩散本来就不差，只是写得太复杂

2024 年上半年，离散扩散在困惑度上的最好成绩属于 SEDD：它学的是相邻状态的概率比，目标函数要用 CTMC 理论推导，网络还要输入时间 \(t\)。D3PM 的 absorbing（掩码）版本早就存在，却一直被当成弱基线。MDLM 与 MD4 在一周之内先后挂上 arXiv（MD4 2024-06-06，MDLM 2024-06-11），各自证明了同一件事：只看掩码这一种前向过程，连续时间 ELBO 就是按掩码率加权的掩码语言模型（MLM）交叉熵，不需要转移矩阵，也不需要概率比。MDLM §3.4–3.5；MD4 §3

本页记号：干净序列 \(x_0\)，长度 \(L\)；加噪序列 \(x_t\)，\(t\in[0,1]\)，\(t=1\) 时全为 \([\mathrm{M}]\)；去噪网络 \(p_{\theta}(x_0^i\mid x_t)\)；\(\alpha_t\) 是 token 保持干净的概率（单调下降，\(\alpha_0\approx1,\ \alpha_1\approx0\)）。MDLM 原文把干净数据写作 \(\mathbf{x}\)、加噪写作 \(\mathbf{z}_t\)，把网络写作 \(\mathbf{x}_{\theta}\)；MD4 写作 \(x_0,x_t,\mu_{\theta}\)。两篇的时间方向都与本站一致。

一句话理解 把每个 token 以概率 \(1-\alpha_t\) 换成 \([\mathrm{M}]\)，让双向网络只在被遮位置做交叉熵，再乘上 \(-\alpha_t'/(1-\alpha_t)\)（线性调度下就是 \(1/t\)）对 \(t\) 积分——这就是负 ELBO。BERT 的 MLM 是它固定掩码率、去掉权重的特例；LLaDA 的式 (3) 是它的原样照搬。

3. 组件拆解

3.1 从 D3PM 的 KL 到加权交叉熵

MDLM 只考虑“插值式”前向过程 \(q(x_t\mid x_0)=\mathrm{Cat}(\alpha_t x_0+(1-\alpha_t)\pi)\)；取 \(\pi=[\mathrm{M}]\) 即掩码扩散。真实后验很简单：\(x_t\) 已揭示就原样保留；\(x_t=[\mathrm{M}]\) 时以 \(\frac{\alpha_s-\alpha_t}{1-\alpha_t}\) 跳回 \(x_0\)，否则保持 \([\mathrm{M}]\)。把 \(x_0\) 换成网络预测 \(x_{\theta}(x_t)\) 就得到反向模型，于是每一步的 KL 只剩一项：MDLM Eq. 8–10；MD4 §2–3

$$\mathrm{KL}\big(q(x_s\mid x_t,x_0)\,\|\,p_{\theta}(x_s\mid x_t)\big)=-\frac{\alpha_s-\alpha_t}{1-\alpha_t}\,\mathbf{1}[x_t=[\mathrm{M}]]\,\log p_{\theta}(x_0\mid x_t).$$

对 \(T\) 步求和是一个黎曼和；MD4 证明它被连续积分从下方界住，所以 \(T\to\infty\) 的 ELBO 比任何有限 \(T\) 都紧。MDLM 的消融印证了这一点：离散 \(T=1000\) 训练比连续时间差约 0.15（27.19 vs 27.04）。MD4 App. D；MDLM Tab. 8

为什么叫 Rao-Blackwell 化。如果按 D3PM 的方式把后验整体代入（MDLM Eq. 11），损失里会出现 \(\langle x_{\theta},[\mathrm{M}]\rangle\) 这类项，网络得自己学会把它们压到 0；SUBS 把它们解析地设为 0，等价于对这些量求了期望，方差也随之下降（作者承认这是对术语的“借用”）。MDLM §3.3

3.2 SUBS 参数化：两条约束，作用不同

零掩码概率：输出分布在 \([\mathrm{M}]\) 上的质量置零。照抄（carry-over）：已揭示位置的输出等于输入。照抄让未遮位置的损失恒为 0，网络的容量全部用于被遮位置；零掩码概率主要是数值上的整洁。消融显示：去掉照抄使 LM1B 上界从 27.19 升到 28.56，再去掉零掩码概率几乎不变（28.51，这一行在数学上等价于 D3PM 的写法）。作者的另一个结论更值得注意：比起 SUBS，工程配方（分词器、DiT 骨干、数值稳定的实现、低差异采样）贡献最大。MDLM Tab. 8、§3.5.1、§6

照抄也有代价：它把“揭示后不可修改”写进了模型，这正是后来 均匀态扩散、DFM 的 corrector（下一页）和 LLaDA 2.1 的 T2T 编辑要绕开的约束。

调度不变性。做变量替换 \(\gamma=\log(1-\alpha_t)\)，负 ELBO 变成 \(-\mathbb{E}\int_{-\infty}^{0}\log p_{\theta}\,d\gamma\)，与 \(\alpha_t\) 的函数形式无关，只取决于端点；但不同调度下单样本估计的方差不同。OWT 上四种调度的 BPD 都是 3.30，每样本方差分别为 1.81（log-linear）、3.30（cosine）、3.30（cosine²）、7.57（linear \(\sigma\)）。MDLM §3.4、App. E.1、Tab. 9

3.3 MD4：同一个目标，另一套推导与一个推广

MD4（Google DeepMind）从离散时间转移矩阵 \(Q_i=(1-\beta_i)I+\beta_i\mathbf{1}e_m^{\top}\) 出发取极限，得到同一个积分（MD4 Eq. 5），并补充了 MDLM 没有强调的三点：MD4 §2–5

  • SNR 形式的不变性：令 \(\alpha_t=\sigma(\lambda_t)\)，损失化为对 log-SNR \(\lambda\) 的积分，调度只通过端点 SNR 起作用——与连续扩散 VDM 的结论同构。MD4 §3
  • 与 score 参数化的关系：掩码状态的离散 score 满足 \(s(m,t)_j=\frac{\alpha_t}{1-\alpha_t}\mathbb{E}[x_0\mid x_t=m]_j\)，且 \(\sum_j s=\frac{\alpha_t}{1-\alpha_t}\)。SEDD 让网络自由输出 score，不强制这个约束，作者认为这是 SEDD 训练不稳的原因（参见 RADD 的同一结论）。MD4 Prop. 1、§7.1
  • 与任意顺序 AR（AO-ARM）的关系：所有位置的揭示时间同分布，揭示顺序是均匀随机排列；调度 \(\alpha_t\) 是 AO-ARM 没有的新自由度——它决定每步同时揭示多少个 token。MD4 §5

调度影响的是采样，不是似然。线性调度给出最好的 ELBO，但在均匀时间网格上前期一次揭示太多 token，相关位置同步采样会冲突；改用余弦调度（或线性调度 + 余弦网格 \(t(i)=\cos(\frac{\pi}{2}(1-\frac{i}{T}))\)）后，ImageNet 64×64 在 \(T=256\) 时 FID 从 70 降到 17。这是 因子分解误差 的一个早期实证。MD4 §4、Fig. 2

GenMD4：状态相关调度。让每个词值 \(i\) 有自己的调度 \(\alpha_{t,i}=1-t^{w_i}\)，希望“重要的 token 先揭示”。ELBO 推广为 MD4 Eq. 12；\(w\) 的梯度要穿过离散采样，作者用 REINFORCE leave-one-out 估计。GenMD4 在 OWT 验证集与 text8 上更好（≤21.80 vs ≤22.13；BPC 1.34 vs 1.37），但学到的 \(w\) 会过拟合数据集统计，零样本迁移反而变差，推理也更复杂。MD4 §6、Tab. 2、Tab. 5、§8

5. 训练目标与似然

$$\mathcal{L}_{\infty}(\theta)=\mathbb{E}_{x_0}\int_0^1\frac{\alpha_t'}{1-\alpha_t}\;\mathbb{E}_{q(x_t\mid x_0)}\Big[\sum_{i:\,x_t^i=[\mathrm{M}]}\log p_{\theta}(x_0^i\mid x_t)\Big]\,dt\ \ \ge\ -\log p_{\theta}(x_0).$$

\(\alpha_t'<0\)，所以积分号前的权重为正。取 \(\alpha_t=1-t\)：

$$\mathcal{L}(\theta)=\mathbb{E}_{t\sim U[0,1]}\,\mathbb{E}_{x_0,x_t}\Big[\frac{1}{t}\sum_{i=1}^{L}\mathbf{1}[x_t^i=[\mathrm{M}]]\,\big(-\log p_{\theta}(x_0^i\mid x_t)\big)\Big].$$

这正是 LLaDA 的式 (3)，LLaDA 为它引用的三篇来源就是 MD4、MDLM 与 RADD。LLaDA §2.1 Eq. 3、App. A.1它成为默认目标的原因可以归结为三条：① 实现就是“随机掩码率的 BERT 损失乘一个标量”，任何 Transformer 训练栈都能直接跑；② 它是似然的上界，困惑度、扩展律和 MC-ELBO 评测（LLaDA 用它做选择题打分）都有了依据；③ 不需要时间输入（RADD / MDLM），网络与 AR 骨干结构相同，便于放大与从 AR 权重初始化。MDLM §3.5、Tab. 12；LLaDA §2.1–2.4

与 BERT 的差别只在两处：掩码率随机采自 \([0,1]\) 而非固定 15%，损失乘 \(1/t\)。去掉 \(1/t\)（即 MaskGIT 式目标）就不再是 ELBO；但 2026 年的 Beyond-Masked 发现，训练时去掉权重、评测时仍用 ELBO，可把 MDLM 的计算效率提高约 12%。

6. 伪代码

mdlm.py（依据 MDLM Alg. 1、§4.1 与官方 diffusion.py 改写的最小版本）
MASK = vocab_size                                  # extra id appended to the tokenizer

def train_step(x0, model, opt, eps=1e-3):
    B, L = x0.shape
    u = (torch.rand(()) + torch.arange(B) / B) % 1.0    # low-discrepancy: one stratum per row
    t = (1 - eps) * u + eps                           # mask prob = 1 - alpha_t = t
    masked = torch.rand(B, L) < t[:, None]
    xt = torch.where(masked, MASK, x0)
    logits = model(xt)                                # bidirectional; no t input (MDLM default)
    logits[..., MASK] = -float("inf")                 # SUBS 1: zero masking probability
    logp = logits.log_softmax(-1).gather(-1, x0[..., None]).squeeze(-1)
    nll = -logp * masked                              # SUBS 2: carry-over -> unmasked terms are 0
    loss = (nll.sum(-1) / t).mean() / L               # weight -alpha'_t / (1 - alpha_t) = 1 / t
    loss.backward(); opt.step(); opt.zero_grad()
    return loss                                       # per-token NELBO in nats (an upper bound)

@torch.no_grad()
def sample(model, L, T):
    x = torch.full((1, L), MASK)
    probs = None
    for k in range(T, 0, -1):
        t, s = k / T, (k - 1) / T
        if probs is None:                             # cache: x_theta does not depend on t
            logits = model(x)
            logits[..., MASK] = -float("inf")
            probs = logits.softmax(-1)
        reveal = (x == MASK) & (torch.rand(1, L) < (t - s) / t)   # (alpha_s-alpha_t)/(1-alpha_t)
        cand = torch.multinomial(probs[0], 1).T       # one draw per position from x_theta
        x_new = torch.where(reveal, cand, x)          # revealed tokens are never changed again
        if (x_new != x).any():
            probs = None                              # canvas changed -> recompute next step
        x = x_new
    return x                                          # at k = 1, (t - s) / t = 1: all revealed

半自回归（SAR）生成：先生成 \(L\) 个 token，再把末尾 \(L-L'\) 个作为前缀照抄、只对新的 \(L'\) 个位置去噪，如此滚动。它没有 KV cache，每轮仍对整张画布做双向注意力——块间 KV cache 要等到 BD3-LM。MDLM §4.2

  • D3PM absorb：要物化转移矩阵，数值不稳，被当作弱基线。
  • BERT：会填空，但没有原则性的生成过程与似然。

之后 → 留下的问题

  • 目标被 LLaDA（8B 从零训练）、Dream 等原样采用；MDLM 代码成为 BD3-LM / Eso-LM 与 Duo 的底座。
  • 揭示后不能改：DFM 的 corrector、均匀态扩散、LLaDA 2.1 的 T2T 编辑。
  • 定长画布：Edit Flows 与 FlexMDM 的插入操作，块扩散的块间自回归。
  • 没有 KV cache、并行冲突：近似缓存与 并行上限的分析。

简答题

Q5为什么掩码扩散的连续时间 ELBO 能化简成“按 1/t 加权、只在 [M] 位置计分的交叉熵”？SUBS 的两条约束各起什么作用，去掉会怎样？

吸收态让真实后验只剩“保持 [M]”或“跳回 \(x_0\)”两种结局，把 \(x_0\) 换成网络预测后，每步 KL 化为 \(\frac{\alpha_s-\alpha_t}{1-\alpha_t}\) 乘以被遮位置的交叉熵；步数趋于无穷时权重变为 \(-\alpha_t'/(1-\alpha_t)\)，线性调度下即 \(1/t\)。SUBS 的“照抄”让未遮位置的项解析为 0，“零掩码概率”让 \([\mathrm{M}]\) 相关项为 0，二者共同把 D3PM 的复杂 KL 变成纯交叉熵。

  • 去掉照抄：网络得自己学会复制未遮 token，LM1B 上界 27.19 → 28.56；再去掉零掩码概率几乎不变（28.51，等价于 D3PM 写法）。
  • 连续时间比 \(T=1000\) 的离散 ELBO 略紧（27.04 vs 27.19），与 MD4 “黎曼和被积分从下方界住”的证明一致。
  • 调度不改变 ELBO 的值（只依赖端点），但改变估计方差与采样时每步揭示多少 token。

依据：MDLM §3.2–3.4、Eq. 10–13、Tab. 8–9；MD4 §3、App. D。

Q6MDLM 与 MD4 同期推出同一个目标，二者在推导、调度、参数化与实验上有何不同？为什么后来的大模型选它而不是 SEDD 的 score entropy？

MDLM 走变分视角（插值前向 + SUBS），强调工程配方、时间无关的缓存采样、半自回归变长生成与 BERT 的联系；MD4 从转移矩阵取极限，给出 SNR 不变性、score 与均值参数化的换算，并推广到状态相关调度 GenMD4。二者的损失在 \(\alpha_t=1-t\) 下完全相同。大模型选它，是因为它只是“随机掩码率的 MLM 损失乘 \(1/t\)”，是似然上界，且不需要时间输入，骨干可与 AR 完全相同。

  • MD4 发现线性调度似然最好、但均匀网格采样冲突大，余弦网格把 ImageNet64 FID 从 70 降到 17。
  • MD4 认为 SEDD 自由输出 score、不满足 \(\sum_j s=\alpha_t/(1-\alpha_t)\) 约束，导致前后向不一致与训练不稳。
