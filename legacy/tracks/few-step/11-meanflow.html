1. 动机：一步需要的是位移，不是切线

Flow Matching 学的是当前位置的瞬时速度。即便训练时数据与噪声之间用直线插值，取条件期望后的边缘速度场仍会产生弯曲轨迹；直接把起点切线延长到数据侧，并不等于沿轨迹积分。MeanFlow 因此改学区间的平均速度，让网络输出整段位移所需的方向与大小，而把积分的代价转移到训练时的微分计算论文 §3、§4.1。

本页统一把真实数据记作 \(x_0\)、噪声记作 \(\epsilon\)，沿用论文的 \(z_t=(1-t)x_0+t\epsilon\)：\(t=0\) 是数据，\(t=1\) 是噪声；训练对的条件速度为 \(v_t=\epsilon-x_0\)，边缘速度为 \(v(z_t,t)=\mathbb E[v_t\mid z_t]\)。平均速度 \(u(z_t,r,t)\) 的目标时间满足 \(0\le r\le t\le1\)论文 §3、Eq. 1–3。

一句话理解把“去噪轨迹的平均速度”定义清楚，再从定义推出训练恒等式。MeanFlow 的生成网络从零训练，不用预训练扩散教师、离线 ODE 配对或逐渐缩小的离散时间课程；ImageNet 256×256 上只调用生成网络一次，FID 为 3.43论文摘要、Tab. 2。这里的“从零”指生成网络：该实验仍使用预训练 VAE 的 latent论文 §5、App. A。

3. 组件拆解

3.1 平均速度的定义：平均的是边缘 ODE，不是配对直线

$$u(z_t,r,t)=\frac{1}{t-r}\int_r^t v(z_\tau,\tau)\,d\tau,\qquad z_r=z_t-(t-r)u(z_t,r,t).$$

积分沿边缘速度场的 ODE 轨迹进行。\(\epsilon-x_0\) 是可采样的条件瞬时速度，不是所求区间平均速度的现成标签；若把所有区间都直接回归到它，就退回 Flow Matching，仍然没有学会大步位移论文 Eq. 3、11–12、§3。

平均速度随 \(r\to t\) 退化为瞬时速度；不同区间的位移满足积分可加性。设 \(r<s<t\)，先到 \(s\) 再到 \(r\) 与直接到 \(r\) 应有同一终点，且第二段应在第一段得到的 \(z_s\)上计算论文 §4.1：

$$(t-r)u(z_t,r,t)=(t-s)u(z_t,s,t)+(s-r)u(z_s,r,s).$$

3.2 MeanFlow identity：对定义求导，消掉难算的积分

对 \((t-r)u=\int_r^t v\) 的上限 \(t\) 求全导数，固定下限 \(r\)，乘积法则给出论文 Eq. 4–8：

$$\boxed{u=v-(t-r)\frac{du}{dt}},\qquad \frac{du}{dt}=\partial_z u\,v+\partial_tu=\operatorname{JVP}_{(z,r,t)}[u;(v,0,1)].$$

这不是凭经验追加的约束，而是平均速度定义蕴含的恒等式。实践中用网络的导数替代未知真值导数，目标因此仍会随网络变化；“真值场与网络无关”不等于“实际回归标签与网络无关”论文 §4.1；iMF §1、Fig. 1。

如果网络实际编码的是 \((t,h=t-r)\)，JVP 应对包装函数 \(u_\theta(z,r,t)=\mathrm{net}_\theta(z,t,t-r)\) 求导：固定 \(r\) 时 \(h\) 会随 \(t\) 变化。直接把内部 \(h\) 的切向量设为零会改变训练方程论文 §4.3；官方代码 meanflow.py：forward。

3.3 CFG 折入训练：学引导后的流，而不是部署时做两次前向

本 track 用 \(w\) 表示 guidance scale（论文用 \(\omega\)）。定义 \(v^{\mathrm{cfg}}=w v(z_t,t\mid c)+(1-w)v(z_t,t)\)，再学习它诱导的平均速度。无条件瞬时速度可由同一网络的对角线 \(u_\theta(z_t,t,t,\varnothing)\) 估计，训练把条件速度换为论文 Eq. 13–19：

$$\widetilde v_t=w(\epsilon-x_0)+(1-w)u_\theta(z_t,t,t,\varnothing).$$

这条 \(\widetilde v_t\) 同时用于目标首项和 JVP 的状态切向。丢弃类别条件的样本回到无引导的条件速度监督。附录另用 \(\kappa\) 混合条件对角线预测，实际 guidance 为 \(w'=w/(1-\kappa)\)，并可限制引导生效的时间范围论文 App. B.1、Tab. 4；官方代码 guidance_fn、cond_drop。因此原版固定训练配方的模型并不具备任意测试时 guidance 控制。

3.4 前驱：Shortcut Models 用步长条件与两段自举

Frans、Hafner、Levine、Abbeel 的 One Step Diffusion via Shortcut Models 已提出：给模型增加步长条件，在零步长上用 Flow Matching，在较大步长上要求“一段等于两段半步”。原论文时间从噪声走向数据，与本页相反；下面转换为本页的噪声侧高时间约定，记 shortcut 速度为 \(S_\theta(z_t,t,d)\)Shortcut §2–3、Eq. 3–4（符号转换）：

$$z'=z_t-dS_\theta(z_t,t,d),\quad S_{\mathrm{tgt}}=\tfrac12\big[S_\theta(z_t,t,d)+S_\theta(z',t-d,d)\big],\quad S_\theta(z_t,t,2d)\approx\operatorname{sg}(S_{\mathrm{tgt}}).$$

后半步的状态来自网络真正走出的第一步，而非重新与数据插值。它把局部生成能力递归传播到大步长；MeanFlow 则直接用平均速度的微分恒等式传播，不依赖离散半步的递归标签Shortcut §3.1；MeanFlow §4.1。

论文内部不一致Shortcut §3 的合并损失式把第二个 shortcut 的时间写成原始 \(t\)，但 Eq. 4 与 §3.1 都明确使用第一步之后的时间。本页按 Eq. 4 展示，并在转换时间方向后写为 \(t-d\)Shortcut Eq. 4、§3 合并损失、§3.1。

3.5 Align Your Flow：同一流映射视角，侧重教师蒸馏

Sabour、Fidler、Kreis 的 Align Your Flow: Scaling Continuous-Time Flow Map Distillation（2506.14603）学习 \(\Phi_\theta(z_t,t,r)\) 将当前位置直接映射到任意较低时间。以 Euler 形式参数化时，\(\Phi_\theta=z_t-(t-r)u_\theta\)，与平均速度表述连接AYF §3、App. D.5。

AYF 的 Eulerian / Lagrangian 目标分别检查区间起点 / 终点的局部一致性；主实验采用预训练教师和 autoguidance，可再做短期对抗微调。它研究的是如何把现有强模型蒸馏成可灵活多步采样的流映射，MeanFlow 主实验研究的是无扩散教师的从零训练；不能把 AYF 的额外教师和后训练收益归给 MeanFlowAYF §3–4、App. F；MeanFlow §5。

CM 是 \(f_\theta(z_t,t)=\Phi_\theta(z_t,t,0)\)：终点固定为数据侧。流映射增加终点条件，覆盖任意 \(r<t\)；CM 常见多步采样需要“先预测干净终点、再加噪”，流映射则可以直接到中间时刻。这是表达对象的扩展，不能据此断言任何有限容量流映射模型都一定比 CM 更好MeanFlow §4.1；AYF Fig. 2、§3；rCM App. F.1。

5. 训练目标：回归恒等式右侧

$$u_{\mathrm{tgt}}=v_t-(t-r)\operatorname{JVP}[u_\theta;(v_t,0,1)],\qquad \mathcal L=\mathbb E\big\|u_\theta(z_t,r,t)-\operatorname{sg}(u_{\mathrm{tgt}})\big\|_2^2.$$

这是无 CFG 的核心形式；带引导时把 \(v_t\) 全部换成 \(\widetilde v_t\)。对角线 \(r=t\) 消去修正项，恢复条件 Flow Matching；非对角线把局部监督扩展到完整区间论文 Eq. 9–11、17–19。

按本 track 的记号，部署时的学生生成器是 \(G_\theta(\epsilon,c)=\epsilon-u_\theta(\epsilon,0,1,c)\)；网络预测平均速度，生成器再将它转换为数据侧样本论文 Eq. 12、Alg. 2。

$$e=\|u_\theta-\operatorname{sg}(u_{\mathrm{tgt}})\|_2^2,\qquad \mathcal L_{\mathrm{adapt}}=\mathbb E\left[\operatorname{sg}\big((e+\delta)^{-p}\big)e\right].$$

\(p\) 控制大误差样本的下权重，\(\delta\) 是平滑常数（论文写作 \(c\)，本页避免与类别条件混淆）。默认 \(p=1\)，论文示例平滑常数为 \(10^{-3}\)论文 §4.3、Tab. 4、Eq. 22。学习依靠数据速度锚点和恒等式，并没有额外的 GAN 判别器或 DMD 分数正则。

6. 伪代码

依据 Alg. 1–2 与 meanflow.py；展示基础 CFG（κ = 0），时间包装保持 (z, r, t) 顺序
def U(z, r, t, label):
    return net(z, t=t, interval=t-r, label=label)

for x0, c in data_loader:                     # 冻结 VAE 的 latent
    t, r = sorted_logit_normal_times(x0.shape[0])
    r = set_diagonal_subset(r, t)              # 部分样本 r=t
    eps = randn_like(x0)
    z = (1-t)*x0 + t*eps
    v = eps - x0
    with no_grad():
        v_null = U(z, t, t, null_label)
        v_guided = w*v + (1-w)*v_null
    label, tangent = drop_condition(c, v, v_guided)
    fn = lambda z, r, t: U(z, r, t, label)
    pred, du_dt = jvp(fn, (z, r, t),
                     (tangent, zeros_like(r), ones_like(t)))
    target = (tangent - (t-r)*du_dt).detach()
    err2 = sum_nonbatch((pred-target)**2)
    weight = ((err2 + delta)**(-p)).detach()
    loss = (weight*err2).mean()
    opt.zero_grad()
    loss.backward()
    opt.step()

# 推理没有 JVP，也没有条件 / 无条件在线组合
eps = randn(latent_shape)
x_hat = eps - U(eps, r=0, t=1, label=c)
image = frozen_vae.decode(x_hat)

9. 承上启下

已有路线

  • 轨迹蒸馏 / Reflow：通过教师轨迹或重新配对，让大步运输容易学习。
  • CM：把同一轨迹的点都送到固定干净终点；Shortcut 把两段小步自举为大步。
  • sCM：用连续时间导数处理一致性，但通常关注固定终点。

MeanFlow 提供的对象

  • 明确的跨区间平均速度及其恒等式，用可采样的数据速度完成无扩散教师训练。
  • guidance 在训练目标中折入，部署时直接走完整区间。
  • 标签含网络自身的导数，原版 guidance 固定；优化与可控性仍有改进空间。

已核实的后续工作 Improved Mean Flows（iMF） 把目标重写为瞬时速度回归，并增加显式 guidance 条件；这里只将它列为后续文献，不把它的结果并入原版 MeanFlowiMF 摘要、§1。图像到视频的实际延伸见 Causal-rCM：它把 sCM / MeanFlow 作为因果教师蒸馏目标，并开发自定义掩码 JVP，已不再是本页的无教师 ImageNet 设置。

简答题

Q21为什么 Flow Matching 的直线训练对不保证一步生成正确？MeanFlow 的平均速度怎样补上这个缺口？

训练对的条件直线速度来自特定数据与噪声配对，但模型给定当前位置只能学其条件期望；该边缘速度场的 ODE 通常弯曲。一步 Euler 使用起点切线，漏掉后续方向变化。MeanFlow 学整段积分除以区间长度，直接预测位移所需的平均速度；它用固定终点的全导数恒等式构造训练目标，避免训练时直接积分。

  • 把平均速度标签始终设成 \(\epsilon-x_0\)，会回到瞬时 Flow Matching。
  • CM 固定流映射终点在数据侧；MeanFlow / flow maps 还学习中间终点，因此要增加目标时间条件。

依据：MeanFlow §3、Eq. 3–11、Relation to Prior Work；AYF Fig. 2。

Q22MeanFlow 为什么既计算 JVP 又对目标停止梯度？CFG 怎样保持一次生成网络调用？

JVP 计算的是沿状态和时间变化方向的输入全导数，它是恒等式构造标签所必需的信息。停止梯度针对随后优化参数的反传，使标签视为常量，避免再对 JVP 求参数导数。CFG 则先定义引导后的瞬时场，再把它诱导的平均速度学进网络，部署时不需要在线组合条件与无条件预测。

  • 导数切向量必须固定目标 r；网络若编码 t−r，需要对正确包装函数求导。
  • 训练仍有额外导数与 guidance 调用；省下的是采样计算。原版固定训练 guidance，测试时不能随意更改它。

依据：MeanFlow Eq. 8–11、17–19、§4.3、App. B.4；iMF §1。
