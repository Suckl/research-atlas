1. 动机：轨迹蒸馏在 1–2 步会糊，GAN 又训不大

到 2023 年下半年，把扩散模型压到少步主要靠两类方法：沿 ODE 轨迹逐段回归（Progressive Distillation / Rectified Flow）和一致性约束（Consistency Models / LCM）。它们在 4–8 步还行，再往下就明显发糊、出伪影 ADD §2。SDXL-Lightning 给了一个直观解释：学生只有一两次前向，容量不够复现教师在相邻噪声之间的剧烈变化，用 MSE 去拟合只能得到条件均值，也就是模糊图 Lightning §3.1。

另一边，GAN 本来就是一步生成，但在大规模文生图上不好扩展：StyleGAN-T、GigaGAN 都观察到容量增大到一定程度后性能饱和，训练依赖精细平衡的专用架构，还要额外借助 CLIP 之类的网络才能对齐文本，并且没有 CFG 可用 ADD §2、§4.1。

一句话理解 对抗蒸馏的配方是“扩散预训练当先验，判别器负责把每一步都推到真实图像流形上”：学生直接用教师的权重初始化，所以对抗博弈从一个已经接近数据流形的生成器开始，而不是从随机噪声开始。ADD 再加一个来自教师的分数蒸馏项，保住大模型的构图能力与文本对齐。之后的 LADD 和 SDXL-Lightning 都在回答同一个问题：判别器该看哪种特征。

3. 组件拆解

3.1 为什么必须从教师初始化：纯对抗训练在大规模上的问题

ADD 的消融里最醒目的一行：同样 4000 次迭代、batch 128，学生随机初始化时 FID 293.6、CLIP 0.065，等于完全崩溃；用预训练扩散权重初始化则是 20.6 / 0.319 ADD Tab. 1c。论文给的理由有三条：预训练生成器本身就能显著改善对抗训练；GAN 的容量扩展会饱和，而扩散模型的扩展曲线平滑，ADD 可以直接借用更大的预训练模型；扩散框架天然支持多步细化 ADD §3、§4.1。

本页的解读：从教师初始化后，生成器一开始就落在数据流形附近，判别器要纠正的只是局部的模糊与伪影，博弈从接近平衡的位置出发；随机初始化时判别器很快就能把真假完全分开，生成器拿不到有用的梯度。另外，学生的输入 xs 在 s < 1000 时本身含有真实图像信息，任务更接近“一步去噪”而不是“从零画图”，这进一步降低了难度。LADD 也指出对抗模型普遍不服从扩展律，加大生成器收益递减，小特征网络反而更好 LADD §1——这说明在大规模上，稳定性主要来自扩散预训练，而不是判别器本身。

3.3 蒸馏项：一个“像反向 KL”的分数蒸馏

蒸馏项让学生输出靠近教师对它的去噪结果。取 c(t) = αt/(2σt)·w(t)、平方 L2 距离时，它对 θ 的梯度恰好等于 DreamFusion 的 SDS 梯度 ADD 附录 A：

$$\nabla_\theta \mathcal L_\text{distill}\;\propto\;\mathbb E_{t,\epsilon'}\Big[w(t)\big(\hat\epsilon_\phi(\hat x_{\theta,t},t)-\epsilon'\big)\tfrac{\partial \hat x_\theta}{\partial\theta}\Big]$$

其中 \(-\epsilon'\) 一项与 θ 无关、期望为零，只起降方差作用；真正起作用的是 \(\hat\epsilon_\phi\approx-\sigma_t\nabla\log p_{\phi,t}\)，即“沿教师在噪声级 t 的对数密度上升方向推样本”。ProlificDreamer 与 Diff-Instruct 都证明 SDS 是“变分分布取单点 Dirac”时的反向 KL 梯度——缺了生成分布自身的分数（熵项）VSD §3.3、Diff-Instruct §3.3.1。所以它是寻模（mode-seeking）的：单独使用会把样本都推向教师的高密度区，多样性塌缩。ADD 的消融正是这样：只用 Ldistill 时 FID 315.6、CLIP 0.076；只用 Ladv 时 20.8 / 0.315；两者合用 20.6 / 0.319 ADD Tab. 1d。

3.4 LADD（SD3-Turbo，2024-03）：判别器改用教师的生成式特征

LADD 做了两处改动 LADD §3：

  • 教师兼任判别器骨干：把学生输出的潜变量再加噪到 t̂，送进冻结的教师（SD3 的 MMDiT），取每个注意力块之后的 token 序列，还原成二维布局后接 2D 卷积判别头。好处是不用解码、天然支持多宽高比；而且噪声级成了控制旋钮：t̂ 偏低时判别器只看纹理，全局结构崩坏；偏高时结构好但细节丢失；默认 logit-normal(m = 1, s = 1) LADD §4.1、Fig. 4。
  • 用合成数据替代真实数据：一步生成时 CFG 只会过饱和，而真实数据的图文对齐度参差（COCO 图像平均 CLIP 0.29，SD3 生成图约 0.35）。改用教师在固定 CFG 下生成的潜变量后，蒸馏项不再有增益，可以只保留对抗损失 LADD §3、§4.2、Fig. 5。

这样“学生—教师—判别器”三者都在同一个潜空间里，最终把 SD3（8B）蒸馏成 4 步、无 CFG 的 SD3-Turbo；用户研究中 4 步的图像质量与 50 步教师相当，文本对齐略低 LADD §5.1、Fig. 10。扩展实验显示学生规模的影响远大于教师和数据生成器 LADD §4.4、Fig. 7。

3.5 SDXL-Lightning（2024-02）：逐段对抗蒸馏，兼顾模式覆盖

ByteDance 的 Lightning 走另一条路：保留 Progressive Distillation 的逐段结构（学生学“从 xt 跳到 xt−ns”），只是把每段的 MSE 换成对抗损失 Lightning §3.2。判别器是 SDXL UNet 编码器 + mid block 的可训练拷贝，在潜空间工作，支持任意噪声级：

$$D\big(x_t,\;x_{t-ns},\;t,\;t-ns,\;c\big)=\sigma\Big(\text{head}\big[d(x_{t-ns},t-ns,c)\,;\,d(x_t,t,c)\big]\Big),\qquad \mathcal L_G=-\log D(x_t,\hat x_{t-ns},\dots)$$
  • 条件于 xt 保住概率流：教师从 xt 到 xt−ns 是确定的，判别器同时看到起点和终点，学生就必须走同一条流，才能骗过它——在理想的条件分布匹配下，这有助于保持教师的模式覆盖；有限容量学生仍可能偏离。
  • 再放松成无条件判别器：学生容量不够复现教师在相邻噪声间的剧烈布局变化，条件对抗会产生“Janus”式的连体伪影；每一段都先用条件目标训练，再用 D(xt−ns, t−ns, c) 微调 Lightning §3.4、Fig. 2。
  • 流程：先用 MSE 从 128 步直接蒸到 32 步（只在这一段用 CFG 6），再对抗地 32 → 8 → 4 → 2 → 1，每段重新初始化判别器 Lightning §3.6。
  • 一步模型的稳定技巧：学生在 {250, 500, 750, 1000} 多个时间步上训练；判别器输入先加噪到 {10, 250, 500, 750}（先 1:1:1:1，稳定后 5:1:1:1），否则以 t = 0 输入时 UNet 编码器只看高频，评判不了结构；一步模型改为 x₀ 预测以消除噪点伪影 Lightning §3.7。

代价是每个步数一个独立检查点（1 步没有 LoRA 版本），以及逐段蒸馏的工程量 Lightning §6。“扩散 UNet 编码器 + 卷积分类头”这个判别器设计后来被 DMD2 直接借用 DMD2 附录 F.1。

3.6 UFOGen（2023-11）：扩散-GAN 混合路线

Google 的 UFOGen 与 ADD 同月出现，出发点是 DDGAN / SIDDM 这类“用条件 GAN 学大步长去噪分布”的扩散-GAN 混合模型。作者把 SIDDM 的重建项改为直接在 x₀ 上重建，使一步采样可行，并用 SD 1.5 同时初始化生成器和判别器，两者都在潜空间工作 UFOGen §4、附录 A.3。COCO-30k 零样本 FID 12.78、0.09 s UFOGen Tab. 3；在 ADD 的同协议对比里是 FID5k 22.5 / CLIP 0.311，被 ADD-M 超过 ADD Tab. 2。它和 ADD 印证了同一结论：大规模一步 GAN 的关键是“从扩散模型出发”。

5. 训练目标

ADD 的时间记号沿用离散 DDPM：xs = αsx₀ + σsε，s 取 {τ₁…τ₄}，τ₄ = 1000 时为纯噪声。总目标 ADD Eq. 1–4：

$$\mathcal L(\theta)=\mathcal L^{G}_\text{adv}\big(\hat x_\theta(x_s,s),\psi\big)+\lambda\,\mathcal L_\text{distill}\big(\hat x_\theta(x_s,s),\phi\big),\qquad \lambda=2.5$$ $$\mathcal L^{G}_\text{adv}=-\,\mathbb E_{s,\epsilon,x_0}\Big[\sum_k D_{\psi,k}\big(\varphi_k(\hat x_\theta)\big)\Big]$$ $$\mathcal L^{D}_\text{adv}=\mathbb E_{x_0}\Big[\sum_k\max\big(0,1-D_{\psi,k}(\varphi_k(x_0))\big)+\gamma R_1\Big]+\mathbb E_{\hat x_\theta}\Big[\sum_k\max\big(0,1+D_{\psi,k}(\varphi_k(\hat x_\theta))\big)\Big]$$ $$\mathcal L_\text{distill}=\mathbb E_{t,\epsilon'}\Big[c(t)\,\big\lVert\hat x_\theta-\hat x_\phi\big(\mathrm{sg}(\hat x_{\theta,t});t\big)\big\rVert_2^2\Big],\quad \hat x_{\theta,t}=\alpha_t\hat x_\theta+\sigma_t\epsilon'$$

LADD 用整流流记号 xt = (1−t)x₀ + tε，t ∈ [0, 1]，判别器特征来自教师 Fϕ(x̂t̂, t̂)，目标只剩对抗项 LADD §2.1、§3。

论文内部不一致 ADD Tab. 1f 的标题写的是“Teacher steps”（教师步数 1 / 2 / 4），而表注又说所有结果都是“单步学生”，正文则说“教师连续多步并无明确收益”。表头的“Steps”应理解为教师步数。另外，ADD Tab. 2 中 Progressive Distillation 一行引用的文献 [43] 实为 Meng 等人的引导蒸馏论文，可能是引用错位。

6. 伪代码

add_train_step.py（依据 ADD §3；官方未开源训练代码，示意）
T_STUDENT = [tau1, tau2, tau3, 1000]           # N = 4，最后一个为纯噪声（零终端 SNR）
G = copy(teacher_unet).train()                 # 学生：从教师初始化
phi = dinov2_vits14().eval().requires_grad_(False)   # 冻结特征网络
heads = [DiscHead(c) for c in phi.layer_dims]  # 可训练判别头 D_psi,k

def train_step(x0, text):                      # x0：真实图像（潜变量）
    s = random.choice(T_STUDENT)
    x_s = alpha[s] * x0 + sigma[s] * randn_like(x0)
    x_hat = G(x_s, s, text)                    # 学生一次前向
    img_fake = vae.decode(x_hat)               # ADD 在像素空间判别与蒸馏
    # ---- 对抗项（生成器一侧）----
    c = (clip_text(text), dinov2_vitl_cls(vae.decode(x0))) # 文本 + 图像条件
    l_adv = -sum(h(f, c).mean() for h, f in zip(heads, phi.features(img_fake)))
    # ---- 分数蒸馏项 ----
    t = sample_teacher_t()
    with torch.no_grad():                      # sg：教师一侧不回传
        x_t = alpha[t] * x_hat + sigma[t] * randn_like(x_hat)
        target = (x_t - sigma[t] * teacher_eps(x_t, t, text)) / alpha[t]
    l_distill = c_weight(t) * ((img_fake - vae.decode(target)) ** 2).mean()  # 像素空间
    (l_adv + 2.5 * l_distill).backward(); opt_G.step(); opt_G.zero_grad()
    # ---- 判别器 ----
    real_f, fake_f = phi.features(vae.decode(x0)), phi.features(img_fake.detach())
    l_D = sum(relu(1 - h(r, c)).mean() + relu(1 + h(f, c)).mean()
              for h, r, f in zip(heads, real_f, fake_f))
    l_D = l_D + 1e-5 * r1_on_head_inputs(heads, real_f)
    l_D.backward(); opt_D.step(); opt_D.zero_grad()

简答题

Q7ADD 为什么要把学生初始化成教师，同时保留对抗项和蒸馏项？只用其中一项分别会怎样？

纯对抗训练在大规模文生图上难以扩展：GAN 容量增大后性能饱和，需要精细平衡的架构，且没有 CFG。从教师初始化后，生成器一开始就在数据流形附近，判别器只需纠正局部模糊，博弈稳定得多——ADD 的消融里随机初始化直接崩溃（FID 293.6），预训练初始化为 20.6。两项损失分工不同：对抗项以真实图像为参照，让每次前向都落在流形上、足够清晰；蒸馏项以教师为参照，保留构图与文本对齐。只用蒸馏项会崩溃（FID 315.6），因为它等价于 SDS，是缺少熵项的寻模梯度；只用对抗项 FID 尚可（20.8）但文本对齐更差（CLIP 0.315 vs 0.319）。 ADD §3–4、Tab. 1 LADD §3 Lightning §3.2–3.7

  • 蒸馏项不能直接喂干净的学生输出，要先再加噪再让教师去噪，否则对教师是分布外输入。
  • 加权方式在“多样性”与“对齐”之间折中：指数加权 FID 最好，SDS / NFSD 加权 CLIP 更高，最终模型用 NFSD。
  • 保留扩散框架的附带好处：可以 1 步，也可以 2–4 步迭代细化；代价是多样性低于教师。 ADD §3–4、Tab. 1 LADD §3 Lightning §3.2–3.7

依据：ADD §3、§4.1、Tab. 1c / 1d、附录 A；VSD §3.3（SDS 是单点变分分布的特例）。

Q8ADD、LADD、SDXL-Lightning 的判别器分别“看”什么特征？各自解决了什么，又带来什么代价？

ADD 用冻结的 DINOv2 ViT-S 特征加可训练轻量头：视觉先验强、容易平衡，但只认像素，潜扩散模型必须解码，分辨率被限制在 518²，也无法区分全局与局部反馈。LADD 改用冻结教师（MMDiT）在再加噪潜变量上的各层 token：不用解码、支持多宽高比，噪声级 t̂ 成了调节“看结构还是看纹理”的旋钮；配合教师合成数据，连蒸馏项都可以去掉。Lightning 用 SDXL UNet 编码器的可训练拷贝，并以 xt 为条件，迫使学生沿教师的概率流走、保住模式覆盖；代价是容量不足时出现 Janus 伪影，需要再用无条件判别器微调，且要逐段蒸馏、每个步数一个检查点。 ADD §3–4、Tab. 1 LADD §3 Lightning §3.2–3.7

  • 共同趋势：判别器从“外部判别式网络”变成“扩散模型自身的生成式特征”，在潜空间、带噪声级。
  • Lightning 的一步模型还要把判别器输入加噪到 {10, 250, 500, 750}：UNet 编码器在 t = 0 只关注高频，评判不了结构。 ADD §3–4、Tab. 1 LADD §3 Lightning §3.2–3.7
  • DMD2 的 GAN 分类头直接借用了这种“扩散 UNet 瓶颈特征 + 卷积头”的设计。

依据：ADD §3.2、Tab. 1a；LADD §1、§3、§4.1–4.2；Lightning §2.4、§3.2–3.4、§3.7；DMD2 附录 F.1。
