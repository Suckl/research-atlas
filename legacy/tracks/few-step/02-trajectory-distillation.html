1. 动机：一次学完整条轨迹，还是逐段合并

DDIM 的确定性采样给出了一个关键接口：固定初始噪声 \(\epsilon\)，教师输出就确定了。Luhman 与 Luhman 的 Denoising Student 是本线最早的单步 ODE / DDIM 映射蒸馏工作，直接回归教师采样器的最终输出，而不是把独立的真实图像随机配给噪声Denoising Student §3。它先生成 1.024 million 对合成样本；CIFAR-10 与 CelebA 教师用 100 步 DDIM，LSUN 用 50 步Denoising Student §3.1、§4。每个配对都要跑完教师，离线数据成本随教师步数增长。

Progressive Distillation（PD）把困难的大跳跃拆开：学生每次只学会替代相邻的两步教师 DDIM，再把训练好的学生冻结成下一轮教师，逐轮减半PD §3、Alg. 2。Rectified Flow 则先改造流的几何和噪声—端点配对，让完整映射更容易用单步表示。两者都利用确定配对，但一个压缩局部积分，另一个先把流拉直。

一句话理解 PD 教学生“用一次跳跃接住教师两步的落点”；Reflow 先重新配对噪声与教师终点，再学习更直的路径。单步效果取决于要拟合的映射有多复杂，而不只取决于教师图像有多好。

3. 组件拆解

3.1 反解 DDIM：监督的是“能够接住落点的数据预测”

PD 使用 VP 约定 \(x_t=\alpha_t x_0+\sigma_t\epsilon\)、\(\alpha_t^2+\sigma_t^2=1\)，t 越大噪声越强。一个学生步长记为 h；教师先从 t 到 \(t'=t-h/2\)，再到 \(s=t-h\)。确定性 DDIM 更新可以写成PD Eq. (7)、Alg. 2：

$$x_s=\alpha_s\hat x_0+\frac{\sigma_s}{\sigma_t}(x_t-\alpha_t\hat x_0),\qquad \tilde x_0=\frac{x_s-(\sigma_s/\sigma_t)x_t}{\alpha_s-(\sigma_s/\sigma_t)\alpha_t}.$$

右边的 \(x_s\) 是教师两步算出的结果，\(\tilde x_0\) 才是学生数据预测的回归标签。一般它既不等于原始训练图像，也不等于中间状态。给定 \(x_t,t\) 后标签是确定的，所以不需要把互不相容的真实图像平均起来PD §3、App. G。

3.2 v 参数化：不要在纯噪声端除以趋零的 α

$$v=\alpha_t\epsilon-\sigma_t x_0,\qquad \hat x_0=\alpha_t x_t-\sigma_t\hat v_\theta,\qquad \hat\epsilon=\sigma_t x_t+\alpha_t\hat v_\theta.$$

PD §4、App. D ε 参数化需要 \(\hat x_0=(x_t-\sigma_t\hat\epsilon)/\alpha_t\)：越接近纯噪声，越会放大预测误差；在 α 为零的端点接口甚至退化。v 参数化通过旋转关系直接得到数据预测，纯噪声端仍能提供有效输出。PD 的 cosine schedule 为 \(\alpha_t=\cos(\pi t/2)\)，对应 \(\sigma_t=\sin(\pi t/2)\)PD §4。

同一个 v 字母，路径不同PD 的 v 是 VP 路径在角度参数下的切向量；线性 Flow Matching 中的 v 是 ε − x₀。本页分别写明路径，不能直接交换两个网络的输出解释。

3.3 Guided Distillation：先吸收 CFG，再减少时间步

Meng 等人的 guided distillation 先训练一个带 guidance 强度条件的学生，匹配教师条件与无条件输出的组合；再对这个已吸收 guidance 的网络做 progressive distillationGuided Distillation §3.1–3.2。它解决了两个成本：CFG 的双分支评价和多步采样。guidance 强度是学生输入的一部分，因而仍能调节质量—多样性取舍；不是只蒸馏一个固定提示词或固定强度。

3.4 Rectified Flow / Reflow：先改变配对，再改变轨迹

原论文把 \(X_0\) 记为噪声、\(X_1\) 记为数据，从时间零向时间一生成。为和全 track 一致，这里反转时间，用 \(x_0\) 表示数据、\(\epsilon\) 表示噪声，\(x_t=(1-t)x_0+t\epsilon\)，生成从 t=1 到 t=0；速度符号相应反转Rectified Flow §2.1，记号与时间重写。训练目标沿条件直线回归 \(\epsilon-x_0\)，最优边缘速度为条件期望：

$$\mathcal L_\mathrm{RF}=\mathbb E_{(\epsilon,x_0)\sim\gamma,t}\|v_\theta(x_t,t)-(\epsilon-x_0)\|^2,\qquad v^*(x,t)=\mathbb E[\epsilon-x_0\mid x_t=x].$$

独立配对的直线可能相交，交点处有多个方向；ODE 只有一个局部方向，所以会重新组织路径，而不是沿每条训练直线原封不动地走。满足论文假设且精确学习时，ODE 保持这些路径的时间边缘分布，并给出确定的端点 couplingRectified Flow §2.2、Thm. 3.3。

Reflow 就是用旧流完整积分得到 \(x_0=\Phi_\phi(\epsilon)\)，保留原噪声，重新在这个 coupling 的直线插值上训练新流。反复执行会减少路径弯曲；理想理论还保证凸位移代价不增加Rectified Flow Alg. 1、Thm. 3.5、§3.4。这不是声称每次有限训练都获得全局最优传输，也不是把任意独立 coupling 的第一条流直接变成完美直线。

组件展示单步平方回归的理论最优输出：独立配对时为数据均值，ODE 配对时为确定端点映射。它没有实际优化神经网络，ODE 端点用四十八步 Euler 近似；连线仅用于解释配对，二维投影上的视觉交叉不等于同一时刻的 ODE 轨迹相交组件 fewstep2d.js：odeMap、draw。实际 Reflow 回归的是整条重新配对的条件路径速度，不只是组件里显示的端点。

3.5 InstaFlow：拉直之后，仍要学会单步出口

InstaFlow 把 Stable Diffusion 当作初始流，从其教师采样端点构造文本条件 coupling，经 Reflow 得到 2-Rectified Flow，再把它的噪声—终点映射蒸馏成固定噪声端的单步网络InstaFlow §3、Fig. 3。Reflow 减少了映射复杂度，但不保证只用一次速度评价就足够；论文中未蒸馏的 2-RF 单步仍明显落后于多步版本。后续先用 L2，再用 LPIPS 蒸馏，提高细节InstaFlow App. D。

2-RF 保留可连续积分的流，单步出口则吸收了生成映射。不要把“第二条训练出的流”与“两次网络评价”混为一谈，也不要把 pilot 的 SD 1.4 结果与完整训练的 SD 1.5 结果混在同一表里InstaFlow Tab. 1–2。

5. 回归目标与仍可能出现的模糊

$$\mathcal L_\mathrm{PD}=\mathbb E\left[a(t)\|\hat x_{0,\theta}(x_t,t)-\mathrm{sg}(\tilde x_0(x_t,t))\|^2\right],\quad a(t)=\max(\mathrm{SNR}(t),1)\ \text{或}\ 1+\mathrm{SNR}(t).$$

PD §4 本页把损失权重记作 a(t)，避免与 guidance 系数 w 混淆。它在低 SNR 仍保留数据监督；v-space 的平方损失等价于数据空间的 SNR+1 加权。这个权重关系依赖 VP 的旋转恒等式。

$$\mathcal L_\mathrm{distill}=\mathbb E_{\epsilon,c}\,d\!\left(G_\theta(\epsilon,c),\mathrm{sg}(\Phi_\phi(\epsilon,c))\right).$$

Denoising Student Eq. (11)；RF Alg. 1；InstaFlow Eq. (6) 确定 coupling 下，平方回归的理想最优解就是教师映射。但高维细节可能超出学生可表达能力；像素或 latent 的平方误差还会鼓励“平均掉难以拟合的差异”。Denoising Student 已报告高分辨率纹理模糊，InstaFlow 则用 Reflow 与感知损失缓解Denoising Student §4.1；InstaFlow §3、App. D。感知损失改变了误差度量，不能替代模式覆盖检查。

def ddim_step(model, x_t, t, s):
    x0_hat = data_prediction(model, x_t, t)   # 若网络输出 v，先转换
    eps_hat = (x_t - alpha(t) * x0_hat) / sigma(t)
    return alpha(s) * x0_hat + sigma(s) * eps_hat

# 一轮 PD：teacher 用 2N 步，student 用 N 步
student.load_state_dict(teacher.state_dict())
for x0 in data_loader:
    t = sample_student_grid(N)               # 取值 i/N，含纯噪声端
    mid, s = t - 0.5 / N, t - 1.0 / N
    x_t = alpha(t) * x0 + sigma(t) * randn_like(x0)
    with no_grad():
        x_mid = ddim_step(teacher, x_t, t, mid)
        x_s = ddim_step(teacher, x_mid, mid, s)
        ratio = sigma(s) / sigma(t)
        target = (x_s - ratio * x_t) / (alpha(s) - ratio * alpha(t))
    pred = data_prediction(student, x_t, t)
    loss = weighted_mse(pred, target, time_weight(t))
    optimizer.zero_grad(); loss.backward(); optimizer.step()
# 收敛后冻结 student 为新 teacher，再将 N 减半

# Reflow 是另一条训练路线，先离线生成确定 coupling
for eps, c in noise_condition_loader:
    x0 = frozen_old_flow_endpoint(eps, c)     # 完整 ODE 解；停止梯度
    save_pair(eps, x0, c)
for eps, x0, c in pair_loader:
    t = uniform_time()
    x_t = (1 - t) * x0 + t * eps
    loss = mse(new_velocity(x_t, t, c), eps - x0)
    optimize(loss)

9. 承上启下

改进了什么

  • PD 不必离线完整采样教师才获得每个局部标签。
  • Reflow 改造端点 coupling，InstaFlow 再用感知蒸馏拟合单步映射。

下一步问什么

  • Consistency Models 不显式回归每段位移，而让邻近状态共享终点。
  • DMD 与 ADD 用分布监督补足逐样本回归的细节。

视频里，轨迹回归仍可作为 CausVid 的初始化。可是从双向教师迁到因果学生时，目标可能依赖学生看不到的未来噪声；确定的完整教师映射不再等于“相对于学生输入确定”，这个区别在 Causal Forcing 中继续展开。

简答题

Q3PD 为什么反解数据预测目标，而不直接回归教师下一状态？v 参数化解决了什么？

学生网络输出数据预测，DDIM 再把它转换为下一状态；反解后才能保证学生一步匹配教师两步的落点。v 参数化避免在纯噪声附近用趋零的 α 除回数据预测。

  • 中间状态与数据端表示同形状，语义却不同。
  • 给定当前输入，教师局部落点与反解目标都确定。
  • 低 SNR 的损失权重必须保留有效监督；稳定参数化与损失权重需要一起考虑。

依据：PD §3–4、Alg. 2、App. D、App. G。

Q4条件路径已经是直线，为什么还需要 Reflow，为什么之后仍要蒸馏？

独立配对的条件直线会给出互相冲突的局部方向；边缘 ODE 重新组织路径，实际轨迹仍可能弯曲。Reflow 用旧 ODE 的确定端点重新配对，让新流更直，端点蒸馏再专门拟合单步出口。

  • 初始条件直线与实际 ODE 轨迹不是同一对象。
  • 理想的凸运输代价不增加，不代表有限训练获得全局最优运输。
  • InstaFlow 中未蒸馏的 2-RF 单步仍较差，说明“拉直”不自动等于“单步训练完成”。

依据：RF §2.1–2.2、Alg. 1、Thm. 3.3/3.5；InstaFlow §3、Tab. 2。
