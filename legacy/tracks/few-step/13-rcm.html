1. 动机：能把 sCM 跑大，不等于大模型生成质量足够好

sCM 用连续时间一致性摆脱离散时间课程：沿教师 ODE 的点都应映射到同一干净终点。但大规模文生图 / 文生视频还遇到两个独立问题：高效 JVP 无法直接与 FlashAttention、参数分片和长序列并行协作；即使解决运行问题，纯 sCM 仍会在小字、细纹理和跨帧物体几何上失真。rCM 同时处理计算基础设施与目标函数的质量缺口论文 §3.2–3.3、Fig. 3。

论文蒸馏 Cosmos-Predict2 文生图模型（0.6B、2B、14B）和 Wan2.1 T2V（1.3B、14B），还验证 Cosmos-Predict2 TI2V（2B）的视频生成论文 v3 §5.1、Tab. 1–3。基础 rCM 生成整段双向视频；后文的 Causal-rCM 才增加自回归流式生成。

一句话理解在数据 / 教师轨迹上学“沿轨迹不变”的一致性，保留覆盖能力；同时在学生实际生成的样本上用 DMD 式分数差修复长距离跳跃的细节。总目标 \(\mathcal L_{\mathrm{sCM}}+\lambda\mathcal L_{\mathrm{DMD}}\) 中，论文使用 \(\lambda=0.01\)论文 §4.1。分数项是正则，整个方法仍有冻结教师和在线 fake score。

3. 组件拆解

3.1 TrigFlow wrapper：复用现有教师，不重训噪声日程

以下 \(t\) 是 TrigFlow 角度：\(x_t=\cos(t)x_0+\sin(t)\epsilon\)，\(t=0\) 为数据，\(t=\pi/2\) 为噪声；\(x_0\) 已吸收数据标准差。用 \(F_\theta\) 表示包装后的速度预测，\(f_\theta=\cos(t)x_t-\sin(t)F_\theta(x_t,t,c)\) 表示一致性函数论文 §2.2、Eq. 3。

教师原始时间 \(\tau\) 可使用 Flow Matching 的 \((1-\tau)x_0+\tau\epsilon\)。wrapper 通过匹配 \(\sigma_\tau/\alpha_\tau=\tan t\) 找到对应时间，并缩放输入、转换输出参数化。师生都做同一包装，所有转换在 FP64 中计算；这减少精度损失，并把“噪声坐标变化”与“学习新生成能力”分开论文 §3.1、Eq. 3。

3.2 FlashAttention-2 JVP、FSDP 与 context parallel

视频 attention 的序列同时包含时间与空间。普通 JVP 若落回显式注意力，会重新引入完整注意力矩阵的内存代价。rCM 的 Triton 核在同一个分块流式循环里计算输出 \(O\) 和切向输出 \(\dot O\)，支持自注意力与交叉注意力论文 §3.2、App. C.1、Alg. 2：

$$\dot S=\dot QK^\top+Q\dot K^\top,\quad \dot P=P\odot\left(\dot S-\operatorname{rowsum}(P\odot\dot S)\right),\quad \dot O=\dot PV+P\dot V.$$

这里省略标准 attention 缩放因子，行和按列广播。切向 softmax 必须减去行均值项；只求 \(\dot QK^\top\) 或只重算普通 attention 都不等于 JVP论文 App. C.1。

FSDP 下不把整模型直接塞给 torch.func.jvp，而是逐层显式传递 primal / tangent，使参数 all-gather 与层前向保持正常边界。Ulysses CP 把 QKV 的序列分片换成头分片再算 attention，切向量走相同 all-to-all；完成后两份输出一起还原序列分片论文 §3.2、App. C.2。工程目标是让连续时间目标能在大模型上训练，并不改变一致性方程。

3.3 为什么纯 sCM 会有细节与时间一致性问题

作者在纯 sCM 的生成中观察到小字失真、纹理模糊以及跨帧物体穿透；扩模型并没有自动消除这些问题论文 §3.3.1、Fig. 3。其误差传播解释是：低噪声处教师信号强，随时间增大，教师项的系数变小，学生自己的 JVP 反馈占主导；局部误差便可能沿时间方向积累论文 Eq. 5、§3.3.2。

这是作者的机制分析。附录的 BF16 / FP32 对照显示 JVP 比普通输出更敏感，支持数值误差值得关注；它没有单独证明所有视觉失真都仅由 BF16 引起论文 App. F.2、Fig. 12。因此既需要更稳的时间导数，也需要直接检查长跳后的生成分布。

3.4 分数正则：把长跳输出交给 DMD 监督

把完整少步采样记作学生生成器 \(G_\theta\)，令 \(\hat x_0=G_\theta(\epsilon,c)\sim p_\theta\)；\(s_{\mathrm{real}}\) 是冻结教师 score，\(s_{\mathrm{fake}}\) 是在线辅助网络估计的学生 score。DMD 的反向散度更新在学生自己的样本上取期望；在去噪器参数化下，可用 fake / teacher 的干净预测差建立停止梯度的伪目标论文 §2.3、Eq. 6。

与 DMD2 相比，rCM 留下独立的轨迹一致性目标，论文不加入 GAN 判别器。作者把这看作“覆盖数据模式的 forward 目标”与“修复生成高密度区域的 reverse 目标”互补，而不是追求单个 DMD 目标的最大权重论文 §1、§4.1、§5.2。

3.5 时间导数精度：图像的可行近似未必适合大视频

论文先尝试 semi-continuous 方案：状态导数用精确 JVP，时间偏导用步长 \(10^{-4}\) 的有限差分；它在 2B 级图像模型上稳定。但在 10B+ 或视频设置中，这个近似对步长敏感，最终回到全 JVP，并强制时间嵌入层使用 FP32论文 §4.2。其余大网络仍可使用 BF16，wrapper 转换保留 FP64；不能把它概括成“整模型改成高精度”。

3.7 TurboDiffusion：步数、注意力与量化的加速相乘

TurboDiffusion 使用 rCM 降步数；另一路把 dense attention 换成 Sparse-Linear Attention（SLA）并微调，之后合并两路参数更新。部署再用 SageAttention2++ 支持的 SageSLA 和 Linear 的 W8A8 INT8 量化，量化块为 128×128TurboDiffusion §1.1–1.3。这不是仅减少 NFE 所带来的收益。

单张 RTX 5090、Wan2.1-T2V-1.3B-480P 的示例扩散延迟从 184 s 变成 1.9 s；论文的速度配置用 3 步、90% attention 稀疏度，而实践建议使用 4 步并适当降低稀疏度TurboDiffusion §2.1、Fig. 1、Fig. 12。计时排除文本编码与 VAE 解码，质量比较主要为视觉示例，不能把其速度或质量声称直接换成下表 H100 上的 VBench / FPSTurboDiffusion §2.2。

3.8 Causal-rCM：先 teacher forcing 一致性，再 self forcing DMD

Causal-rCM 将互补原则推广到因果训练：用离线真实 / 合成历史的 TF-CM 建立少步因果起点，再用学生自身历史的 SF-DMD 修正部署分布。连续时间 sCM / MeanFlow 需要为带自定义掩码的 FlashAttention-2 开发 JVP，才能支持因果蒸馏；论文还比较 TF、DF、ODE 回归等初始化，而不是把它们都视作等价起点Causal-rCM §3.1–3.2、Tab. 5。

TF-sCM 在拼接的干净历史 / 带噪当前块上沿因果教师求导，历史的切向量设为零，只有带噪分支沿教师速度移动。这里改用 RF-native 目标：作者发现基础 rCM 的 TrigFlow wrapper 在因果 TF 设置中表现较差；日程可解析转换，也不保证归一化后损失的训练行为相同Causal-rCM §3.1.2、Eq. 15–19、App. A。

Wan2.1-1.3B 的逐帧设置中，论文的 2-step 与 1-step 行都报告 VBench Total 84.63，但 NFE 分别为 3 与 2：另一次前向用于写入干净 KV context；2-step noisy-context 行则为 2 NFE、83.11Causal-rCM Tab. 4、§3.1.3。这些少步数指后续块，首块仍使用 4 步Causal-rCM §4.1 的采样日程。摘要的“1 或 2 步”不能直接读成“1 或 2 NFE”。这些因果结果来自后续论文自己的协议，与基础 rCM 的双向视频结果分开。

5. 训练目标与论文 / 代码差异

先令 \(D_tF_\theta=\partial_xF_\theta F_{\mathrm{teacher}}+\partial_tF_\theta\)。由 \(f_\theta=\cos(t)x_t-\sin(t)F_\theta\)，沿教师轨迹的全导数为论文 Eq. 5：

$$D_tf_{\theta^-}=-\cos(t)(F_{\theta^-}-F_{\mathrm{teacher}})-\sin(t)(x_t+D_tF_{\theta^-}),\qquad g=\cos(t)D_tf_{\theta^-}.$$

论文的切向归一化损失写为（\(\delta\) 是平滑常数，区别于文本条件 \(c\)）论文 Eq. 4：

$$\mathcal L_{\mathrm{sCM}}^{\mathrm{paper}}=\mathbb E\left\|F_\theta-F_{\theta^-}-\operatorname{sg}\left(\frac{g}{\|g\|_2^2+\delta}\right)\right\|_2^2.$$

对学生样本加噪 \(\hat x_t=\cos(t)\hat x_0+\sin(t)\epsilon\)，定义归一化预测差 \(\Delta\)；生成器损失采用停止梯度的伪目标论文 Eq. 6、§4.1：

$$\Delta=\frac{f_{\mathrm{fake}}(\hat x_t,t,c)-f_{\mathrm{teacher}}(\hat x_t,t,c)}{\operatorname{mean}|\hat x_0-f_{\mathrm{teacher}}(\hat x_t,t,c)|},\quad \mathcal L_{\mathrm{DMD}}=\mathbb E\|\hat x_0-\operatorname{sg}(\hat x_0-\Delta)\|_2^2,\quad \mathcal L_{\mathrm{rCM}}=\mathcal L_{\mathrm{sCM}}+\lambda\mathcal L_{\mathrm{DMD}}.$$

fake 网络则对 detached 学生样本做 Flow Matching，目标速度为 \(v=\cos(t)\epsilon-\sin(t)\hat x_0\)。它学习当前学生分布，不能长期冻结为教师拷贝论文 §5.1、Alg. 1。

论文 vs 官方代码论文 v3 Eq. 4 写 \(\|g\|_2^2+0.1\)，但核查到的官方 _student_scm_step 用 g.norm(p=2) + 0.1，即L2 范数而非平方范数；代码先转 double 后归一化。Wan 配置用 loss_scale=100、loss_scale_dmd=1，相对权重对应论文的 \(\lambda=0.01\)官方代码 rcm/models/t2v_model_distill_rcm.py；rcm/configs/experiments/rcm/wan2pt1_t2v.py，提交 ed3cb14。以下伪代码按代码归一化；不能把两种分母默认为等价。代码当前 rollout 长度也按迭代循环，论文 Alg. 1 描述为随机抽取官方代码 _student_dmd_step；论文 Alg. 1。论文实验实际使用哪一种归一化分母、差异是否为排版问题，尚未核实。

依据官方 _student_scm_step / _student_dmd_step 与 Alg. 1；展示 warmup 后的 TrigFlow 分支
student.load(teacher.weights)
fake.load(teacher.weights)
for it, (x0, c) in enumerate(data_loader):
    # wrapper 负责原始基座与 TrigFlow 之间的转换
    N = 1 + it % Nmax                         # 代码循环；论文用随机长度
    if it % update_freq == 0:
        t = sample_time_G(); eps = randn_like(x0)
        xt = cos(t)*x0 + sin(t)*eps
        with no_grad():
            v_real = teacher_velocity_cfg(xt, t, c)
            a = cos(t)*sin(t)
            F_sg, scaled_dF = layerwise_jvp(
                student, (xt, t), (a*v_real, a), c)
            g = -cos(t)**2*(F_sg-v_real) - a*xt - scaled_dF
            g = g.double() / (l2_norm_nonbatch(g.double()) + 0.1)
        pred = student_velocity(xt, t, c)
        Lcm = squared_norm(pred - pred.detach() - g.detach())
        # 去噪 / 重加噪交替，时间单调下降，只有最后步有梯度
        xhat = backward_simulation(student, c, N, grad_last=True)
        td = sample_time_D()
        xhat_t = cos(td)*xhat + sin(td)*randn_like(xhat)
        with no_grad():
            real_x0 = teacher_denoise_cfg(xhat_t, td, c)
            fake_x0 = fake_denoise(xhat_t, td, c)
            denom = mean_abs_nonbatch(xhat-real_x0).clamp_min(1e-5)
            delta = (fake_x0-real_x0) / denom
        Ldmd = squared_norm(xhat - (xhat-delta).detach())
        update(student, cm_scale*Lcm + dmd_scale*Ldmd)
    else:
        with no_grad():
            xhat = backward_simulation(student, c, N, grad_last=False)
        td = sample_time_D(); eps = randn_like(xhat)
        xt = cos(td)*xhat + sin(td)*eps
        velocity = cos(td)*eps - sin(td)*xhat
        update(fake, squared_norm(fake_velocity(xt, td, c)-velocity))

9. 承上启下

图像与早期视频配方

  • sCM：连续时间局部一致性与 JVP，偏重轨迹保留。
  • DMD / DMD2：在学生样本上反向分布匹配，生成细节更强但可能损失覆盖。
  • Video consistency：把少步一致性迁到视频，仍需要解决大基座的工程与质量瓶颈。

rCM 与两个延伸方向

  • 局部一致性 + 长跳分数正则；用可分片的 attention JVP 把框架扩到大视频。
  • TurboDiffusion 把步数缩减与稀疏注意力、量化组合，解决单步成本。
  • Causal-rCM 联合 TF-CM 与 SF-DMD，连接 Self Forcing、Causal Forcing 的因果谱系。

它仍需要教师、fake score 和生成 rollout；如果目标是去掉在线扩散监督网络，应继续比较 RDM / ViRDM。这是一种监督来源变化，并非 rCM 已经验证的替代方案。

简答题

Q25把 sCM 扩到大视频模型时，为什么既要改 JVP 工程又要改目标？两者能互相替代吗？

工程解决的是能否在长序列、参数分片与有限内存下正确高效地计算输入全导数；FlashAttention-2 JVP 和逐层切向接口让连续时间目标可运行。目标改动解决的是运行之后的生成质量：局部一致性依赖自身导数反馈，长跳输出仍可能失真，所以加入学生生成分布上的 DMD 正则。更省显存的同一目标不会自动得到这项监督，正则也不会使不兼容的 JVP 可训练。

  • FP32 时间嵌入稳定导数；整个网络并没有全部改成高精度。
  • 视频分数评估看完整时间序列；基础 rCM 仍为双向生成，因果部署需另加配方。

依据：rCM §3.2–3.3、§4.1–4.2、App. C、F.2。

Q26为什么 rCM 把 DMD 当正则保留 sCM？怎样判断质量提升是否牺牲了多样性？

DMD 在学生已生成样本上寻找教师高密度区域，容易修复细节，但也可能收缩到少数模式；sCM 在数据 / 教师轨迹上保持映射约束，为未被当前学生充分生成的模式留下监督。联合目标用较小的分数正则修复长跳，而不完全放弃数据侧约束。评估需要固定 prompt、采样日程并改变种子，看输出差异与覆盖；仅靠 VBench 或 GenEval 的均值不够。

  • λ 消融给出质量与多样性的相反趋势，但本论文主要是样例证据，不能宣称严格保证不坍塌。
  • Causal-rCM 进一步区分离线 TF 初始化与 on-policy SF 精修；后者改变历史输入的来源，不只是改一致性权重。

依据：rCM §2.3、§5.2、Fig. 1、Fig. 7、App. D；Causal-rCM §3.1。
