1. 动机：能否只更新生成器，把监督提前算好？

Self Forcing 与 Causal Forcing 的 DMD 后训练要同时维护生成器、冻结 real score 和在线 fake score：典型 Wan2.1 配置是 1.3B 学生、14B 教师、1.3B critic。score 差间接估计分布误差，每个更新都要调用大教师并训练 critic论文 §1、Tab. 7；Causal Forcing App. D。

RDM 在图像上提供另一条路：固定参考分布，直接比较生成结果与参考在冻结编码器中的分布。ViRDM 把它搬到少步因果视频，目标是去掉后训练中的在线扩散教师和可学习 critic。它仍需要一个已完成因果适配的初始化、离线视频参考、冻结表征网络与可微解码器；“generator-only”描述的是更新对象，并不表示训练只有一个网络或不继承教师生成的数据论文 §3.2、§3.4.2、§5。

一句话理解 保留 Causal Forcing 的 causal ODE 起点，把 DMD 换成固定视频—文本表征的 MMD；用随机干净退出、轻量解码器和分阶段 VJP 让梯度放进显存，再补一个低权重光流正则。最终 20 次生成器更新得到 VBench 84.87，后训练耗费约 16 A100 GPU-hours论文摘要、§4.1、Tab. 7–8。

3. 组件拆解

3.1 从图像到视频：RDM 的三处前提失效

图像 RDM 把生成样本经冻结特征编码器后做 MMD。ViRDM 保留终点分布目标，却发现“接一个视频编码器”并不足够：少步 AR 展开、视频解码和时序表征改变了计算与优化条件论文 §1、§3。

图像侧经验搬到视频后哪里失效具体改动
一步生成后直接反传到像素与特征少步因果 rollout、视频 VAE 与编码器的反向图共驻显存随机干净退出 + 轻量解码器 + 分阶段 VJP
大量新鲜样本；可从双向基座后训练整片视频采样昂贵；短后训练不能自行建立因果生成能力小规模新鲜视频群体；使用已适配因果的初始化
图像表征分布能约束外观与语义逐帧边缘分布不识别帧序；池化视频表征对较强运动的梯度变弱整片上下文视频表征 + 显式动态正则

这些是该基座与后训练设置的受控经验，并非“小批量 MMD 普遍更好”的结论；ViRDM 没有把图像 iRDM 的多编码器加权与超大批量配方原样复制论文 §3.4–3.5。

3.2 显存：退出点缩短轨迹，VJP 分开模块

普通 ODE 采样只在走完轨迹后得到终点；若终点 loss 穿过所有去噪评估，就要保留整个展开。consistency-style 采样每次预测 \(\hat z_0\)，继续采样时再加噪，所以每个退出都能解码为干净视频并接 RDM。随机监督一个退出让训练覆盖不同采样步，同时截断之前的去噪图论文 §3.3.1、Fig. 2。

但退出并未消除 decoder 与 encoder 的激活。冻结参数只省参数梯度，仍须保存计算输入梯度的激活。ViRDM 先获得表征梯度，再依次重算编码器、解码器、生成器；完整 Wan VAE 即使独立反传仍放不下，因此替换训练桥梁为 TAEW2.1。三项同时使用才得到可行配置论文 §3.3.2、Tab. 1。

3.3 新鲜样本：视频群体的边际收益很快降低

固定更新预算的群体消融中，B=8 已能改善，B=64 取得较好的质量—时间平衡；B=1024 比 B=64 的 Total 只高 0.16，单次更新却约 96 分钟。不同于图像 RDM 的大批量经验，这里新鲜视频的边际收益很快降低论文 §3.4.1、Tab. 2。这些群体消融尚未加动态正则，不能与最终主表混为同一个阶段。

3.4 初始化：短后训练需要已有因果能力

同样的 20 次更新、B=64 下，原始双向基座直接改因果推理只到 Total 65.80；TF 起点到 83.21；causal CD / causal ODE 分别到 82.99 / 83.41。TF 已能提供有效信号，说明预先少步蒸馏并非必要条件；causal ODE 则进一步改善动态，成为默认初始化论文 §3.4.2、Tab. 3。短期分布微调能精炼已有因果 transport，不能可靠地凭空创建它。

3.5 时间动态：表征看得见运动，不表示处处给出足够梯度

作者把视频均匀抽帧再重复到原长度，逐渐恢复运动。逐帧 DINOv2 的 MMD 在保留 25% 到 100% 动态之间几乎不变；V-JEPA 2.1 对运动更敏感，但主要响应发生在接近静止处，较强运动之间的差异变小。对 MMD 开方仍出现这一趋势，因此不能只归因于平方损失尺度论文 §3.5.1、Tab. 5。

冻结 RAFT 提供可解释的位移信号，单侧阈值避免不断奖励更大运动。默认低权重正则修复动态不足；高权重虽继续抬高 Dynamic Degree 和总分，却降低闪烁、主体与背景一致性。训练目标和 VBench 动态都使用光流，作者因此另查时间质量指标与人类偏好论文 §3.5.2、§4.3、Tab. 9。

5. 训练目标与梯度路径

\(\varphi\) 为冻结视频编码器，\(\tau(c)\) 为归一化文本特征。联合特征 \(\Phi(x,c)=[\varphi(x);\beta\tau(c)]\)，\(\beta=\sigma_v/\sigma_t\)，两种带宽由参考的中位数启发式计算；高斯核等于视觉核与文本核的乘积，因此语义不同的提示词不会仅凭外观相近就产生同样的吸引论文式 (1)–(2)、§3.2。

$$\mathcal L_{\mathrm{RDM}}=\frac{1}{B^2}\sum_{i,i'}k(\hat h_i,\hat h_{i'})-\frac{2}{BN}\sum_{i,j}k(\hat h_i,h_j^*)+\frac{1}{N^2}\sum_{j,j'}k(h_j^*,h_{j'}^*),\quad \hat h_i=\Phi(D(\hat z_{0,i}),c_i)$$

生成—生成项维持分布多样性，生成—参考项提供吸引，参考—参考项对生成器参数为常数。不是把某个生成视频逐样本回归到某个参考视频论文式 (3)。

$$g_{h,i}=\nabla_{\hat h_i}\mathcal L_{\mathrm{RDM}},\qquad g_{x,i}=J_{\Phi,i}^{\top}g_{h,i},\qquad g_{z,i}=J_{D,i}^{\top}g_{x,i},\qquad \nabla_\theta\mathcal L_{\mathrm{RDM}}=\sum_iJ_{G,i}^{\top}g_{z,i}$$

这是选中随机退出、历史已截断的计算图上的链式法则，并非完整多步 rollout 的精确梯度。随机退出改变了被训练的目标路径；分阶段 VJP 本身只改变同一截断图的执行顺序论文式 (5)、Alg. 1–2。

$$\mathcal L_{\mathrm{dyn}}(\hat x_0)=[\tau_{\mathrm{dyn}}-s(\hat x_0)]_+,\qquad \mathcal L=\mathcal L_{\mathrm{RDM}}+\lambda_{\mathrm{dyn}}\mathcal L_{\mathrm{dyn}}$$

\(s\) 为光流动态得分，\(\tau_{\mathrm{dyn}}\) 是运动阈值，与文本编码 \(\tau(c)\) 区分。默认 \(\lambda_{\mathrm{dyn}}=5\times10^{-4}\)论文式 (6)–(7)、Tab. 6。

论文 vs 官方代码
  • 论文式 (3) 展示完整参考 MMD；公开代码以 4096 个 Nyström landmark 近似参考吸引项，保留精确批内排斥与固定参考常数，并用 raw / (abs(raw.detach()) + 1e-7) 自归一化。这个梯度尺度细节不能由论文公式单独恢复代码 virdm_integration/reference.py、trainer/virdm.py、config_virdm_bs64_1x8.yaml。
  • 正文对光流聚合只给概述；代码对每个帧对取光流幅度最大的 5% 像素的均值，再取第 10 大帧对得分作 s，阈值 11.25。等价地，至少 10 个帧对超过阈值才使 hinge 不活跃（按代码推导）代码 trainer/virdm.py 的 _dynamic_reg_s10_hinge_latent_gradients；默认配置。
  • 基础 YAML 的 virdm_dynamic_reg_enabled 默认为 false；README 区分 nodynamic / dynamic 配方。对应最终 84.87 的模型需使用带动态正则的版本代码配置、README；论文 Tab. 6。

6. 伪代码

virdm_step.py（论文 Alg. 1–2 的执行顺序；加入式 (6) 动态支路）
# 离线：固定视频—文本参考，后训练不再更新
H_ref = encode_reference(reference_videos, reference_prompts)
G = load_causal_ode_initialization()
freeze(D, video_encoder, text_encoder, raft)
def update_generator(conditions):
    cache = []
    # 首遍无梯度：每个 distributed microbatch 同步选退出
    for microbatch in conditions:
        S = synchronized_uniform_exit()
        for c in microbatch:
            with no_grad():
                z, trace = causal_rollout(G, c, S, record_randomness=True)
                # 所有 chunk 同一 S；退出 S 前无梯度；KV detach
                x = D(z)
                h = joint_features(video_encoder(x), text_encoder(c))
            cache.append((c, S, z, h, trace))
    H = gather_fresh_features(cache).requires_grad_()
    loss_rep = mmd(H, H_ref)                   # 完整群体上的损失
    grad_h = grad(loss_rep, H)
    release_representation_loss_graph()
    grad_z = []
    for item, gh in zip(cache, local_rows(grad_h)):
        gx = replay_encoder_vjp(item, gh)
        release_encoder_graph()
        gz = replay_decoder_vjp(item, gx)
        release_decoder_graph()
        gz += lambda_dyn * staged_flow_hinge_latent_gradient(item)
        grad_z.append(gz)
    optimizer.zero_grad()
    for item, gz in zip(cache, grad_z):
        z = replay_same_rollout(G, item.trace, grad_only_at_exit=True)
        z.backward(gz)                       # 历史 KV 仍然 detach
        release_generator_graph()
    optimizer.step()

伪代码的 mmd 写论文目标；公开实现的 Nyström 与自归一化需按上方代码说明加入。分阶段动态支路与主支路在 latent 梯度处相加代码 trainer/virdm.py。

9. 承上启下

继承的东西

  • RDM：固定参考、联合视觉—文本核、直接终点分布匹配。
  • Self Forcing：自生成历史、随机退出与 KV 梯度截断。
  • Causal Forcing：先建立因果兼容的少步 transport。

改变与边界

  • 去掉后训练在线扩散教师和 critic，以固定参考表征直接提供分布梯度。
  • 模块分阶段回传、小规模新鲜视频群体和动态正则构成视频特有配方。
  • 依赖初始化与固定表征的归纳偏置；更大模型、更高分辨率与长视频仍待验证论文 §5。

简答题

Q33冻结视频编码器和 VAE 后为什么仍会超显存？随机退出与分阶段 VJP 各自省掉什么？

冻结仅关闭参数更新，损失仍须经过编码器、解码器的输入梯度回到生成器，激活仍要保存。随机退出截断先前去噪步骤的图，并以该步的干净终点预测接受分布监督；分阶段 VJP 则按表征、像素、latent、生成器顺序复算，避免不同模块反向图共驻。完整 Wan VAE 单独反传也放不下，还需要轻量解码桥梁。

  • 复算须恢复相同噪声、退出步和历史缓存，才能使用缓存输出梯度。
  • VJP 的分阶段执行保持同一截断图的链式法则；随机退出本身改变训练路径。
  • 生成器是唯一被更新的参数集合，冻结网络仍参与计算。

依据：论文 §3.3、式 (4)–(5)、Alg. 1–2、Tab. 1。

Q34为什么匹配图像或视频特征分布仍会生成弱动态视频？ViRDM 如何验证动态正则没有只刷光流分？

逐帧图像边缘分布不感知帧序与间隔；池化视频特征虽能区分静止和运动，对中等到较强运动的分布差异却不够敏感。ViRDM 用整片上下文表征，再加单侧光流阈值补运动不足。由于正则与 Dynamic Degree 都依赖光流，它同时检查未参与训练的时间一致性指标、权重变化和人类偏好。

  • 高动态不保证连贯性：崩坏与闪烁也会产生大位移。
  • 高正则权重能抬总分却伤害时间质量，默认权重选择平衡点。
  • 短后训练仍需要因果兼容起点；正确 loss 不会自动修复注意力结构转换。

依据：论文 §3.4.2、§3.5、Tab. 5–6、§4.3、Tab. 9、Fig. 6。
