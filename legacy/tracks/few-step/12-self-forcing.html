1. 动机：训练时看真值，推理时看自己

自回归视频扩散模型在推理时，第 i 个 chunk 以自己刚生成的前 i−1 个 chunk 为条件。但两种主流训练方式给它的历史都不是这样的：Teacher Forcing（TF）给干净的真实历史帧；Diffusion Forcing（DF）给每帧独立加噪的真实历史帧论文 §1、Fig. 1。CausVid 的 DMD 阶段属于后者——Self Forcing 的消融把“DF + DMD”明确当作 CausVid 配方在同一代码框架下的复现论文 §4。训练从没见过“带着自身瑕疵的历史”，推理时误差就逐帧累积——即序列模型里熟知的暴露偏差（exposure bias）。

一句话理解 训练就照推理的样子做：学生从噪声出发，带着 KV cache 逐 chunk 自回归地生成整段视频，再对这段自生成视频整体做分布匹配（默认 DMD，教师为 Wan2.1-T2V-14B）。为了让“串行展开 + 反传”放得进显存，每个 chunk 只在随机选中的那一步去噪保留梯度，历史 KV 一律截断梯度。结果：1.3B 模型在单张 H100 上 17.0 FPS、首帧 0.69 s，VBench 总分 84.31，略高于多步采样的 Wan2.1 基座（84.26）论文 Tab. 1。

3.2 训练时的自回归展开为什么不慢

串行展开看似比 TF / DF 的“整段一次前向”慢，论文给出两点理由论文 §3.2、Fig. 6：① 每个 chunk 内部的所有 token 仍然并行，GPU 利用率不低；② TF / DF 需要特殊注意力掩码（FlexAttention），SF 用的是推理同款的普通注意力 + KV cache，可以上 FlashAttention-3。实测每次迭代耗时与 TF / DF 相当，同样墙钟预算下质量更好；DMD 版本在 64 张 H100 上约 1.5 小时收敛论文 §4（README：600 次迭代，64 张 H100 不到 2 小时官方 README）。

3.3 随机梯度截断：三个“只”

  • 只有一步留梯度：每个 chunk 只有退出步 s 的那次前向保留计算图，前面的去噪在 no_grad 下完成；
  • 只在一个随机的 s：s 每次迭代均匀采样，使学生在 4 个时间步上都得到训练，也让“第 s 步的输入”恰好来自学生自己前面几步的输出——这就是 DMD2 的 backward simulation； Self Forcing §3–5、Tab. 2 LongLive / Rolling Forcing / Self-Forcing++ 原文
  • 只对当前 chunk：历史 KV 由 no_grad 的 t = 0 前向写入，梯度不跨 chunk。

三者合起来，一次迭代的反传开销约等于“7 个 chunk 各做一次单步前向”的计算图（推算）。代价是不能学习跨 chunk 的长程依赖，论文把它列为局限，并提议未来用循环结构（如状态空间模型）论文 §5。

3.5 滚动 KV cache 与外推

训练只见过 5 秒（21 个 latent 帧）。推理时用固定大小的滚动缓存外推：满了就逐出最旧的 KV。关键坑是 Wan VAE 的第一个 latent 帧（不做时间压缩）统计上与其他帧不同，训练中模型总能看到它，缓存一旦把它逐出画面就闪烁；修正办法是训练时让最后一个 chunk 的注意力看不到第一个 chunk论文 §3.4、附录 B。10 秒视频上，每次平移都重算 KV 只有 4.6 FPS，滚动缓存 + 该技巧为 16.1 FPS论文 §4。即便如此，远超训练长度的视频质量仍会下降论文 §5。

3.6 从图像到视频：把 DMD2 的 backward simulation 推广到时间维

DMD2 训练多步生成器时遇到过同样的问题：如果第 k 步的训练输入是“给真实图像加噪”，而推理时第 k 步的输入是“生成器自己前几步的输出”，训练与推理就不一致。它的解法是 backward simulation——训练时先让生成器自己从噪声跑几步，产生中间输入DMD2 §4.5。这是步数维度上的“self forcing”。

搬到因果视频，“输入”多了一个维度：当前 chunk 还以历史 chunk 为条件。CausVid 的代码里其实有 backward simulation 的开关，但视频版配置把它关掉了（backward_simulation: false），历史仍用带噪真值。Self Forcing 做的事可以看成把 backward simulation 同时推广到步数与时间两个维度，并处理随之而来的三个新问题：

图像（DMD2）时成立的假设

  • 模拟几步去噪的成本可以接受，整条链都能留梯度或只留最后一步；
  • 生成器输入只有 xₜ，不存在“条件从哪来”；
  • 损失对单张图计算即可；
  • 推理长度 = 训练长度。

视频里失效后的改动

  • 7 个 chunk × 4 步无法全程反传 → 随机退出步 + 只留一步梯度 + KV 截断； Self Forcing §3–5、Tab. 2 LongLive / Rolling Forcing / Self-Forcing++ 原文
  • 条件就是 KV cache：训练时用推理同款的缓存路径（无特殊掩码，FlashAttention-3）；
  • 损失必须对整段视频计算，才能覆盖“以自生成历史为条件”的分布；
  • 要外推到更长 → 滚动 KV cache + 训练时屏蔽首个 chunk。

没有变的是“非对称”：评委仍是双向教师（这里升级为 14B）。Causal Forcing 后来指出，这条流水线里真正有问题的环节不在 DMD，而在它沿用自 CausVid 的 ODE 初始化。 Self Forcing §3–5、Tab. 2 LongLive / Rolling Forcing / Self-Forcing++ 原文

5. 训练目标

记 \(\hat x^{1:N}=\mathrm{Rollout}_\theta(\epsilon^{1:N},c)\) 为带 KV cache 的自回归展开（第 i 块以 \(\hat x^{\lt i}\) 为条件），\(q_t\) 为前向加噪。整段视频的目标论文 §3.3：

$$\mathcal L_\text{SF}(\theta)=\mathbb E_{t}\;D\big(p_{\theta,t}(x^{1:N})\,\big\|\,p_{\text{data},t}(x^{1:N})\big),\qquad p_{\theta}(x^{1:N})=\prod_{i=1}^{N}p_\theta\big(x^{i}\mid \hat x^{\lt i}\big)$$

D 取反向 KL（DMD）时，梯度为

$$\nabla_\theta\mathcal L_\text{DMD}\approx-\mathbb E_{t,\epsilon}\Big[\big(s_\text{real}(\hat x^{1:N}_t,t)-s_\text{fake}(\hat x^{1:N}_t,t)\big)\,\frac{\partial \hat x^{1:N}}{\partial\theta}\Big],$$

其中 \(\partial \hat x^{i}/\partial\theta\) 只经过第 i 块第 s 步的那一次前向（随机梯度截断），且 \(\partial \hat x^{i}/\partial \hat x^{\lt i}\) 被置零（KV 截断）。SiD 把 D 换成 Fisher 散度 \(\mathbb E\lVert\nabla\log p_{\theta,t}-\nabla\log p_{\text{data},t}\rVert^2\)；GAN 版用相对论配对损失加近似 R1/R2 正则，按 APT 的做法用有限差分近似论文 §3.3、附录 A。

6. 伪代码

self_forcing.py（依据论文 Alg. 1 与 pipeline/self_forcing_training.py，简化）
STEPS = [1000, 750, 500, 250]                     # 代码中再按 shift=5 映射

def rollout(G, noise, c):                         # noise: [B, 21, 16, 60, 104]
    kv = init_kv_cache(frames=21)                 # 训练时也用 KV cache
    s = randint(0, len(STEPS))                    # 本次迭代的退出步，各 chunk 共用
    outs = []
    for eps in noise.split(3, dim=1):             # chunk-wise：每块 3 个 latent 帧
        x = eps
        for j, t in enumerate(STEPS):
            if j < s:
                with no_grad():                   # 退出前：无梯度去噪
                    x0 = G(x, t, c, kv)           # 只读历史 KV
                    x = add_noise(x0, randn_like(x0), STEPS[j + 1])
            else:
                x0 = G(x, t, c, kv)               # 唯一保留计算图的前向
                break
        outs.append(x0)
        with no_grad():
            G(x0.detach(), 0, c, kv, write=True)  # t=0 写入干净 KV；梯度不跨 chunk
    return cat(outs, dim=1)

for it in range(600):                             # README：600 次迭代
    c = sample_prompts(64)                        # 只需要 prompt
    if it % 5 == 0:                               # 生成器 : critic = 1 : 5
        video = rollout(G, randn(B, 21, 16, 60, 104), c)
        loss_G = dmd_loss(video, real=wan_14b, fake=critic, cfg=3.0)   # 整段视频一个损失
        loss_G.backward(); opt_G.step(); ema.update(G, 0.99)
    with no_grad():
        video = rollout(G, randn(B, 21, 16, 60, 104), c)
    loss_c = denoise_loss(critic, video, c)       # critic 学“学生分布”的 score
    loss_c.backward(); opt_c.step()

9. 承上启下

Self Forcing 解决了

  • CausVid 训练 / 推理历史不一致的暴露偏差：训练即自回归展开；
  • 展开带来的显存问题：随机退出步 + KV 截断，训练成本与 TF / DF 相当；
  • 流式推理的外推：滚动 KV cache 与首帧屏蔽技巧。

Q23Teacher Forcing、Diffusion Forcing 与 Self Forcing 在训练时给模型的“历史帧”分别是什么？为什么前两者蒸馏成少步模型后更容易误差累积？

TF 给干净的真实历史，DF 给每帧独立加噪的真实历史，Self Forcing 给模型自己（带 KV cache）刚生成的历史。推理时历史一定是模型自己的输出，带着它特有的瑕疵；TF / DF 训练时从未见过这种输入，于是一旦某帧出错，后续帧处在训练分布之外，错误被放大并逐帧传递（暴露偏差）。少步模型每步“修正”的余地更小，这种偏差更难被后续去噪抹平。

  • 数据：4 步 DMD 下 chunk-wise TF / DF / SF 为 82.32 / 82.76 / 84.31；frame-wise 为 78.12 / 80.56 / 84.26——自回归次数越多（frame-wise），差距越大。 Self Forcing §3–5、Tab. 2、Alg. 1
  • Self Forcing 还把损失放在整段视频上：联合分布按链式法则包含了每个“以自生成历史为条件”的条件分布，逐帧损失做不到这一点。
  • 与 LLM 的 scheduled sampling 思路相同，但这里不需要真值对齐：分布匹配损失只看整段输出是否像真实视频。

依据：Self Forcing §1、§3.2–3.3、Tab. 2。

Q24Self Forcing 训练时要串行展开整段视频，它靠哪些设计把显存和时间压到与 TF / DF 相当？各自牺牲了什么？

三处设计：① 随机梯度截断——每个 chunk 只在随机退出步 s 那一次前向留梯度，之前的去噪在 no_grad 下完成，显存约等于每块一次单步前向；② KV cache 截断——历史由 no_grad 的 t = 0 前向写入，梯度不跨 chunk；③ 推理同款的注意力路径——chunk 内 token 并行、无需特殊掩码，可用 FlashAttention-3。实测每次迭代耗时与 TF / DF 相当，DMD 版约 1.5 小时（64 张 H100）收敛。 Self Forcing §3–5、Tab. 2、Alg. 1

  • 牺牲①：每次迭代只训练一个时间步（靠随机 s 在期望上覆盖全部 4 步）。 Self Forcing §3–5、Tab. 2、Alg. 1
  • 牺牲②：学不到“为了后续帧而调整当前帧”的长程依赖，论文列为局限。
  • s 随机还带来一个好处：第 s 步的输入正是学生自己前几步的输出——这就是 DMD2 的 backward simulation。

依据：Self Forcing §3.2、§4、§5、Alg. 1；官方代码 pipeline/self_forcing_training.py；DMD2 §4.5。
