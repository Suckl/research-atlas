少步生成：扩散 / 流模型蒸馏，从图像到视频

轨迹蒸馏 · 一致性与流映射 · 对抗蒸馏 · 分布匹配（DMD）· 表征空间匹配与漂移（时间线 2020 → 2026-10）

这条路线在讲什么

扩散 / 流模型要几十次网络前向才能出一张图或一段视频。这条路线按监督信号从哪来把少步方法分成五个范式：沿教师 ODE 轨迹回归（Progressive Distillation、Rectified Flow）、轨迹上的自洽（Consistency Models → LCM → sCM → MeanFlow）、对抗（ADD / LADD / SDXL-Lightning）、分布匹配（DMD → DMD2）、表征空间匹配与漂移（Drifting → RDM）；再逐一追踪每个范式搬到视频时哪条假设失效、改了什么（VideoLCM / T2V-Turbo、rCM、Seaweed-APT / APT2、CausVid → Self Forcing → Causal Forcing、ViRDM）。每页末尾附两道简答题，共 34 题。

一句话看迁移 图像方法搬到视频，坏掉的通常不是损失函数本身，而是它默认的三件事：显存（3D 潜变量让 JVP、多步展开、解码器反传都变得昂贵）、数据（视频数据少且画质差，逼得方法要么用奖励、要么干脆对抗真实数据），以及因果性（流式生成要求块因果学生，于是出现双向教师与因果学生的错配、训练用真值历史而推理用自生成历史的暴露偏差）。

贯穿路线的几条线索

线索 1

监督从“轨迹”走向“分布”

先回归教师 ODE 的端点（需要大量教师求解），再要求轨迹上自洽（只需相邻两点），再到只要求学生的样本分布对：反向 KL（DMD）、判别器（ADD / APT）、特征核（Drifting / RDM）。每一步都在减少对教师采样的依赖，代价是多出 fake score、判别器或编码器。

线索 2

回归只会得到条件期望

独立配对做一步回归只能学到均值，所以要用确定性的 ODE 配对（蒸馏、reflow）。同一个问题在因果视频里又出现了一次：双向教师的 ODE 配对对只看过去的学生不是函数，Causal Forcing 因此改用自回归教师。

线索 3

训练时就用推理时的输入

DMD2 的 backward simulation 让多步学生在训练时吃自己前几步的输出；Self Forcing 把它推广到时间维（训练时自回归展开、用 KV cache）；APT2 的 student forcing、ViRDM 的随机干净退出都是同一思路。

线索 4

前向散度与反向散度互补

一致性类目标接近前向散度，覆盖模式、多样性好但细节易错；DMD 是反向 KL，锐利但会挑模式。rCM 把两者加在一起：一致性管多样性，分数正则管细节。

线索 5

教师从必需变成可选

MeanFlow、Drifting 从零训练就能一步生成；Seaweed-APT 的最后阶段只对抗真实数据；ViRDM 去掉了 DMD 式后训练所需的大教师与 critic。“蒸馏”逐渐变成“少步生成”。
